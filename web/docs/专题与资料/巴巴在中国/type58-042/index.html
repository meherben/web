分享人：毫末儿，于2019.10.15

三、磨砺

我和爱人12岁就认识了。第一次看到那会儿，他很害羞，那张可爱俊秀的脸和他的名字吸引了我。他天性善良，内心纯洁，没有什么欲望，不怎么努力但很有福气。不知道为什么公公给他取名海法，也许是想着办法像海水一样多吧。

我看到他的第一眼时心生一种怜爱。他后来一直顽固地要和我在一起，没放弃过，也没爱过别人。但在性格和认知上的差异以及我严重的我执，导致了20多年来冲突不断。我潜意识里要寻到一个完美的人去爱，有各种标准，极度隐忍中内心感到折磨，精神上痛苦，总想改变对方也互相很多伤害，但从没能分开过。

很多事情和人我都能做到平和淡然，唯有他最是让我拿不起也放不下爱不了也离不开的人。相互都觉得情投意不合，爱其心而恶其言行。但从各种角度，我不喜破碎，执著于圆满和完整，因此常常感受到活不下去但又不能去死的内心绝境。我甚至告诉弟弟和朋友，我死以后一定要烧一个离婚证给我，我想通过这个方式今生了结掉这个缘。

遇到巴巴后，我做过几个清晰的梦，现在联想到似乎和他从野兽或野人时就遇见了。有一次梦见一只狮虎样的动物，来到院子里，我和父亲搜寻，在一个方形院墙里它安静地蹲坐着，父亲举起剑的那刻，我心生怜爱，说，留下它吧。我内心觉得那只虎就是他。同样，他应该也用生命救过我，否则为何无论怎样我事后想起他就心疼，也做不到决绝。我还有一次做了一个清晰的梦，梦见和他在黑暗的野人时代砍柴。

也许这些梦的确有所意义吧。如果这些梦是一种启示，那他的说法也许是真的，他说他出生时婆婆做了一个梦，一颗星从天空滑落，她捧着双手去接，但这颗星落到了地上的猪食槽，他难道是神安排的来磨掉我的业力？我难道就是那个猪食槽？按照一些标准，我觉得他本性里比我更接近一个求道者和修行人，此生的主要任务就是破掉我的情执和愚痴。

我女儿2002年10月7日出生，取名豪默。

她天生目光犀利，头脑比我清醒。小的时候常说一些我不好回复的话，比如问过我几次：为什么我感到这个世界的主题就是我，我是这个世界的中心？我不理解她的感觉，想她难道是能感到万物一体吗？她说，我看到身边经过的每一个人的脸，带着他们的过去。她的肋骨下有一块胎记，她说，难道我上辈子是被别人杀死的吗？很小时打开袜子里看到恰是希望得到的圣诞礼物，问：爸爸，上帝是你的朋友吗？

初中以后，她一反小时候的乖巧，总想各种相反的尝试。有一天听到她给同学打电话说：我和你说，我妈妈现在爱上了一个人，叫美赫巴巴。

找到巴巴之前，父亲的去世是个巨大的震动，而外公像一位我们生命中的天使，从祖母开始他就守护我们这条线的苦难，他是神安排的在我年少时引领我，让我能体验和给我最接近上帝之爱的那个人。与爱人的相爱相杀，就像埋在蚌壳中的沙砾，让我时刻感受疼痛而提醒我不要忘了去磨那颗珍珠。

遇到巴巴后，回过来看这些生活布景和磨难，不再觉得是巧合和偶然，祂总是用两手，一边护佑一边开刀，不断提示让我今生能提出和去寻找那些问题的答案。这一度心中装满的深情、痛苦、孤独和悲伤，使我内心充满了对遇见完美之爱和完美之人的渴望。

四、神的线索

2009年11月，我去呼和浩特，信爱基督的舅舅走在路上和我说：不是神找到你，是你找到祂，因为祂一直就在那里。**很多设备有说明书，而《圣经》是人和这个世界的说明书。**所以，神在《圣经》开篇就首先说了：起初，神创造天地。这样一来，很多无解的问题就有答案了。

从2006年看了《西藏生死书》之后，到2017年，我一边在现实中浮沉，一边买了一些佛教类的书。从《图解佛教》开始陆续读一点，感觉佛法太浩瀚了，无法深入。

2014年，我遇见了伟，她刚看完《西藏生死书》。我们说起共同认识的某个人，是他因工作安排伟来找我。伟说：这个人在我生命中出现的唯一意义就是告诉我有这么一本书，还有就是让我遇见你。我开玩笑说：你出现在我生命中的意义现在还不明了。有一天，她发给我一张图片，上面有宗萨钦哲仁波切的一段话，我们开始读他的书，然后讨论。看他的第一本书是《正见》，我们认为他很睿智，对佛法的阐释简洁明了。我自从知道了“出离”这个词，就不断地遇事时用“诸漏皆苦”这句练习出离，但我理解不了佛陀的智慧，苦、无常、寂灭这些词让我联系现实生活时感到悲观。

《乔布斯传》里提到《一个瑜伽行者的自传》，通过这本书我了解到瑜伽和不同类型的圣人，这个世界存在着神通和神秘学，最重要的是第一次知道阿瓦塔。书中描述了通过瑜伽修习和冥想能产生合一的宇宙意识——这也打破了我之前在传统习俗和信仰里对神灵形象的想像。在论述科学的一章，书里引用了19世纪一位物理学家《神秘宇宙》中的一句话，印象很深刻：知识的潮流朝向真理发展，宇宙已经开始看起来像一个巨大的思想，而不是一个巨大的机器。我后来常常想到这句话：**宇宙是个巨大的思想。**还有一章提到：“上帝创造的每一个灵魂都被赋予不同的个性。不论他在暂时的角色中是中流砥柱还是寄生虫，都是宇宙组织内不可或缺的一部分”。我受到鼓舞，想去寻找上帝。根据书里提示，我读了《薄伽梵歌》和《瑜伽经》。感觉《薄伽梵歌》真正伟大。

有一天，在一个公众号看到了一句话：神是人类的集体意识，显化在每个人的内在。出自《与神对话》。那本书不像是一个常人能凭空想出来的语言。看来神的确是无所不在，能来到人中间，用这样的媒介和人对话。

伟开始听读《金刚经》的时候和我讨论，我理解不好，她给我讲解了很多。她喜爱佛陀。她说被阿弥陀佛一遍一遍地讲感动哭了。我们一致认为，如果某一世我们曾经是师兄弟同修的话，一定是分科的，我习瑜伽她修佛法。她理工科头脑，亲缘简单，当时仍单身，我则相反。她是我唯一感到曾经没有尘世业力纠葛而相遇的人，我们一致认为，我此生要破除愚痴和我执，她要破除嗔怒和我执。我有一天录了一段蚂蚁筑巢的视频发给她，留言“看蚂蚁想上帝”——就是那时的写照。尝试打坐、冥想和抄经一段时间后，伟觉得必须要去寻个师傅，渴望有一天能够出家去修行。我甚至去买了一套《佛教十三经》，放在一个金刚铃下面供奉着，即使不读也想摆在那。

就是这样，很多书籍和信息都随着伟的出现而集中出现了，有一点很确定：**所有的圣典都在讲一个终极真理：这个世界由神创造和主宰，每个灵魂最终都要回归到神的家园，与神合一。**但当这些一知半解的信息出现的越多，头脑里冒出的问题就越多，困惑成堆时我们就说，既然神存在，那祂当初弄出这么一大摊子是为了什么呢?

上帝或者说神，看来必然是存在了，耶稣基督来过，佛陀是最伟大的成就者，可是，怎样找到神呢？很多人通过冥想、修行能到不同的境界，而且教义里面说，求道者必须要找到一位在世上师，古鲁，信爱并跟随他，得到印启或者说加持才可最终走向道路。金刚经里说“信解受持”，哪里有能使人信服的活着的大师呢?

回过来看，这些线索，像神在我脚下不同时间摆放的一个个台阶或者识字卡片，最终让我一步步循着问题走向祂。美赫巴巴中文网站和朝圣者客栈那么早就在了，但我却从未听说过只言片语。只有你准备好了，祂才会出现。而这种准备，要靠祂的恩典。
