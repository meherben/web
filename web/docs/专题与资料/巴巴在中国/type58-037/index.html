光阴似箭，不觉间我已进入古稀之年。犹记得小时候，跟着妈妈去庙里上香的光景，那个时候，怎么也没有想到，后来长大后我结了佛缘，并一路下来，最终遇到生命中给予我无限珍宝的大师美赫巴巴。

1980年代，在我30多岁的时候，我第一次有意识地跟邻居去当地的寺庙上香，开始接触佛教。那个时候谈不上什么知识上的理解，就是烧烧香，拜拜佛。不过，我经常心理纳闷“为什么要拜佛?拜佛究竟为什么?就是为了身体好，为了发财?”，我想，就放几个水果等贡品放在那，就向佛菩萨要求这个那个，不可能的。我刨根问底地问别人，别人也讲不出来，解释不明白。为此我也看过一些相关的书，但是感觉看不太明白，可能是我太笨了。我一边接触着佛教，一边内心充满着各种疑问，看到很多的形式主义和教规，进步很慢。直到后来，我听一位老居士说，有一位叫净空法师的老和尚，讲的挺好，于是我就借老居士的光盘去看去听，感觉确实不错，当宝贝一样。听了他讲的，我很多东西才开始一点点真正的明白，净空法师是我的启蒙老师之一。不过那时虽然理性上明白了一点点，但是并没有做到。学佛的时候，建设过居士林，也跑了很多寺院，四大名山都去过，最后一个去的是峨眉山。在去峨眉山的时候，有一天我寻找打开水的地方，遇到一个住茅棚的老和尚，我向老和尚行礼问路，这个老和尚给我帮忙之后，对我说“你在家专心念佛，以后会有人去找你的”。这个老和尚的话，净空法师也有过类似的说法。我深深地记住老和尚的话，从峨眉山回来之后，结束了跑寺院的日子，外面基本不去了，在家念佛。

我觉得一心念阿弥陀佛很好，就一门深入念佛。不过后来，大概在2012年左右，我无意中接触了奎师那知觉的求道者。奉献者们的唱诵很吸引我，大家经常一起齐诵圣名，这是令我非常高兴和感动的，我很喜欢，感动之余还曾哭过。另外，记得第一次看到奎师那和拉妲等5个人在一条两头尖尖的船上的照片时，我感到一种很熟悉的感觉，好像在哪看过。不过，除了这两点，在接下来的四五年时间里，我并没有什么别的特别感受。每天的念诵功课，每月的爱卡达西日，甚至还有长时间的戒食，包括到上海参加奎师那知觉在中国20周年大会、在其他城市参加聚会，以及后来几次到北印度朝圣等，这些我都不太喜欢。在接触印度教这几年的时间里，我也同时有听经念佛。

2017年从印度玛雅普朝圣回国后，我就变得极度迷茫，我几年前糊里糊涂地走进奎师那知觉，现在我不知道是继续学奎师那知觉，还是回去专心念佛。我记得净空法师也说过，要一门深入。在迷茫低落之际，我来到浙江天台山国清寺挂单(注：即到佛寺、道观短期住宿参学)，心想，也许还是要一心念佛吧。让人意外的是，我在国清寺遇到了一个人，她和我是住在一个房间。听说她是从杭州来的，我就问她知不知道奎师那知觉(我知道杭州有很多)，凑巧的是，她说她接触奎师那知觉也很久了。我问她，为什么我去杭州几次参加联谊活动，从来都没见过她。她说她现在不学奎师那知觉了，学美赫巴巴了。于是，从她口中，我初步知道了巴巴。记得当时是晚上，国清寺宿舍的灯光是很昏暗的，但她当时给我看巴巴的照片，我就记在心里了，尤其是对巴巴的长头发、瘦瘦的照片印象很深刻。她还说是巴巴让她来国清寺找人的，如此看来应该就是找我，我说“不可能吧?你都不知道我的名字啊!”就这样，在我的信仰找不到归宿，走投无路的低谷中，巴巴走进了我的世界。

随后，到了8月份，我看到别人在网上发的美拉巴德的照片，我就感觉好像有点印象，然后我就问在国清寺遇到的竺澜，希望她发给我更多的美拉巴德照片来看。看了一些照片后，愈加觉得熟悉，我就想呀想，到了晚上大概9点钟的时候，突然想起来了，照片中的环境，是我20多年前，大概1995年或者1996年做过的一个梦里的场景。那个时候，我刚刚不上班。我记得梦里，我在三摩地旁边的地上坐着开会，周围有大树，还有盛开的很美的花，地是那种泥土地，不是水泥地，也没有铺别的东西。我当时起了点私心，因为那花太好看了，我想摘一朵带回家，可是有人说不能摘，然后我就暗自想，等我一会回家的时候再摘。正想到此时，台上有个人喊我名字，说让我上去领工资，一个月500块，我说我已经下岗不上班了啊，哪有工资?然后就醒了。想到这个梦，我觉得我定是和美赫巴巴有缘。(这个梦之前我一直没解开，悬在那。学习奎师那知觉后，我去北印度的印度教圣地朝圣时，想到了这个梦，动了找这个地方的念头，我想可能这个地方在印度，可是在温达文、玛雅普等地都找过，就是没找到。)

盼着盼着，终于，在2017年12月底，由竺澜带队，我们一行朝圣者的印度行出发了。我们从加尔各答入境，因为有的求道者要去奎师那的圣地，所以在北印度逗留了20多天，直到2018年1月18日才去美拉巴德。在北印度这个期间，前面我也是跟着团队去那些印度教圣地跑。在温达文，本来1月13日打算去圣山哥瓦尔丹山的，但是这座山我已经去过两趟了，可去可不去了。同时，1月12日晚上，我梦见巴巴了，在梦中，巴巴身穿粉色衣服，像是站在天上，显得满面红光，光芒四射。梦后我想，既然准备到巴巴的三摩地，还东跑西跑的去其他地方干吗呢?所以后面就没再去其他地方。我在温达文天天念巴巴的名字，只想着能早点到巴巴的三摩地。

到了美拉巴德，在去巴巴三摩地的路上，我远远地看到在梦中见过的三摩地旁边的大树，不由地兴奋地跑上前去拥抱。在美拉巴德，从1月18日到2月4日离开，总共待了17天，感受很深，我只能说的是：巴巴每天都给我很多东西，这些东西是以前在国内去佛教四大名山呀，还有去奎师那知觉的印度教圣地等，都没有得到的。以前太傲气了，觉得自己了不起，巴巴让我看到了自己的渺小。巴巴的永恒日纪念活动是在1月31日左右，2月4日刚刚结束，我们就要离开。其实我还没有待够，恋恋不舍地不想走。

第一次朝圣之后，我彻底丢掉了之前学佛和学奎师那知觉的东西，只专心学习巴巴，念记巴巴。
