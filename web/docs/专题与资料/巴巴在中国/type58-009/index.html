2006.1.1

从2005.12.18到美拉巴德，经常能感受到巴巴的关爱，比如Arti时的感动流泪和一些事情的回应，多数是一种被爱的感觉，所以有些习惯了这样的情感。但昨晚到今天却没有什么感觉，反而因为自己有一种顺理成章的期待感没有得到回应，觉得有些受巴巴的“冷落”，情绪也跟着低落。

田心说她也有过这种感觉，巴巴对人们都是这样，象一种游戏，对你忽冷忽热，消除你没有意识到的自我，增强你对神爱的渴望。她这样说我心里好受多了，其实是自己对巴巴的信任还不够深。

1.2

今天去了舍地的赛巴巴那里，人很多，在三摩地旁无法跪拜，里面的门徒见到我，隔着栅栏递给我一朵玫瑰，我感动得想哭，之前有些后悔没有买束花，可赛巴巴不但没有索取，反而给予，接着那个门徒又递给我两大束。出来看到商店里有赛巴巴的像，眼神非常美，非常慈悲，就买了一个，回到车上又流了些泪。

然后又去不远的乌帕斯尼.马哈拉吉的埃舍，这里很清净，女门徒一直在念诵和举行一种仪式。田心在这里很有感觉，有一种全身微微的震动感，我没有什么感觉。在跪拜三摩地时，我看到供着赛巴巴的像，还以为是专为赛巴巴虚设的三摩地，就虔诚地跪拜赛巴巴，心想终于有机会向他跪拜了，头碰地时心里有一种感动，后来才知道这就是乌帕斯尼的三摩地。Arti完了以后，我想美赫巴巴那里有Prasad，这里没有。过了一会儿在椅子上休息时，一个印度老头走过来坐在我身边，也不说话，递给我一块椰子肉就走了，第一次吃新鲜的椰子肉，感觉非常非常香。我想这是完美大师给我的回应。

赛巴巴

1.3

晚上去彼夫那里，看了他拍摄的第五层面玛司特穆罕默德生前的录像，Erico和另一个女人给他洗澡，非常耐心。穆罕默德很老了，腰弯得厉害，据说他是暴躁型的玛司特，但录像里像个小孩子，很温和，他的眼睛看镜头时非常亮，我丹田会有较强的气感，据说他还有三世才成道。

穆罕默德

1.4

上午去一个美国人家，看他怎样种树，这里山上的土壤贫瘠，表层土下面都是红色的碎石。他先在塑料袋里育苗，树苗长大后再由小袋移植到大袋，移三次，最后再栽种到山上，很聪明的办法。他说水是大问题，有两年都是大旱，雨季也没有下雨，这里旱季的草都是枯黄的。

晚上Arti的路上碰到詹姆斯，他说他在三到六月份还在这里，每当天太热，他念巴巴的名就凉快了。到了三摩地我很饿，突然受詹姆斯的启发念巴巴的名，刚念两遍，本来强烈的饥饿感就消失了，然后就不断地念，不念时就又感到饥饿。

Arti完了去吉奥家，他给我调了很好喝的柠檬苏打盐水，临走他对我说让我点燃这次的度内圣火，我真是受宠若惊。

1.5

今天去美拉扎德，爬了巴巴的闭关山，捡了几块水晶石，不过好的都被捡走了。下来在巴巴的房间静坐，有丹田的气感，不舍得离开。

下午跟田心聊天，她以前不太了解中国的现状，比如下岗失业。我一直工作不安定，而田和家人一直是传统的安定型。感觉现在的我有点象巴巴的新生活，无助而无望。

晚上Arti，在巴巴的窗外突然觉得很委屈，哭了一会儿。上午在Trust的书店付了买书的5000卢布，上次选好书后没有带够钱。回来后发现其中两本没有贴价签的书占了一半的钱，这两本书在美国出版，是巴巴的爱者写的，选书时我以为《上帝的礼物》是巴巴写的，所以跟田心说想退了，省点钱，因为回国后我就没有多少钱了，还要过年回家和付房租等等，田心说我以后应该安定些。这两年为了求道我确实有些不负责任，没有好好挣钱，但是现在要想诚实地挣大钱真是难。

1.6

上午田心回家，我也要搬到D区，一直以来她对我照顾得很周到，以后要一个人了。也好，有更多时间想巴巴。

今天搬到D区，感觉很新鲜，一切都更简朴，包括饭食。不过便宜得不好意思，吃住每天共70卢布，合14元人民币，还有早茶和下午茶，这里主要是照顾印度人才这么便宜。巴巴又为我省钱了。

中午吃完饭劳拉想让我陪她画画，我就在草地上睡了一觉，很舒服，直到4点，被苍蝇叫醒。洗完衣服去三摩地，看了一会儿《神曰》，然后一直坐到Arti结束。时时感到巴巴的爱，尤其是听歌时。今晚有人过生日，买了生日蛋糕做为Prasad，我没吃到，专心念巴巴的名，拒绝了食物的诱惑。以前有好吃的点心，田心总是碰巧能领到，然后分给我吃，她一走，我就没得吃了。晚餐碰到萨拉和迈克，聊得开心，感觉英语有所提高。

1.7

吃完早饭去三摩地静坐，突然有领悟：最终的和最重要的仅仅是爱。然后感到从巴巴的墓里流涌出一股“爱的潮流”，脑袋发麻，并有一阵耳鸣。心里平静和释然了很多，就不太执著于静坐念巴巴的名，但清楚念巴巴名时能得到指导。走出三摩地，Theos建议我去图书室看看，我正好看到《无限智慧》，巴巴写到从无限无知到无限知需要一个无限想象与错误创造的过程，所以现在的经历是必须的游戏，并提到最高的巴克提瑜伽时服从完美大师。

上午一直容易记得巴巴的名，但下午心情突然低落，晚上看了乌帕斯尼的电影，情绪还是不好，晚上没有去Arti，很早就睡了，怀疑巴巴的头脑又来了，晚上又做恶梦。

1.8

早上没有去参加Arti，上午看了一会儿《上帝的礼物》，很感人，作者的工作经历和我有点象，并提到服从。从昨天的经历我明白，尽管心是爱巴巴的，但记得随时臣服巴巴却很难。自己根本不知道还有潜藏的一股反对信任巴巴的力量在，有些身不由己。

在太阳下看了一会儿书，就想去巴巴闭关的小蓝屋看，里面却在清扫，于是去满德里大厅看巴巴的照片。出来正好碰到Erico，他看我情绪不高，从路边摘了一朵小野菊花给我，说巴巴虽然喜欢庭院的玫瑰，但更喜欢野花。我很感动，和那些生活环境优越的西方爱者比起来，我确实是野花，但我又觉得没有野花的坚强，有时还会自卑。

1.9

早上Arti，想起巴巴帮我解决了与一个朋友的过节，很感动，只有巴巴有能力帮助我。（昨晚吃饭时，受劳拉的启发，我想回国以后给一个很久以来有过节的女朋友几个Prasad，与巴巴结缘，这是我能想到的对她最好的方法，刚想到这儿，马上感到一股热流从丹田升起，催我含泪，我想巴巴在帮助我了）

上午写了会儿日记，就去三摩地。静坐时感到想亲见巴巴的欲望太强、太心急，然后去学习室看书。Theos说如果我累了可以在巴巴坐过的长沙发上休息甚至打盹儿，他出去后，只剩下我一个人，我躺下来，放松时突然意识到巴巴想告诉我要平衡，弦不要太紧，欲速则不达，接受神性需要时间。

下午看书时，《上帝的礼物》里正好提到这一点。让我感动的还有，作者提到巴巴让她辞去教师工作，因为这个工作对于她压力太大了。我认为只有巴巴能理解我，我周围的人都认为我辞去教师工作是逃避责任。只有巴巴知道什么对我们最好，他最希望的是我们更接近神性，而不是一味承担与服从。

晚上我的心情又有些不好，也许因为今天正好来了例假，我想这全是我的自我，深处的坏东西出来了。吃饭时遇到迈克，我说有点sad，他说这是巴巴对我做的工作，高兴时要想“巴巴让我高兴”，不高兴时要想“巴巴让我不高兴”，不要认为是自己的错，因为没有什么对错，怎么能证明你是错的呢？谁在意你的错误呢？我自己也想到：高兴时我自认为是个好人，比别人做得都好，而事实上没有什么好与更好，所以碰到一些事情就发现自己并没有想象的那么好，于是就又认为自己不好甚至坏。奥修对这个问题倒是说得很清楚，以前看他的书没有白看，能让我想起一些道理，他说如果越高就会越低。我又对迈克提起点度内火的事情，我感觉有点压力。他说不需要把重担放在自己肩上，巴巴会自然地做他的工作。这样说让我又轻松了很多，这个道理早就知道，可遇到具体事情还是犯同样的毛病，妄想分担巴巴的工作。他对我们每个人只有给予，没有索取，他什么都不缺，且有无限能力，他让我们臣服并不是为了取悦于他，而是让我们准备好接受他的神圣礼物。有了这个大靠山，还要担心什么呢？哈哈哈！
