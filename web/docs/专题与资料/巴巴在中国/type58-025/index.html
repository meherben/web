26日一早，我提前踏上前往美赫巴巴三摩地的旅程，本来打算最后一天再去，当天返回。感到巴巴在召唤。。。一大早司机很准时的到来，包了一辆不错的小汽车，本来飞机上说几个同伴跟我一起去，结果最后都不去，只有我自己一个人，带着些许郁闷的心情，开往了美拉巴德－美赫巴巴的三摩地，一路上，感觉还是荒凉，路上看到上学的印度学生，不少前面写了圣人名字的卡车，还有满满的公交汽车，一些繁忙的小乡镇，黑黑的印度人，印象感觉比较贫穷落后。。。

一路上路况还算不错，经过两三个市集，过了一个半小时，看到一些很美的风车，很漂亮，在一片很空旷的平原上。再过了半个多小时，司机靠边，说已经到了。啊？比较惊讶，原来以为需要三个小时以上，怎么就到了？带着怀疑和犹豫下车了。。。

往里走到一个拱形建筑，一下就给雷到了，很不可思议的事情发生了，头突然感觉到一种很大的疼痛，但是很清凉，一股强大的能量往下压，不知道怎么去形容这种感觉，你头很痛，但是很享受很喜欢。人会变得很安静，很清晰。进去以后，有两个西方人接待了我，其中那个年纪大的人非常热情，询问我是否订了房间。我说着不是很好的英文，说我还没有决定是不是留下，想先去看看三摩地。她热情的向我指明三摩地的方向，于是我朝那边走过去。越过了一条公路和一条铁路，前面出现一条两边有白色石头引路的山路，路两边长满了大树。一踏上这条小路，刚才在拱形建筑的那种感觉再次袭来，甚至更强烈，像是踏入了一个不属于尘世的世界，眼泪几乎夺眶而出。怀着一种崇敬而感动的心情，继续向前走，走了一会儿，看到了巴巴的三摩地。因为快到中午了，人很少，周围很安静。在三摩地的凉棚外脱了鞋，放下背包，我进入三摩地朝拜。一进去感到很清凉，并闻到一种奇妙的香气。想在里面静坐一会儿，但是因为三摩地很小，已经坐满了人，没有地方，于是静静的退出来，坐在外面的木凳上。等了一会儿，走了两个人，我就进去静坐。在里面静坐感觉很好，自己的节奏整个慢了下来，那股香气仿佛穿透了身体最深层的地方，眼泪开始涌出来，慢慢地感觉越来越强烈，像个小孩儿一样哭泣起来，而且丝毫没有羞愧感，只觉得在这里彻底放松，彻底被接受。过了好一会儿，整个人变得很清爽，很干净，很沉静了。心里已经决定在这里多呆两天。带着喜悦的眼泪走出三摩地，有位慈祥的老太太递给我两颗糖果作为presad，即神的礼物。顶礼了美婼、玛妮等人的墓，然后下山跟司机说两天后再来接我，又来到接待处，请他们给我安排住宿，刚才为我指路的人说：“我就知道你会留下来的。’

她们帮我叫了一辆三轮车，上车后司机朝另一个方向驶去，我有点蒙了，心想怎么住的地方离三摩地这么远呢？三轮车在乡间柏油路上走了有二十分钟，路上我有些着急，这要去巴巴的三摩地也太远了吧！因为我就想离巴巴三摩地近点，好回去静坐。

三轮车来到一个很宏伟的建筑，风格和印度建筑截然不同，感觉很舒服。一进去我就感觉很踏实了，那种头疼但清凉的感觉又回来了。一个满面红光的美国人接待了我，他非常热情，我用很破烂的英文问他，是不是回巴巴三摩地也要走那么远，他非常有耐心的向我解释，说有一条小路可以直通三摩地，说了一大通，看我听不太懂，就给我看一张地图，我一下子就明白了，原来三轮车为了走柏油路带我绕了一大圈！而这个朝圣中心可以不用经过刚才的铁路和马路，走路十分钟左右就能直接到达三摩地，这让我觉得棒极了，也放心了。拿着他给我的钥匙，沿着高高长长的走廊，我找到了自己的房间。房间很简洁，一张铁床，一张书桌，一张椅子，一盏台灯，简朴而干净，墙上挂了两幅巴巴的照片。没有奢华的东西，但是觉得所有需求都被满足了。放下背包，四处溜达了一下，发现这是一个三层的大建筑群，分成男女两个区域，这里是禁止性爱的。走廊边上有一些纯净水处理器，可以随时饮用。因为不是旺季，住的人不多，整个大院很安静。我走到走廊尽头的读书室，在里面可以自由阅读有关巴巴的书籍。上到二楼，发现这座建筑位于山顶，周围一望无际。虽然现在印度天气很热，但是走廊上没有一丝炎热的感觉，坐在走廊的椅子上，很清凉，很静心，很享受，很舒服。

然后去吃午饭，餐厅好大呀，墙上画满了大幅的壁画，描述着巴巴的感人故事。看着这些画，想起这些故事，你会感受到巴巴爱的散发、流淌。。。午休后，从朝圣者中心往巴巴三摩地走，太阳很热烈，但是感受很好，因为一路上不用经过马路和铁路，让人觉得比起原来的旧中心，没有断裂感，而是在同一个场的保护中行走，也了解了建造者选址的用心，这样朝圣者在这个场中不必受外界打扰。

第二天很幸运，有去巴巴故居美拉扎德的活动。我参观了巴巴的房间，美婼和玛妮的房间，蓝车，满德里大厅，闭关小屋等。巴巴的房间非常凉快，顶礼巴巴的脚垫时，第三只眼非常胀疼，坐在巴巴的床对面的沙发上，都不想走。美婼和玛妮的房间清静整洁，有一种纯洁的氛围。坐在满德里大厅的地垫上，感觉能量很强，很肃穆，能感觉到这是经常举行重要会议的地方，让人很觉知、警醒。参观的时间不长，走的时候恋恋不舍，还想多坐会儿。

这一天的午餐和晚餐时，跟巴巴爱者们交流了很多。他们大多是美国人，感觉像是进了好莱坞。他们都很有耐心的跟我说着英语，到第三天我离开时感觉自己的英语进步了很多，不怕跟人说话了，真是不可思议。这里的饭菜很美味，是自助餐，每次都吃得很饱。

值得一提的是在巴巴三摩地附近看朝阳和夕阳都非常美，我有幸都看到了。第三天早上我在路上碰到一个五六十岁的澳大利亚女爱者一起走去三摩地，天上还有星星，大地很清凉安静。我们没有说很多话，只是一起感受着这宁静的时刻。

到了三摩地，有些爱者在打扫巴巴的三摩地，坐在那里看着他们打扫，我就想今天就要走了，我要是能去打扫多好呀，正这样想着，一个印度的女负责人就出来叫我，让我进去帮忙，让人感到很神奇。我怀着崇敬的心情，擦拭了巴巴墓碑上的一些字‘我不是来教导，而是来唤醒’。身边早到的每个人都有机会做打扫三摩地的事情并非常的崇敬和欢喜。

快到arti的时候，我想可惜看不到日出了。正想着，和我一起来的那个爱者就来叫我去看日出，她带我去了一个很特别的地方，在七色旗前面，说只有在这里能看到日出，这里原来是巴巴闭关的一个小屋，现在已经拆掉了。这是我看过的最美丽的日出，太阳出来的时候象一个圆苹果。这个爱者也是我见过的一个非常可爱的人，我对她说是巴巴派她来叫我的，她听了象个小孩子一样，开心地手舞足蹈呵呵的笑高兴得不得了。

Arti结束后，该回去了，我围着三摩地转了一圈，心情有些恋恋不舍。转到三摩地后面时，朝圣者中心建筑师的爱人站在那里，向我打招呼，她说起巴巴的一个已经去世的女满德里Katie，临去世时对她提起见过的中国爱者，说巴巴爱着他们，会好好照顾他们的。我很感动，像是收到了巴巴对我的送别赠言。

在巴巴这里的两天，我的身心受到了极大的滋润和清理，有一种完全被接纳被包容的感觉，真不想走呀。。。依依不舍的告别了美拉巴德，我中午回到普那，回到奥修社区，整理好在社区的行囊，见到了每一个我想见到的人，处理好每一件该处理的事情，当天晚上就启程从普那往回国的路上走了。。。

梦幻般的十天，也是最实在体验最丰富的十天，难忘的印度之旅，我只知道并且确信的事情是，我还会再回来。。。
