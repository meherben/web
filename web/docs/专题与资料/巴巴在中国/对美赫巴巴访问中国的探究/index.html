**说明：**本文尝试从还原历史的角度，以《美赫主》、《完美大师》等对美赫巴巴访问中国的相关记述为依据，结合笔者在上海和南京的生活经历，以及对大师曾经去过的地点的游览追忆，尝试对其访问中国的历史进行还原（包括部分推测），仅供读者参考。（本文整理时间：2023年6月）

1932年，巴巴在中国（可能是南京太平门外，身后为白马湖和紫金山）

美赫巴巴访问中国的时间，是从1932年6月22日下午在上海登陆开始（1932年6月4日从美国出发），在上海停留了一天半之后，6月23日晚上11点乘火车前往南京，在南京待了三天后返回上海，在上海又待了一天半，于6月28日下午乘船从上海离开。7月1日上午7点，巴巴在香港停靠，分别游览了港岛和九龙，7月2日离开香港，继续返回印度的航行。

背景：

1、1931年-1937年，是美赫巴巴的世界旅行时期。1931年9月，巴巴在访问英国期间（访问中国的9个多月之前），对赫伯特·戴维说：你将跟随我，按我的直接命令在中国工作。稍后赫伯特受国际联盟邀请到中国国立中央大学（南京大学等高校的前身，旧址在今东南大学四牌楼校区）教英国文学，巴巴指示他即刻起身去中国，并指示他：“吃素食。不要抽烟喝酒。每日静心一到两个小时。业余时间同中国人交往做朋友。此外，你无论对他们做什么，都将会来自内在驱使。决不要吸鸦片。友好对待英国人和中国人。过简朴的生活。至少每两周举行一次聚会，对那些感兴趣者谈论我。不要担心，要尽职尽责。我将到中国看望你。”

2、1932年3月24日，巴巴在印度将12名门徒分为两组，让6个人去中国，6个人随巴巴去英美。赴华组的6名成员经上海前往南京，住宿由赫伯特·戴维进行安排。6名成员是古斯塔吉、弟弟佳尔、彭度、劳先生、韦希奴和鲁斯特姆。也就是说巴巴到中国时，有几名门徒已经在中国待了两个多月——除了其中两名门徒：韦希奴和劳先生，在到了中国一周之内，就被巴巴遣回印度。另外，巴巴在从美国出发前，指示鲁斯特姆于6月9日到檀香山（属于美国夏威夷州），后来在檀香山会面后，巴巴又安排鲁斯特姆去澳大利亚做灵性工作。（注：鲁斯特姆没有再回中国）

3、1932年3月到6月，巴巴从印度出发，经埃及、意大利、英国、法国、瑞士、美国做重要的灵性工作。在美国访问期间，巴巴表示，为了其灵性工作，他有必要中断在美国的访问，先去中国。他说“我想在东西方之间铺设一条完整的电缆”。美赫巴巴和弟子于6月4日乘船从洛杉矶出发，途经檀香山和日本前往中国。

4、此时的中美：巴巴访问美国期间，美国正经历1929—1933 年的经济大萧条，很多问题一团糟。而在中国上海，人们还没有完全从刚刚结束的战争中缓过神来——日军于1932.1.28在上海发动一二八事变，中日双方最终于1932.5.5签订《淞沪停战协定》。

行程：

巴巴在上海

时间段：6.22日下午2点半或3点-6.23晚上11点，6月27日上午8点-6月28日下午4点

6月22日下午2:30到3点，美赫巴巴和随从在上海登陆，巴巴身穿时尚西服，头戴巴拿马帽。从南京过来的赫伯特·戴维和弟弟佳尔前来迎接。乘车几英里，下榻黄浦江边外滩的汇中饭店（今和平饭店南楼，赫伯特给订的房间可以俯瞰黄浦江景色和外滩）。

图3：民国时期的汇中饭店（右侧六层的楼）

图4：现在的和平饭店（南楼和北楼分别位于南京东路南北两侧）

在汇中饭店用茶后，巴巴指示赫伯特：“我想出去，到华人中间走走，带我到人多的地方。”赫伯特带巴巴和满德里们沿着外滩，从法租界出发，坐无轨电车穿过英租界，来到火车北站（现上海铁路博物馆）附近被战争毁坏的地区（日军发动一二八事变造成的），但人都不够多，不合巴巴的意。于是他们乘无轨电车回来，他们看到南京路（现南京东路），灯火通明的中国商店，重庆路（现重庆北路），沿着西藏路（现西藏中路）看到赛马场（现上海人民广场）。他们穿过拥挤的街道和狭窄的小巷，街道上到处都是人，穿着长袍的职员、穿着短衣的苦力，还有大量的黄包车夫，笑脸相迎地拉客。狭窄的街道上挂满了纸灯笼和飘动着的招牌。当他们进入狭窄的小巷时，引来卑微居民的好奇注视，巴巴显得很高兴，很喜爱他们。晚饭后，赫伯特租了汽车，他们坐车沿着法租界、英租界和中国城转了一圈。（“中国城”应该指的是华界——即租界以外的上海其他地区。华界的城区主要包括闸北、以老上海县城为主的“南市”，还有当时正在新建的五角场一带的新华界中心）

图5：1930年代上海租界地图及汇中饭店在外滩的位置

第二天，一些从赫伯特那里听说巴巴的人来饭店见巴巴。赫伯特一直对东方哲学感兴趣，经常与一些有文化的中国人谈论佛教——特别是静心等问题。随后，巴巴遣赫伯特和禅吉去订回印度（或去欧洲）的票，他们跑遍了几乎所有船票代理商，在下午5点快要打烊的时候，筋疲力竭地坐黄包车回到外滩住处。当天晚上，巴巴和弟子们受到来访的中国朋友邀请，到一家餐馆赴宴用餐。他们都是第一次学用筷子吃饭，巴巴很开心。晚饭后，他们在赛马场后面散步，随后坐黄包车，并在晚上9:30左右去法租界的国泰大戏院（现国泰电影院，依然营业）看了一场电影《城中野兽》。看完电影后，他们驱车去火车站，乘晚上11点的火车前往南京。

图6：如今的国泰电影院

赶到火车站时，火车就要开出，巴巴问赫伯特还能不能赶得上，赫伯特说可以。于是他们匆匆忙忙上了车。

▶推测：巴巴的登陆地点，根据美赫巴巴旅行网，说是在浦东的某个码头登陆，然后摆渡过黄浦江，再乘汽车到外滩的汇中饭店。结合巴巴从檀香山换乘的船是日本女皇客轮来看，轮船到上海停靠的码头是日本公司经营的码头可能性最大（当时上海有很多码头，大部分是公司私营）。经查资料，日商公司当时在浦东地区有日清轮船公司的老摆渡码头（又称老白渡码头）和张家浜码头（1949年之后，统称老白渡码头，为上海煤炭装卸公司使用）。而从巴巴登陆后乘车几英里到汇中饭店的描述来看，董家渡和老码头一带到和平饭店（汇中饭店）的距离也符合这个描述。所以，巴巴登陆的地点，估计就是当时的老白渡码头。（现在主要是老白渡滨江绿地，位于上海浦东新区杨家渡渡口和塘桥渡口之间沿江的狭长地带，对岸是浦西的老码头一带）

▶推测：据说，巴巴还在上海联系了玛司特。拜访了玉佛寺，龙华塔及龙华寺，豫园。但时间不确定。据笔者推测，巴巴去的这几个地方，应该是从南京返回上海后的一天半时间里去的，因为去南京之前的一天半，时间安排的很满，而以上几个地点相互之间的距离又比较远，去的话需要花费一些时间，所以去玉佛寺、龙华寺、豫园不大可能是巴巴去南京之前去的；而巴巴联系玛司特，则既可能是在去南京之前，也可能是从南京回上海之后。

巴巴在南京

时间段：6月24日早晨7点——6月26日晚上11点

6月24日早晨7点，巴巴和弟子们抵达南京（当时的沪宁铁路火车站，是位于南京下关地区的“南京车站”，南京长江大桥建成后更名为南京西站，2012年停止客运业务，现在正在改造为南京铁路博物馆，火车站旧址在今龙江路8号）。彭度和古斯塔吉在站台迎候巴巴。一行人到距车站两英里远的赫伯特家住宿（应该是百子亭1号，见下文的推测说明）。在赫伯特的小房子里，坐满了9个人。

早饭后，赫伯特带着巴巴爬上60英尺高的古城墙（明城墙）行走，左边是玄武湖，右边是南京城区，前方是紫金山。巴巴沿湖走了很远。（从视角的描述来看，巴巴走的是鸡鸣寺附近往太平门方向的明城墙。结合笔者从网上查询、实地去三段不同的明城墙考察，以及南京爱者的共同推测，可以肯定的是，只有鸡鸣寺附近往太平门方向的城墙，符合赫伯特描述的视角。）。（注：鸡鸣寺附近的解放门，是1954年新开的城门，民国时期并没有这个城门。不过如今，从解放门登城墙倒是更方便了。另外，紧挨着鸡鸣寺，还有一段特殊的废弃段明城墙——起始位置在今江苏尼众佛学院北门对面——和主城墙相连，民国时期可以从这里登上明城墙的可能性比较大。综合来看，巴巴当时极有可能是从百子亭南边的这段废弃段明城墙或者百子亭北边的玄武门登上城墙的。）

图7：现鸡鸣寺（解放门）-太平门段明城墙

图8：现在的解放门、玄武门和玄武湖、紫金山位置示意图

南京是座宜人的城市，这让巴巴和满德里想起普纳（巴巴的故乡）。下午，来了个法国人和他们一起，开着他的车和另一辆租来的车，大家前往紫金山，并参观中山陵。道路崎岖不平，但巴巴喜爱沿途风光，像个童子军团长，兴致勃勃地带大家登山。

图9：民国时期的中山陵

晚上，大家在巴巴房间，围坐在他身边听音乐。之后，巴巴就其计划变更（不再返回美国访问，而是回印度）授述电报，让禅吉发往英美和印度。

在南京期间，有几个学生和上了年纪的中国人来见巴巴。空余时间，赫伯特带巴巴去城市中更安静的地方。但巴巴说：“不，带我去人多的地方。”在南京期间，巴巴也漫游了南京穷人区肮脏狭窄的巷子，居民们好奇地凝视他。

在巴巴访问中国（的灵性工作）将要结束的同时，赫伯特也即将暂时结束他在中国的教学任务。他希望服务巴巴，说：“如果您要我回伦敦时取道大连、满洲、西伯利亚、莫斯科和华沙，我会的。”巴巴回答：“好。那就经满洲和俄国到马赛，7月20日在那里与我会合。”

6月26日星期天，巴巴参观国立电影院，再次驱车穿过城中密集的车道小巷，路很窄，汽车几乎碰到两边的墙壁，敞开的商店摆放着数不清的手工艺品和商品。他们随后去参观了一座孔庙。巴巴当天就要离开，赫伯特送他一尊漆塑弥勒佛像。弥勒佛是中国人对未来佛的称呼。

在南京逗留三天后，巴巴乘6月26日晚上11点的火车前往上海，赫伯特的几个仆人都去火车站为巴巴和满德里们送行。

次日6月27日上午8点，巴巴一行到达上海。6月28日下午4点，他们乘S·S·恺瑟-伊-印地号轮船赴印度孟买。

巴巴从上海离开的6天后，赫伯特也启程回英国。

▶推测：赫伯特在南京的住址。根据从网上查到的赫伯特于1932.9.10写给禅吉的英文信件，以及《美赫主》记载巴巴在赫伯特家用完早餐，赫伯特带巴巴爬明城墙的描述，综合来看，其在南京的住址，基本能确定，应该就是赫伯特在1932.9.10写给禅吉信件所写的地址：No.1.Pei Sze Ting，即玄武门附近的百子亭1号（“百子亭”是一条路的名字，此处离玄武湖和明城墙很近）。此地距他工作的国立中央大学步行约20多分钟，距离当时的火车站南京车站是三四英里（五六公里）。百子亭在民国时期是文化精英和社会名流的聚居区（比如徐悲鸿、傅抱石等），现在还有部分民国时期的建筑保留下来，成为百子亭民国建筑风貌区。

▶推测：国立电影院，经查资料，当时没有叫“国立电影院”的，很可能是在南京城南夫子庙和江南贡院旁边的首都电影院（1930年开业，楼上下共设有1357个观众席，其规模在当时南京首屈一指。开业时，还在当时的《中央日报》上刊发了“首都最堂皇的剧场，东方最富丽的天国”广告语。1949年解放后曾改名为“解放电影院”。现原址改为首都大戏院电影博物馆，但笔者2022年和2023年去了两次考察，都未营业）。

▶推测：孔庙，可能是南京夫子庙（另一个南京城区的孔庙，是朝天宫）。因为夫子庙地区当时就是热闹的商业街区，而且与首都电影院距离不远（步行十分钟即可到达）。

巴巴在香港

7月1日早晨7点-7月2日（离开时间不详）

7月1日上午7点，巴巴在香港登陆，一位叫鲁斯特姆·E·迪赛的帕西人来接。巴巴和满德里到了他家，迪赛和妻子准备了印度饭菜。饭后，大家出门游览城市。晚上到皇后戏院（位于香港中环戏院里，皇后大道中31号陆海通大厦，2007年已停业）看电影《肤浅》。看过电影，巴巴和满德里回船。

翌日他们在九龙上岸。迪赛先生在香港的一位朋友，鲁斯特姆·S·佩斯同吉，把巴巴和满德里接到自己家。他们驱车游览城市一小时，接着返回恺瑟-伊-印地号轮船，继续航行。

之后，经新加坡、斯里兰卡，最终于1932年7月15日星期五，晚11点45分，巴巴和满德里在印度孟买登陆。

美赫巴巴第二次途经中国：

1935年1月，美赫巴巴结束在加拿大的访问后，返回印度途中，曾经停靠上海（1935.1.30-1.31）和香港(1935.2.2-2.3)。
