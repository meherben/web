坎坷人生

余义玲是湖北武汉人。兄妹五个人排最小，她自己说从小被父母兄长娇惯，养成了傲慢霸道的性格。在80年代就毅然辞去幼儿园老师工作，开始做服装生意。短时间内积累起了几十万现金，在那时算非常富有。她自己说几万块钱放桌上都不会看一眼，暴富也助长了傲慢，为了选哪个人做老公的问题，可以和父母闹决裂，这也是她“苦难”命运的起点。由于自己有钱，全凭个人喜好，选了一个穷老公，第一个孩子没保住，打掉了。终于怀了第二个，在她第二个儿子三四岁时，与丈夫争吵时没注意，孩子从板凳上摔下来磕到了头，送医院后越治越重，最后成了脑瘫。从此夫妻就都舍了工作，带着儿子全国跑好医院，不见好转，花销大到需要借钱度日，最惨时捡烂菜充饥。余阿姨说，当时背着脑瘫的儿子过北京的立交桥，几次都想直接跳下去一了百了。这种全心照顾持续了十几年，直到儿子22岁离世才算结束。

可她苦难的命运并没有结束，在儿子生病后，她丈夫由于长年辛苦，加上夫妻争吵不断，终于撑不住患上大病，为了不拖累就和余阿姨协议离婚。在儿子去世后没一年，丈夫也因病离世。从此至亲不再，只剩余阿姨一人，由于常借钱，很多朋友都躲远了。留下的只有丈夫名下的一套房和一点微薄的存款，丈夫的兄妹嫌弃余阿姨是外人，执意与她争房产，那时余阿姨已学佛修行，在舍弃心下把房子拱手让出去了。剩一点存款也在朋友投资赚钱的借口下被骗走了。真正的孤身一人，身无分文，是她那时的真实写照。

为了找住的地方，她拜托朋友，有个朋友看她可怜，就把自己的车库让了出来，让她住车库，一住就很多年。

修行历程

2014年的时候，我到武汉去过她的车库，密不透风没有窗，水管也没有，接水都到公厕或公共水池，车库里摆满了破烂旧物。土鳖横行，实在不是人住的地方。基于这种情况和很深的缘分，巴巴通过我在北京密云租了间房让她居住，从此安心走上生活与修行的正轨。

她的修行历程很丰富，从佛法、奎师那奉爱、到音流瑜伽等等。曾赴印度，冲破安保，抓住古鲁的手不放。就算听不懂，为了亲近音流瑜伽上师，借钱多次飞去印度道场。这些经历，使她找到了人生价值，升起了解脱的向往。在至亲都离世，心如死灰时，是奎师那的喜乐唱诵拯救了她。在2012年左右，她已身心俱疲，自嘲自己就是个修行的油子，世俗生活被摧残的一塌糊涂，心性境界上也没有半点成就。

与巴巴建立联系

2013年6月我们第一次在佛教法会上见面，因为有缘很快成了知己，也慢慢知道了她的这些情况，自然而然把美赫巴巴介绍给她。她一开始并没有信心，仍然念记自己的印度师父。自从住到北京密云后，慢慢对巴巴了解越来越深入。
2年前我让她邮购了巴巴的书籍和照片。这两年她患上病后，身体越来越不好，但反复说这都是巴巴的恩典。我原以为她一直徘徊不定，看来她在患病之后，越来越专一于巴巴（之前还需要提醒）。

后来通过朋友知道，她那时一个人在密云被疼痛折磨得满地打滚，要用棍子戳胸才止痛。肺癌基本发现即晚期，不治疗大多也就活8个月，她生生靠意志支撑了2年。这两年间她对巴巴产生了巨大的依恋，在疼痛、日渐的体力衰弱、食难下咽、艰难的喘息中，不断忏悔自己的过往，将所有的一切都视作巴巴的完美安排，我从未想到过，她的进展可以达到巴巴亲见的程度，只能说巴巴的恩典不可思议。

“我比他们都更爱你”

在她死前一个月，曾兴奋的对我说，做了一个关于巴巴的梦，在梦里她看见了所有在世和不在世的亲戚朋友师父等，然后巴巴站在另一边，指着所有这些人说，“我比他们都更爱你”。从她分享梦境时兴奋的态度，我知道她就要坚定的全身心投入巴巴怀抱了。

在离世前一星期左右，她说自己做了一个梦让我解一下，梦里看到巴巴开面馆，价格是25元一碗，到她这里巴巴说：“你免费吃吧”。她不知道这个梦什么意思，当时她早已水米不进，我从安慰她的角度说，25元表示代价，意味着“爱我”，面是主粮支撑生命，你只有全心专一的爱巴巴，付出这个代价才能获得巴巴的加持活下去。当她去世后，我才突然领悟，“面”并不意味着支持肉体的延续，而是巴巴在告诉她，就算你未必十分专一（这与她的修行经历有关），我也会与你见面，面是亲见本来的意思。想到这时，我已是泪流满面。这里有一个插曲，在陪她治病时，我曾几次在打坐时“质问”巴巴，为什么让虔诚的爱者如此死去？如果您真的慈悲，至少应当让她坚持到朝圣回来。这几年她曾几次对我说一起去美拉巴德，如果连这种小小的愿望都实现不了，您的恩典何在？您的大能就像笑话！并非大能不在，只是我可怜的想象力无法知晓，不用她去，巴巴会亲来。

归真恩典

因为我有缘陪伴至最后，见证了整个殊胜的临终过程。本来虚弱到身体不能动，话都说不了的余义玲，从22号晚间到23号白天一整宿，一直睁眼不睡，精神亢奋，不断的诉说着巴巴，并且亲见了巴巴接引，场面非常殊胜。我有幸用手机抓拍下了多段视频，现在想发几段有代表性的，让大家一起见证。

【简单声明，由于是半夜，房间漆黑，她两个月来几乎没吃东西，非常瘦，加之有地暖太热，衣未蔽体。希望大家不要被表象吓到，静下心感受她内在正经历着的无上幸福。】
这个21秒视频，在讲“巴巴爱我全家”，讲的时候真的给我吓一跳，措手不及。她已经是肺癌晚期全身转移的患者，无论骨头还是大腿远端，都是癌细胞。最后这俩月每天就只喝点水，已经虚弱到不能说话了。没想到竟在巴巴恩典的加持下，把所见所闻都畅快表达出来。（一般肺癌晚期都有脑转移，以至人是昏迷的，但是她直到最后都是清醒的，我认为这也是巴巴的恩典之一。）

这个视频摄于她离世当天的上午，我在与几位医生沟通完，确定放弃治疗后，惭愧的没能经受住情感冲击哭了起来，她看见我哭立马笑了，她用我听得见的声音说：“我爱巴巴”。我立刻开始录制，问她想说什么，她就重复“我爱巴巴，巴巴，巴巴”，这个视频中的声音，才是她实际体力的声音，夜里亢奋的视频已经是恩典介入了。

在其他的视频里，她望着上方幸福的说：“我的父母都被巴巴带走了”，然后她竟开始鼓掌，笑得像个小孩。

这个2分多钟的视频，是晚上她看到巴巴亲自来接她，一直指着天花板说“巴巴在这里来了”，一边叫巴巴一边洋溢着灿烂的笑容，好像剧烈的癌痛没有了一样，沉醉在光辉灿烂的圣爱中。

她这种弥留之际的彻夜讲述，已经不是她自己在讲了。巴巴的力量在支撑着她的表达。她清晰地对我说，“巴巴兑现了承诺！” 只可惜这段没有录下来，在我拿手机追问她兑现什么承诺时，她已经不作回答了。

不过，从她经常说下辈子绝不再来推测，是永远的回到了巴巴那里。

余义玲这位默默无闻的巴巴爱者，在经受了2年肺癌的剧烈折磨后，于2022年11月23日晚上10点22分宣告去世（终年66岁）。昨天到现在一直忙于她的后事，今天下午刚睡醒，就陷入到情不自禁的悲痛，看到美赫巴巴公众号更新的文章，巴查麦忍受一年多乳腺癌，最终被巴巴接走，立马释然了。我知道巴巴正在回应。 感谢嘉童，我相信今天公众号关于巴查麦的分享，就是巴巴通过这点告知我，余义玲已经回到巴巴那里，获得了解脱。

叙述者后记

余义玲阿姨和（巴巴故事中的）巴查麦的性情很像，天真轻信，无论哪个圣人都愿意去接触。为了灵性追寻可以舍弃一切，对经受的一切无任何怨言，也许正是她的不顾一切，天真纯粹，尽管未必专一精进，也同样蒙神恩典。她是我的榜样。

我是她很亲密的一位道友。和她没有血缘关系。由于她的至亲都早早去世，一生命运多舛，最后巴巴借我为她养老送终。我想客观如实的介绍一下她，因为我感到这位中国爱者的如此殊胜经验，不应该被隐没，应该公之于众以增进大家的信爱与道心，见证临终解脱的真实不虚。

她往日的一幕幕浮现脑海，刚刚又哭刚平复。虽然眼泪在流，但我的内心十分喜悦，我知道她一生苦命的追寻已开花结果。

田心感触

衷心感谢黄兄弟对余义玲大姐的照顾和陪伴。巴巴的满德里说，陪伴这样一个行将解脱的灵魂度过最后的时刻，是极大的幸运和巴巴的恩典。

昨晚和今早看了好几遍，每次都同样的震撼。巴巴不会忘记任何一位爱神者，安排这位年轻的爱者照看余阿姨，至亲一样为她养老送终。还赋予他智慧和清醒，在人们通常会悲痛不已和手忙脚乱的时刻，为我们留下如此珍贵的记录和见证。余阿姨对巴巴的专注和信爱，也跟这位爱者的无私服务和友情分不开。

记得乌帕斯尼大师说，一个国家的物质福报，取决于这个国家的爱神者。余姐承受的苦难和最终的解脱，不仅让其亲友收益，也对国家有利。

一个灵魂解脱，对整个宇宙都有影响。可以说是宇宙间的大事。

余姐离开的同一天，我做了个梦，只记得最后的部分。和很多中国爱者一起参加战争。前面有大片大片的火，可能是炮弹炸出来的，但是又看不见敌人。我们都用身体扑火，连滚带爬，最后把所有的火都扑灭了。这时候也累醒了。

记得梦醒后第一个反应是想起巴巴在字母板上的最后一篇讯息：巴巴与我们割断外部联系也就是离开肉身，能够使所有的人，通过相互之间的内在联系捆绑一起，来共同证悟真理。

相信大家一起在巴巴的帮助下，终有一天能够扑灭无明的火焰。

倚靠主怀

田心记述：12月4日，今天上午在（澳洲）阿瓦塔之寓每周一次的阿提结束之后，跟大家分享了余义玲大姐的故事。看到在场者有的眼圈红了，还有几位在擦眼泪。随后大家深情地为余姐唱了一首歌。大意是：

怎样的伴侣，怎样的欢喜
我轻轻倚靠在您永恒的怀里
怎样的荣福，怎样的安寂
我静静倚靠在您永恒的怀里

向伤害告别，将危险驱离
我永远倚靠在您永恒的怀里
