拉妲-奎师那，悉妲-罗摩，美婼-美赫，

为什么人们把你的名置于主的名之前？

造物主怀着无条件的忠爱

前来膜拜他的造物界，

所以自古至今，你的名皆在他的名前被咏唱。

——宝·喀邱瑞《献给美婼的歌》

1952年5月24日，在发生在美国的那次车祸中，巴巴和美婼同时被抛出车外，双方躺在血泊里。巴巴的左臂、左腿和鼻梁骨折；美婼的头盖骨全部破碎，用见证者的话说，就像是被打碎的鸡蛋壳，并且失去知觉48小时。住院期间，躺在病床上的巴巴每天派人去美婼的病房探视问候，下面是巴巴给美婼的一个字条：

“这是我的最大的受难，也是最后一次；因为你，我的至爱，不得不分担一半，这让我感到非常骄傲与幸福。这次与你的分离让我甚为不安，我不断地想着你的痛苦——但再过三四天的时间，我们就能见面了，一切都会好的，我们都将很快恢复。

你的所有愿望都将得到满足，我将让你幸福高兴。相见后我将告诉你一切。在这三四天里，你必须让高荷清洗并治疗你的眼睛。我们还有很长的岁月，享受真正的幸福；因此，你千万不要担心、思虑或感到紧张。巴巴永远与你在一起，每天时刻都在想着你。你一定不要担心，要放松，休息好。”

女门徒高荷医生评价说：

“巴巴喜欢要美婼快乐。他总是想要她幸福。他从不想让她因任何的事情而不快或伤心。他总是想看见她微笑快乐。巴巴爱她很深。有很多次，他说美婼是他的一部分。‘若是美婼不悦，我就不悦。若是她伤心，我就伤心。若是她哭泣，我就哭泣。若是她快乐，我就快乐。所以，你们若是让她快乐，等于让我快乐。首先，保证不在任何方面让美婼不悦。’以这种方式，巴巴让我们知道他实际上有多么爱美婼。”

“在晚年，巴巴身体伤残，不能走动，美婼在饭桌前服侍巴巴。如果她因故离开一会儿，巴巴就会问，‘美婼在哪儿？’即使一小会儿，他都会想念她。当我们大伙都跟巴巴在房间里时，巴巴总是喜欢让美婼在场。有时谈起某个话题，巴巴总是等美婼来之后再讨论。”

阿露医生说：

“通过观察巴巴和美婼在一起，我逐渐明白了什么是真正的灵性之爱，美婼怀着那样的爱来服侍巴巴。当美婼作为爱者跟巴巴交谈时，她总是称呼他toon（古吉拉特的非正式亲昵称呼）。巴巴会吻她，她会吻巴巴。巴巴会喂她吃饭，她会喂巴巴。那么温柔。这对我来说是真爱的典范。如此纯洁，如此神圣。”

“在巴巴与美婼之间的那种爱，那种纯洁的、神圣的爱的表现，是甜美与纯洁的示现。你看着它就会感到非常幸福。巴巴有一次对我们说，‘在我和美婼之间，我仅仅保留着一层帘幕。她就像我一样。”

“美婼没有意识到她的位置，她是多么地伟大。她具有某种权威，自己却毫无觉知。例如，她会说某样东西，而这就会真的实现。巴巴听得见她的祈祷。巴巴会满足她所要求的一切。应该把她当做神圣的存在来对待。对她友好，但要保持应有的尊敬。”

阿娜瓦丝：

“巴巴脸上流露的对美婼的爱，没有言语能够表达。美婼充满爱意地注视巴巴——她的整个生命——的画面，甚至天神们都渴望看见。如此之美。巴巴会跟每一个人交谈，开玩笑，或授述语录。美婼自始至终都望着巴巴。在早年，她会忘掉身边的一切，除巴巴之外。她眼里别无他人；她思想里别无他人。惟有巴巴。必须如此；这是她的角色，她的使命。”

巴巴解释说阿瓦塔的圈子由十个同心圆组成，每一个圈子都有12个成员，内圈还有两位特殊的附属。巴巴说，美婼是其中一个，玛妮是另一个。巴巴的门徒兼传记作者宝·喀邱瑞还说，阿瓦塔的圈子的每一个成员都代表着神的相反属性。比如早年，巴巴称古斯塔吉是他的“黑暗面”，意思是古斯塔吉代表着无限黑暗（相对于神的无限光明）；另一个门徒代表着无限无知，作为无限智慧的反面，等等。巴巴通过他们和其他圈子成员来为整个造物界工作。宝说：“不过，美婼则代表了神的一切相反属性，因此在至爱的圈子里有着独特的位置。

这每700年或1400年仅仅发生一次，当至古者用人身降临人间的时候。她代表着夏娃。每一次主来到地球上，就会有一个人代表那个位置，它是永久性的。亚当是第一个人，第一个水滴；夏娃是他的受造物，摩耶。

在本初，当创世开始时，第一滴水（阿瓦塔）成道，随之成为第一个至师。他膜拜摩耶，因为摩耶曾经是且仍然是成道的媒介。因此，当他一个又一个时代降临地球时，他带来一个人，以代表拥有神的所有相反属性的整个造物界。美婼就是那一个。”

玛妮也谈到这个方面，美婼代表造物界的角色：“我心中有一个很强烈的肯定（尽管巴巴从未直接说过），美婼代表了他的造物界——世界。如果美婼代表他的造物界，她自然是他的至爱。对造物主来说，什么会是他的所爱呢？——他所创造的世界。”

邓·斯蒂文思：

“巴巴在很多场合提到，他进入造物界的职责之一是提供一个活的榜样。毫无疑问，他通过向我们示现该怎样互爱而做到了这一点，因为他对我们每一个人的全然无余的理解与接纳，超过了我们的最大期待。

在直接地向我们示现这种完全接纳的同时，巴巴还把我们每一个人应如何回报该无比恩典之挑战，局限为一个纯洁的楷模——美婼对他的爱的方式……美婼向我们示现了爱的理想：完全无所求的爱——这是爱所能够且必须做到的真正回报。”

有人问美婼，“我们该怎样在内里唤醒爱？”

美婼回答，“那个你做不到。巴巴将为你做。他将感动你的心。逐渐地，越来越多地，你将感受巴巴的爱，当时机成熟时。在另一个方面，你确实爱巴巴。因为你爱他，你才问这个问题。你已经爱巴巴了。但你想更加爱他。那将自然地到来。”

今天（12月22日）是美婼诞辰周年纪念日，这是巴巴为他的至爱选定的庆贺日。

愿圣洁的美婼帮助我们爱巴巴——以他应该被爱的方式；帮助我们取悦巴巴——以他应该被取悦的方式。
