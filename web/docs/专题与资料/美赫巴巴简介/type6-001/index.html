问：您几岁上学？

答：5岁。

问：您最喜欢哪些科目？

答：除了算术，都喜欢。

问：您记性好吗？

答：并且还敏锐。

问：在历史人物和诗人中，您最喜爱谁？

答：哈菲兹。

问：您是否为自己是印度人感到自豪？

答：为被众人喜爱而自豪。

问：您是否把目前的地位归功于您的学校老师和大学教授？

答：教育跟真理何干？

问：遇到巴巴简之前，您有没有拜访过别的圣人？

答：想都没想过。

（上述问题由印度的K. J. Dastur先生提出。时间1928年。）

问：您能起死回生吗？

答：如果必要的话。基督曾经起死回生，让盲人复明。对任何一个达到我所达到的意识状态者，奇迹不过是儿戏而已。

问：您现在所教导的一切，是巴巴简传授给您的吗？

答：不是。严格地说，她没有教我。她打开了门。那时，我知道自己内在具有能力；但她向我显示那是什么。那不是可以教的，必须亲证和体验。

问：您给跟随者强加戒律或生活规则，鼓励禁食和素食吗？

答：完全根据个人需要。在印度，我有一个门徒，仅靠水和一点牛奶已经生活了4年。但如果一个人有家庭，我也许不会让他遗弃自己的家。

问：您从哪些宗教里获得自己的哲学的，基督还是佛陀？

答：没有从任何具体的导师那里。基督，佛陀，奎师那……这些都是意识状态的名称。

（上述问题由伦敦的《每日镜报》记者提出。时间1932年）

问：您是圣雄吗？

答：什么是圣雄？我知道真理。你住在伦敦，你知道这一点。我只是知道。

问：您是神吗？

答：我与神为一。我活在神里，如同佛陀、基督和奎师那活在神里。他们知道神，就像我知道神一样。每个人都能够知道神。

问：您解决了“恶”这个问题吗？

答：恶并不存在。只有不同程度的善。

问：您的秘密是什么？

答：消除自我。

问：您有没有一本类似《圣经》，《可兰经》那样的经典？

答：我不是来教导，而是来唤醒。

问：您相信佛陀和八圣道吗？

答：所有的宗教都是通向同神完美结合的上升阶梯。

问：您相信哪个神？

答：对一切人只有同一个神。

问：哪个宗教离您的最近？

答：一切宗教都是同一个神的启示。

问：有没有来世？

答：有。灵魂不死，从一生到另一生，直到融入神。

问：涅槃？

答：是的。但不是个我（self）的失去。

问：个我继续存在吗？

答：是的。但它最终融入神。灵魂不是大脑，灵魂通过大脑发挥作用。大脑是它的工具……。

问：神是人，还是某种能力？

答：神既是人格的，又是非人格的。他在文学艺术里，在万物里。

问：您是泛神论者吗？

答：不是，当你知道神时，一切都会简单明了。在体验的顶点，大我（Self）与神合一。

问：您结婚了吗？

答：性对于我是不存在的。

（上述问题由《星期日快报》记者James Douglas先生提出。时间1932年。）

问：有人说女人是男人的拖累，阻碍他获得神的恩典。您看，所有的圣人都……

答：啊，不！在获得神圣恩典的过程中，女子可以发挥重要作用。与男子平等。只要她对自己真实，一切都好。但如果她屈服于环境（你明白我的意思），婚姻就会失效。就会出现离婚。

问：而圣人发誓独身……？

答：那并不重要。有些人结婚，另一些人最好独身。结婚的人并不意味着落后。女子能够用爱激发男人认识真理。但她必须培养爱而非淫欲。这是开启幸福的钥匙。

（上述问题由《每日速写》(Daily Sketch)记者提出。时间1932年。）

问：在您的崇高使命和高尚事业中，保持静默给您造成表达困难吗？

答：不会，因为内在的和外在的媒介都任我支配。

问：您是否集中精力提升琐罗亚斯德教？

答：我实际上在为全宇宙的灵性提升而工作，包括琐罗亚斯德教在内。

问：国内和国外的新闻媒体打扰，让您烦恼吗？

答：从来不因任何事或任何人而烦恼。

问：除了宗教，您有没有政治目标？

答：灵性包括了宗教的、政治的和社会的问题。

问：依您的看法，当前经济萧条的原因与前景是什么？

答：自私是经济萧条的原因，萧条将会过去。

问：您的工作路线是什么？

答：爱与服务。

问：您是否认为：现今的文明导致了人类堕落？

答：不对！凡是造成堕落的东西，就不是文明。

问：您是否关注印度和西方国家的政治进展？

答：（我关注）每个国家的每个生活领域。

问：像英美这样的国家能够给世界提供工业教育，带来繁荣，是这样吗？

答：西方可以把物质的东西教给东方，东方可以把灵性的东西教给西方。

（上述问题由Nasik的一个学生提出。时间1933年。）

问：“超意识加浊意识”是指什么？

答：与意识相关的状态有六个：

A=潜在意识（无意识）：这里（在超越状态的）灵魂意识不到大我，也意识不到宇宙。

B=半意识：这里（在矿物、植物和动物界的）灵魂一部分意识到宇宙。

C=意识：这里（在普通人类的）灵魂完全意识到浊界，却根本意识不到精界和心界，也意识不到大我。

D=半超意识：这里（在灵性道路上的）灵魂不仅意识到浊界，而且意识到精界和心界，但却仍然意识不到大我。

E=超意识：这里（在“我是神”状态的）灵魂完全意识到大我，却根本意识不到宇宙=浊、精、心界。唯有这个状态是真实状态，是一切瑜伽的目标，是一切宗教的目的。这就是人们所说的“涅槃”或“涅未卡帕三摩地”，或“瓦苏-埃-伊拉易”，也就是无限神圣意识。在此，人彻底摆脱（让幻相呈现为真实的）摩耶的束缚，证悟真理（成道），体验永久绝对的存在、无限知识和无法言喻的神圣喜悦。

F=超意识加造物界意识：这里灵魂除了保留上帝意识（同于E）之外，还恢复了对宇宙（浊、精和心界）的意识，同时其上帝意识丝毫不变。换言之，人与神合一之后，又回到浊、精和心意识（这样的人极少），意识到神圣大我，并意识到宇宙的真实面目——空无。这样的人既是神又是人。真实不断的证悟让他知道，作为一切万物里的大我，他且唯有他是无所不在的；他还知道宇宙只是海市蜃楼和幻觉现象的结果而已。

问：怎样才能辨认真正大师？

答：口渴者被海市蜃楼吸引，但他很快会发现那是幻相，而非生命活水。假“大师”也许会通过外表，比如个人魅力或对灵性的智性论述，吸引人们的注意力；但他不可能做到真大师所能做到的：唤起人们的最高理想，感动亿万人的心灵。

问：知识成就对个人的灵性进步起着帮助还是阻碍作用？

答：靠谈话、辩论或阅读，不可能获得灵性真理或者说成道。唯有通过心灵，但这是一个极其漫长的过程。当心灵和头脑并行发展、平衡和谐时，人的进步则会更快。

那些头脑（智力）比心灵发达的人，容易获得定见，从而对其知识成就和优越性产生执著。心热的人信心也更大，会为了爱和真理而放弃一切。

智力是最低的认识形式，是从阅读、听闻、推理和逻辑中发展而来的。这些过程会制造获得“真知”的假象。

更高的认识形式是永久觉照，人藉此能够体验并见到事物的本来面目。他在该状态感到与万人万物和谐一体，在各个生活领域里实现神性，并能够把幸福给予他人。

最终最高的认识状态是灵魂融入无限知识、喜悦和能力之无限海洋的结果。达到该状态者能够帮助成千上万的人达到完美。

问：为什么说冥想至师是最有效的静心形式？

答：通过冥想一位神圣且完全意识到其神性的至师，一个神圣却尚未完全意识到其神性的个体，就会被引向神圣的大我意识。

问：师利美赫巴巴的工作是否将是传道式的——如基督那样？

答：他不会建立新的宗教，但他的工作将包括一切宗教的精华和精神，也就是说，将涉及到宗教的密意和灵性方面，与仪式教规和枯燥教条毫无关系。因此，他的工作不是狭义的传道，而是渗透所有的宗教。

问：他为什么经常改变计划，并且拖延他所许诺的“医治”时间？

答：虽然他似乎在改变计划，并且似乎不在他所承诺的日期开口讲话、医治世界等，事实却并非如此。因为作为至师，他知道将要发生的一切。实际上，一切事情都是他预先计划安排好的。所以，他虽然实际上知道他注定将在何时开口讲话和医治世界，但却经常推迟日期，以便给他的最后工作以更大力量，也是为了使他在过去这些年里所计划的一切，在他显现的那一天完全地显示出来。

问：既然大师能够起死回生，他又为什么让门徒生病或死亡？

答：虽然灵性上，大师是万物的主宰，但他从来不会没有必要地干预自然法则和羯磨（因果）律，这些法则和规律统摄着一切的存在，属于大师本人。以往的大师及其弟子所承受的可怕痛苦，一方面是因为这些自然法则的作用，在另一方面，他们通过代人受苦而在灵性上帮助全人类。

问：既然大师是超人的，他为什么仍会饥饿、口渴和需要睡眠？

答：大师在不同的层面上工作——灵性、心体、精体和肉体层面。为帮助处于不同进化阶段的不同个体，他降临到不同的层面。即使在肉身里，他也能够帮助心层面的高级灵魂，精层面的灵魂和浊层面的普通人。他分别以灵、心、精或浊体为媒介，在相关的层面上工作。

真正的老师是能够降到学生层次上的老师。大师降入人间，是为了提升人类。肉身是他的工作媒介，他也有肉体的需要，吃饭休息等。必要时，他则能够连续数日不吃不喝。事实上，他经常长时期禁食。

对大师身体需要的照顾，虽然表面上与常人相似，但却有着本质的不同。与常人不同的是，那不是为了满足饥饿、口渴或睡眠欲望，也不是为了从吃喝等享受中获取快感。大师照顾身体需要，纯粹是为了维持身体，以便用这个媒介来完成他必须在物理层面上为人类做的伟大工作。

问：既然大师无所不知，他为什么还向人提问题？

答：一个人从无数往世的体验中，积累了无数的印象（业相），这些印象以念头的形式保留在他的心体，像种子一样潜伏着，未显现。一旦遇到合适的环境，这些念头便表现为精体的欲望和情感。被更充分地表现时，则发展成浊体的肉身行动。

大师知道每一个人的已表现和未表现的念头，但他有时候仍然提问。在提问过程中，通过内层面上的工作，对被问者的已表现和未表现的印象做工作，使这些印象尚在心体就失去效力，不至于发展或表现为欲望和行动。

总之，大师通过在精层面工作，来控制恶念的发展，消灭未表现的欲望，防止这些欲望发展成可能会对一个人造成危害并阻碍其灵性进步的相应行动。

问：什么是无私服务？

答：神仅仅作为神，不是自觉的人；人仅仅作为人，不是自觉的神。神人既是自觉的神，又是自觉的人；因此神人既是宇宙之主，又是宇宙之仆：帮助一切众生证悟实相的主；不断承受一切众生负担的仆。服务那个服务一切众生者，即是服务整个世界。

无私服务和爱是孪生神圣品质。只有能够爱的人，才能够服务。

你服务至爱神人，就是在服务其他每一个自我中的你自己。

他所要求的服务，是为了你自身的灵性利益；但这种服务必须是自发自愿，全心全意，没有条件，不计酬报。对神人的服务是对你的身、心、灵的严峻考验；倘若方便易行，怎能谈得上是完美服务？身体受痛苦，头脑受折磨，但无私服务大师者的精神却充实喜悦。

只有拥有者，才能舍弃。国王放弃一切，成为乞丐，是真正的舍弃。只有毫无疑问且不顾后果服务神人者，才是在真正服务；否则就无异于有偿劳动。

问：如果一个人尽可能地行使了智力之后，得出的结论是神不存在，他应该坚持自己的结论吗？

答：只要这个结论不把你引向道德犯罪，就没有关系。这样的结论属于智力运作掩盖了真理的情况。当时机成熟时，真理就会逐渐显示出来。

问：阿瓦塔的显现是指什么？

答：成道的大师一直存在于物质和其他层面，但并不总是被人知道或看见。经过若干时间周期之后，当灵性处于最低潮、物质主义达到顶点的时候，在世界充满混乱和悲哀的危机关头，神性的非人格方面便降世为人，世人便看到阿瓦塔或先知的肉身显现。

同一个神圣人物，曾经以不同的肉身和不同的名字，显现为阿瓦塔。这些阿瓦塔和先知在完成使命——给全人类以巨大灵性推动——之后，便放弃肉身，重新回到神性的原始、非人格方面。但即使在非人格方面，他们也总是自觉地意识到自己的神性。

问：既然已经有了这么多美好的宗教，为什么还需要先知再次显现，还需要阿瓦塔重新带来神的启示？

答：在具体一个阿瓦塔显现的时候，总体灵性推进力量异常强大，乃至于带来新的意识觉醒。这与阿瓦塔肉身在世期间的教导和活动结合起来，被他的跟随者赋予一个外部形式——新宗教。

随着时间推移，灵性推动的潮水逐渐减弱，灵性也逐渐减退，直到变得无足轻重。宗教（或者说其外部形式）成为干枯外壳，随时都会崩溃，世界状况也到了紧要关头。就是在这个危机关头，阿瓦塔在物质层面出现，重新给世界以灵性推进。这种灵性推进力量，依照当时的环境条件，再次被赋予新的、外部的、宗教的形式。

这就是为什么目前的诸宗教有着不同的外部形式，都归因于其创立时期的时代和环境差异；尽管在本质上都是同一个人生理想。在不同的时间和条件下，同一个神性以肉身出现在人间，一次又一次教导那个理想。

问：师利美赫巴巴对以往的大师是怎样评价的？

答：基督、佛陀、穆罕默德、琐罗亚斯德、奎师那和其他大师，实际上都是同一个神圣大我意识的化身，根据不同时期和不同国家的需求而化身为人。

问：能够施展奇迹者，在灵性上一定完美吗？

答：在西方，人们对奇迹很感兴趣。有能力施奇迹，未必意味着灵性上高级。凡是已获得完美且享受“基督意识”者，都能施奇迹。对于这样的人，医治病人、让盲人复明、甚至起死回生，都不过是儿戏而已。就连那些尚未与无限合一、还在不同意识层面上行道的人，也能够施奇迹，让物体出现与消失等。

问：大师们为什么施奇迹？什么时候施奇迹？

答：灵性大师的奇迹不是定做的，也就是说，他们施奇迹不是为了满足无聊的好奇心，而是根据现实需要。为了给整个宇宙灵性推进，大师们曾经施展过奇迹。

问：大师用什么方式帮助求道者？

答：一般来说，大师根据求道者的性情和灵性准备程度，给予个别帮助。但由于现在是阿瓦塔时期，师利美赫巴巴对人类的灵性帮助，既是个别的，也将是集体的。他把新的生命注入旧秩序，使之恢复活力，并把最高的灵性状态——与无限喜乐、知识和能力海洋成为一体——给予一些特选者。他将给整个宇宙以总体灵性推进。

问：师利美赫巴巴宣称自己是这种新灵性分配的阿瓦塔吗？

答：如果没有事实的支持，这种宣称将毫无价值；而一旦被事实证明，就不再有宣称的必要。在他公开显现时，师利美赫巴巴是谁和其使命性质，将得到充分展现。

问：师利美赫巴巴是从哪里获得权威的？他是如何知道自己已经成道的？

答：一个人从亲身体验中，能够以权威口气说自己是人；美赫巴巴同样也从其持续地、自觉地与无限合一的体验中，知道他自己的神性。

问：美赫巴巴开口讲话，与他所预言的人类意识转化，将会有什么关系？他保持静默已经八年，为什么？

答：按照当前的构造，人类用三个媒介表达念头，体验三种意识状态。

这三个媒介是：

（1） 心体：念头产生处，念头是业相（过去体验的印象）的结果。这些念头可能像种子那样潜伏于心体，也可能被表现出来。若被表现出来，它们采取欲望的最初形式，首先经过

（2） 精体，或者说（由五个精神器官构成的）欲望体。念头可能以梦或未满足欲望的形式留在精体；也可能被进一步表现出来，通过

（3） 肉体及其五个身体器官。

与上述三个媒介相对应的三种意识状态：

（1） 无意识，如在无梦深眠里；

（2） 下意识，如在梦里或模糊、未形成或未满足欲望；

（3） 醒意识，如在日常活动中。

念头“从心体—经由精体—进入肉体表现”的过程，可被称作“人类意志的表现”。

为了有效地表达思想，三个表现媒介都必须清晰，相互作用必须和谐。头脑与心灵必须统一，理智与情感必须平衡。为把思想传递给别人，人类用言语或文字，或其它物理表现媒介，或在有些情况下（比如在心灵感应中），思想则通过精体被传递和接收。

神人既不思想，又无欲求。通过他，神圣意志必然得以完美显现，直接从（在常人里未发展的）精神体进入身体表现。对于他，超意识就是正常的意识状态。他所传递的不是思想，而是真理；他要么通过深层的、内在的体验，在他所帮助的个体里唤醒该真理；要么通过肉眼、身触或言语，把该真理直接从超意识传递到意识，从精神体传递到肉体。当他开言的时候，真理将被更有力地显现出来，胜过他靠“视”或“触”所传递的真理。

因此，当师利美赫巴巴开口时，他将示现神圣意志，这将带来世界性的意识转化。

问：师利美赫巴巴通过开口说话，能够缓解世界萧条，解决失业、禁酒和犯罪问题吗？

答：我们所有的个体和社会困难，根源都是自私自利。正是私利让腐败的政客接受贿赂，背叛选民的利益；也是私利让酿造、偷运和贩卖私酒者为谋取利润，违犯那旨在帮助整个国家的法律（无论该法律是否英明）。这让大众为个人享乐而破坏法律，造成对法律的普遍不敬，犯罪巨增。

其他形式的自私自利让个体或团体为自身利益去剥削人类大众：将促进人类总体福利的发明创造束之高阁，只因使用它们意味着废弃现成的低劣设备，从而阻碍文明进步；当人们挨饿时，任意毁掉大量食物，只是为了维持市场价格；在世界利益要求黄金流通时，大量囤积黄金。

然而要消除自私自利，即使一个人愿望真诚，也不易做到，并且绝对无法完全达到——除非有至师的帮助。这是因为自私自利产生于对大我真性的错误观念。必须根除这种观念，体验真理，才有可能消除自私自利。我打算在开言时揭示众生中的同一个无上大我。做到了这一点，认为大我乃有限、分别存在的观点就会消失，自私自利也随之消失。合作将取代竞争；确知将取代恐惧；慷慨将取代贪婪。剥削将会消亡。
