神圣计划：接下来七百年

显然，只有当我们诚实地评估自己，认识到自身对分别自我的自满认可时，才能开启转变过程，引领我们过上人间天堂生活。这种诚实的驱动力让我们觉察到需要改变之处。在《世界新秩序的阵痛》这篇语录中，美赫巴巴就神圣计划作了一系列强有力的明确声明，其中描述了人类的现状，并解释了将帮助我们转变的力量。他首先授述：

人类已经不能自行解决个体和社会的问题：这种失败显而易见。人类无力建设性和创造性地处理自身问题，这表明在正确认识人类本性和生活真正目的上，存在着可悲的缺陷。

鉴于个体、社会和国际间的问题已发展到如此灾难性的地步，我们要如何解决，从何入手？可在美赫巴巴称作的神圣计划中找到答案。在对神圣计划的解释中，巴巴让我们懂得人类历史上这段痛苦时期的原因是由于人类的灵性正被唤醒，从而减轻了我们自身为世界状况感到的忧苦。他在《新人类》这篇语录里说，世界的混乱状态“都是神圣计划的一部分，也就是给这个饥饿疲惫的世界重新赐予永恒唯一的真理”。除非阿瓦塔告诉我们，否则谁能想象人类的灵性重生竟然需要世界处于目前的动荡状态？

为什么会这样？也许在这个灵性重生时期发生的事情是：所有隐藏并潜伏在人类无意识中的暴力、淫欲、贪婪、仇恨等等现已被释放，暴露了这些心理及情感上的疾病。这种从无意识进入有意识的整体释放，或许就是阿瓦塔工作的结果。

我想象美赫巴巴周全缜密地工作来释放人类的这种无意识，允许它从隐蔽的深处浮现出来，在痛苦中被体验认识，然后在他的帮助下予以转化。他可能选择了这种释放，作为将人类重新导向真理的方式。要让这样一场神话般的世界性戏剧发生，是奇迹般的事情。也许这份在全球范围释放人类的无意识以便将其重新导向真理的阿瓦塔工作，就是美赫巴巴在1960年代所提到“将要发生而从未发生过的事”。

那么，美赫巴巴对人类的神圣计划是什么，它将怎样实现，又在何处实现？首先要知道，我们在该计划中都有角色要扮演，而这从我们准备好面对自己开始。巴巴宣布：“现在是人类正视所受灾难的真正原因的时候了。”

我们都知道直面现实有多么困难。事实上，通常是在我们的所有操控都未能解决所面临的问题之后，最后诉诸的行为才是直面自己。倘若普遍来讲，面对自己是如此令人厌恶，我们又何以被迫这么做呢？

美赫巴巴说，人类将通过苦难来面对自己。苦难将是实现神圣计划的媒介：

巨大的苦难唤起深刻的认识。当极度的痛苦唤醒疲惫的人类，在其内心激起对真知的渴望时，便达到目的，产生真正意义。空前的苦难带来空前的灵性成长。使人把生活建立在不可动摇的真理基础之上。

尽管这听起来像个大灾难预言，模糊提及某种将迎来新人类的劫难式事件，但对我来说，它表达了一个基本真理的简单断言——痛苦的价值与必要性，当然我们可能并不想听到它。我确信他的陈述当前就适用于我们个人层面，因为我看到它在我自身生活中发挥了作用。

大约十年前，我是人类中疲惫不堪的一员。正如我在其他书中所述，我来到了一个不知如何更亲近美赫巴巴的境地。过了这么多年，我焦虑地感到自己喜爱阅读的真理阐述依旧仅仅停留在字面上。这种痛苦状态驱使我愈发强烈地念记美赫巴巴，远甚于我知道他的20年来有过的程度。或者正如美赫巴巴在上述声明中说的，曾经经历的痛苦在我内心激起了对真知的渴望。最终从这种痛苦中呈现的明晰，使我的头脑和心灵发生根本性转变，带来灵性成长。

当我连在生活中的小事都专注于美赫巴巴，藉由念记之光，我开始看到自己是怎样以种种方式维护分别自我的（而之前从未意识到）。我觉察到：随着不再那么执着于做个正确者，我发现自己能开始驱除那只可怕的隐形野兽——骄傲，它使我总对他人有分别心。几十年以来的哲学概念，现在成了我看得见的对手——我的虚妄分别心。很自然，当觉察到自己行为中的虚妄性时，我会试着找到心灵的元素，去愈合我和他人之间的隔阂伤口，一体性从而得胜。

一旦将这种认识诉诸言语，或许无法传达它所承载的变革催化力量。尽管如此，我再怎么强调都不为过：它确实改变了我，某种程度上转变了我的生命。开始运用这种一体感时，我惊讶地发现，生活中的痛苦减轻了，一种和平感伴随着我。当然我无法避免与他人之间的误解，但我发现基于拥护一体感去生活时，自己会更沉稳地与人打交道。

赢得这个新视角后，我凝视着自身的心理战场，现在和平了。当我审视刚经历的成长过程，不得不承认自己人生中这段空前痛苦状态的价值乃至必要性。我开始接受并理解美赫巴巴的保证，即苦难会成为把我们引向有效改变的催化剂。苦难确实把我引向成长，带来真正认识的开端。

因此，由于我亲身经历的危机与改变阵痛，美赫巴巴关于神圣计划的另一段重要声明在以前觉得是不祥的，现在看来仅仅是对我们所有人必将经历之事的实际陈述。“现在是普遍苦难加快人类走向灵性历史转折点的时候了……在这个普遍苦难的危机时刻，人们也逐渐准备好转向高我与实现神意。”

诚然，我所经历的痛苦是个转折点。它将我转向一个新方向，使我接受了一种以前决不可能欢迎并视为合理的存在模式——以努力维护一体感作为首要目的。因此，我认为美赫巴巴所说的转折点，可能就是从“旧人类”转向他所称为的“新人类”。

在我看来，“旧人类”和新人类之间的主要区别是，新人类将坦然活出内在一体真理。根据美赫巴巴所述，当今世人正在经历的痛苦，无论是集体的还是个体的，势必将为这种转变提供动力。我还发现，当我尝试拥护一体感时，它很自然地改变了我与他人相处的基础。

这让我们想到美赫巴巴关于神圣计划的另一句重要声明：“现在是时代痛苦成为真正认识人类关系的媒介的时候了。”

毫无疑问，我们所有人生活中的一个主要问题就是人际关系问题。在这句话中，美赫巴巴让我们知道，我们的痛苦也将被用来向我们透露人际关系的本质。他在解释神圣计划的下一句声明中解答了该本质是什么的问题：“现在是寻求对真理的新体验的时候了。”可能我们过去没有把对真理的体验看作人类关系的根基。尽管如此，跟随美赫巴巴会带给我们在真理基础上重新调整人际关系的感悟。美赫巴巴阐明了这种感悟是什么，以及它何以是对真理的体验。

感悟到一体性的灵性价值，即是促进真正团结与合作。四海兄弟成为真知的自然结果。基于灵性认识的新生活是对真理的肯定。不是乌托邦空想而是完全切实可行。

由于对美赫巴巴语录的熟悉，我们可能会一扫而过低估他的这番话，因为这都是我们之前读过的。然而倘若我们进一步细观他的讯息，就会注意到如何培养这种感悟的过程。

首先，我们必须认识到一体性的灵性价值。但要做的不止是认识该价值，还必须使该价值成为我们生活中的至高追求。早先我们读到美赫巴巴所述，若要体验和分享爱与幸福，必须把普遍的神圣生活视作我们生活中的最重大诉求。而这个诉求实际上正是对一体灵性价值的认可。一旦我们将其视为“生活中的最重大诉求”，就会发现自己开始欢迎该诉求所支持的那些价值和行为，而不再延续分别自我的习气。对一体性价值的感悟会重塑我们的行为，这样四海兄弟就自然而然地通过我们的行为传播开来。

在此过程中你可以观察到，四海兄弟不再停留在头脑空想上，而会因为将其真理付诸行动而得到促进。内在一体的感悟是美赫巴巴上文所述对真理的新体验，并且是人类关系的基石。

不过即使四海兄弟是对真理的表达，美赫巴巴怎么能说它完全切实可行呢？他之所以说切实可行，是因为“人们将依据这个古老一体真理来重新定向生活，将在日常生活当中重新调整对邻居的态度”。要是巴巴告诉我们可以在日常生活中感受对真理的新体验，就意味着可以在生活中的任何时间任何活动中体验之。

这场不可逃避的个人与全球性痛苦戏剧（称为神圣计划）已经被命定，以便推动我们感悟一体性价值，并且将此感悟付诸行动。鉴于对这个转变过程的研读，让我们再看一看美赫巴巴的《最后宣言》。

七百年后我再次来时，意识的进化将达到一种顶点，物质主义倾向将自动转化为灵性渴望，灵性大同平等感将普遍实现……在接下来七百年期间，这种一体感将逐渐地取代分别倾向，并统摄众人之心，驱逐滋生痛苦的仇恨、妒嫉与贪婪。幸福将统领人间。

但愿（在我们尚未研读美赫巴巴关于神圣计划的声明之前）看似遥不可及的理想，对当今的我们确实成为可能，对子孙后代则必将实现。

“对一体灵性价值的感悟”及其伴随的价值观在日常生活中的运用，是解释何为灵性体验的另一种方式。因此让我们更仔细地探究美赫巴巴在《新人类》中关于灵性体验的阐述，以及我们如何依据一体性的古老真理为自己定向。
