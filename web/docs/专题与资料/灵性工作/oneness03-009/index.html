美赫巴巴在语录“为人类灵性自由工作”结尾时向我们指出，他不仅是邀请我们，而且是指导我们，分担他将灵性自由带给他人的工作。他说：

在这个上帝意愿、上帝计划、上帝规定的给人类带来灵性自由的任务中，你们，我的亲密跟随者，必须帮助我，哪怕以生命为代价……在履行帮助他人找到神的责任中，你们必须准备欢迎各种痛苦和牺牲……我完全相信，我的爱徒，你们会分担这一重任。

美赫巴巴声明的“以生命为代价”、“欢迎各种痛苦和牺牲”以及“分担这一重任”这些不常见的表述，或许看起来有些极端。但与此同时，巴巴让我们知道在这项工作中帮助他的重要性，他在语录“灵性工作者的任务”中再次强调，要他的追随者“分担我灵性化世界的宇宙工作”。他甚至宣称，“在道路上，做弟子的最重要条件，就是随时准备为灵性事业工作，帮助人类越来越走近神。”

《语录》的大多数读者不太会认为这是追随美赫巴巴的最重要条件。但他是对我们这些把生命奉献给他的人说的，他的爱已然触动了我们的心，我们也真正接受了他，开始了通往他的漫长旅程。无论我们称这段旅程为“道路”，还是称自己为“弟子”，都无关紧要。我们所有的，不过是他以之为凭借的这颗心，随时准备帮助他的事业。

通过回顾《语录》中美赫巴巴关于服务所言，我们已经看到他确实无需我们帮助。他自己的言语可以证明这一点！他解释了如何传递灵性认识，鼓励我们帮助别人赢得最伟大的礼物——灵性自由。最后，他甚至告诉我们来分担他灵性化世界的工作，并完全信任我们会进行下去。

在《语录》“真正的师徒关系”一篇中，美赫巴巴进一步阐明了我们在做这项工作时与他的关系。他说：

因此服务大师即参与他的事业——服务一切众生。在分担大师工作的时候，弟子可能需要接触社会。不过，虽然按照等待他的工作周旋于世，他却同作为无限生命的大师，保持内在联系。因此，弟子通过分担大师的工作，更接近大师，成为大师意识的一个有机组成部分。

美赫巴巴有关分担他的事业的讯息之美，深深地打动心灵，因为我们可以分享一些来自内心深处的东西。当我们依靠他给予的直觉指引时，他的爱和真理能触及别人的心。

尽管必须真诚地努力，我们也不应过于紧张而不敢开始。可以从日常生活中的小事开始。当心无旁骛时，简单的行动可以包含一体性的真正表达，以提升我们所处的氛围。我们太常忘记，生活就是由这些微小的时刻组成的，正如画笔上恰到好处的一点色彩，让一幅画变得美丽。

我们非常幸运，美赫巴巴赋予我们与他亲密无间的关系，也予以这种关系的欢怡，以及为他人灵性自由努力工作的困难。放松努力、只是享受他的临在之温暖，常常很诱人。无疑的，我们偶尔应该融入这种温暖。然而，如果我们宁愿追逐这种感觉，以至忘记他的事业，自满就会成为一个问题。

有意思的是，每个人都有沾沾自喜的时候。当我打着这些字，我想起有一天，在美拉扎德埃瑞奇的小屋，他告诉我他变得自满了，是真的。毕竟，服务美赫巴巴是没有止境的。那么，如果埃瑞奇会感到自满，我们又会怎样？

我知道，变得自满使我偏离人生目标。但每当认真思考美赫巴巴关于灵性认识和自由的信息，并重新吸收其中真理时，我发现自己重新充满活力，再次自信地踏上了通往一体性真理的旅程。

译自《世界一体（第三册）服务：为人类的灵性自由而工作》
