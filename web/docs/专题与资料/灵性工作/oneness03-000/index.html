封面

试想，我们能否生而不为人或物服务的——为某个人或某个理想？造物中的每件事物都服务于一个目的，这一功能必然将其与别物联系在一起。理念导向活动；人受雇从事活动；物被用于活动——这一切皆服务某个超然目的。我们可能不把自己的思想和行动看作是服务，但于我而言，存在即服务。若是这样，那么重要的是要认识到，我们的服务描绘出生活，而服务的方式则赋予生活以意义。

现今，人类前所未有地彼此关联。正因为此，人类不得不走出其区域性孤立，走出本能的狭隘聚焦，去关注他人的困境。籍由现代技术，生活的经纬不再是松散的编织，给织线以呼吸的空间，而是紧密交织在一起，以至牵一发而动全身。

这样，这种密织的社会经纬使得大量组织应运而生，社会得以运行。其中之一便是服务机构的过度发展和增长，几乎涵盖了每一种服务目标。在这个服务成为世界性现象的时代，我们是幸运的，那就是，通过追随美赫巴巴，我们的服务冲动指向了他——人身上帝，万人万物之源。

我们怀着极大的热情出发，想要服务美赫巴巴，将自身的服务本能与巴巴所说的无私服务相结合。然而不久之后，不管初衷多好，我们开始经历想象不到的障碍，甚至震惊于服务的受阻。

例如，我们经常发现想要帮助的简单意图被人误解。有时人们甚至认为我们自私，提供服务只是为了坚持自我或自身观点。我们可能会开始郁闷，于自身是全心全意的努力，却显得毫无价值。当这样的障碍继续出现，对于别人对我们尝试服务的反应，我们甚至可能感到痛苦，并最终达到这样的地步，判定为美赫巴巴服务太难了；我们可能会屈就于认为，既然他已不在人身，就不可能为他服务，也不可能为他人之内的他服务。

很可能我们每个人都已经到了这个临界点——甚或已经历多次。我们也许能够咽下挫折继续服务。然而，服务又不损及全心全意之愿，有非常实际的解决办法。我们可以选择参照美赫巴巴有关服务的教言，来检视自身的服务理念，尤其是《语录》中的话语。通过认真比较他的话与自身想法，我们一定会依据巴巴而获得对服务的更深认识。

每次重读《语录》，我总会遇到先前错过的美赫巴巴述及的某个要点；感觉就像再次触及真理。我面临挑战，是改变还是保持旧有的认识？更深入思考时，我看到的是，旧的见解使得自己的灵性生活停滞不前，由此产生的惰性是我在服务巴巴时感到受阻的原因。

举例来说，我们认为在做无私服务，但也感到障碍重重，这使得我们不确定如何继续服务。而翻阅《语录》，我们会发现美赫巴巴解释说，服务中需要的不只是无私。读到这里时，我知道我受到了震动。他接着说，在那些情形里我们缺少的可能是“灵性认识”。将灵性认识付诸行动会逐渐排除障碍，因为现在我们以不同的方式看待事物。

对我们陈旧服务观念的另一个挑战，是美赫巴巴在《语录》中对无私服务的定义。我想，我们中的许多人仍在遵行这个世界的无私服务理念，而非依照美赫巴巴之言。我知道我自己依然天天沦陷。因此，有必要回顾巴巴对此是如何定义的。有鉴于此，重要的是要弄明白我们究竟为何要做无私服务。这会在试行新见解的服务中，给予我们采取不同行动的动力，从而在灵性上得以成长。

美赫巴巴授述过几篇关于服务的语录。它们是“无私服务”、“求道者的条件III——随时准备服务”、“为人类的灵性自由而工作”、“业相的消除II ”、“撒达那的深层方面、“真正的师徒关系”和“灵性认识的途径”。

假如有机会注目一只里面全是珍贵珠宝的盒子，我猜我们会倾倒和折服于它们的美与价值。若从盒子里取出一件珠宝，置于某个背景中，我们就能更好地欣赏赞美之。美赫巴巴在《语录》里的话语——来自真理之源的宝语盒——与此相似。我们可以称颂《语录》独特、无价而优美。与此同时，换个情境来读巴巴的话，由衷地赞叹并领悟其中含义，使我们有额外之机去真正看到其美。重读他的话，我们可能会惊呼:“哦，我不知道巴巴说了那句话！我以前从没读过。”至今我仍然发现自己不时这么说，比如在美赫巴巴日历里看到引自《语录》中的话语时。

认识到服务的生活对我们有多重要，我在这本小册子里所做的，就是从不同的语录中，将美赫巴巴有关服务的话语提取出来，汇集一处，这样我们便可在不同的情境下进行审视：什么是无私服务，为何应该无私服务，如何做到，无私服务的类型，以及具体如何履行。从上述角度看巴巴有关服务的话语时，我们会发现一些令人惊讶的、或被疏忽乃至无视的、与无私服务相关的要素。

我想要着重强调的是，如果未曾认真探索美赫巴巴的教导、从而重新审视自己的服务生活，我的生命会更为贫乏和大不同。事实上可以说，我甚至被基于“克雷格”教的先入为主的灵性观念所自我禁锢。这是毫无疑问的。经过深思反省，他的许多教导已然成为我生活的基本准则。它们为我提供了更新之见，所给予的方向与灵感为我的生活注入活力。当然，与此同时，将它们付诸行动，仍然是日复一日的挣扎。

让我再补充一点，在我看来，美赫巴巴关于无私服务的语录不单涉及无私服务，同时也是积极生活的一份活动与幸福指南。

我希望通过这些材料，你们能像我一样被充实。或许你也会发现，这给了你重新检视自身、行动和生活的机会，从而能够更大程度上做出改变，以便更接近那个已在自己内心的真理。
