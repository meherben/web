朝圣季节

阿瓦塔美赫巴巴的陵墓全年开放。但信托为访问者提供的住宿和大部分其它设施，仅仅在规定的朝圣季节开放，即每年6月15日至3月15日。印度夏季——3月15日至6月15日——美拉巴德的设施关闭。招待所D的关闭时间是3月15日至5月25日。美赫巴巴的家美拉扎德（距美拉巴德15公里）每年从3月1日关闭到6月30日。

美赫巴巴的陵墓：   全年开放

朝圣季节：   6月15日—3月15日

不提供住宿：   3月15日—6月15日

招待所D关闭时间：   3月15日—5月25日

美拉扎德关闭时间：   3月1日—6月30日

美拉巴德

* 美拉巴德是阿瓦塔美赫巴巴的陵墓所在地。美赫巴巴墓地达善开放时间是每天早晨6点至晚上8点。阿提分别在早上7点和晚上7点。在陵墓内及四周要求保持静穆。

* 每月12号日落时度内火在下美拉巴德点燃。

* 每周至少放映一次美赫巴巴影片。地点临时通知。

* 每周一次徒步导游美拉巴德。

* 其它活动节目临时通知。

美拉扎德

* 美拉巴德是美赫巴巴的家。目前大多数满德里的住处。欢迎朝圣者每周星期二，星期四和星期日在规定的时间内访问。星期一，星期三，星期五，星期六谢绝访问。

* 美拉扎德的闭关山极易水土流失。山上树木对土壤和石块起着保护作用。朝圣者要注意爱护。捡山上的石子做纪念，请勿超过一块儿。

美赫纳扎

* 阿瓦塔美赫巴巴信托办公室所在地。位于阿美纳伽。

* 院内阿美纳伽美赫巴巴中心每星期六晚上7点至8:30分聚会。通常有灵性歌曲和音乐节目。

* 美赫纳扎书店开放时间：每星期一至星期六：上午10点至下午12:30。下午3点至4:30。星期日关门。

美赫朝圣者静修所

美赫朝圣者静修所位于上美拉巴德，巴巴陵墓不远处。可容纳200位朝圣人员。男女分住。房间类型有单间，双人间，三人间和四人间。男女分住。每天提供三餐加两茶。全部素食。静修所食宿每人每日490卢比。

如何预定住宿

可用邮件或电子邮件（电子邮件更快捷方便）。回复也是用邮件或电子邮件。临时预定可用电话，但一般不在电话上确认。

怎样抵达美拉巴德

* 美拉巴德位于印度马哈拉斯特拉邦的阿美纳伽郊区6公里处。

* 最近的机场在普纳和阿朗德巴得。从两地坐车到阿美纳伽需要3小时左右。最近的国际机场在孟买，坐汽车到美拉巴德通常需要6个小时。

* 朝圣者中心会提供交通方面的信息。来信联系时请注明您的要求。

注册登记

* 印度境外的访问者，到美赫朝圣者静修所办理住宿之前，要在美拉巴德的朝圣登记处填写公安登记。要求每人带两张护照大小的照片。登记时间是上午10点至下午6点。

* 静修所住宿登记时间是上午10点至下午7点。

* 迟于上述时间者可在附近阿美纳伽的旅馆自行安排当晚住宿。

注意事项

* 衣着：要求朝圣者在朝圣期间穿戴适中。阿美纳伽地区比较保守，当地人不习惯西方或印度大都市的生活方式。因此无论在美拉巴德和美拉扎德，还是在城镇，请穿戴宽松、不暴露的衣服。不适合穿短裤、低领、紧身衣。有些地方可穿至膝的短裤（但不可以在巴巴陵墓周围）。6月到9月要带雨衣。整个朝圣季节，平时清早和晚间可能很凉。需要夹克或毛衣。11月到2月，需穿更厚暖的服装。太阳帽和手电筒也有必要。

* 当地人：请勿向当地人出售物品或者跟镇上的人兑换货币。美赫巴巴爱者来此的目的是朝圣。因此应避免上述交易。由于驻军，阿美纳伽是个敏感地区。朝圣者请勿拍照任何军事场地、设施或建筑。也不要进入军事区域。

* 安全：日落之后，女子请勿单独行走。

* 动物：请勿在美拉巴德喂食或触摸走失动物。

* 物品：静修所给每人提供一个上锁的橱柜。登记处也备有保险箱，可置放贵重物品。请随处注意照管好自己的物品。

* 交通：阿瓦塔美赫巴巴信托免费为朝圣者提供从美拉巴德到美赫纳扎到美拉扎德的交通。静修所和招待所提供有时间表。

* 行为规范：应尊重美赫巴巴的希望，已婚夫妇请勿在阿美纳伽的旅馆同居一室。朝圣者（包括已婚夫妇）请勿公开亲昵（拉手拥抱亲吻等）。以免给当地人造成误解和不良印象。

* 毒品：满德里期望每一个朝圣者尊重美赫巴巴关于禁止使用毒品的指示。违反规定者将被要求离开静修所。
