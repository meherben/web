复活节

复活节的讯息充满哀伤，同时也充满喜悦。它是非常悲伤的一周，因为在星期五主耶稣被钉十字架。三天后，在当今叫复活节星期日的那天，他起来并以不同的方式向他的使徒们显现。

对耶稣的两个使徒多马和巴多罗买来说，复活节是个喜悦的日子，他们看见了他的肉身。一开始多马很怀疑。他在想：“耶稣被钉十字架并埋葬了，他怎么会起来？”可是当耶稣把他身上的钉伤给他看时，多马认可了。巴多罗买，当然毫不怀疑。虽然耶稣为这俩人起来了，世上其余的人则悲恸不已。

主耶稣从墓穴起来，带着这两个使徒离开耶路撒冷。他往下经过缅甸，到达印度。没人知道此事。人们仍然认为，当他被钉十字架时是主耶稣的结束。没人能够理解他的工作，他的神圣里拉（游戏）。

为何主一个个时代降临地球，没人知晓。同一位至古者背负造物界的责任，因为他是第一个知道自己真正是谁的人。造物界的责任落在他身上，他无法推卸自己对造物界的责任。这就是他一个个时代降临地球的原因。他没有在其他行星上采用形体，虽然在浊界有无数个行星。

起来后，主不断地走，行遍印度。他去了阿约提亚，罗摩出生之地。还走到斯里兰卡罗摩杀死拉瓦纳的地方。（罗摩还去了斯里兰卡，而因为他必须带领他的军队，军队就建造了一座桥，他们缩短了距离。主耶稣去了马图拉和温达文，奎师那出生地。）他还去了杜瓦尔卡，奎师那的王国建立之地。他去了鹿野苑，佛陀建立僧团之处。他继续不断地走，去了许多不同的圣地。没人知晓他如何做这些事的。

多马（被称为“多疑的多马”）和巴多罗买跟着他。没有其他使徒知道；连圣母玛利亚也不知道。主耶稣指示约翰照顾圣母玛利亚，他照做了。没有其他使徒知道耶稣被钉十字架之后去了印度。

他继续不断行走，最后到克什米尔的斯利那加。离斯利那加六英里处，有个地方叫哈万。他在那里住了许多年，之后他离开肉身，被葬在哈万的一座山上。至爱阿瓦塔美赫巴巴说过，至古者离开肉身之后，他的显现发生在一百年后。可是在耶稣时代，它用了不止一百年。为什么？原因是他没有在被钉十字架的时候离开肉身。他三天后起来，又来到印度。后来，他用了多年不停地漫游，做他的内在工作。

是什么内在工作？至爱美赫巴巴解释得非常清楚。他说过：

没有开始也没有结束，只有神在其超越超越状态。他既不是有意识的，也不是无意识的。该状态无以描述。当人进入涅槃状态，那是心的寂灭状态。它是完全空的状态，不过那只有一会儿。接着就有意识地体验神的状态。第一个体验该状态的灵魂被称为至古者，他背负起造物界的整个责任。

在神的超越超越状态，他来了心血来潮：“我是谁？”需要无数世纪才能找到“我是谁？”问题的真答案。至爱阿瓦塔美赫巴巴以故事的形式予以解释。有两个故事。一个叫《淘气的小鸡》，一个叫《两个国王》。在《无与有》书中，我写了这两个故事。我还在该书中写了关于亚当与夏娃的故事。这个故事也是关于造物界中幻相的开始与结束，虽然它以不同的形式。另外，我根据吠陀经写了（象头神）伽内喜的故事。所有这些故事都描绘了创世的同样主题——虽然故事有不同形式，人们不理解这些故事。伊斯兰世界里，还有另一个故事……不过它们都是同一个…(关于希瓦，宝表示巴巴曾告诉他们类似的故事，但他不记得了。)

故事背后的真理，没人知道。知道者，自己成为秘密。为了让灵魂知道该秘密，造物界得以产生。我们说，海洋有不计其数的水滴，可我们不知道每一个水滴就是海洋。当他知道“我是海洋”时，他成为秘密。

这个水滴形体是什么？神是不可分的，神是独一者。神无法分割。在每个水滴里，神在那里，完整不分。但是为了回应心血来潮的“我是谁？”问题，心产生了。幻相何以维持？它维持是因为我们制造的业相。只要业相在心里，我们就留在水滴形式中。一旦业相被清除，心被歼灭，我们就是海洋。这就是秘密。

被钉十字架后，主耶稣从安放他的墓穴起来。他活在身体里许多年，在印度不同地方漫游。最后，在克什米尔的哈万离开肉身。之后，他的显现用了一百年。那就是为何在主耶稣生平里，我们发现它用了不止一百年时间。为何如此？因为他没有死在十字架上。主起来，他还去了印度。

复活节是非常重要的日子，因为是它示现了主耶稣的荣耀。他多么隐蔽地做宇宙工作。可许多见过他的人，即使从远处，都会感到他的非凡。这就是印度有许多基督徒的原因。他在做什么？为了意识的进步，他从每个人身上收集那些制造障碍的业相。

“我是谁？”问题在每个水滴里面，每个水滴都在寻找对该问题的答案。这一寻找制造了善恶业相。它们是非自然业相，因为它们是束缚。那些为了回答该问题制造的业相被称为自然业相（印象）。这些业相存留在浊界。一个人通过浊意识体验它们。实际上，从石头至动物形体，业相几乎都是自然的。但是在人类阶段它们变得不自然，因为在浊界中欲望与需求增加了，浊意识仍然强烈。那就是为何在浊界，尤其在地球，一个人只能体验到神性的百分之一，如果此人爱神，以全心信仰跟随神的话。在许许多多世纪之后，那时仍爱神，浊业相被清除。精业相留存在精界；行为和思想是精（形式）的，有精意识。在心界，心业相留存；思想和行为是心（形式）的，有心意识。

不过，从心界的第六层面，那时人体验到神的无限光辉，焦渴变得难以想象。灵魂穿越心界，经过涅槃之后，知道了自己不是别的，正是神。

复活节给我们的真正讯息是什么？它告诉了我们，我们应当全心爱神，顺服他的希望。那时我们才能以极乐、知识与能力的形式享受神的无限喜乐。主耶稣从墓穴中起来，是为了清除那些阻止意识遵从“我是谁？”心血来潮继续进步的业相障碍。

至古者一再降临地球上，是为了不断的受苦，他受苦是因为他拿走了阻碍意识进步的束缚性业相。他来到地球是为了给予宇宙性推进，因为从石头到动物界自然进步的较低王国，被人类采用不同科学手段所剥削。这是一个较低王国的意识被严重剥削的时代，因为这是一个大时间周期的结束。有那么多的科技发展，由于它们的使用，造成较低王国的意识停滞不前，无法前进。这就是为何至古者降临地球，以便清除——给遵从“我是谁”的心血来潮从石头到人类的意识进步造成障碍的——这些不良印象。这被称为宇宙性推进。

人们认为主耶稣在十字架上受难，但是没人知道，在他的十字架刑之后，他经受了多么巨大的苦难。要收集这些障碍性的印象是无限艰难的。唯有他能做到。至师也无法做这样的工作。他经历了意识的进化及内化，然后证悟神，他又通过心、精与浊界下降到造物界意识。

至古者已经历意识的进化及内化，获得成道，然后他下降到造物界意识。他是第一个，永远是这第一个至古者，直接下降到造物界意识，直接从神状态降入人身。神圣计划是一个十分确定的计划，至师也不能修改或改变。唯有基督或者说阿瓦塔能够做任何改变，不过它很少发生，因为它是一个十分确定的计划。

地球上总有五位至师，他们按照神圣计划工作。当需要宇宙性推进时，至古者不得不作为阿瓦塔、基督或先知直接下降。他给予宇宙性推进。阿瓦塔给予宇宙性推进，而至师不能。阿瓦塔或基督成为万人万物，而至师只是扮演。举个例子，如果至师表现出生病，他只是扮演。他并不是真生病。而阿瓦塔实际生病。他下降到意识的每一个层面——对于人类，他作为人；对于动物，他成为动物；对蚂蚁，他是一只蚂蚁。他处于意识的每一个层面。他的角色，唯独他能担任。没人能担任他的角色，即使至师也不能。

复活节给了我们这样的讯息，它让我们深情地、诚实地、真挚地、全心全意地服从神的希望，从而使他的负担轻些。当我们服从他的希望时，他感到多么宽慰啊，可当我们没有服从他的希望时，他受苦更重。所以说要“俯首顶拜他的足，决不抬起，直到心走掉。”不是指一个人应该用身体这样做，而是应当毫无疑虑、百分之百地服从他的希望。可能会怀疑，假如来了，别担心。下决心全心全意地服从他的希望。

1957年发生一件事，当时哈里·肯莫尔（ Harry Kenmore ）医生来到美拉扎德。他是纽约来的盲人脊椎按摩师。他听到至爱巴巴的（车祸）事故后，直接来美拉扎德。他听说， 巴巴因事故忍受着疼痛。巴巴允许他为自己治疗，于是肯莫尔医生在满德里大厅摆置了按摩桌。每当巴巴早上来到满德里大厅，他会给他治疗。开始两天，巴巴会表现得他很愉快。

于是他会来提供治疗，不过会问：“巴巴，疼痛怎样了？”
巴巴会说：“比昨天更疼。”

对此他想了又想。“巴巴的疼痛为何加剧？”整天他会很难过，夜不成眠，坐立不安。次日早上又来，对巴巴说：“巴巴，您的疼痛怎样？”
巴巴说：“比昨天更疼。”

肯莫尔医生心烦意乱。他想：“我是来为巴巴减轻疼痛的，可我给他减轻了啥？我使他越来越疼。”他非常难受。之后，他去找埃瑞奇。他眼里含着泪。埃瑞奇一开始以为他一定是因为爱而流泪。

他静静地流泪，埃瑞奇看着他。接着埃瑞奇问他：“你怎么了，哈里？”
他说：“我非常悲哀。我原以为我会减轻巴巴的疼痛，为此我来这里。可我没有减轻，反而增添了巴巴的痛苦。”

埃瑞奇说：“不，哈里，你爱他。我们都明白，巴巴也明白，不是这样的。”然后他讲了有关奎师那与纳姆德乌（ Namdev ）的故事。

本特尔布尔有一座神庙，里面有个叫纳姆德乌的信徒。他不分昼夜地待在奎师那的神像旁。他母亲、兄弟、姐妹或父亲会把食物送庙里来。他会待在那里；哪里也不去，每时每刻都念着：“维托巴，维托巴，”（意思是“奎师那，奎师那”）他吃得很少，但一整天不断地念着：“奎师那，奎师那，奎师那……”

一天食物送来后，他对奎师那说：“奎师那您先吃，除非您吃，否则我就不吃。”
他等了很久，没吃，因为想让奎师那先吃。后来发生了什么？奎师那的神像吃了食物！人们为他的虔诚而深受震撼。

哈里从埃瑞奇那里听到这故事，就想：“看看，纳姆德乌使神像吃饭！他有怎样的爱啊——我啥也不是。我只是在表现我爱巴巴，可是我没有爱。”一整夜都没睡着。第二天，他忧心忡忡地去巴巴那里。

巴巴看着他：“你为啥发愁？昨晚睡了吗？”

哈里回答：“没睡。我不过自以为爱您，可我不爱您。纳姆德乌，他的爱如此之深，使神像吃饭。可是像我这样的人，只增添您的痛苦！”

巴巴笑道：“哈里，你知道我为何受苦吗？你明白吗？我承受着这个痛苦，我承受着负担，这就是为什么我从事故中获得这份痛苦。当我的工作完成后，这个痛苦将消失。它不需要任何治疗，而因为你是来为我治疗的，那是你的爱。但不要期望你自己想要的任何结果。留给我吧，我会满意。

“爱寻求至爱的愉悦，而虔诚寻求自己想要的。爱和虔诚之间有着天壤之别。纳姆德乌使奎师那的神像吃饭——那是他的愉悦，而非奎师那的愉悦。你在治疗我，我很快乐。为何我给你这个机会？因为治疗我是你的愉悦。但不要寻求结果。时间一到，我的痛苦将消失。你将看到。”

复活节给我们机会想起至爱的希望，并实践它，那就是爱。关于复活节，我只能说：“至爱啊，让我们值得服从您的希望，寻求您的愉悦。您为整个造物界受苦，所以若我们遵守您的希望，才是从内心庆祝复活节。我们一定要爱您，始终不渝地献身于您的希望。这是您的要求——我们必须服从您的希望。”

这份决心将使我们不用外在形式庆祝复活节。吃好，睡好，要快乐，但保持这份坚定的决心来服从他的希望。那是我们的真正复活节。

（2006年宝·喀邱瑞讲述）
