《美赫主》是阿瓦塔美赫巴巴的20卷传记，英文版共6742页。

1968年10月，巴巴授述指示，要求写一部传记，其中包括五位至师的生活。1969年1月巴巴离开肉身后，宝·喀丘瑞着手为传记收集资料。此后至1972年12月，宝写了《美赫主》，《无与有》及其它书。他每天工作15至18小时。《美赫主》几乎逐日地详细记载本时代的阿瓦塔美赫巴巴的生活及工作，附有大量珍贵照片。
