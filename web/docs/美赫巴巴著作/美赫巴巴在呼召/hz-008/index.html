64 发现我是你自己

你必须时刻牢记，唯一值得牢记的事是：忘记别的一切，记住我，以便能爱我，之后发现我即你自己。

我比你自己的呼吸离你还近。想着我，我便与你同在，我的爱将引领你。我是人类中总是被失去并找到的那一个。你对自己的爱失去我，你对我的爱找到我。爱我超过一切，因为现在我在你们中间时，最容易发现我的真相。

如果你想对神有任何了解并得到他，就紧紧抓住巴巴的衣边。如果你在乎神，在乎爱，渴望与神结合，唯一的办法就是紧紧抓住巴巴。

65．不要感到无助

如果你认识到神在你里面，而且知道神是无所不能的，那么你一定也是无所不能的。那为什么你还感到无助？我永远是同一个永恒者，在一切万物中；因此，你们所有的人也都是神；而你却感到那么无助。这是为什么？是因为有某种面纱把你与神隔开。你自己就是面纱，你要揭去它——你自己这个面纱——是不可能的。 你很小的眼睛能看到广阔的景象和其中包括的所有事物，可它们却无法看见自己。要看见自己，需要一面镜子。因此，当我的恩典之镜降临时，你的真我瞬间就会显示出来。

你必须让自己彻底淹没于我的爱海，就会在那里发现我的恩典。

66．我也许什么都不给你

我也许会给你更多，远远超过你所期待的，或许什么也没有，那个什么也没有也许就是一切。所以我说，怀着敞开的心来，从神圣至爱那里接受许多或什么也没有。

与其来接受我的话语，不如接受我的沉默。

神做一切，在另一种意义上什么也不做。虽然神什么也不做，但那些怀着爱和臣服来接近他的人，则获得在灵性领域重要的一切。

你，是我可信赖者之一。我明确向你保证，你将永远和我亲近，直到与我结合。你还要什么？还有什么可要的？我对你谈的不多，因为这不言自明。你知道。这在内里。

67．紧紧抓住我

当我下降到你们的层面时，由于这造成的熟悉和亲密，你们完全忘了我的神性——忘了我知道每件小事。我和你们大家坐在一起，询问你们的健康等等，你们忘了你必须告诉我每个细节，同时你们又忘了我知道一切。

让你们的心灵对巴巴所决定的一切保持纯洁。不要让误解萦绕不散。如果你们都有爱并相信我是阿瓦塔——我确实是，那么你们必须听从我，必须爱我。如果你们没有做好服从我的准备，或者有怀疑并希望实现自己的意愿，那么你们必须离开我。你们如果爱我，就必须紧紧抓住我。

68．分享我的意识

我在每一个层面与你一体，但只有当你的自我和智力不干涉时，你才知道这点。那时巴巴就会现出真相。

当我以神圣权威说，实在的一体性是极其绝对地无限与遍在，在此无限不分的一体中，不但“我们皆一”，就连这个集合名词“我们”都无一席之地。

我永远意识到我在你里面；而你从来意识不到我在你里面。日复一日，我支撑你并分享你的意识。现在我要你支持我，以便有一天你能分享我的意识。

出于经验的成熟，通过个体心的溶解，灵魂进入神圣生命的一体性。

69．真爱

如果有什么会触动我的宇宙心灵，那就是爱。

爱与强制永远不能并行，可是虽然不能把爱强加于人，却能通过爱本身来唤醒它。爱在本质上是自我传递的；没有爱的人从拥有爱的人那里感染到它。从别人那里接收爱的人，不可能只是接受者而不给予回应——这回应本身就是爱的性质。

真爱不可战胜，不可遏制，且不断集聚力量，传播自身，直到最终转化其所触及的万人万物。通过心与心之间纯爱的自由无碍互动，人类将获得一种新的存在方式。

自从第一次降临，我唯一重申的就是：爱神。一个又一个时代，我唯一所说的就是：爱神。

70．照我说的做

假设我说：“别担心你的孩子！”你一定要相信我的话，把它视作来自神，因为我就是那。神这个词意味着什么？神一定知晓一切，做一切。因此，当他说“别担心你的孩子”时，这意味着你不必担心。假设我转动钥匙，明天发生地震，五分钟之内你们全部消失。那你的种种烦恼、家庭和孩子该怎样？所以，我说“遵照我的话”——无论我给你什么指示。唯一需要的就是这个。照我说的做，把其余的交给我。但要照我说的做。

我不关心你拥有的种种资历。我希望你拥有的唯一资历是爱。爱我，我就对你满意。

71．我的宇宙宗教

当我的爱之宇宙宗教日趋式微时，我来给它注入生命，并且结束以宗教的名义玷污它、用仪式教规窒息它的教条闹剧。

我来把爱的种子播在你们心中，以便通过爱在世界上所有国家、信条、宗派和种族之间建立一体感。

世界所有的宗教都宣称，只有一个神，造物界一切众生的父亲。我就是那位父亲。

我不属于任何一个宗教。每一个宗教都属于我。我的个人宗教是我作为至古无限者，我教导众生的宗教是爱神。

72．唤醒者

我不是来创建任何的新事物，而是把生命注入旧事物。我不是来建立静修院或修道场。我为了我的宇宙工作而建造它们，一旦目的达到，即刻拆除。

我意欲把所有的宗教和派别集中一起，像珍珠串连在一条主线上，为个人和集体需要给它们重新注入活力。

我的讯息一直是，将永远是：神爱。让全世界都知道这个。

我不是为摧毁幻相而来，因为幻相什么都不是。我是来让你们认识到幻相的虚无性。通过你们，我维持那只是我的无限大我之影的幻相；通过我，你们在体验其虚妄性时抛弃幻相。

要勇敢，要快乐，我和你乃一体。那永恒属于我的无限，有一天也将属于每一个人。
