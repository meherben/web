55．完全信任我

如果你对神有磐石般的信，有火焰般的爱，那么世上就没什么能影响你。痛苦无法折磨你，谄媚无法触动你，快乐无法取悦你。这种信和爱会使你超越虚假的现象，让你认识到唯有神真实。

完全地信任神，祂会解决一切困难。忠实地把一切交给祂，祂将照管一切。真诚地爱神，祂将向你显示祂自身。这种爱无需仪式和炫耀。你的心必须爱得连头脑都意识不到。

不要让任何东西动摇你对我的信心，你的一切束缚将被摇落。一旦展开羽翼飞翔，你必须像天鹅一样直飞。不要像麻雀那样在树间飞来飞去，否则许多事情将在道路上使你分心。

56．不要害怕苦难

你应当把身心痛苦看成神的礼物。它们带来了自身的教训：短暂事物的徒劳无益和永恒生命的内在价值。

当逆境、灾难和不幸扑面而来时，不要气馁惊慌。要感谢神，给了你培养忍耐与坚韧的机会。那些获得忍耐逆境之毅力者，能够轻易进入灵性道路。 

不要害怕受苦或把它归咎于别人。按照统驭宇宙的律则，一切的痛苦都是你的爱之劳动，旨在揭开你的真我面纱。与你获得“我是神状态”时所体验的无限喜乐相比，你所经历的一切痛苦与折磨根本算不上什么。

57．内心纯洁

为了净化心灵，不要去管念头，但要对行动保持警戒。当你产生愤怒、淫欲或贪婪的念头时，不要为之烦恼，不要试图制止。让所有这些念头自来自去，不要将之付诸行动。努力想相反的念头，以便看清、辨别、认识和——最重要的——消除那些由于你的印象所引起的行为。

如果有人待你不诚实，给你制造麻烦，欺骗你，而你却保持诚实与纯洁，你是很幸运的；因为这些骗子或所谓的敌人，乃是你的朋友。他们洗掉你的罪恶与弱点，清洁了你走向神的道路。

58．传播我的大爱讯息

那些真正爱我者是我在世界上的“中心”。让每一个巴巴爱者，无论他或她在哪儿，都成为一个“巴巴中心”化身，散发永恒的神爱讯息，过着爱、牺牲和诚实的生活。

当你向人传播我的永恒大爱讯息时，首先向他们示现你真正爱我。不要只是让他们读我的书和讯息。做多点——活出这种爱、牺牲、宽容和忍耐之生活，这样其他人才会爱我。如果不做真正的爱的工作，反而开始为我做组织宣传工作，是荒谬可笑的。我不需要宣传或广告。要是你不能过爱和诚实的生活，就应当停止为我工作。

为我工作者不是在为我，而是为他自己工作。

59．渴望与神结合

要渴望一样东西，为一件事骚动不安；要渴望一个会消灭千百万其它渴望的东西——渴望与至爱结合。你应当沉迷于不惜一切拥有至爱的想法。当你在内心深处准备好，要以生命和全世界嘲笑为代价，来获得与神结合时，也许可以说你已进入神爱轨道。

即使渴望与至爱结合也制造束缚。因此，不要为分离或结合烦恼——只是去爱，更炽热地爱；那样你能把自己和道路交给至师——他就是道，你会经历逐渐的转化，自我肯定越来越少。那时无论至师叫你做什么，你都能做到。

60．谋取神性

你能以额上的汗水谋生，也能用心中的血谋取神性。

除非变得像尘土，否则你就不能证悟神。但首先你得变得像石头，因为你不能马上变成尘土。所需要的是保留人类意识并且变得像石头，然后在至师足前把你自己磨成尘土。

要受自由所束缚——要执著于超脱。那意味着有欲望——但做它们的主人而非奴隶。

为自己活着的人，真正死了；为神死去的人，真正活着。

61．在我面前

想我在场时你会毫不犹豫想的事；说我在场时你会毫不犹豫说的话；做我在场时你会毫不犹豫做的事。

是你的妄我用它所知道的每一种诡计，使你远离你的真我。在诚实的外衣下，这个自我甚至欺骗它自己。比如说，你的自我宣称“我爱巴巴”。事实是假若你真的爱巴巴，你就不会自己做这种自我声明! 这个自我，非但没在爱中被消灭，反而相信并宣称“我”爱巴巴。

坚强生谦卑，故作谦卑意味着懦弱。唯有真正伟大者才能做到真正谦卑。

62． 爱神的途径

爱。如今人人都用 “爱” 这个词；它已被用得极其廉价。一个人如果真的爱，就不会发出那个词。爱神意味着什么？这是一件非常、非常伟大的事情。神的真正爱者什么也不说。他忘了他爱神。

将怎样爱神？该怎样爱神？不是通过所谓的祈祷或其它事情。有两种方式。一种是离开万人万物。那意味着你一无所有，甚至自己的身体——彻底放弃一切。一切的意思是不但身外之物，而是一切事物，包括你自己。

第二种是很了不起的事。你不必放弃任何东西。过你的家庭生活，活在世间，做你的工作或生意，做礼拜、看戏赴宴，一切事情。但要始终做一件事！不断地想，不断地努力，让他人快乐，即使以自身幸福为代价。

63．在地上体验天堂

神是无限能力、无限智慧、无限爱、无限仁慈与无限喜乐，他住在你们每个人内。在你们每个人内，还住着所有这些无限品质的似乎反面，比如无助、无知、淫欲、残酷、痛苦等等。渴望上帝者发展同情、无私与克己之舍弃。追逐短暂幻影——欲望对象——者则培养自私、贪婪和仇恨。前者给人间带来和平；后者带来战争与毁灭。放弃低级及不必要的欲望，你就会在人间体验天堂。

巴巴希望他的所有爱者认识到，不屈从淫欲，非常重要。诱惑是并将是巨大的，但你对他的爱应当更大。全心全意想念他，从你跌倒的地方迅速站起来，在他的爱和服务里前进。
