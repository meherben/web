卡比尔是诗人也是至师。其诗集《卡比尔瓦尼》（Kabirwani）因对神、爱神、神圣道路和幻相宇宙的清晰阐述而甚为独特。作为至师，卡比尔为入道者也为市井凡人开示。用譬喻和浅白的语言，毫不犹豫地揭示了一些灵性秘密。这些秘密虽在普通人的理解范围，但却只为灵性开悟者所知道，因为唯有他们真正了解他的大多数言语的深义。

有的修炼密法的瑜伽士能够在暂时入定（samadhi）期间让自己身体悬空；有的能够不靠外部工具在水上行走或在空中飞行；但这些都不是体验神爱的标志或证明。在灵性天平上这些奇迹都毫无价值。事实上，一般瑜伽士所兜售的奇迹不仅与灵性道路大相径庭，实则是对个人灵性进步的障碍。如下故事就足以说明作为真理化身的至师对奇迹的漠视：一天，有位印度教大师在河边候船（乘客只需付小小的一安那就被摆渡过河的小船）。一位瑜伽士看见大师这么等侯，便走过来，在水面上走了个来回，说道：“这不容易多了？”“是的，”大师笑答，“而且价值低于区区一安那的船票。”

能够不断行使对自身低级欲望的控制，乃是非同小可的成就。获得对一切欲望的持久升华，成就的确更伟大。然而最伟大的是永远地烧毁全部个人欲望，而这唯有神爱才能做到。因为神爱从来没有丝毫炫耀，所以这种在爱中“燃烧”总是“无烟的”——不炫耀。神爱的外部表现有的时候也许等同于英雄主义，但是在任何时候仅仅为炫耀而卖弄自己对神的爱，则无异于对神的污辱。这就是为什么卡比尔说，你采用某种姿势静心想神时，应避免诸如摇摆身体之类的表演，即便那仅仅是为了自身的满足。

与梦相比，物质生活确实是一种现实。而同道路现实相比，世界及一切世俗生活同样是人做的空梦。但就像世界及其体验全都虚幻不实，引向实在的灵性道路也一样。前者可被称作假幻，后者可被称作真幻。尽管两者之间差异巨大，但却都是幻相，因为只有神是唯一的实在。

真知被获得时，无知被驱逐。而要让无知离开，就必须获得真知。一方面，神和人见神成神的能力一直在。另一方面，真理向人隐藏着，一直到他实际踏上道路或者证神。这种明显反常归因于两个不同因素：人对真理的无知；真理超出了推理能力并且远远高于智力领域之事实。不过事实仍然是人曾成为神，人能成为神。原因很简单：人是神，不管他知不知晓。只因人的无知继续，才似乎有无尽的多种多样虚幻事物。获得神圣知识时，人认识到神的不可分割一体性是没有止境的。人与神在宇宙二元幻相下的貌似分离总是被大师们称作“面纱”或“帷幔”。至师兼大诗人哈菲兹说：

“在爱者与至爱之间没有屏障；哈菲兹，

将你自己挪开，你才是大我上面的盖布。”

关于揭开七折的面纱，卡比尔如是说：

“揭开自己的贡哈特，你就会发现神。”

贡哈特（Ghunghat）的字面意义是指妇女蒙在头部和脸部的面纱；面纱有几折，灵性上代表对人隐藏真相的层层厚重无知。一折一折揭开面纱，相当于行道者从神圣道路的第一到第五层面逐级行进。

这个将“愚昧中人”与“全知之神”隔开的面纱极其精微，甚至连最高最细的念头都无法穿透。这个面纱有七个折，分别由七种深暗颜色构成。每一折打着一个结；因此七个折共有七个结。七色代表七个根本欲望，相当于七个基本印象——淫、贪、嗔等，并涉及到面部的七窍：（1）口，（2）右鼻孔，（3）左鼻孔，（4）右耳，（5）左耳，（6）右眼，（7）左眼。

灵魂在实在中并作为唯一实在永远是神，无始无终。假幻始于灵魂以七个物质阶段的下降，真幻止于灵魂到第七个灵性层面的上升。

神是大宇宙，神是小宇宙，神又永远超越二者。自觉地，人是身，人是心；但不自觉地，人还超越了身心（如在酣眠中）。

从类比的角度看，人确实是按神的形象创造的。头顶代表最高灵性状态（vidnyan bhumika或arsh-e-ala）或者说大梵（Brahman）之位。前额相当于神性入口。额中心（就在两眉中间）是内眼或称第三只眼的位置。当面纱及其七折最终全部揭开时，人就能够通过第三只眼面对面见神，这比他平时用肉眼看自己的身体和世界还更真实自然。为了达到位于前额的神性入口，人必须经过由面部七孔代表的七道门。

当求道者成功地实际进入神圣道路时，这对他是一种“七合一”的成就，应用到七折面纱的第一折，就是：（1）第一个结的解开，（2）第一个折的消失，（3）第一个根本欲望的歼灭，（4）相应根本印象的消灭，（5）第一种深暗颜色去掉，（6）通过第一道门（由口代表），（7）到达精领域（pran bhuvan或称alam-e-malakut）的第一个层面。

一般人在梦里能够通过精意识部分地利用精体，但这仅仅关系到浊体验，仅仅涉及到浊对象。第一层面的入道者开始通过精体用精意识来体验精界，正如他通过浊体用充分的浊意识体验浊界那样。

入道者若能继续前进并保持进步，会在精界继续行进到第四层面。这种进步涉及到类似第一个七重结果的第二和第三个相继的 “七合一”成就。穿过（由右鼻孔和左鼻孔代表的）第二和第三道门带来真幻相的更大强化，也就是带来更高级的道路意识。入道者通过第二道门之后，获得对精界更奇妙的体验，同时开始面对可能迷失于奇异迷宫的危险。过了第三道门，道路的神秘魅力还更大，被迷惑的机会同样增加。就像有浊意识的人把浊领域及其虚幻的体验视为真实，沉浸于精领域奇观的行者也同样可能错误地把自己所处的层面视作终极实在。因此行者往往陷在某个层面，被狂喜迷惑，错误地把这个层面视作目标，一直到至师或者甚至是一位有心意识的灵魂施以帮助，把他推到下一个层面。

第四个“七合一”成就是双重成就，因为同时（1）第四和第五个结解开；（2）第四和第五个折消失；（3）第四和第五个根本欲望粉碎；（4）第四和第五种深暗颜色消失；（5）第四和第五种相应的根本印象消灭；（6）通过第四和第五道门（由右耳和左耳代表）；（7）行道者到达精领域的最高层面——第四层面。

如前所述，第四层面是灵性奇观和神圣能力（anwar-o-tajalliyat或称siddhi）层面。前进至此的行道者除了能够做许多其他事情之外，甚至能够起死回生。面临着滥用这些能力、从而招致灾难的严重危险。只有极少数人能不靠至师帮助，独立地安全通过这些令人眩晕的高地。关于他们，哈菲兹这样说：

“在至爱的门槛上，要当心天堂的诱惑，

以免从崇高宏伟巅峰跌入堕落毁灭深渊。”

在这种情况下，一个人不仅被剥夺掉在道路上所取得的灵性进步，还从他通过生理进化而达到的位置上被抛回到石形体状态。

对一个在漆黑的夜里行走未知路径的人，什么事情都有可能发生；对一个没有至师引领而必须经过第四层面的人，同样什么事情都有可能发生。这就是为什么基督密教把穿越第四层面的期间称作“灵魂暗夜”——尽管这个层面充满眩目奇观和能力*。

[*第四层面的能力对行道者就像公认的引人误入歧途的“魔鬼”。若非赛古鲁奈安涅希瓦（Dnyaneshwar）的及时帮助，大瑜伽士禅狄瓦（Chang Deva）就会在这个层面惨遭劫难。巴巴·法瑞得· 甘吉-夏喀（Baba Farid Ganje-Shakar）到达这个阶段时，同样也忍不住令飞鸟死掉再又复活，以此检验自己的能力。他也是及时地被一位第五层面的老妪挽救的。就是在这个事件之后，巴巴·法瑞得才与自己的大师建立密切联系。大师引领他最终达到库特博亚特（Qutubiyat）也就是至师状态。]

高级行道者如果真的能够抵制灵魂暗夜的诱惑欺诈的话，就会取得（类似于第四个成就的）第五也是最后一个双重“七合一”成就，进入心领域（mano bhuvan或称alam-e-jabrut）。现在面纱的折全部揭开，连同相应的扭结、欲望、颜色和印象；通过第六和第七道门（由右眼和左眼代表），到达光与爱的第五层面。

安全抵达第五层面的人是瓦隶安拉（wali Allah）——神的朋友。现在，内在视觉（第三只眼）得到充分发展。然而即使面纱的七折全部消失，但面纱本身依在。因此行道者尚未面对神；看不见至爱。

因其未受妄我玷污的对神的纯爱，第五层面行者的位置是安全的，没有倒退的可能。能够并且确实，有意识或无意识地，对精界和浊界的人给予巨大帮助，又不会给自己造成任何危害。

现在，除了罕见的例外，单靠自己是不可能取得进步的。通过至师的帮助（恩典）就能完全揭去面纱，到达第六层面：心领域最高层面，“见神”层面，神性入口（由前额代表）。在此，人能够实际上面对面看见神无处不在，无物不在。这被称作“视见确信”。

浊领域相信神存在的人将确信建立在单纯的信心和信仰之上。这是理性确信（ilm-ul-yaqin）并有别于如下几种确信：

（1）直觉感知确信（yaqin-ul-yaqin）；

（2）视见确信（ain-ul-yaqin）；

（3）实证确信（Haqq-ul-yaqin）。

直到第五层面，行道者通过明确的直觉肯定（yaqin-ul-yaqin）而知道有神；其确信建立在确定知识之上。第六层面行者见神无处不在；其确信基于实见。第七层面者通过与神合一，将确信建立于实证之上。

第六层面的高级行道者仍然在二元领域之内。虽然面对着神，但是“见者”与“被见”依旧被一个不可测量的深渊隔离，唯有至师的点触才能帮助他跨越这个深渊。虽然人有可能独立地获得前五种成就，但是在第五层面实际上揭去面纱，通常需要至师引领之恩典才能完成。不过从第六层面的幻相跳跃到第七层面的实相，单靠自己是不可能完成的；这完全依赖于一位完人或者至师（赛古鲁）的直接点触。

在第七层面之无限知识、能力和喜乐层面，个体融入神并成为神：在一切时间并且超越一切时间的完人。这时保留还是放弃肉身已经无关紧要。一般来说，浊外壳在成道后的短时间内脱离，但在有些情况中，肉身则持续很长时间。这些成道者被称作玛居卜（Majzoob）或者卜拉弥卜特（Brahmi Bhoot）。

而且，也只有靠至师的直接和亲自帮助，那些成道者中间才有一个回到普通人的层面，重新获得对所有（浊、精、心）领域的意识，同时完全保留神圣意识。他现在是人神、至师、赛古鲁或者说库特博。

有光明处，黑暗不再。有知识处，无知不在。由于面纱的折、面纱以及分离深渊全都属于无知领域，因此至师，作为全知“真阳”，能够在眨眼之间，把成道赋予任何一个被他所选之人*。
