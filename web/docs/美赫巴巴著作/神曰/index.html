题词

神曰 创世及其目的主题 美赫巴巴著 题词 献给宇宙—— 维系实相的幻相

卷首语

我不是来建立任何的教派、社团或者组织；也不是来建立新的宗教。我将提供的“宗教”，教导的知识是“多”后面的“一”。我将让人们读的书，是掌握着生命奥秘钥匙的心灵之书。我将带来头脑与心灵的完美和谐。我将给所有的宗教和宗派注入新活力，把它们如珍珠般串在一条主线上。 美赫巴巴
