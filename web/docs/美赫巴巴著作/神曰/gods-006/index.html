第六部 神圣意识状态概述

为体验帕若玛特玛，阿特玛（灵魂）采用人体并获得所渴望的全意识。然而阿特玛还是不能体验帕若玛特玛；因为即便获得了全意识，但只要该意识仍然集中于浊印象，阿特玛就不得不意识到浊体，从而必须体验浊界。

没有人体，阿特玛就不可能获得对精体、心体以及对大我的意识。同样也不可能积累对精界、心界和对帕若玛特玛的体验。要进化意识、进化形体并体验浊界，浊业相（印象）则绝对必要；而只要有浊印象，阿特玛就意识不到精体与心体。

在人类形体，由于完全意识的进化，由于人类形体这个完美形体的进化，由于对浊界的充分体验，已经不再需要浊印象。浊印象可以成为精印象，精印象可以成为心印象，心印象可以消失。所以在人类形体，阿特玛可以获得对精体、心体和对阿特玛本身的意识，对精界、心界和对帕若玛特玛的体验。但不幸的是阿特玛在人类形体获得全意识之后，不是立刻获得对精体、心体和大我的意识；同样也不体验精界和心界，不体验帕若玛特玛。这是因为阿特玛在人类形体获得全意识后，浊业相不立刻成为精业相或者心业相，也不立刻消失。原因是当最后一个动物形体创造的第一个人类形体被放弃时，第一个人体的印象被遗留下来，每一个随后出生的人体皆由上一个人体的业相构成。因此，只要浊业相存在，阿特玛虽然有全意识，但是还要多次采用人类形体。

最终，两种情况之一发生：阿特玛的浊业相可能会突然全部消失，阿特玛失去对浊体的意识并获得对大我的意识，从而失去对浊界的体验并获得对帕若玛特玛的体验。或者第二种，也是可能性更大的情况是，浊业相终于衰弱，成为精业相；精业相进一步衰弱，成为心业相，最后心业相衰弱，以至消失。在这种情况下，阿特玛首先失去对浊体的意识和对浊界的体验，获得对精体的意识和对精界的体验。之后阿特玛失去对精体的意识，获得对心体的意识；失去对精界的体验，获得对心界的体验。最后阿特玛失去对心体的意识，从而获得对阿特玛本身的意识；失去对心界的体验，获得对帕若玛特玛的体验。

在获得大我意识并体验帕若玛特玛之后，阿特玛继承三个状态之一（一定是三个状态，而不是两个或四个状态）：

第一状态A：在上述高之最高体验之后不久，阿特玛通常放弃所有的（浊、精、心）幻身，永恒享受总体的个体化体验——神的无限能力、知识和喜乐——但不使用这些属性。

第一状态B：阿特玛也许过一段时间才放弃三体，尽管对这三体完全没有意识。除了保留三体，其状态实际上与“A” 同样。

第二状态：阿特玛保留三体，但同时还通过大我意识，意识到三个幻影（浊、精、心体），并且同时体验神的无限能力、知识和喜乐。阿特玛还把浊界、精界和心界体验为神的影子，但是不使用神的能力、知识和喜乐来帮助心意识、精意识和浊意识阿特玛，因而是独立的。

第三状态：同第二状态完全一样，唯一区别是阿特玛利用其无限能力、知识和喜乐，让浊意识阿特玛获得精意识、精意识阿特玛获得心意识、心意识阿特玛获得大我意识；甚至一举让浊意识阿特玛获得大我意识。

精体和心体在人体中的充分发展与意识内化

只有在人类形体，精体（普拉）和心体（末那）才得到充分发展。因此阿特玛即使有浊意识，并且意识不到普拉和末那，但是也能通过普拉和末那（非直接地，在浊层面）工作。有浊意识的人体阿特玛即使意识不到普拉和末那，因而不能认识能量和心，但也能够通过能量的不同方面（比如核能）来利用能量，能够通过心的不同方面（比如思想、欲望和感情）来利用心。

在人类形体，阿特玛有精意识时，意识不到浊体（夏里亚）和心体（末那），但却通过夏里亚和末那（在精层面，非直接地）工作。因此有精意识的人体阿特玛即便意识不到夏里亚和末那，因而不能认识浊界与心界，但也能通过浊的不同方面来利用浊体，比如吃、喝、睡、视、触、听等，并通过心的不同方面来利用心，比如思想、欲望和感情。

在人类形体，阿特玛有心意识时，意识不到浊体（夏里亚）和精体（普拉），但却通过夏里亚和普拉（非直接地，在心层面）工作。因此有心意识的人体阿特玛即便意识不到夏里亚和普拉，因而不能认识浊界与精界，但也能通过不同的浊方面来利用浊体，比如吃、喝、睡、视、触、听等，并通过不同的能量方面来利用能量，比如核能等。

打个比方，我们把一个有浊意识的人体阿特玛视作远离太阳的地球上的一个灵魂；把地球视作浊层面标准，把太阳视作精层面能量的本源和心层面心的本源。（这里太阳和地球纯属比喻，绝不可被误作太阳系的太阳和地球。）

这个（现在被我们用作标准的）太阳，不断地同时把能量和心光线射向（被我们用作浊层面标准的）地球上；地球上（只意识到浊层面）的浊意识人体灵魂，无意识地从太阳光线中吸收精层面的能量——通过在浊界以核能形式最充分地利用能量的方面。地球上的这个浊意识人体灵魂，还在浊界无意识地利用（该灵魂同样从太阳光线中吸收的）心的思想、欲望和感情方面。

继续打比方，我们把有精意识的人体灵魂视作空中的灵魂，因而要远比地球上的浊意识人体阿特玛更接近太阳。这个空中精意识人体灵魂仅仅意识到精层面，有意识地从这个太阳（能量本源）充分吸收能量，并且有意识地利用这种初生的巨大能量。因此这个有精意识的人体灵魂能够施展巨大能力，完全能够让盲人复明或者让残疾复原。这是前三个层面的领域，该灵魂能够释放能量的程度，取决于其在第二和第三层面获得的精意识的程度。

在能量领域有意识地利用初生状态的能量时，这个精意识人类灵魂意识不到心层面。所以是无意识地利用心的思想、欲望和感情等方面。因此，该灵魂虽然能通过对能量的意识而施展巨大能力，但在无意识地利用心方面的时候，却容易被心纠缠。为此原因，这个有精意识的人体灵魂尽管能力强大，但有时候却在通过奇迹能力有意识地利用能量时，滑入较低层面的精意识。

更确切地说，有精意识的人体灵魂，根据其获得的精意识的程度，位于第一或第二或第三层面；也可以说精界的领域由第一、第二和第三层面构成。而第四层面则是那个在精界领域与心界领域之间划出界线的意识状态。换言之，第四层面的精意识人体阿特玛，就好比是一个站在（心界）门槛的人体灵魂：这个门槛把精界与心界分开。

因此，在第四层面意识阶段的精意识人体灵魂，充分意识到第一、第二和第三层面并且充分体验精界，因而完全意识到精界的巨大能量。现在，这个在心界门槛上掌握着处于巅峰状态能量的人体灵魂，最接近心领域（心界），因而更容易受心的（思想、欲望和感情）方面的强大势力影响。这个第四层面的精意识人体灵魂尽管有意识地利用处于巅峰状态的精界能量，但却仍然意识不到心。因此是无意识地利用心的不同方面。这些方面极其强大，因而也最有诱惑性，这个灵魂可以说不得不面临和承受处于巅峰状态的心方面（思想、欲望和感情）的全力冲击。

这种情况极端可怕，因而对第四层面的人体灵魂极端危险。在此，拥有（可被用于最好或最坏目的的）最高能量的灵魂，必须在两种处于巅峰状态的力量——精界能量的巅峰和心界的心的强大方面的巅峰——之间保持某种平衡。在无意识地使用心的思想、欲望和感情时，这个第四层面的人体灵魂如果被这些方面的强大诱惑征服，那么他就抵制不住滥用处于高峰状态能量的诱惑，完全为满足强大欲望而施展强大奇迹，诸如起死回生，治愈失明病残等等。他甚至能够创造整个形体世界及其一切造物：精意识人体灵魂意识到的能量达到顶点时就是如此巨大。

因此，通过同样处于巅峰状态的媒介和心方面的巨大诱惑，对处于巅峰状态的能量的滥用，在（表现为强大能力的能量巅峰同表现为心的无法抗拒的欲望巅峰）两个根本超自然力量之间，造成某种巨大而无法挽回的短路，结果在第四层面精意识人体灵魂的高级意识中，造成无法想象的巨大冲撞和爆炸。从而给这个灵魂的意识带来绝对混乱，导致该人体灵魂的高级意识彻底崩溃。因此这个有精意识的人体灵魂被迫堕落到意识最低层，也就是最粗浊形式的最有限意识类型。这个人类灵魂则不得不采用石形体，重新经历进化过程。

浊意识科学家的例子

让我们来举例说明这种情况：即便在浊层面，对一个掌握着巨大的能力，又多半被展示自身能力的强烈欲望所征服的普通人，有时会发生的事情。

我们把（如上所述的）第四层面有精意识的人体灵魂，比作浊界的著名科学家。这位对浊层面有着充分意识的大科学家，纯粹通过努力和对能量科学领域的大量研究，充分认识到通过某些实验来释放巨大能量的可能性。

为了便于解释，我们假设这位科学家逐渐地意识到（逐渐为他掌握并将最终被他完全控制的）巨大能量。现在他强烈渴望利用这种能量。

不过，即便这位浊界的浊意识科学家意识到能量的最高级浊方面，但他也丝毫意识不到初生状态的能量：那种能量仅仅属于精界的领域，只能被有精意识的人体灵魂体验与控制，在任何情况下都绝不会被任何有浊意识的人实验或体验。

因此，当浊界地球上的这位浊意识科学家意识到核能的最高浊方面时，他实际上只是充分意识到精界领域能量的最高浊方面之一。

当这位意识到能量的最高浊方面之一的科学家，被一种要利用现在完全受他控制的核能的强烈欲望（也是心界的心的最高方面）征服时，这位科学家的整个职业生涯安危未定，因而往往岌岌可危。

这些冲突的念头一方面刺激科学家去展示能力，一方面却要他保持平静：在这个节骨眼上，科学家必须极其谨慎地保持定力，也就是平衡自己掌握的强大能量。是利用它造福世界，还是滥用它造成毁灭，还是根本不用——完全取决于他。科学家面临着心的主导方面的难以抵制的力量——强烈欲望。这些欲望用声名权力纠缠他，竭力刺激他的自我去满足自私目的，不管可能会造成怎样的毁灭与破坏。

因此，如果科学家屈服于这个（处于巅峰状态并指向自私目的的）自负欲望，滥用他所掌握的能力（能量的最高方面之一），他便有意识地让自己尝试爆炸在他控制之下的最致命武器——甚至比最先进的氢弹还要强大的武器。

就是在这个阶段，最关键的时刻来到。

科学家爆破他的武器，扩散毁灭性的结果；迄今为止在使用能力与强大欲望之间勉强维持的平衡完全被打乱。

这位难以知足的科学家，无法在（赋予其强大能力的）武器的潜在能量方面，与不顾无法想象的后果去有意识地爆炸武器的强烈欲望之间保持平衡。

整个事情的悲剧是，这位意识到炸弹爆破后果和高度自私的科学家是爆炸冲击波的第一个直接受害者，不管他采取怎样必要的预防措施。对他本人的直接后果是，他首先是被自己的实验彻底震慑惊呆，直挺挺昏倒在地，完全失去知觉。更可悲的是，当他恢复知觉时，是以什么为代价？他彻底忘了自己曾是顶级科学家，想不起自己最近的生活、童年和青年时代的活动，以及有关妻儿和朋友的一切。而最大的变化是，他甚至感觉不到失去了任何东西，包括自己的记忆和自己曾是大科学家。医生把这种情况称作失忆症。这位科学家只意识到自己是个最原始类型的人。重新开始生活，绝对想象不到自己曾经是大科学家，控制着巨大的能量。第四层面的最高级精意识人体灵魂的悲剧亦然。后者作为能量化身，滥用精界处于巅峰状态的能量，结果失去全部意识，除了最有限的意识；只得按照进化规律采用最粗浊的石形体，体验最有限的意识。

至师的作用之一是保护第四层面的灵魂避免因误用神圣能力而毁掉灵性生涯*。通常来说，如果第四层面的灵魂将要失去对心的控制，其能力就被（能控制一切精意识和浊意识灵魂的心的）至师夺走。因此实际坠落事例极为罕见，仅仅作为例外事件而发生。这些例外终极上也不能归因于至师们缺乏警惕，而是因为神本身内的原始驱策。所以说宇宙中的每个事件，无论大小，皆按全能者的意志而发生：此乃千真万确。

[* 当编辑询问有关耶稣的“诱惑”时，美赫巴巴答道：

“事实上不是耶稣被撒旦引诱，而是耶稣让他自己受引诱，从而战胜诱惑。这背后有一个重要目的。他必须让自己受引诱；从而承担起当时在世界上占据优势的诱惑力量的负担。耶稣随后战胜了一切诱惑，并以这种方式，制造出巨大的力量，对宇宙性的诱惑力量起到强大的抵制作用。佛陀的情况亦然，在阿瓦塔时期每一次皆如此。每当神作为阿瓦塔在地球上显现时，其神性给予宇宙性的推动，结果也是宇宙性的，就是说，不仅人类而且整个造物界的万物，都将从这种宇宙性的推动中获益。”]

必须认识到，虽然一旦全意识在人体被获得就永不会失去是个既定事实，但就第四层面的精意识人体灵魂而言，却存在着失去这种意识的可能性。如果第四层面的能力被滥用，如果不能在自己掌握的最高能量与无限欲望（心的最高方面）的强大诱惑之间保持平衡，上述情况就会发生。虽然心的三个根本方面是思想、欲望和感情，但是欲望却构成了心的最高方面。

不过，如果第四层面的精意识人体灵魂不去滥用自己掌握的能量，并且通过慎重地把无限能量用于最好的目的而保持平衡，那么这个第四层面的灵魂则不仅跨越第四层面这个门槛，进入心界的第五和第六层面领域，还直接获得第六层面的意识。这是因为这个（有精意识并且慎重使用处于巅峰状态的能量的）灵魂能够战胜并且抵制心的最具诱惑性和难以抵制的最高方面——处于巅峰状态的最为强大狡诈的欲望、思想和感情。就这样，这个拥有精意识的人体灵魂，通过战胜处于巅峰状态的欲望、思想和感情，成为控制它们的主宰（他现在控制甚至有能力创造这些欲望、思想和感情）而直接获得第六层面的意识。

一些拥有精意识的人体灵魂，既不利用也不滥用在精界释放的处于巅峰状态的能量大泛滥；这些有精意识的人体灵魂如果不被处于巅峰的欲望吞噬，就会跨越第四层面的门槛，获得心界领域的第五层面意识：在此，这些有心意识的人体灵魂意识到那个控制思想的心的第一状态，因而不再是心的奴隶。

现在第五和第六层面的心意识人体灵魂完全意识到心，并根据第五和第六层面意识的进步程度来体验心界。这些第五和第六层面的心意识人体灵魂对精界第一、第二、第三、第四层面的意识程度不再有意识，也不再体验精界。因此，这些有心意识的人体灵魂意识不到精界的巨大能量。现在这些心意识人类灵魂虽是心的有意识主宰，却绝对意识不到精界的能量；正是为此原因，这些有心意识的人体灵魂永远都不能施展任何奇迹：不能起死回生，也不能让盲人复明或让伤残复原，尽管他们的内化意识高于精意识人体灵魂的意识。然而作为心的有意识的主宰，这些心意识人体灵魂能够创造并且控制浊意识和精意识人体灵魂的心。对于他们，在必要时创造和控制心只不过是儿戏。

就心意识人体灵魂而言，我们假设他们在位置上靠近（在比方中被用作标准的）太阳。这个人体灵魂有意识地吸收并控制心的思想、欲望和感情等方面，并在心界充分利用源自（为便于解释而被视作本源的）太阳的那个心。因此这个有心意识的人体灵魂，在第五和第六层面领域不仅完全意识到心及其诸方面，还能够创造并控制一切其他心的思想、欲望和感情。现在这个灵魂相当稳定，绝不会像第四层面的精意识人体灵魂那样，坠落或者下滑到任何低级意识层面（因为浊意识人体灵魂和精意识人体灵魂都是心的奴隶，心意识人类灵魂则是心的主人）。

最终，有大我意识的人体灵魂就好比在太阳本身里的灵魂。（试图理解这个解释时，应该记住，这里所说的太阳只是一种比喻形式。不应错误地把这个太阳视作我们地球的太阳，或者错误地把我们地球的太阳视作无限能力、知识和喜乐的无限永恒本源的真正标准。也不应给我们地球的太阳赋予任何重要性，因为我们地球的太阳只是灵魂自身创造的造物界的物体之一。）

这个第七层面的大我意识人体灵魂，意识到这个（被用作能量和心本源例子的）太阳；虽然他总是永恒地体验并且辐射无限能力、知识和喜乐，但是在有些情况中，这样的一个灵魂为了帮助其他灵魂从浊、精和心界的业相中解放出来，也直接地和有意识地利用无限能力、知识和喜乐。
