  3 分钟阅读  

1927年12月27日，周二，穴屋

【复习昨天的要点：当能量与虚空冲突时，产生火、水、风、土四大元素。在进化过程中，从石头到植物形体与土有关，鱼与水有关，鸟与风有关，兽与火有关，而人与所有元素有关。】

现在我们以光球的一个影子（一个世界）为例。假设那是我们的世界。我们发现土无处不在——在陆地，也在海底。水同样无处不在——在陆地，也在溪河海洋等。陆地的水在土下面，海洋的土在水下面；一个在上时另一个就在下，反之亦然。风也同样无处不在——在印度，在美国，也在其他地方。火也是无处不在。我们所说的火是指“电光（tej）”。这种电光无处不在，但被一层以太覆盖。火与兽类有关，因此兽类的“饿火”很强烈，食量可怕，仿佛就是为食而生。孟买维多利亚花园有只大象，你随时参观，都看见它在吃。这是事实！

这样我们了解到火、水、风、土四大元素无处不在；还了解到从石头到植物都与土有关，鱼与水有关，鸟与风有关，兽与火有关，人类与所有元素有关。现在我们看进化是怎样发生的。首先要记住顺序：石头、金属、植物、虫、鱼、鸟、兽、人。

植物之后，有一种虫，全身绿色，几乎跟植物（草）一样，难以分辨。这是第一种虫形体；最后一种虫形体是龟，生活在湿土中。也就是说，龟从土进入水；要成为鱼，故找水。之后是鱼形体。蟹是最后一种鱼形体。蟹要从水中出来，因而有着“转向”形体（脸朝地面）。蟹之后，第一种鸟形体是水禽。你们会注意到，有些鸟类喜欢水。最初的鸟形体与水有关，之后与风、最后与土有关。倒数第二种鸟形体是公鸡，有翅膀，喜居地面，基本上不能飞。最后的鸟形体是一种大鸟，长腿长喙，下巴挂着血红色肉袋，仿佛喉咙垂了下来。

鸟类之后，第一种兽形体是袋鼠。最后一种兽形体是猿猴。【这里提到达尔文的进化论——虽然构思巧妙，但仅仅是理论。而师利讲的乃实际所见。】

我们已经看到每类重要形体的最初与最后物种。实际算一算总共有840万物种。在进入细节之前，我们来看看形体的7个阶段。

如上图所示，石头和金属是第1类形体，第2类是植物，第3类是虫，第4类是鱼，第5类是鸟，第6类是兽，第7类是人。人类之后不再有更先进的形体。这里人类智力无限，但却有业相。这就是为什么神与人之间有层帘幕。要看见或达到神，就必须行走“层面道路”，因而有7个层面。记住，灵魂在所有这些形体中都是同一个。现在注意，终极的形体是人类，之后不再有进一步的形体。神在第7层面，也同样没有进一步的层面。灵魂在人体中如果不“转向”层面道路，就会根据行为也就是业相继续用人体出生，或者退回动物等形体。【译注：美赫巴巴早期指出，在罕见情况下灵魂有可能从人类形体退到亚人类形体。后来又具体解释说这仅仅发生在第4层面滥用能力的情况下。】

换句话说，灵魂就像磨油厂的牛一般原地打转，却不向层面道路前进。这种前进需要心的“转向”。通常来说，心是不会转向的。难乎其难。

那该怎么办？必须求助于一位能够使你的心“转向”者。这样的人是谁？赛古鲁！赛古鲁又是怎样让你的心转向，把你推入层面道路的？通过你对他的坚信和深爱。这就是他的要价。所以，亲爱的孩子们，要生发“爱”！你们很幸运有赛古鲁在你们中间，实际上他殷切期望你们为成道付出真诚努力。所以，你们要爱他，用尽全力爱他，全心全意爱他。努力生发对他的爱，他定会让你们的心和目转向，让你们看见神，把你们推向神。

赛古鲁如果愿意，如果心血来潮，就会让你省去行走7个层面的全部麻烦，直接撕开你与神之间的帘幕，让你与神合一。
