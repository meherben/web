1927年12月7日，周三，水塔西屋

我们已经看到无意识上帝是怎样开始运动而成为（B点）造物主的。我们进而把真理视作无边无际的海洋，并且发现这个海洋的最初运动形成3样东西：波浪、泡沫和气泡（也就是波浪中连续不断的无数光球）。要记住这些气泡有两类：“波浪气泡”和“水滴气泡”。每个波浪在运动时都形成自身的气泡——“波浪气泡”；这个波浪里的每个水滴都有各自的“水滴气泡”。一个波浪里有无数的水滴，因此每个波浪除了自身的波浪气泡外，还有不计其数的水滴气泡。如下图所示，波浪C有无数的光球；也就是说，波浪是连续不断的光球，光球是波浪的组成部分；因此波浪和光球是同一个。

现在我们看看造物主是怎样创造的？

上图中，A表示海洋（无意识上帝）。这个海洋（在创世点B）开始运动时，制造无数的波浪（我们首先只讲波浪）。B点叫做“噢姆点（Om Bindu）”。可把这些波浪分为三排：右E，左D，中C。每一排都有无数的波浪。不过在这些无数的波浪中，我们只讨论离B点最近的。左边最近的三个（1、2、3），右边最近的三个（4、5、6）和中间最近的一个（7）——这7个波浪离创世点B最近。

这些无数的“波浪气泡”即众多的“世界”或“星辰”——怎么称呼都行。在这些无数世界中，仅仅7个离创世点最近的世界里有物种存在。在这7个世界中，一个有石形体，也就是只有石头、山峦等；一个有石头+风；第3个有“上述两者+金属”；第4个有“上述一切+水”；第5个有“上述一切+植物”；第6个有“上述一切+动物”，最后第7个有“上述一切+人类”（如上一讲所解释的那样）。所有这些世界一直存在。

我们来看看离创世点最近的第7个世界。这个世界由3个世界组成：在创世点正下方、呈一直线的a、b、c。这些（a、b、c）是有人类（居住）的3个世界。创世点下面最近的世界（a）是我们生活的世界（地球）；只有在这个世界才能成道，因为离创世点最近。在这个世界（a），人的智力相当发达（有智慧）。在最下面的世界（c），人的智力最发达，只用头脑运作。在中间的世界（b），人的智力胜过a世界的人，但不如c世界的人。在这3个世界（a、b、c）的人都有浊身体。

但这一切的乐趣在于：人在最下面的世界（c）离开身体后会前进到上面的世界（b）出生，然后到最上面的世界（a）——也就是我们这个离创世点最近的世界，因为只有在这个世界（a）才能成道。为什么不能在下面两个世界（b、c）成道？因为只有在最上面的世界（a），才有一切的心、精、浊（体验）。

【这时又从谈话中顺便提及：解释这一切的正是创造这一切的造物主本人！】

现在注意发生了什么！根据内化和进化理论，经过很长时间之后，最上面的世界（a）冷却，变得像影子（之前是光球、星），离开原位，移到一边——从a到a’（如上图所示）。世界（a）刚到一边，下面两个世界（b和c）就分别上升一步；换言之，（b）取代（a）的位置，（c）取代（b）的位置，等等。

设想通过运动，形成波浪，之后“波浪气泡”、众多水滴，再之后众多“水滴气泡”等等。现在拿我们这个离创世点最近的世界为例加以说明。在这个世界，从最开始进化发生，逐渐经过不同形体——从石头到人类，一直持续到上面说的世界开始冷却，移到一边。

必须注意，在所有其他六个世界，这个进化都发生在局限之内。也就是说，在第1个“石头”世界，只是石形体的反复进化；在第2个世界，进化仅限于石和风形体；在第3个世界，石、风和金属形体；第4个世界，所有这些形体+水；等等。换言之，在所有这些世界（1到6）中，进化仅限于每一个世界里的物种数目。然而只有在最后第7个世界（我们的世界），才有从石头到人类的进化。

进化是怎样产生的？

我们已经看到，世界是个气泡，也就是虚空（pokaḷ）。不仅我们这个世界，而且创世点下面的一切事物都是气泡（虚空、影子）。超灵（海洋）在上面。在这个海洋开始运动的时刻，运动就与虚空发生冲突。这种“冲突”是二者相撞（接触）造成的。“运动”与“虚空”的冲突（撞击）造成“电光（vīj）”。

为清楚理解这一切，只要记住：

运动=能量（prāṇ）

虚空=空间（ākāsh）

运动与虚空接触（冲突）所产生的“电光”，现在被科学家称作“电子”。（因此，电子=电光。）

记住，这个电子中也有水滴（海洋的水滴**，也就是海洋本身，但在有限形体中）。还要记住，在每个气泡里，不管是“波浪气泡”还是“水滴气泡”，都有水滴（无数水滴）。如上所述，由冲突造成的“电子”是第一个气泡**，也就是浊（物体）。这个电子（水滴）里也有灵魂。（因为水滴或气泡是无限大灵的有限因素。）

当今世界的先进科学已经发现电子。然而浊界科学无法超越这一点，因为用浊手段无法达到（超出电子的）“精”。

不过，这个虚空在哪儿，又是什么？我们只知道世界乃空无。

世界及其运作皆是无中之无。

  • ——哈菲兹*

让我们从理论上来证明：

我们说神是一切，无处不在，因此除了神，无有存在。

这意味着无存在。

所以我们看到，从这个无中产生了这一切混乱。就连这个无也是神，因为神也在无中。因此可以得出结论，有中存在着无，无中存在着有；神是有，宇宙是无，等等。如果有什么真实的话，就只有上帝与道路——从下到上呈一直线，通过层面从无意识上帝到达有意识上帝。

除了上帝与道路，其他一切皆虚幻。
