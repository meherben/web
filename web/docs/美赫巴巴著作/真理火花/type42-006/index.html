灵魂的性质

如果你问一个从花园回来的人，“你去哪儿了？”他通常会毫不犹豫地回答，“我在花园。”他把自己看作自己的肉身，相信自己就是肉身。他用肉眼看见花园，相信花园真实存在；所以能立刻回答有关其行踪的询问。虽然他对自己的答案十分肯定，但他所相信的东西，终极上却不真实。

人看见某些东西，就下结论说这些东西存在。但是有很多我们看不见的东西，却和我们同在。例如，嗔、善、爱、妒等，也许不为肉眼所见，但却存在。你用肉眼只能看见别人的外部身体。即使X光也只能显示其肉身的内部，却不能显示其心中的念头、情感和欲望。不过，你虽然看不见，却感受得到他的这些心理状况——倘若你和他生活一些日子的话。相处一段时间后，你也许能够说他嫉妒还是善良等。普通人对认识别人的心理状况有一定的能力。但这种认识的获得不迅速也未必准确，因为通常主要是从外部事物推断出来的。

但却有可能发展对心理状况的迅速准确认识。高级灵魂只要看看一个人，就能直接无误地知道其性格与倾向。不过这种能力很罕见。

通常，人是通过跟他人交往，逐渐地了解其心思。我们想认识一个人时，不仅想知道他的身体，还想知道他的思想、感情和欲望等精神生活。

人的好奇心并不局限于当前。人心还经常问有关未来的问题。例如，“明天会发生什么？”对大多数人来说，未来是一本密封的书。那些只信眼见为实的人，对预测不感兴趣。从早到晚，生活中并没有什么事情让他们寻求那种直接了解他人的心或同未来建立确切联系的更高感知。

但即便在这些人的生活中，也会发生一些事情，能够真正引起其兴趣与考察。人睡觉时，伸展四肢，闭上眼睛。慢慢忘记周围的一切。但他可能会开始做梦，到别处漫游。梦中的有些漫游不纯粹是头脑的想象；而往往是灵魂用灵体进行的实际旅游。灵体的这些漫游可能很远很广。没有过不去的高山，没有过不去的大海。有时候，人醒后回忆起这些漫游，可能会视之为梦。灵体有自身的意志和能力。浊体做不到的事情，在灵体中却容易做到。一段时间后，这些漫游可能会停止。之后，人进入深眠，什么都体验感觉不到。必须经历这种彻底的自忘，才能得到休息，次日感到精神焕发。

一般来说，人不可能同时体验醒与梦。他在醒中做平凡的事，但却清楚明白地做。在梦中可能会做非凡的事，但却模糊不明地做。很少有像高级灵魂那样的情况，同时体验醒与梦；这时灵体的非凡成就清楚明确。很高级的灵魂也同样有可能同时体验醒与睡。一个人如果将醒与睡结合，就能在醒状态有意识地体验酣眠状态的无条件、纯然喜悦。

圣人能帮助他人一方面将醒与梦结合，一方面将醒与睡结合。这种结合也可以通过瑜伽过程达到。然而，彻底的自忘和完全的极乐状态，却是来自灵性大师的馈赠。能结合梦与醒者，稍微比不能结合这两个状态者高级。不过他就跟普通人一样，也在想象领域。

但是能将醒与睡结合者，则达到真理并成为真理。对他而言，世界不存在；唯有神存在，别无他物。如果你问这样的人， “你在哪儿？”他会如实回答，“我一直是过去无处不在，此刻无处不在，并将永远无处不在。”他知道自己不同于身体，知道自己就是无处不在的真理。因此，他会从最高体验的角度，绝对肯定地确认自己现在和过去总是无处不在。他甚至无法想象自己曾在花园，因为他甚至意识不到自己的身体。这种知识和体验极为罕见；但却是生命的终极真理。

大我一旦从一个微点出来，就降入幻相，开始其世间旅程。即便高级瑜伽行者，及其所有的超自然能力，也仍然处于幻相的支配之下。受到内在层面的迷惑，成为幻相的牺牲品。他们像普通人那样，意识到大我的影子或投射，却意识不到大我。不过，这种瑜伽行者一旦摆脱内在层面的诱惑，就会回到并进入（灵魂最初从中出现并开始漫长旅程的）那个微点。在这个状态，他体验到整个宇宙都从他自身出现。但随着成功地超越该点（通常称作噢姆点），他也完全失去对整个宇宙的意识。对他而言，没有形体，唯有永恒存在；没有短暂悲喜，唯有永久极乐。这就是“睡中醒”或“醒中睡”的真义。

先被束缚后被解放的过程，充满重大意义。灵魂与身体混淆，然后陷入其中。灵魂如鹦鹉，身体如笼子。在笼外，鹦鹉是自由的；却不能欣赏或享受这种自由。在笼中经历囚禁之后，才通过痛苦的束缚，体会到自由到底是什么。重获自由时才真正享受自由。当灵魂通过大师的恩典，从“我是可灭肉身”的噩梦束缚中解放出来时，也会发生同样的事情。

灵魂实则是神。这对那些深陷“我是身或心”幻相者，显得不可思议。比如，怎能把一个躺在安乐椅上的人，等同于普遍与全能的神圣存在？灵魂只要仍受无知支配，就无法证悟自身无限性。尽管如此，“灵魂同于神”依然是不可逆转的事实。在深眠中，灵魂存在却不知其存在；同样，灵魂其实也与神一体，但在无知中却意识不到这一点。人的眼睛看见很多东西，却看不见眼睛本身（除了在映射中）；同样，灵魂通常也意识到整个世界，却意识不到自身（除了通过与可灭身体的虚幻认同）。

灵魂在对自己即真理的终极知识中，知道自己就是一切。真理是有。除了有之外，什么都没有。因此，有包括无。这意味着虚妄世界幻相本身什么都不是，只能在真理之中而非真理之外有其存在——即便是作为幻相。宇宙存在，但却不实，也就是说，宇宙存在于想象——被强加于真理的想象。
