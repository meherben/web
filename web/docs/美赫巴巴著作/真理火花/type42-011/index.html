瑜伽士使用的能力，基于一种类似电的能量，但它不同于科学家控制的电，并且强大得多。不过，为了便于理性解释，我们可把这种能量视作一种“电”。这种电位于世界的第三层，取之不尽。瑜伽士通过呼吸控制等修炼，把这种取之不尽的宇宙能量源或电，同自身的第三层能量或电结合起来。这种结合使他们能够创造很多奇迹。

瑜伽士将这两种能量或储电结合起来之后，只需要想一想，即可获得想要的结果。可以说是心想事成。他们能知晓过去和将来。能知晓他人的心。也能看见或听见任何地方发生的事情。例如，他们能从美国看见印度的人在做什么。他们能让石头变成碎片。甚至能起死回生。与人类的有限能力相比，这些能力确实强大。但是与真理或与真正灵性毫不相干。真理远远超出对这种能力的行使。

瑜伽士能让事物显得与实际情况完全不同。就好比给你戴上有色眼镜，实则白色的东西，在你看来却是自己所戴眼镜的颜色。让你把白色看成别的颜色，是毫无特殊灵性优势的。有色的事物和原来的白色都是假的。都属于醒梦。至师绝不会用一个幻相来换取另一个。相反，他会揭示整个世界的虚幻性质，展现简单纯然的真理。

杂耍者或魔术师同样可能会在你面前用纸板变瓶子。但既然瓶子和纸板都是假的，你就算看见这种转变，又有何用？它可以变成任何东西；但却还是假的。不能向你揭示不变的真理。这种奇迹也许能吸引大众，赢得世人赞叹；但至师对这些东西毫无兴趣。他所关心的是让你证悟“除神之外一切皆幻”；这种知识是任何瑜伽能力都无法提供的。

假设有人想知道远方城市正在发生什么。他必须亲自到那里了解情况，必要时甚至得步行。瑜伽士能够用高级身体立刻到那里，看看发生了什么。但他也必须去那里。这就像乘汽车会比步行更快到达目的地。乘车者与步行者只是程度的区别。二者都必须去；都把所看见的当作真实的。但却尚未发现实相。他们认为醒梦是实有。到远方城市后所 “发现”的，只是大幻的一部分。至师只关心把大幻从心中赶走，因为大幻让这个世界的种种事物貌似存在，但实际上只有被称作大我或神的无形实相真实存在。

瑜伽士的能力虽大，但是同与神合一者的无限能力相比，却不足挂齿。可把神比作太阳。瑜伽士比普通人更接近这个太阳，因此能把太阳的一些光线吸引到自身。这些光线成为其各种神秘能力。但要使用这些能力，瑜伽士必须操纵这些光线并付出努力；瑜伽士的奇迹是辛苦得来的。但至师的奇迹则无须这种努力，因为至师与“太阳”一体，其所有奇迹都毫不费力。与神合一的至师还拥有使用神圣无限大能的权力。但他很少使用自己的能力。即便使用，也完全是为了灵性目的——将受缚的灵魂引向真理。

至师不仅能向你展示神是什么，还能把你引向目标——完全与神结合。但这不意味着求道者应该一次次纠缠大师，迫切要求他“向我示现神。”渴望见神和证神是可以的。但若认为神就像电影中的事物那样可被显示或看见，则曲解了真正的寻求。不升到必要的心层面，就见不了神。必须彻悟浊界的空无，才能一睹神的本质。本末倒置是毫无用处的。求道者的当务之急，是挣脱将其束绑于虚妄的精神局限。当人把系缚在自心上的眼罩摘掉时，神就会自动显现。

事实上，神离求道者并不远。见神也并非真的很难。神就像太阳，一直当空照耀。但你却在自己头上举着五花八门的印象之伞，这让你看不见祂。你只要把伞拿开，太阳就已经在那里让你看见。无需从别处请祂来。但是像伞这种微不足道的物件，就能挡住你对太阳这种惊人事实的视线。印象就像这把伞。虽然本身看上去微不足道，却在你和神之间造成屏障。至师帮助你消除这些印象。当这个屏障被移开时，你就面对面看见真理之神。

永远不可能纯粹通过智力来证明神的存在。任何仅仅诉诸于智力的论点，都倾向于引诱人相信神；但却绝不会完全令人信服。怎能把实际上超越智力的东西带入智力领域？要求纯粹在智力上证明神的存在，如同要求能够用耳看。耳只能听。不能看。要看就得用眼睛。如果你紧闭双眼，呼吁让你的耳朵看见东西，谁能帮助你满足如此荒唐的要求？然而，所谓的“知识分子”恰恰陷入了这种荒唐。他们想要对神的理性证明；异想天开地认为通过使用智力就能认识神。

事实上，这些知识分子对神根本不感兴趣。只是热衷于争论和虚荣。他们若真想认识神，就会为这种知识付出代价。就会立即放弃那些阻止自己见神的东西。就会开始变得谦卑、无私和友爱。就会开始彻底净化心灵。这会比任何的无用辩论都更可靠地把他们带向神。

人们不愿割舍世俗执着，哪怕是为了见神。为了获得所执着的对象，他们甘冒生命危险，甚至英勇牺牲。然而为了灵性进步，甚至禁食两天都很难做到。这表明他们是怎样为无知所牢牢掌控。神一定会向那些欣然为祂受苦者显现自身。他们必须意志坚定。神一定会光临那些有勇气烧毁全部欲望者。世俗执著和纠葛会永无止息，不会带来任何结果。因此，求道者有责任远离这个世界的诱惑。这就是为什么古往今来的大师，都像耶稣基督一样召唤：“卖掉一切来跟从我。”

有人想要对神的理性证明时，有时是期待某种奇迹，对沉浸于世间并视之为不争、终极现实的凡人，予以猛烈的震惊。但是不能将神与超自然界或其中事件混为一谈。奇迹能够证明的是，在世人完全沉迷其中的事物之外，还存在着其他东西。但是奇迹不能让他见神。他从一个非真走向另一个非真，结果只能再次陷入新的幻相。丝毫没有接近真理。至师总是蔑视对奇迹的要求。他们知道生活的真正目标；致力于把世人带向该目标，而不是迎合世人的无聊好奇。他们希望启悟而非惊骇或麻痹人类。即便施展奇迹，也总是为了把人引向灵性道路；从来不是为了自我展示。对他们来说唯一值得做的奇迹，是让人证悟自己其实就是真理这个奇迹。
