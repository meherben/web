没有提供成道的市场。即使有人提供，客户也会极少。世人深陷无知，没有能力评估灵性真理的价值。但大师们却一次次用大众懂得的语言描述神性，试图帮助笨拙摸索的人类。通过降到凡人的层面，也只能传递对该真理的某些瞥见。即便如此，大多数情况下，那些笼罩于深重无知者，就连对这种赐予也无动于衷。他们的心已经因世俗思想和感情习惯而变得顽固不化。

世人大多不珍视真正重要事物的价值。即使在那些欣赏者中，大多数人也无法从中获益。可用一个故事来说明。有个村子里住着神的一位信徒。在敬拜中度过一生大部分时间之后，信徒心中升起新的渴望——证神成道。这让他变得骚动不安，恨不得立刻拥有这种至高体验。一天，村中碰巧有圣人来访。信徒毕恭毕敬地走来，对圣人说，“我曾四处朝圣；也拜访过不少圣人，寻求帮助和祝福。但是我的唯一愿望还远远没有实现。我等得够久了。现在完全向您臣服，希望会从您这里获得光明和帮助。”

他说得无比真诚，相信自己真的已经准备好接受最高灵性体验，却不知自己实际上根本没有准备好。他并不知道自己在要求什么。因此，为让他明白他其实还需要进一步的准备，圣人从长袍中取出一块看似大理石的宝石递给他，说：“拿上这块石头，去市场换五磅蔬菜。”信徒不知宝石的真正价值，将之视作普通大理石。他犹豫不决，认为做这种注定要失败的事，乃是白费力气。不过，当圣人叫他不要带入个人想法，只需按要求去做时，他决定尝试一下。

当信徒提出用一块石头换五磅蔬菜时，人人都嘲笑他的这种非分之想。不过，有个人觉得买来给孩子当玩具倒也不错。但却只出了四磅菜的价。信徒返回，对圣人讲述了发生的一切。圣人听完却要他去换五磅糖果回来。

信徒肩负新差回到市场，又遭众人取笑。不过，有位想给戒指镶上宝石，又买不起真宝石的人，感到这尽管只是块大理石，也许可以充当宝石镶在戒指上。于是同意交换，但他出的价是四磅糖果。信徒再次返回，向圣人汇报了第二次卖石经过。

这时圣人却要他找位金匠，卖一百卢比。当他第三次来到市场时，又被人人笑话。不过，有位金匠心想这或许是块真宝石，但只出价九十卢比。信徒的耐心已经到了极限。三次尝试皆告失败。因此要求圣人收回石头，因为他永远无法满足圣人的要求。

然而，圣人却要他找位珠宝商试试，要价一千卢比。信徒只好带着那块石头去见珠宝商。珠宝商一眼认出这是一块值钱的宝石，知道其真实价值绝不会低于两万卢比。他认为终生难遇的机会来了，可要利用一下这个对珠宝一窍不通的外行。但是贪得无厌的珠宝商只愿出八百卢比，从而丢掉了一桩好生意。

现在信徒彻底失去耐心。他扔掉石头，对圣人说，“我来找您是为了证得最高真理，与神合一，不是做这些徒劳的差使。要么把我渴望的东西给我，要么让我回到原来的生活。”圣人回答，“没有不懈的耐心，就别想与神合一。连这种普通考验都受不了，就不要指望承受真正求道者必须面对的严峻考验。你最好还是回到世间。但在你离开前，我希望你总结一下，从四次卖宝石的经历中，你学到了什么？”

圣人接着说，“出价四磅蔬菜的商人，就像对神一无所知的大众。他们连想都不会想自己有一天必须拥有这个无价宝藏。只出价四磅糖果的商人，就像认真或者有思想的人。他们有时候意识到其生活方式需要改变，但却满足于用另一个虚假物来换取他们已厌倦的虚假物。并不热衷于拥有真正的东西。他们想要的只是某种改变，因为对现实生活极度不满。

出价九十卢比的金匠，就像有的求道者，知道有更高的生活，也想拥有这种生活，但却没有足够的诚意为此付出真正努力。珠宝商知道宝石的真正价值，却只出价八百卢比，就像求道者知道永恒生活的真正价值，却不想为之付出真正代价。这个真正代价就是放弃分别自我生活。然而，他却通过提出做其他很多远远低于最低标准的事情，想以此来欺骗大师。”

圣人最后说，“而你，我亲爱的孩子，就像那些拒绝从经验中学习的不幸者。在接连几次的差使中，你有充足的机会注意到，随着你去找的人越来越识货，对那块石头的估价也越来越高。但你却依然坚持当初认为它毫无价值的看法。进而在绝望中竟然扔掉真正有价值之物。你需要更多阅历，需要从自身和他人的经验中学习。等经验丰富了再来找我吧。”

很少人能够珍视灵性生活的真正价值。即使在这少数人中，大多数人也因性情使然，继续受到琐事的限制和支配。错过把感悟到的真正重要价值融入生活的机会。他们做的最多的就是谈论或写作或思考这些价值——作为打发闲暇时光的有趣方式。然而，不被实践的价值就不是价值。当人仅仅在脑子里思考价值概念时，这个概念就如其他纯粹智力概念完全一样：一个玩物而已。

单纯思考、谈论或写作所消耗的能量，就像通过火车引擎的汽笛冒出的蒸汽。弄出噪音，甚至有趣，却不能驱动引擎哪怕一寸。再多的汽笛声都无法推动火车。必须明智地操纵和利用蒸汽，以便把火车开到目的地。这就是为什么圣人历来都主张实践而非理论。这尤其适用于那些想知道和证悟神的人。
