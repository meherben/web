不死之生命

生命不因死亡而终结。死后生命如同生后死亡一样真实。为死而生，或者为生而死，的确是个拙劣的命题。生后的死不是无生命，死后的生也不是不死亡。生是真正存在的正面显现，这不是负面的死亡所能消灭的。要结束无尽的生死相继，就必须在生命中歼灭死亡。通过把意识从一切幻相中完全解放出来，而在生命中消灭死亡，人就在自身真正存在的赤裸裸真相中成为神。不管保留或者放弃浊、精或心体，他都无限地意识到神，正如无论人穿衣与否都依然是人那样。

只要人仍然不知其神圣大我，就无异于一块石头；人生活，石头存在，两者对真理同样无知。如卡比尔所言，人不实现真理，不过是块石头。

人通过无尽虚幻体验而辛苦进化的全意识，陷入这些曾对他获得意识极其必要的体验本身。在人类，意识进化完全。意识不再需要增加，只需要被引向人的真正身份。

只有在人体，生命才能达到终极目的：证悟遍在而无限的神性。只有在人身，人才能实现证悟和创世目的。因此才有获得人身的无上重要性。

实际上，获得人身即旅程终点，但在获得意识的苦旅中积累的业相，阻挡着人对永恒大我的视线。人所经历的一切苦难挣扎，都是为了磨掉这种障碍，而这个过程是无止境的。人靠自己无法移除障碍，至师却能为他做——当他赢得其恩典时。

束缚性的噩梦

被束缚然后被解缚的过程，充满重大意义。灵魂与身体混同，然后卷入其中。

灵魂像鹦鹉，身体像笼子。在笼外，鹦鹉是自由的，却不能充分理解什么是自由。由于不曾体验局限，所以识别不出笼外的“自由”。经历了笼中囚禁，痛苦的束缚使鹦鹉体会到自由真正是什么。这时，鹦鹉从笼中被放出，真正地享受自由。

当灵魂凭借至师恩典，从其所认同的身体牢笼的束缚性噩梦中被解放出来时，也经历同样的事情。

能动自由

证悟真理者的无限自由是唯一真正和完全的自由。只有在这种流经至师的能动自由中，作为真理的大我才能显现自身，从而表现宇宙心的神圣化印象。神圣化的印象因无限地服从大我，而具有无限的创造性和效率；并且释放不受限的创造性和神圣行动。

然而，我心的一般束缚性印象总是无休止地攻击大我，寻求自身满足；因而在效率和创造性方面无限地受限。

直达上帝之旅

试图遵守仪式教规来达到真理的群众，可以说是乘货车，在各个站台无限期地耽搁。那些真诚专心地冥想神或献身于为人类服务的人，可以说是乘普客，按照列车时间表在每一站停下。但那些前来跟随成道的大师，怀着彻底的臣服和信心执行大师命令的人，可以说乘上特快，在最可能短的时间内被带到目的地，不在中途站滞留。

大师即道路

通过日夜想念大师，弟子接近实现最终极目标，这也是各种静心和专注修习的目标。将大师的工作置于个人需要之上，弟子通过彻底舍弃，实现目标。

通过真诚臣服于大师，弟子非常接近心止，这也是大多数瑜伽修炼的目标。通过不惜以任何代价来服从大师并且无我地服务大师，弟子几乎到达知识和行动之道顶峰。通过爱大师超过其他一切，弟子与作为真理的大师合一，从而凭借大师恩典获得神性——所有寻求与奋斗的目标。

宇宙研磨机

至师成为宇宙中心。发现自己是整个宇宙不停地绕着旋转的唯一绝对和不变点。宇宙就像研磨机，证真大师就像中心销。除了那些附着在中心销上的谷粒，谁都无法逃脱这个研磨机的重复永久研磨。

永恒的闪光

至师的行动不重复。不单纯是在新的环境中重做那从前所经历之事。而是做那在二元体验局限内不能做之事。这是一种全新的创造，是真理降入幻相。因此具有无限的创造性。至师的救赎行为，是永恒在否则只会是严格因果关系当中的闪光。此乃至师所赐神圣恩典之奥秘。

翻译：美赫风    田心
