何从与何去？

人心只要不直接体验终极实在的本来面目，就会被每一种企图解释宇宙起源与目的的努力所困惑。远古似乎笼罩于神秘莫测的迷雾中，未来又好像是一部密封的书。由于摩耶的迷惑，人心至多只能对宇宙的过去和未来进行高明的推测。既达不到对这些问题的终极认识，又难以满足于在这方面的无知。“何从？”与“何去？”成为两个持久而尖锐的问题，让人心神圣地骚动不安。

开始与终结

在对宇宙起源的探究中，人心不会满足于无穷的倒退，也不会安于无目标无止境的变化。倘若没有最初的起因，进化就难以理解；倘若不引向某个终点，就失去一切方向和意义。“何从？”与“何去？”问题本身便预设了这个进化世界的始与终。进化的开始即时间的开始，进化的终结即时间的终结。进化有始也有终，因为时间有始也有终。

在这个变化世界的始与终之间有很多周期。但在这些周期中并通过这些周期，是连续的宇宙进化。进化过程的真正终结被称作“世界大绝灭”（摩诃普罗来亚）。届时世界会变成原来的样子，也就是什么都没有。可把世界大绝灭比作人的睡眠。对于深睡的人来说，形形色色的经验世界完全消失。当世界大绝灭发生的时候，作为摩耶产物的整个客观世界也同样消失于乌有。就仿佛宇宙根本未曾存在过。

存在超越时间

即使在进化期间，宇宙本身也仅仅是想象而已。事实上，只有一个不分而永恒的存在。它无始无终，超越时间。从这个超时间存在的观点看，整个时间过程纯属想象，已经过去的亿万年和将要到来的亿万年甚至没有一秒钟的价值；就仿佛根本未曾存在过。因此不能说多元和进化的宇宙是这个独一存在的真正结果。倘若是独一存在的结果，存在就要么是个相对术语，要么是个合成存在。不过事实并非如此。独一存在是绝对的。

存在与无

独一存在本身包含着一切存在。它是“有”，“无”是其影子。“无所不包的存在”这个概念意味着在其存在之外什么都不存在。当你分析这个“存在”概念时，已隐含着“非存在”概念。这个非存在（无）概念能帮助你弄明白存在概念。因此存在的补充方面是不存在（无）。但不能认为“无”本身具有分别和独立存在。它本身什么都不是。也不可能是任何事物的起因。多元和进化宇宙不可能是“无”本身的结果；你们也已经看到，它也不可能是独一存在的结果。那么多元和进化的宇宙是怎样产生的呢？

存在与宇宙

多元和进化的宇宙产生于独一存在与“无”的混合。当这个“无”被置于独一存在背景中时，宇宙便从中产生。但这并不是说宇宙一部分是独一存在的结果，或者说它具有存在的成分。宇宙是“无”的结果。它什么都不是。仅仅貌似存在。而其表面存在乃归因于那个似乎在“无”背后的独一存在。当“无”被添加于独一存在时，其结果就是多元和进化的宇宙。

因此，无限和绝对的独一存在不经历任何变化。它是绝对的，丝毫不受任何加减的影响。一体存在总是保持原样，完整而绝对，对产生于“无”的宇宙万象不关心也无牵连。“无”可被比作数学的零。零本身没有正值，但与另一个数字相加，就会产生多。同样，当“无”与独一存在结合时，多元和进化宇宙也产生出来。

自我与环境

这把生活基本上划分为“我”与“非我”，也就是自我及其环境。由于这个有限我的虚妄和不全（它仅仅是实乃不可分整体的一个假想部分），意识不可能满足于永远地与之认同，因而陷入了无休止的骚动，被迫去试图与非我认同。那部分被意识成功认同的非我或者说环境，作为“我的”被纳入自我。而那部分没有被意识成功认同的非我，则成为不可简化的环境：这就不可避免地对自我构成限制与抗衡。

因此意识所达到的不是局限性二元的终结而是其转化。而只要意识仍然受制于虚妄想象的作用，就不可能成功地结束这个二元。意识为同化非我（环境）所做的各种努力，结果只是原来的二元被同一个二元的其他无数新奇形式取代。对环境某些部分的接受或者拒绝分别表现为“想要”或“不想要”，从而产生了乐苦、好坏等对立两面。然而，无论是接受还是拒绝，都不能引向不二的自由，意识就这样不停地从一面摇摆到另一面。这种相反两面之间的摇摆，构成了个体进化全过程的特征。

业相完全决定论

受限个体的进化完全由其自古所积累的业相来决定。虽然这都属于想象，但决定论却是彻底而自动的。每一个行动和体验，不管多短暂，都在心体中留下一个印象。这个印象是对心体的某种客观修改；由于心体连续几生保持不变，个体所积累的印象也能够坚持几生。当如此积累的业相开始表现（而不只是潜在于心体）时，就被体验为欲望。也就是说，这些业相被看作主观的。客观与主观是业相的两面：前者是被动潜在状态，后者是主动表现状态。

这些业相通过主动阶段来决定受限我的每个体验和行动。正如在电影院把一个简短动作放映到银幕上会需要几英尺的胶片，决定受限我的一个行动也常常涉及到很多的业相。业相通过这种表现和实现得以耗竭。微弱的业相通过心体被耗竭；较强的业相以欲望和幻想的形式，通过精体被耗竭；强大的业相则通过表现为身体行动，借助肉体被耗竭。

这种业相消耗尽管不停地进行，但却不能最终摆脱业相，因为新业相不可避免地被创造出来——不仅通过新的行动，甚至还通过消耗过程本身。就这样，业相负荷继续增加，个人发现自己在甩掉这个负担的问题上无能为力。

通过对立达到平衡

具体行动和体验所积累的业相，让心容易受类似行动和体验的影响。达到某点之后，这个倾向又被一种自然的反作用所抑制和抵消，完全转向直接相反面，为反面业相的运作腾出空间。这两个对立面往往构成同一个想象链的不同部分。比如说，一个人可能首先体验到自己是位名作家，拥有财富、名望、妻子等人生中称心如意的一切。不过后来，他可能会在同一生失去财富、名望、妻子等等一切。有时候一个想象链似乎不包括相反的两面。例如，某人可能整个一生都体验到自己是位威震四方的常胜君王。在这种情况下，他只得在来世通过失败或者类似体验进行平衡，再用一生来完成其想象链。因此，纯粹的业相心理强迫乃受制于灵魂的更深目的之需要。

杀人事例

假设有人今生杀了人。这会把杀人业相积存于他的心体。假若意识只是简单地完全由这些杀人业相造成的最初倾向来决定的话，那么他就会继续一次又一次地杀人不止，每次都从随后的同类行动中集聚更多动力。若非经验的逻辑提供必要的遏制，就无法逃脱这种复发决定论。但这个人很快意识到单方面体验的不完整，并且不自觉地走向反面，试图以此恢复失去的平衡。所以，有杀人体验者会产生被杀的心理需求和倾向。他通过杀人，只认识到整个情势的一部分，其中他是杀人方。整个情势的另一半，也就是被杀的角色，对他来说依然陌生，未被认识，尽管已经进入他的体验。这就产生了通过把个人经验的反面吸引到自身来完成体验的需要。意识也有满足这种迫切新需求的倾向。一个杀过人的人很快发展出被杀的倾向，以便通过亲身经历来涵盖整个情势。

这就产生了“谁在来生杀他？”的问题。也许是前生那个被他所杀者，也许是另一个具有类似业相者。作为个体之间相互作用的结果，业相联系或纽带产生。当一个人采用新肉身时，也许出生在那些之前同其有业相联系的人中间，也许在那些有着类似业相的人中间。生命的奇妙调整使进化中二元的自由作用成为可能。

通过对立超越对立

人心就像织布工的梭子穿行于两极之间，编织生命布匹的经纬。最能代表精神生活发展的不是直线而是曲线。以河岸的作用为例，如果没有两岸，河水就会流散，无法抵达目的。倘若没有对立两极的制约，生命力也会以无穷无尽的方式消耗殆尽。最好把生命河岸视作两条在解脱处汇合的线，而非平行线。随着个体接近目标，摇摆幅度也越来越小；在他抵达目标时，摆动也彻底停止。好比重心在底部的不倒翁玩具。摇一摇，它就继续左右摇摆一会儿，但是摆动幅度越来越小，直到最后一动不动。这种对立两面的交替停止，就宇宙的进化而言意味着世界大绝灭；就个体灵性进化而言则意味着解脱。

意识内化层面

然而，从二元走向不二，不纯粹是意识状态的差异问题。二者因性质不同而有着无限差异。前者是非神状态，后者是神圣状态。这种无限差异构成了第六与第七意识层面之间的深渊。前六个意识层面相互之间也分别由某种峡谷（距离）分开。尽管它们之间的差距很大，但却不是无限大，因为都同样受制于有限体验的两极对立交替。第一与第二、第二与第三层面，一直到第六层面等之间的差距都很大，但却不是无限大。所以严格来讲，这六个二元层面的任何一个都不能说比其他层面更接近第七层面。这六个层面的任何一个与第七层面的差距都是无限的，正如第六与第七层面的差距是无限的。经由前六个层面的进步是想象的进步。对第七层面的证悟是想象的终止，因而是个体在真理意识中的觉醒。

通过层面进步

尽管如此，经由六个层面的想象进步仍然是无法完全避开的。必须彻底耗竭想象，才能证悟真理。即便有大师，也必须穿过全部六个层面。大师在带领弟子通过层面时，可能让他要么睁着眼，要么蒙着眼。如果弟子在掩护下行道并且意识不到自己正在穿越的层面，欲望就会坚持到第七层面。但如果他睁着眼被引领，并且意识到自己正在穿越的层面，那么在第五层面及之后就不再有欲望。大师如果来工作，通常会选择掩蔽作业，因为让弟子蒙着眼，可能比让他睁着眼，更有利于大师的工作。

穿越意识层面的特点始终是解开业相。应把业相的解开过程与消耗过程认真区别开。在消耗过程中，业相积极主动，表现为行动或体验。但却不能带来对业相的最终摆脱，因为新业相的不断积累不只是取代被消耗的业相，消耗本身也会制造更多业相。但在解开过程中，业相则被对无限的渴望火焰削弱与消灭。

对无限的渴望也许会带来大量的灵性痛苦。一般痛苦同一个人穿越层面时所经受的强烈痛苦无法相比。前者是业相的结果，后者是解开业相的结果。当肉体痛苦达到高峰时，人会失去知觉，痛苦因而得到缓解。但是对于灵性痛苦，却没有这种自动的缓解。不过，灵性痛苦不会变得无聊乏味，因为其中亦搀杂着某种喜乐。

对无限的渴望愈来愈剧烈，直至高潮，之后渐渐地开始冷却。在冷却过程中，意识不会完全放弃对无限的渴望，而是继续坚持其证悟无限的目的。这种冷却但却潜伏的渴望状态，是在对证悟无限做准备。渴望在此阶段已经成为歼灭其他所有欲望的工具，其本身也准备好被无限的深不可测寂静所熄灭。

证悟之和平

在通过证悟无限来满足对无限的渴望之前，意识还必须从第六层面过渡到第七层面。必须从二元过渡到不二。必须到达想象终点而非流连于想象之中。大师知道一体存在是唯一的存在，“无”只是其影子。对于他而言，时间被吞没于永恒。他已经证悟存在的永恒方面，因而超越了时间，并将时间的始与终包含于自身存在之中。他不受由“多”的作用与反作用所构成的时间过程影响。凡人既不知造物界的开始又不知其结束；陷入时间而缺乏正确观点，因此被逼近的貌似严重事件所压倒。他从自身业相能否实现的观点看待一切，对世界上发生的事情深感不安。对于他而言，整个客观世界似乎是某种不受欢迎的限制，必须要么战胜，要么容忍。

另一方面，大师则摆脱了二元及其特有的业相。他没有任何的局限。宇宙的风云变幻影响不了他的存在。世间一切喧嚣及其建设和毁灭过程，不会对他有任何特别意义，因为他已经进入真理圣殿——在造物界变幻不定的瞬间价值中只得到部分或微弱反映的永恒意义之寓所。他把一切的存在都囊括于自身存在之中，把现象世界的全部活动仅仅看作是一场游戏而已。
