神圣计划

正如人类历史上所有的重大关键时期一样，人类目前也在经历灵性再生的阵痛。强大的毁灭性力量正在酝酿之中并且似乎占据上风；然而挽救人类的建设性和创造性力量也在通过若干渠道被释放出来。这些光明力量的运作虽然基本上悄无声息，但最终定将带来重要的转变，确保人类安全稳定的灵性进步。这都是神圣计划的一部分，也就是给饥饿疲惫的世界重新赐予永恒唯一的真理。

人类问题的根源

当前人类面临的紧迫问题，是想方设法消灭以一切微妙和粗浊形式呈现于生活各领域的竞争、冲突和对抗。军事战争固然是混乱与破坏的最明显原因，但战争本身却并不构成人类的核心问题，而是本质上更严重问题的外部症状。单纯靠反战宣传是无法完全避免战争及其造成的苦难的。必须从根源上解决，才能让战争从人类的历史上消失。实际上，即使没有军事战争，个体或团体也会不断地卷入经济的或其他一些微妙的战争形式。只是当这些地下原因恶化时，才会出现军事战争及其涉及的种种残酷。

自私自利

动乱催生战争；动乱的根本原因是大多数人受自我主义和自私考虑所掌控，个别地并集体地表现自我主义和自私自利。此乃人类所陷入的虚妄价值生活。正视真理就是认识到：在多元的显现中并且通过多元的显现，生命皆一。有了这种认识，就是在“生命一体”的觉悟中忘掉束缚性的自我。

随着真正认识的降临，战争问题就会即刻消失。必须清楚认识到战争既不必要也不合理；当务之急不是如何停止战争，而是对造成这种残酷痛苦局面的思想态度发起灵性攻势。在众生一体真理中，合作和谐的行动变得自然而然。因此，那些深切关心人类重建者所面临的首要任务，就是尽最大努力驱逐笼罩着人类的灵性无知。

消除自我

战争的出现不只是为了进行物质调整。战争往往是与狭隘利益盲目认同的产物；这些利益通过与自我联系，被纳入所谓“我的”那部分世界。物质调整只是更广泛的灵性调整问题的一部分；灵性调整则要求消除自我——不仅从生活的物质方面，还要从那些影响人的思想、情感和文化生活领域中消除自我。

灵性认识

把人类问题仅仅理解为面包问题，是把人类降到动物性层次。即便是有限的纯粹物质调整工作，也需要灵性认识才会成功。个人利益必须让位于舍己之爱，才有经济上的计划与合作行动：倘若认识不到这一点，经济调整就不可能；即便拥有物质领域的最佳设备和效率，人类也无法避免冲突和匮乏。

科学的地位

从当前的斗争和苦难阵痛中诞生的新人类，将不会忽视科学或其实用成就。把科学视作反灵性是不对的。科学是帮助还是障碍灵性，取决于对它的使用。正如真正的艺术表现灵性一样，如果处理得当，科学也能成为灵性的表现与实现。有关浊界的肉体及其生命的科学真理，可成为灵魂认识自身的媒介；为达到这一目的，就必须把科学真理适当纳入更大的灵性认识。这包括对真正与持久价值的稳定感悟。倘若缺乏这种灵性认识，科学真理与成果就容易被人类用于相互毁灭，以及那种可能会强化精神枷锁的生活。科学和宗教只有携手并进，才能保证人类的全面进步。

灵性体验的必要

给即将到来的新人类文明赋予灵魂的将不是枯燥的理性教义，而是活生生的灵性体验。灵性体验能够把握单靠智力所无法企及的深层真理；它也不可能独立地产生于智力。常常能够通过智力来表述灵性真理。固然智力有助于灵性体验的交流，但其本身却不足以让人获得或者交流灵性体验。如果两个人都患过头痛，就能运用智力来共同探讨头痛经验，相互解释明白。但对一个从未患过头痛的人，再多的理性解释都不会让他懂得头痛的滋味。理性解释永远取代不了灵性体验；它充其量只能为后者打基础。

灵性体验的性质

灵性体验所涉及的不仅仅是智力所能掌握的。人们通常称之为神秘体验来加以强调。神秘主义往往被视作反理性和晦涩混乱、或者不切实际和无关体验的东西。事实上，真正的神秘主义绝非如此。作为（也应该是）对实相的视见，真正的神秘主义毫无非理性的成分。这是一种绝对明晰的感悟形式；极其实用，可在生活中的每一刻被体验，在日常职责中被表现。它同体验的联系是如此深刻，在某种意义上可以说是对一切体验的终极认识。当灵性体验被称作“神秘”时，不应认为那是什么超自然的东西，或者说完全超出了人类意识的理解。那只是意味着在有限的人类智力超越其局限并通过直接证悟无限而被照亮之前，神秘体验是人类智力无法企及的。耶稣基督说“舍弃一切跟从我”，即指明通往灵性体验的道路。换言之，人必须放弃其局限性并确立于神的无限生活。真正的灵性体验不但涉及到在高级层面上的证悟，而且关系到对世间义务的正确态度。如果脱离了与生活各方面的联系，我们得到的就会是一种神经质反应而远非灵性体验。

逃避不是灵性体验

将给新人类赋予生命活力的灵性体验，不可能是对生活现实的严峻不妥协要求的一种反应。那些无力适应生命流动的人倾向于从生活现实中退缩，躲进自造的幻相堡垒中寻求庇护。这种反应是通过逃避生活挑战来延续个体分别存在的一种企图。靠提供虚假的安全和自我完整感，只能对人生问题给出错误的解决方法。那甚至不是向持久实际解决方法的迈进，而是对真正道路的偏离。通过逃避来保护个体分别存在，只会被无法抵挡的生活新浪潮一次又一次从虚幻的庇护所中抛出，给自身招致新形式的痛苦。

新人类不执著形式

正如一个人可能通过逃避来试图抓住分别体验，他也可能通过不加批判地认同形式仪轨或传统习俗来抓住这种体验。形式仪轨和传统习俗在大多数情况下阻碍无限生活的释放。倘若是表现无限生活的灵活媒介，就应促进而非阻碍神圣生活在人间实现。但它们往往倾向于为自身树立声望权威，而非表现应表现的生活。出现这种情况时，对它们的任何执著都必将给生活造成严重妨碍与限制。新人类将挣脱受限的生活，让创造性的灵性生活无碍发展；还将打破对外部形式的执著，学会使之从属于灵性的要求。届时，受限的幻相和虚妄价值生活将由不受限的真理生活取代；分别我赖以生存的局限性也将随着真正认识的降临而衰亡。

与狭隘群体认同

正如一个人可能会通过逃避或者认同外部形式来试图抓住分别存在，他也可能会通过认同某个狭隘的阶级、信条、教派、宗教或性别来试图抓住分别存在。个体通过与更大整体的认同，可能似乎失去分别存在。但事实上他往往正是通过这种认同来表现分别存在，因为这会使他享受与其他阶级、民族、信条、教派、宗教或性别的分别感。

有限我靠对立生存

分别存在通过与一个对立面认同并与另一个对立面比较来获取生命和力量。一个人可能会通过认同于一种而非另一种意识形态，或者通过认同于自身善恶观中的善而非恶，来试图维护个体分别存在。与狭隘群体或有限理想的认同不可能带来分别我的真正融化，只可能带来融化的假象。受限我要真正融入普遍生命海洋，就必须彻底放弃一切形式的分别存在。

未来的希望

绝大多数人都深陷分别和武断倾向的魔掌。被人类的这些桎梏景象所压倒者，对人类未来注定只有无法缓解的绝望。要正确认识人类当前的痛苦，就必须深入考察现状。新人类的真正可能性对那些仅仅看到世界形势表面的人隐藏着。但这种可能性确实存在，只需灵性认识火花就能充分生效，大展风采。淫欲、仇恨和贪婪势力造成不可估量的苦难与混乱。但人性中一个可取之处是：即使在破坏势力当中，也无不存在着某种形式的爱。

爱必须摆脱局限

即使战争也需要合作，但是与有限群体或理想的认同，使这种合作范围受到人为的限制。战争往往是通过某种形式的爱进行的，但那是一种未被适当认识的爱。为了让爱大行其道，就不能对之约束限制。爱确实存在于人类生活各阶段，但却是潜在的，或者因为个人野心、种族傲慢、狭隘忠义与竞争及对性别、民族、教派、种姓或宗教的执著而受到限制与毒害。人类要复兴，就必须打开人心，让新的爱诞生——不受腐蚀并且完全摆脱了个人或集体贪欲的爱。

爱自行传播

新人类将通过丰富无量的爱的释放应运而生。唯有大师带来的灵性觉醒才能促成这种爱的释放。爱也不可能产生于单纯的决心。一个人通过行使意志力至多能够做到尽职尽责；通过奋斗努力，也许能够保证自身的外部行为符合自己的是非观。但是这种行为缺乏自发爱的内在美，所以在灵性上是贫瘠的。爱必须自发地从内里产生，绝不服从任何形式的内外势力。爱与强制永远走不到一起。不过，虽然不能将爱强加于人，却能通过爱本身来唤醒爱。爱在本质上是自行传播的；无爱的人能从有爱的人那里感染到爱。接受到爱的人不可能只是接受而不予回应，这本身即是爱的性质。真爱不可战胜，无法抗拒。不断地聚集力量，传播自身，直到最终转化受到触及的每个人。通过纯爱从心灵到心灵的自由无碍作用，人类将获得一种新的生存方式。

通过神爱拯救人类

普遍的神圣生活囊括万人万物，无一例外。当人们认识到没有比这种神圣生活更高的诉求时，爱将不仅在社会、国家和国际领域建立和平、和谐与幸福，还将闪耀自身的纯与美。神爱是神性本身的表现，绝不会被二元攻击战胜。也是通过神爱，新人类将配合神圣计划。神爱不仅将把不朽的甘饴和无尽的喜乐引进个人生活，还将使新人类时代成为可能。通过神爱，新人类将学会合作和谐的生活艺术；将挣脱僵死形式的暴政，释放创造性的灵性智慧生活；将抛弃一切幻相，确立于真理；将享受和平与持久的幸福；将被接纳进入永恒的生命。
