每年美赫巴巴抵达古鲁帕萨德之前，美赫文、盖麦和玛奴·杰萨瓦拉，还有杰罕古和谷娜·苏卡德瓦拉，会把宫邸打扫干净，充分准备好。不过，巴巴抵达时，除美赫吉、美赫文和杰罕古之外，谁都不许在场迎接。

11点半巴巴抵达，他当天上午比往常更多走动和登台阶，加上坐车疲劳，导致他髋关节疼痛。于是让他坐入抬椅，由男子们将他抬上古鲁帕萨德的台阶。一如既往，巴巴逗留普纳期间，卡卡·巴瑞亚留下照管美拉扎德，凯克巴德被送往美拉巴德山，和家人同住。由于1963年拜度中风，巴巴已把拜度送往孟买，住女儿莎瓦·塔拉坡瓦拉家（此后每年把拜度送去他女儿家，还允许他和另一女儿朵拉及妻子苏彤，在普纳居住几周）。同巴巴居住古鲁帕萨德的五名男满德里是埃瑞奇、彭度、阿娄巴、宝和弗朗西斯。伴随巴巴的六名女子，是美婼、玛妮、高荷、美茹、拉诺和娜佳。娜佳照例住宾德拉屋，负责做饭。

鲁斯特姆或索拉伯、蔻诗德、埃瑞奇、杰罕古·苏卡德瓦拉、美赫吉

每年纳纳·科尔会从那格浦尔来古鲁帕萨德，同满德里居住3个月。保·纳图会在那里度过5或6周的学校假期。蔻诗德也获准从孟买来，住3个月。纳瑞曼和吉姆·米斯特里每到周末就来。只要巴巴居住普纳，就有这些安排，直到他过世。

大多数时间，巴巴在古鲁帕萨德闭关，不许外人来见。仅珊塔迪薇王妃获准，于4月的某周天天来见。不禁止萨达希乌·帕特尔、美赫吉、美赫文·杰萨瓦拉、弟弟佳尔和贝拉姆、侄子希鲁、鲁斯特姆、索拉伯和杰罕古来访。但多数人有工作，故只会周日过来，那时巴巴会把马杜苏丹、罗摩克里希南、普若塔普、纳伦德拉、基桑、卡姆卜里、辛德和波特等爱者召来玩牌。暹罗猫佩古，也获得巴巴的诸多关注。总体上，那年古鲁帕萨德的氛围静谧和平，因巴巴继续闭关工作。

期间，巴巴给宝一小时，从下午3点至4点，从事写作。故这个时间，美赫吉遵令在巴巴身边守卫。4点后，宝守卫至午夜，该时间安排持续到后续几年。（注：后在古鲁帕萨德，宝从下午2点半至晚8点在巴巴身边守卫。彭度、阿娄巴和拉诺接着轮班守夜。）

一天下午3点半，美赫吉从巴巴卧室出来，径直走过宝身边，去找埃瑞奇。宝看到他，但以为他要带口讯，会回来。几分钟后，巴巴击掌，高荷赶去。“宝在哪儿？”巴巴问，“我在找他。他为啥不来？”

高荷告诉宝，他进入巴巴卧室。巴巴显得不快，问：“你为啥不来？我一直等你。美赫吉没告诉你，我要马上见你？”

“没，他没说。”宝说。

巴巴召来美赫吉，问他：“你为啥不叫宝来我这里？”

“我忘了，”美赫吉回答，“可宝有责任问一下，我为何提早离开您的房间。”巴巴同意，就训斥宝不问美赫吉此事。从那天起，美赫吉来值班时，宝只好在外面门廊等着，美赫吉一离开，就去巴巴房间。

换班时，虽然巴巴看似熟睡，他会突然打响指，问出了何事。离去者会对下任守卫耳语，巴巴打鼾了多少分钟，因为巴巴每天早晨会问，他实际睡了多久。但巴巴的“睡眠”相当不同。就在看上去他最终入睡时，他会忽然问起一个爱者，询问其家人、孩子及总体福利。也可能问起巴基斯坦的某人，是否获得申请的工作。巴巴会指示宝，次日写信那人问此事；也可能叫守卫者给某人写个便条，谈到某件貌似世俗的私事，其真实重要性只为巴巴所知。每晚都会这样度过——神人睡得很少，念记着世界各地的爱者，无疑以他自己的方式，关注着他们的福祉。

普纳炎夏期间，按巴巴意愿，卧室门窗保持紧闭。待在他房间里，感觉像置身于火炉！人在里面待久了，闷热得令人窒息。巴巴不许开一点窗，使守夜者甚是烦恼沮丧。而冬季，常人需要三层毯子保暖，巴巴只用一条薄的白布单，还会被汗水湿透。由于出汗，他的枕头和床罩须经常更换。

那年普纳夏季酷热，连夜间也热。有一回，宝守夜，坐在巴巴卧室角落，汗流浃背。巴巴躺床上，也流汗。少顷，巴巴坐起，问他：“你在想什么？”

宝回答：“没啥，没啥，巴巴。”他其实在想，外面酷热难忍，而房间里更热。他想知道：“巴巴为啥夜间一就寝，就要关闭所有的门、窗和换气扇？”宝感觉自己快被蒸熟了！

巴巴看着他，打手势：“今晚我感觉很冷。”

宝大惊，立即回答：“不，巴巴，热得要命。屋里很热！”

“我告诉你我冷，”巴巴坚持，“今晚很冷！”并重复多遍。

宝辩论说：“巴巴，天很热。不管问谁。我感觉热得难受。”巴巴一直坚持说天气多冷。

最后，巴巴厌烦了，问宝：“你把我看成什么？”

宝回答：“神。您是神。”

“你把我看成神，却不信我说的话！如果我是神，我就是真理！真理决不会撒谎。真理永远说真话。

“如果你有这种确信，就会感到冷，因为我说天冷！我永远说真话。”

宝那年38岁，却仍旧犯错误。

普纳工作者常周日来伴随巴巴。一天，普若塔普·阿希尔来到，巴巴对满德里评论：“普若塔普（1950年）在马哈巴里什沃来见我时，个子多小。当时他还是个少年。现在他长大了，非常爱我。”

巴巴转向他，问：“你记得我叫你脱衣服吗？我要你光着身子站我面前。”

普若塔普说：“是，巴巴，我记得。”

巴巴评论：“你多幸运，我瞥视过你的裸身。”

侄子索拉伯和鲁斯特姆在场，巴巴示意他们，从口袋里取出几枚弹珠。巴巴开始同他们玩弹珠。他记起，普若塔普在美拉巴德同他玩过弹珠，也叫他参加游戏。巴巴把一枚弹珠摆在地上，要普若塔普用另一枚弹珠从远处击之。因普若塔普瞄得准，击中。巴巴又摆一枚弹珠，示意普若塔普再击。他又命中。第三次也击中目标。巴巴随后把弹珠摆远处，叫普若塔普再试。他举起一盒巧克力，说：“你若击中，我就给你这盒巧克力。”

巴巴从盒里取一块给他，普若塔普放入口袋。他试了，却未击中。巴巴又给他两次机会，但他均未击中。普若塔普错过第三次后，巴巴不但没把整盒巧克力给他，还叫他归还已经给他的那块！

4月10日，巴巴再次到红宝石厅医院，由格兰特医生做体检。格兰特医生从检测结果诊断，巴巴的糖尿病得到良好控制。

纽约的世博会计划于1964年4月22日举办，美国爱者捐款并设立了一个漂亮的资讯展台，以传播美赫巴巴的宇宙讯息。展台位于美国室内建筑展馆的三楼。这期间的4月12日，巴巴给伊丽莎白·帕特森和简·海恩斯发去此电，给协助布置展会的全体爱者：

我的美国爱者出于爱，用美赫巴巴的宇宙讯息给纽约世博会增光溢彩，是蒙福的。我把爱之祝福给予所有爱者和工作者，他们使此举成为可能，并在展会期间为此工作。

展会开幕延期至5月8日，但巴巴的电报，使难捱的最后几周成为喜悦而非考验。估计每天有50万人来观展，许多人经过巴巴的拐角展位，看见他的相片，听到他的名。多亏伊丽莎白、吉蒂、简和许多其他人的不懈努力。巴巴从一开始就指出：“我将以自己的方式在展会做我的工作。”这很明显，因许多人被他吸引，后来致信默土海滨中心要更多信息。弗雷德和艾拉·温特非特，询问怎样回答人们可能提的问题。巴巴通过玛妮，写信答复：“巴巴说，他的爱与你们同在，故根本不用担心可能被问到的问题。你们对他的爱将说明一切，并解答所有问题。”

吉蒂后来叙述：

展台的多位工作者讲述了相同的故事：有些参观者感到巴巴相片的巨大吸引力（1956年约瑟夫·哈勃在默土海滨中心拍的大幅彩照）。他们经过时会突然止步，停下问他是谁，甚至听到他的名后，仍出神着迷。少数人可能谢绝（免费派发的）册子，对这位独特人物的记忆于他们足矣。一块优美铜匾的半身肖像底下，清晰可见他的名字**——美赫巴巴。**

美赫巴巴抱着小山羊的相片（1939年蓝车旅行期间伊丽莎白·帕特森所摄）也展出，还有这则给孩童的讯息：

我爱小动物，因为它们是我造物界的一部分。但我更爱孩童，因为和他们一起，我是永恒的孩童，开心游戏中的他们是我的玩伴。

纽约世博会开放到1964年10月。1965年4月重新开放，直到10月。

美赫巴巴答应过罗摩克里希南，在建筑竣工后祝福普纳中心，并指示他以简朴静谧的方式安排开幕式，因为巴巴在闭关。在建的会堂可舒适地容纳700人，另提供浴室和厕所，还有一间办公室和一间巴巴休息室。全部竣工，开幕的各项安排就绪。

1964年5月1日，自夏季抵达普纳，（除了去看医生外）巴巴首次走出古鲁帕萨德地界，驱车至索姆沃路441/1号的阿瓦塔美赫巴巴普纳中心。因他严格闭关，禁止一切活动和达善，不许公开庆祝。仅亲近爱者及家人受邀。可他们带来亲戚朋友，故人数增至500多人。

美赫吉的女儿佩琳，开车送巴巴和满德里去中心，上午8点55分抵达。车驶抵大门时，集会的爱者们欢呼致敬。轿车驶向主厅外的前廊，大厅用巴巴旗的七色来装饰。

巴巴一下车，中心主席萨达希乌·帕特尔献上花环。巴巴含笑拥抱他，然后走近大厅门，美赫吉端给他一个摆着剪刀和钥匙的托盘。巴巴取剪刀，给门前系着的七色缎带剪彩，再用钥匙开门。

巴巴步入主厅，七名中心信托成员和摄影师比库拜跟随其后。从门阶往前，铺毯过道上撒着柔嫩花瓣，一直通往主席台，台上摆着巴巴座椅。这把带垫扶椅是专为活动制做的。进入大厅后，巴巴打量四周，称赞墙上装饰着他的带框照片，呈现了他生平和工作的诸多方面。照片是比库拜赠予中心的，巴巴要他为他拍照。贝拉姆和杰罕古为活动拍电影。

巴巴一入座，阿迪从主厅的天花板展开巴巴的七色旗。之后外面等候的爱者鱼贯进大厅，各自就座。大厅坐满后，从小侧间走出七个小孩，唱着欢迎阿瓦塔的歌。每个孩子各捧一只花环，花色分别为巴巴旗的七色之一。孩子们一一将花环挂上巴巴的颈间，并在他跟前唱歌跳舞，以此表达全体普纳爱者的欢喜，因为他们受宠享受巴巴的莅临。巴巴脸上笑容洋溢，表明满意欢迎式。他表扬孩子们，赞赏马杜苏丹的努力，他过去几天在训练他们。普纳满德里组随后演唱巴赞，马杜苏丹为中心揭幕（瑙兰伽的美赫达姆，科弗尔的美赫斯坦，德拉敦的美赫达姆）专门创作的几首歌，还有为本次活动写的另一首歌。

美赫巴巴在古鲁帕萨德结束公众聚会时，通常大家会唱阿提。阿提的术语和概念，或者说敬拜神的歌曲，对西方人并不陌生。有无数基督教圣歌，用于赞美神，为生命中“神的礼物”献上感恩。拉姆·金德医生1968年10月对纽约团体的谈话中，对阿提的意义做了感人阐释。金德医生的原话是：

我想给你们朗读巴巴阿提的译文，是按我自己的诠释思考所作。这里聚会结束时，做阿提是惯例，我不知道你们有多少人听懂，因为它是用印地语或马拉地语写的。而我认为，倘若你们懂得阿提按我翻译的至少一种含义，或许它会有助于你们更好地领悟其重要性。

阿提是一种崇拜形式，是圣坛上其他崇拜形式结束时做的。我们印度人会焚香，点蜡烛，献花，献供品，敬酒等等，最后的仪式，是结束时唱阿提。它是感恩上主的慷慨和仁慈，他给我们生命中的赐予。我将朗读我的译文，或按我理解的——该阿提的含义。[阿提是马杜苏丹写的，他在古鲁帕萨德对美赫巴巴唱过多次。]

想象翱翔九天上，无从思维测度祂。

词穷墨尽难描画，无可比拟徒试尝。

韦达体系自古传，神圣经典如是述：

非此非彼乃真理，汝之荣光亘古扬。

至古永存神圣主，无上慈悲您拥有，

怜悯我辈并救赎，全世界与造物界。

美赫啊无限极乐赐予者，

我们的衷心阿提请接受。

焚香表示舍感官，缓慢持续毁欲望。

点燃烛光或点灯，真理之光入心房。

香膏涂抹您圣足，恶行错事慎莫犯。

献您鲜花与水果，赞颂至美与慷慨。

美赫啊何以侍奉崇拜您？

我们的衷心阿提请接受。

心血来潮一声令，宇宙万物由此创。

亲自背负此责任，救赎众生离幻相。

惟您存在理应存，终极真理无非您。

美赫啊人身上帝阿瓦塔。

我们的衷心阿提请接受。

一切生命非生命，飞禽走兽与静物；

悉皆源自于摩耶，无非是您之幻影。

谁可衡量您大能？不受限者乃无限。

美赫啊，我们的衷心阿提请接受。

未有自知无明人，怎能认识您荣光？

理当歌颂您荣耀，一心只求您怜悯。

美赫啊，我们的衷心阿提请接受。

您的慈悲与祝福，无穷无尽赞慈父！

凡夫俗子是我辈，何物可赠造物主？

爱者唯有祈求您：从现在乃至永远，

一切思言行当中，赐予念记真礼物。

美赫啊，我们的衷心阿提请接受。

金德医生谈话的原始录音稿，是他儿子苏哈斯·拉姆·金德写的。

马杜苏丹唱毕，5岁的美婼·科罗瓦拉走到话筒前，用英语背诵《帕瓦蒂伽祷文》和《忏悔祷文》。然后巴夫萨的女儿，苏妲和阿莎，念马拉地语祷文。索曼代表新普纳中心的爱者，表示他们感谢巴巴慈悲莅临中心的揭幕式。他还感谢，以各种方式援助建设并为之苦干的全体爱者。

巴巴告知萨达希乌·帕特尔：“从今天起至1965年5月1日的一年内，我将仅在普纳中心再施一次达善。之后，我将继续在古鲁帕萨德的常规达善活动。”

说完，孩子们唱巴巴阿提。他亲手触过的糖果，作为帕萨德分发。巴巴让桑吉瓦妮·科尔唱歌。她去年在古鲁帕萨德对他唱过，巴巴很喜欢她的演唱。巴巴心情极佳，虽先有规定谁都不得达善，仍允许大家走近、会见他并献花环。C·D·德希穆克让普纳艺术家，纳瑞希·丹德普里，制作了一尊巴巴半身铜像。他把铜像带来，请巴巴触摸祝福，巴巴应允了。

上午10点半许，巴巴在埃瑞奇和弗朗西斯协助下，走下主席台，进入私人房间。霍麦·D·玛拉提给房间做过装饰，为他备好。巴巴坐到床上，接过一杯鲜椰汁抿一小口，并触摸献给他的水果等食物，之后让满德里享用。他接着前往办公室，坐到一把椅上。11点钟，轿车驶近办公室门前，巴巴坐入车中，驱车回古鲁帕萨德。

1964年5月1日，普纳中心开幕式

一如既往，巴巴和女满德里的食物，是在宾德拉屋做的。男满德里的伙食，由佳尔·多拉伯吉的餐馆安排。多拉伯吉的独生女，嫁给孟买的克基·比利莫瑞亚。1964年5月底的一个周日，多拉伯吉夫妇带着独女和亲友，驾舟去孟买附近的象岛石窟，遭遇严重事故。

女儿和外孙女从船上落水，淹死了。悲剧发生后，巴巴虽禁止访客，却破例把多拉伯吉夫妻召到古鲁帕萨德。悲剧夺去了他们唯一的女儿和外孙女，俩人在巴巴跟前获得极大的安慰与力量。

尽管女儿去年来达善过巴巴，女婿却丝毫不信巴巴的神性。不过由于悲恸，克基·比利莫瑞亚对岳父表示他想见巴巴，多拉伯吉传话给彭度。彭度恳请巴巴接见悲痛欲绝的克基，巴巴便再次破例，把他召到古鲁帕萨德。克基·比利莫瑞亚见到巴巴后深受触动，对巴巴说：“我妻子去年想说服我跟她一道来，说：‘我说不清你见巴巴会有何收获，但只需在他足前坐几分钟，你就会知道’——而我没有来。现在我来了，懂得她的意思。我永远为此感激她，但十分懊悔，我没有在她活着时来见您。”巴巴对猝失妻女的他安慰有加，克基·比利莫瑞亚离去时，内心更勇敢平静，臣服于神意。

去年1963年，巴巴曾指示阿玛尔·辛·赛伽尔，转告让印度总理贾瓦哈拉尔·尼赫鲁来古鲁帕萨德见他。尽管赛伽尔对尼赫鲁转告了巴巴的意思，他却未抽时间过来。

来年巴巴到普纳后，宝守夜时，巴巴每天会问他：“我在闭关，若尼赫鲁突然来访，会怎样？”

宝回答：“尼赫鲁不会那样来，巴巴。若他有意见您，先会派人来预约。他这样做，我们将告知他，因为您在闭关，不可能会面。”

巴巴问：“他若不预约就过来，会怎样？”

“那不可能，巴巴。尼赫鲁太忙了！”

“但如果这样呢？”

每天就这样，跟守夜人来回问答。

然而5月26日，下午2点半左右，巴巴对满德里宣布：“贾瓦哈拉尔将很快来我这里；他一定会来！”

还解释：“纯靠他的精力和意志力，最近中风过的贾瓦哈拉尔康复得很快。但如果他再次心脏病发作，就活不了，将立即去世。”

巴巴讲话后24小时，电台就播报了尼赫鲁的死讯。埃瑞奇的弟弟美赫文，于5月27日下午2点半打电话将消息通报古鲁帕萨德。那时宝才明白，尼赫鲁怎样无需预约就能“来”巴巴这里。当天晚些，巴巴对满德里评论：

随着潘迪特吉的去世，印度损失了第一位总理，他忠诚地服务其深爱的印度，亦谓首屈一指。贾瓦哈拉尔·尼赫鲁是无与伦比的政治家，印度将不得不再等700年，才能找到另一枚像他那样的珍宝。

可以说他是一名真正的羯磨瑜伽士（注：吠檀多里的羯磨瑜伽，指人通过超然无执的工作追求证悟神的道路）。他有阿玛尔·辛·赛伽尔赠予的《神曰》，只要他至少读过一部分，就会受益。

只有当我再来，下次降临地球期间，才会有另一个（印度领袖）像贾瓦哈拉尔那样。

第十八卷完
