1962年8月26日周日，美赫巴巴在美拉扎德召开普纳工作者专场会议。会议持续三小时，确定了有关“东西方大会聚”安排的若干要点。算出安排的预估费用，提交巴巴批准。估计至少需7000卢比，用于古鲁帕萨德内部的安排费（遮篷、租椅、麦克风、电力设备、厕所、供水和日常劳工费）。巴巴选了九个亲近爱者分担上述费用：约瑟夫·哈勃付1500卢比，纳瑞曼·达达禅吉、霍桑·巴如查和基申禅德·伽吉瓦尼各付1000卢比，索拉伯吉·斯甘坡瑞亚、美赫吉、巴布萨赫伯·辛德、弥奴·德赛和弥奴·巴如查，各付500卢比。

8月31日，巴巴又授述两篇语录，首篇为《爱者与被爱者》：

神即爱。爱必须爱。要爱就得有被爱。但因神乃是无限永恒的存在，除了自己外，他别无可爱。为了爱自己，他必须将自己想象为（他作为爱者所想象的他爱的）被爱者。

被爱者和爱者意味着分离。分离制造渴望；渴望导致寻找。寻找越是广泛热切，分离感就越强，渴望就越严重。渴望最为强烈时，分离也达至极限，分离的目的实现——爱将自身体验为爱者和被爱者；合一随之而来。结合达成时，爱者便知道他自己一直就是他所爱的、且渴望与之合一的被爱者；

他还知道他所克服的一切不可思议的困境，都是他给自己在道路上设置的障碍。

达到结合难乎其难，因为不可能成为你已然是的！结合只不过是知道自己即唯一者。

第二篇语录标题为《宽恕并忘却》：

人们求神宽恕。但神就是万人万物，要他去宽恕谁呢？对受造物的宽恕已经存在于他的创造行为中。但人们依然请求神的宽恕，他则宽恕他们。然而，他们不是忘却其祈求宽恕之事，却忘记神已经宽恕了他们，反而记住已被宽恕之事——从而滋养恶行的种子，使之再次结果（怨恨）。他们一次又一次祈求宽恕；大师一次又一次说，我饶恕。

然而，要人们忘记所做的错事和别人对他们做的错事是不可能的。他们因无法忘却而难以宽恕。但宽恕乃是最好的善举。（一个人富有时给穷人施舍钱物较容易，而宽恕却很难；如果能做到，它却是最好的事情。）

人们非但不努力相互宽恕，反而相互打斗。他们曾一度用双手和棍棒厮打。后来用长矛和弓箭。后来用枪支大炮。再后来他们发明了炸弹和轰炸机。如今他们造出能毁灭数千里外百万人的导弹，且准备使用之。使用的武器改变，人类的侵略性却依旧。

目前人们计划登月。第一个到达的人将插上自己的国旗，那个国家会宣布，它是我的。而另一个国家会质疑这种宣称，他们便会在地球上争夺对月球的占有权。无论谁到那儿将发现什么呢？仅仅是他自己而已。人们若去金星，也会发现除他们自己之外什么都没有。人类无论是飞进外太空，或是潜入最深的海底，他们将发现原来的自己，未曾改变，因为他们不会忘记自己，也不会想到去实践宽恕的美德。

对他人的统治绝不会使人改变自身；他的征服越伟大，头脑告诉他的断言就越强固——除了他自己的力量之外没有神。他依旧与绝对全能的神分离。

当同一个头脑告诉他，存在着可被称作神的某物，并进而促使他寻求神，以可能面对面见神时，他就开始忘记自己并且宽恕别人，无论他们对他做过什么。当他宽恕了每一个人并且全然忘记自己时，他便发现神已经宽恕了他的一切，并且记起他自己实际上是谁。

期间，弗朗西斯忙于给这两篇及其他语录做英语上的润色，收录在巴巴取名为《有与无》的新文集。玛妮和拉诺打字。宝把一些语录译成印地语。一天，巴巴把文稿交给他，打手势：“我要你把这个译成印地语，使它（对印地语读者）生动有趣。”

宝说：“如果英语写得有趣，印地语自然会引人入胜。”

巴巴回话：“那我不知道。我要你译得生动有趣，语言要简练。”

宝斟酌了巴巴的话。他想到以对话的形式编写全书，用该风格完成一篇。他读给巴巴听，巴巴表示满意，表扬他：“对，这就是我的意思。”

巴巴还提议应该收录歌曲，并提到也应该加一篇祷文。宝记起，1959年巴巴授予他一个印地语的特别对句，在此基础上宝续写了11个对句。

次日晚他去守夜，巴巴问：“你写祷文没？”得知他写了，巴巴要宝读给他听。巴巴满意，但表示祷文应该长些。那天巴巴心情甚佳，伴着诗行的节奏，以拳击大腿，开始创作新的对句，宝做笔记。巴巴坐在床边，授述了另17个对句，就这样《惟有您存在》祷文成形。后来一段时期，巴巴表示有一天全世界都将唱诵这篇祷文。以下是这篇诗体祷文的全文：

9月5日，巴巴的另一名亲近老跟随者，玛丽·白克特，在英国去世。时年86岁。巴巴总把玛丽和她丈夫威尔称作他的“大天使”。7日致电威尔：“我的大天使玛丽完成指定任务后，已来我这里。在我的爱里保持愉快。”

9月7日是辟鲁·萨达生日，巴巴同意上午11点到访阿克巴棉纺厂10分钟。他率埃瑞奇和另三名满德里过去。巴巴给辟鲁一个生日拥抱，并接见萨达和达玛尼亚家庭的全体成员。没有外人获召。饭菜做好后，巴巴带回美拉扎德用午餐。

基申禅德·伽吉瓦尼之女莎玛，忠爱巴巴，现居美国。她和丈夫儿子一起回孟买探亲。征得巴巴准允，9月10日，伽吉瓦尼带他们到美拉扎德。小男孩胆大淘气。巴巴给每人一块糖，男孩往巴巴嘴里放了一块，说：“巴巴，您也应该来一块太妃糖！您分给大家，他们都吃了，可我不吃我的糖，除非您先吃一块！”

母亲试图让他安静，巴巴却拦住她，安慰她说：“别阻止他，我喜欢。今天是他的吉日！”他们待了2小时，期间由于男孩调皮捣蛋，美拉扎德的一切都陷入停顿。

9月19日，巴巴为聚会者授述：

“有些人存在，是为仇恨嫉妒他人，使他人不快；

有些人存在，是为爱他人，使他人快乐；

与神合一者，为众生存在，不管其好坏。

要与神合一，人不必舍弃任何东西，只要舍弃自我。”

1962年9月20日，给印度、巴基斯坦、欧洲、美国和澳洲的将会参加11月普纳‘东西方大会聚’的全体爱者寄发一则通告，就爱者来访给予一些最后指示：

他们应当带着集体享受巴巴临在的单一想法而来，而不要希望或提出要求他给予任何个别关注或指导，不管这些问题涉及他们自己，还是其家人和朋友，或者关乎巴巴的工作、团体或中心的活动。不应该提任何问题，不管是灵性上或其他。

美赫巴巴表示，今年11月的聚会将是独特的，不同于以往的任何撒晤斯或达善。他因此强调，除了只安住于他的临在，任何其他的期望都会干扰巴巴想要的氛围，并会导致这样的干扰者损失安住于巴巴临在的真实利益。

9月30日周日，巴巴解释造物界的众生皆是“无知的化身”，并就此主题授予另一篇讯息。10月2日他为‘东西方大会聚’活动授述一则短讯：

“无人死，无人生。

惟有幸运的罕见者死去，

死于真死，在神里诞生。”

随着聚会时间临近，为10月底前往普纳的准备工作继续加快步调。每天都会出现新情况，要求巴巴的全面关注和指示。10月7日，普纳中心的罗摩克里希南和几名工作者被召到美拉扎德，商议细节并确定聚会的一些事务。10月14日，美赫吉也为此而来。

10月16日，阿美纳伽布思医院的澳洲外科大夫，基督徒，欧内斯特·佩德森医生，来美拉扎德访问巴巴。

巴巴对佩德森医生解释：

神不可分地在万人万物里。表面的孤立是由于无知。海洋里的水滴同海洋一体，一旦它被覆以泡沫形体，就与海洋分离。当泡沫破裂时，水滴又与海洋合一。

同理，当灵魂被心、能量和物质之泡沫覆盖时，就与神分离。可一旦泡沫破裂，即通过对神的爱歼灭自我时，他就发现自己与神为一。

当人与神合一后，下降到人类层面的正常意识时，即获得基督意识，并且为了全人类在灵性上、精神上和身体上持续地受苦。

库希如大院里的阿美纳伽中心于1959年启用。随着阿美纳伽的信徒数量渐增，感到需要更大的场地，因旧屋只能坐下50人左右。萨若希负责整修委员会，将库希如宿舍的两个房间合并成一个大厅。1962年10月21日周日，被定为揭幕日，巴巴虽然身体不适，仍接受萨若希的邀请，出席活动并宣布中心开放。他率领几名男满德里于上午9点抵达库希如大院。近500人参加。

巴巴到后，走上三层台阶到中心前廊，为七色缎带剪彩，并推开门。他进入装饰华美的大厅，上台入座。

萨若希先献花环，他儿子默文的未婚妻、瑞士姑娘艾妮塔随后。巴巴向她保证，不用烦恼，要保持开心。

阿美纳伽巴赞组，包括拉塔·丽玛耶，唱了几首歌。那年拉塔未被选作候选者参加德里举办的演唱比赛，但巴巴对她保证，不用为之烦恼。对她说：“有一天，你本人将成为评选者之一。”

埃瑞奇随后宣读巴巴授予揭幕式的讯息：

我宣布，阿瓦塔美赫巴巴阿美纳伽中心，对所有敞开心灵接受我的大爱祝福者开放。

今天你们全体在场者，只要全心全意地爱神，乃至完全忘却世间事务，就总是能够接受我的充分祝福。

但要记住，灵性道路上哪怕最轻微的虚伪都会阻碍进步。全心全意爱神，即在万人万物中见神。因此，你应当以这样的方式爱神，以至于看见神无处不在！

对萨若希来说，阿美纳伽中心的整修工作做得尽善尽美，是真正的爱之劳动。我把爱和祝福给予他和建设中心的所有工作者。

一首歌唱毕，巴巴授予这篇关于爱的语录：

爱神是神给人的礼物，因此人不可能靠自己去按应爱的方式爱神。除非人成为该礼物的接受者，否则不可能让他去爱神。然而，至师的恩典能够使人按应爱的方式去爱神，而当人开始爱神后，世界及其事务便不复存在。

爱是保持世界运行，并给我们的生活赋予意义的粘合力。没有爱，世间万物无非是垃圾！

拉塔唱起大阿迪给她的一首格扎尔。演唱中，巴巴轻轻点头，用手打拍子。他解释歌词意思：“这首格扎尔表示，一个人不该满足于沐浴阳光下，而应该成为太阳本身。成为太阳不容易！它需要勇气，亿万人中只有一人，能通过彻底抹除自己并臣服于至师，来实现难乎其难之事。爱的义务就是全然臣服于至师。”

纳夫勒在主席台旁，巴巴问他家人在不在。纳夫勒作肯定答复，巴巴评论：“一切皆幻相，其中无实质。”随即告知纳夫勒将举办东西方大会聚，并调侃说：“不许你参加，除非你有我的爱之信物！”

萨若希简短致辞，感谢巴巴出席揭幕式。达克站起，以一贯生动的马拉地语，滔滔不绝地讲述创世的起因和目的，并宣布巴巴作为人身上帝一次又一次地来临，通过使人类认识其真我来救赎之。

达克的冗长赘言被巴巴叫停，并对听众说：“他说的话，连我都不易听懂！虽然心在一定程度上能有所领会，讽刺的是，只有在心走掉（被歼灭）时，才能体验达克所言！那时人不但知道，且成为之！”

继而说：“我不是你们看见的样子。我是无限的爱之洋，其无限广袤。是你们的心的耍弄，使你们看见我的样子。将是同一个心的耍弄，在我离开这个地方后，使你们忘记巴巴在这里。即便如此，你们的爱让我非常满意，我把全部的祝福给予你们。”

巴巴向聚会者行合十礼。多名军队和市政官员带着家人在场，阿迪领着几个到台前见巴巴。一个是阿美纳伽地区总警长，D·S·索曼。阿迪告诉巴巴，他送了一本《神曰》给此人。巴巴说：“如果你仔细通读全书，将知道何为真正灵性。”

巴巴随后触摸当帕萨德分发的甜食。阿提由阿美纳伽歌手演唱，巴巴表示：“我走之前，要拉塔唱首格扎尔。她唱完后，我离开大厅时，谁都不得上前顶拜我。”

拉塔唱起歌，巴巴解释其意：“据说一个人应当痛饮神爱之酒，陶醉其中，乃至忘却一切，除了神什么都意识不到。为了证悟神，那种陶醉是必要的！”巴巴拥抱拉塔，在“阿瓦塔美赫巴巴凯捷！”的欢呼声中活动结束。10点15分许，巴巴启程赴美拉扎德。

此时巴巴健康不佳。他开始患严重的抽搐和肌痉挛。（自1962年起，巴巴出现剧烈痉挛时，整个身体会从床上弹起。）他发烧，任何治疗都不起作用。可他拒绝让高荷咨询外面的医生，而因忙于准备赴普纳，她没有时间查阅病理资料。最后，巴巴同意让邓肯来美拉扎德帮助诊断。邓肯开始全天研究最新的医学书刊，却弄不清巴巴急性病症的肇因。他和高荷试过多种不同的药，却无一能缓解这种怪病的症状。

由于第二次汽车事故致伤，巴巴的右腿仍很疼。每当他在床上休息，宝或另一个满德里会给他按摩。巴巴勉强同意，用轻微热敷治疗他的腿，一次10分钟。

尽管健康糟糕，巴巴不愿休息搁置当前的工作。他保持活跃，照例处理日常的指示和通讯。10月21日周日，他授述此电报，发给欧洲、美国和澳洲的西方爱者：

我的健康很糟，但你们的爱将在东西方大会聚期间帮助支持我。将本通知传给与你们一起旅行的全体相关者。

译自宝·喀邱瑞著《美赫主》第十八卷
