2007年12月24日晚约11点，寇斯若·纳密朗尼安（Khosrow Namiranian，巴巴寇斯若），修爱院的最后一个学生，与他的至爱阿瓦塔美赫巴巴合一。

巴巴寇斯若1918年3月23日出生在伊朗的耶兹德（Yazd）。他八岁时被美赫巴巴的满德里拜度（Baidul）先生带到印度，同往的还有他的孪生兄弟寇达亚（Khodayar）和其他12个伊朗孩子。他们和印度各地来的100多个孩子一起在美赫巴巴的学校“美赫埃舍学校”（Meher Ashram）读书。他们的父母送孩子来受教育，他们不知道这些孩子的命运还包括接受至爱美赫巴巴的大爱之火。

开学一段时间后，至爱巴巴为了其特殊的宇宙工作，从美赫埃舍学校挑选出28个学生，建立了“修爱院”（Prem Ashram）。寇斯若就是其中之一。至爱巴巴对他们做的工作，超越了我们的人类理解力。本时代阿瓦塔的神爱火焰在这些孩子的心里点燃。有时候他们会哭泣数日数夜。事实上我们只有像孩子一样，才能进入那个神圣喜悦状态。这些特殊的孩子对至爱一定是渴望了很多世，才在今生被本时代的阿瓦塔呼唤来。

寇斯若的幼小心灵也被神爱之火点燃，并且燃烧了整个一生。尤其是在晚年，寇斯若几次访问了他的故校，他上过的唯一学校。每一次重访美拉巴德山上的博物馆，他都哭得像个婴儿一般。在修爱院期间，允许年龄大些的孩子用手推车（车如今存放在博物馆里）推巴巴，只有八岁的寇斯若因身材矮小，不可以帮助推车。他多么渴望表示自己对至爱巴巴的爱，这种爱的强度终生不减。至爱美赫巴巴的话是寇斯若一生的写照，“心灵像孩子，智慧像老人。”

巴巴寇斯若满怀着爱和慈悲，服务他唯一的至爱美赫巴巴，并坚信一切生命为一。他住在伊朗，通过伊朗人民来服务巴巴。他在舍拉子（Shiraz）的家被巴巴爱者称作“神爱酒馆”。这个酒馆向进来的每一个人，昼夜地分发着极其独特的神圣爱酒。通过做祈祷，无私服务和臣服至爱。

无论谁走进他的屋子，巴巴寇斯若总是亲吻他脚上的尘土，对他们说，“你来到这里，是至爱巴巴的意愿，所以你对我很珍贵。”

很多人走进这个酒馆时失魂落魄，走出时心里装满神爱。在这个酒馆里，问题一次次奇迹般地得到解决，以简单至极的方式。这些事件帮助巴巴爱者明白巴巴为什么说：

明白了，生活是个玩笑；

不明白，生活成为苦恼。

战胜之，生活脱离烦扰。

行道中，生活考验不少。

融于爱，生活极致达到。

至爱美赫巴巴通过学生寇斯若，深深地影响着每一个接触他的人。这也表明了寇斯若对至爱阿瓦塔美赫巴巴的彻底臣服、奉献、爱和服务。

2007年12月6日，巴巴寇斯若像往常一样，半夜刚过，就起床做祈祷和静心。早晨3点时他摔倒在地，右大腿骨折。他用了近6个小时，从摔倒处挪到电话旁，给女儿打电话求助。

在事故之前，巴巴寇斯若一个人生活，独立地料理一切所需。

手术不久他被送回家，一天24小时由巴巴爱者和他的子女看护。靠着助走器，他又能慢慢地走路了。寇斯若的学生和巴巴爱者感到这其实是至爱巴巴给他们的一个机会，来服侍爱护他的最后一位修爱院学生。

他们知道，在服侍巴巴寇斯若中，他们在服务至爱美赫巴巴，并且为此感激巴巴寇斯若。

在这47天，每天夜里巴巴寇斯若的学生中有两个来照料他。那天夜里他看着照料他的学生说，“好消息，好消息，你们应该转告给其他人。从今晚起，谁都不必为我呆在这儿了。我将把负担从你们肩上卸下。你们再也不必每夜来这儿了。我已没有特别的工作。有的话，我的女儿们可以做。”

当一个学生坚持留下时，巴巴寇斯若（用他的祈祷串珠）跟至爱巴巴商议此事，并且得到巴巴的许可，学生们应该可以留下，最后一次。

那天夜里，当巴巴寇斯若的女儿们回自己家之后，他要学生把他从椅子上挪到床上躺下，过了几分钟，他突然呼吸减慢，并且开始念至爱美赫巴巴的名，随后他举起双手，说道，“至爱美赫巴巴救我，巴巴，巴巴，巴巴。”之后他似乎经受着很大疼痛，并且挥手告别。寇斯若加入了他的至爱，并淹没在至爱里面。

巴巴寇斯若家（酒馆）里有一株茉莉花树。极不寻常的是，这棵树一年四季天天开花。每天早晨巴巴寇斯若都会采一些花，献在至爱巴巴的双足照片前，花香弥漫酒馆。巴巴寇斯若加入至爱的那天早晨，我们惊讶地发现，花全部卷缩在树上，除了一朵之外。我们把这朵花摘下，放在巴巴寇斯若的胸口。

“我以我的神圣权威对每一个人和所有的人说，无论谁只要在生命的最后一息持我的名，都将会来我这儿；因此不要在最后的时刻忘记我。除非你从现在开始念记我，否则当最后的时刻到来时，你就很难记住我。你应该从现在开始练习。你即使每天持我的名一次，也不会在临终一刻忘记我。”

即使在睡眠或无意识时，巴巴寇斯若都一直念至爱巴巴的名。他对至爱美赫巴巴的深爱，将他自己的存在与巴巴的名结合在一起。

对巴巴爱者和来酒馆拜访他的人，他总是用下面的特殊欢迎词，他们也学会全部用英语回答：

巴巴寇斯若会说：你是巴巴

巴巴爱者会说：一切都是巴巴

巴巴寇斯若会说：巴巴是一切万物

巴巴爱者会说：一切万物都是巴巴

巴巴寇斯若会说：巴巴是神

巴巴爱者会说：神是巴巴

巴巴寇斯若会说：巴巴是爱

巴巴爱者会说：爱是巴巴

巴巴寇斯若会说：谢谢您巴巴

巴巴爱者会说：谢谢您巴巴

如果某个人因不熟悉而不回答，巴巴寇斯若会看着他或她的眼睛，面带甜美的微笑替他们说。

在生命的最后几年中，巴巴寇斯若不让人用拥抱或亲吻表示对他的景仰，但在最后47天他躺在床上时，巴巴爱者有机会亲近他，他经历的疼痛和痛苦是他向至爱做的最后奉献和无私服务。

他还对我们承诺说，如果某一天他跟至爱巴巴合一了，他会首先向所有热爱真理者伸出援助之手。

如有人赞扬他，哪怕只是表示敬意，他也从不允许。他总是指着至爱美赫巴巴的照片说，“当你有了百分之百，就不要找任何低于那个的。”

他还会说，“我只是个老熊，你们应该紧抓住至爱巴巴的衣边，不要松开。你们的一切尊敬、慈悲和爱都应该献给那个无上的大爱和大爱者的形体。”

巴巴寇斯若说的对，但我们还知道这样一个事实：他是我们的至爱美赫巴巴的燃烧的火炬，把光明给予伊朗。1920年代后期，至爱巴巴在关闭美拉巴德的几所学校时，说这些学校仅仅像是他为真正工作所搭的脚手架。也许那些后来在世间做至爱美赫巴巴的灵性工作的学生们就是建筑。

关于巴巴寇斯若，有谈不完的话，恰如他对众生的至爱阿瓦塔美赫巴巴的爱也无止境。

2007年5月25日，巴巴寇斯若最后一次朝圣印度，因为至爱阿瓦塔美赫巴巴的呼唤，使得他的最后一位修爱院学生（时隔81年后，以89岁的高龄，拿着学生签证）重返故校。这次旅行没有一步归功于巴巴寇斯若自己的意愿。唯有至爱巴巴知道必须要做什么内在工作。

对生活在巴巴寇斯若附近的学生和巴巴爱者说，巴巴寇斯若的无私服务，慈悲和爱是非凡和独特的。很多时候，我们目睹了巴巴寇斯若的酒馆（家）的满屋子人，带来很多问题和烦恼，离开时却像自由的飞鸟。

这会持续一天，有时候他没有机会准备或吃午饭。但衰老虚弱的他依然连续谈，用至爱美赫巴巴的名，解决他们的问题。很多来访者是生人，他们只是听说了巴巴寇斯若，他们并不是巴巴的爱者。这对他并不重要，他同样尽力帮助他们。至爱美赫巴巴，在一次达善时，要满德里去找寇斯若带来。他们在成千上万的人群中找到寇斯若，带他来见巴巴。对这个修爱院的学生来说，那是个极其特殊的时刻。至爱巴巴给他私下达善。寇斯若解释说，从那一刻起，他在道路上的大多数障碍都被至爱拿去了。

巴巴寇斯若是至爱美赫巴巴的真正使者。他过着至爱所希望他过的一生。一次只是因为巴巴书里的一句话，他就把全部世俗财产送了人，变得一无所有。他的住处（酒馆）是他已故妻子的终生积蓄，他始终不让归在他的名下，而是要它继续永远作为舍拉子的巴巴中心——伊朗的很多城市和舍拉子的巴巴爱者的唯一酒馆。

至爱巴巴的希望是：传播我的大爱讯息。那些真正爱我的人，就是我在世间的“中心”。让每一个巴巴爱者，无论他或她在哪儿，都成为“巴巴中心”的化身，散发永恒的神爱讯息，过着爱、奉献和诚实的生活。

你传播我的永恒大爱讯息时，首先向人们显示你真正地爱我。不要只是叫他们读我的著作和讯息。要做更多——过着爱、奉献、宽恕和忍让的生活，使得其他人也爱我。

巴巴寇斯若就是这样一个纯洁、慈悲的爱者，他的爱和慈悲使他成为至爱在世间的一个中心。他有着孩子般的纯洁心灵和老人的智慧，他的头脑一直在控制之下，直到生命最后一息。像至爱美赫巴巴的其他弟子一样，他通过爱、奉献和诚实的一生，散发着永恒的神爱讯息。

他每天站在至爱巴巴的照片前，背诵哈菲兹的对句：

“我献出自己的灵魂，但很难为情，因为这对至爱是如此不足道的牺牲。”

随后巴巴寇斯若会向我们解释说，只有过爱和慈悲的无私服务生活，才能做到为至爱美赫巴巴牺牲自己的灵魂。

他曾住在舍拉子，但他学生遍布全伊朗，他们用他的爱之道作为向导。哈菲兹说：

“爱是不可能谈论的，酒商，斟酒给我们，让我们中断这个谈话。”

最后是无话可说的，因为如至爱美赫巴巴所言：“真正的东西是在沉默中给予和接受的。”

感谢至爱阿瓦塔美赫巴巴，如巴巴寇斯若所说：

胜利属于阿瓦塔美赫巴巴——永远的真正朋友。
