一个叫谢赫的穆斯林司机（巴巴很喜欢他），自1959年起一直居住美拉扎德，但他于1966年辞职，以便花更多时间陪伴在普纳的妻儿。另雇了一名司机，但1966年4月1日周五，大阿迪像几乎每年夏天那样，开着蓝色迪索托车，将巴巴和女子们送往古鲁帕萨德。巴巴已有九个月未离开美拉扎德。阿迪遵令开得很慢，但巴巴仍感到旅途不适疲惫。

{注：7月大阿迪返回普纳，开车接他们回去。}

那年，不允许访客来古鲁帕萨德，巴巴在闭关工作，足不出户。然而，有个小家伙仍能自由出入，那就是猫咪佩古。巴巴一到，它又在古鲁帕萨德安顿下来。看到巴巴对这只猫的喜爱和兴趣——它每天早晨都会一溜烟地跑进巴巴的卧室，并用脑袋蹭他的足——美婼和玛妮决定把这温馨可爱的一幕拍摄下来。结果发现此事颇费周折。巴巴坐在床上，但他感觉不舒服。地上放着垫子让他搁脚。

{注：为了拍电影，垫子被拿掉，以便猫可以玩耍。}

玛妮准备就绪后，希拉·喀邱瑞（她住在古鲁帕萨德且特别喜欢猫）便放出佩古。可玛妮一打开贝拉姆的泛光灯，猫就停止玩耍，盯着灯光看，因为那是新鲜事物。“没关系，”巴巴说，“明天再试。现在先收起来吧。”女子们失望地离去。接下来几天里，情况如出一辙。她们反复尝试拍了几段巴巴和猫的镜头，效果都不理想。

“我们很有耐心，继续拍摄，直到猫习惯了灯光。”美婼说。

另一日，当玛妮拍摄美婼等女子和佩古的几个场景时，这只猫很配合，可女子们却让玛妮头疼不已。

一人说：“你不能这样拍……在这可爱的开花灌木旁拍些镜头吧。”

蔻诗德说：“你没拍过我站在美婼身边的镜头。”就这样持续着。

玛妮恼火地说：“有五个演员和五个导演！”

为锻炼身体，巴巴会在古鲁帕萨德宫三面环绕的游廊上踱步。[古鲁帕萨德的背面没有游廊。]晚餐后，玛妮为他读书。巴巴说过，他小时候爱读英国侦探塞克斯顿·布莱克的冒险故事。1966年，遵照巴巴的要求，小阿迪从英国寄来几本塞克斯顿·布莱克的书，这些书都读给他听了。“早期，巴巴最初喜爱的是塞克斯顿·布莱克，”玛妮说，“之后是埃德加·华莱士。拉诺和我给他读过很多埃德加·华莱士的书。玛格丽特也读了不少。后来，他非常喜欢尼罗·沃尔夫系列的书，我们不得不再次为他朗读，[每本书]读了两遍。我在书上标了日期，大概隔了一年左右，又重读一遍。”

{注：拉诺还继续给巴巴读《时代》杂志上的文章。具有讽刺意味的是，1966年4月8日那期的封面故事是《上帝死了吗？》。}

大约下午5点半，美婼等女子走出巴巴房间，宝过去守夜。多个晚上，女子们都去看电影。6月美婼给艾琳写信：“阿娜瓦丝和恺娣同我们一起住些日子，我们去看了一些好电影。其中一部是关于格林兄弟的生平 [《格林兄弟的奇妙世界》]，我们都非常喜欢。”

另一晚，她们看了音乐剧电影《俄克拉荷马》。美婼喜欢看那些马儿，欣赏套马的场景。于是她们去看了另一部西部片，黛比·雷诺斯主演的《永不沉没的莫莉·布朗》。“这是我们记忆中最棒的电影之一。”玛妮指出。

当女子们看过沃尔特·迪士尼喜剧《飞天老爷车》后，美婼对巴巴说：“您一定要去看，巴巴，您会喜欢的。太有趣了。”巴巴同意了，之后带满德里一起去，男子们都很高兴能去看电影。“那些日子巴巴难得外出，”美婼说，“下午5点，巴巴准备好了。我陪他走到车旁。他回来后告诉我们，他一直笑个不停，那是一部很棒的电影。他说自己笑得厉害，连腮帮都笑疼了。巴巴多么喜爱那部电影啊！那是巴巴看过的最后一部或倒数第二部电影。”

阿娜瓦丝为她们挑选在普纳看的电影；她在孟买时已看过其中的大部分，也知道美婼会喜欢哪些影片。一天早晨吃早饭时，巴巴对阿娜瓦丝说：“看看报纸，有没有好电影，女孩们会喜欢的好影片？”阿娜瓦丝戴上眼镜，和巴巴讨论可能的选项。当晚女子们去看了一部电影。两天后，巴巴建议她们去看另一部。

起初，美婼等女子很高兴能去看电影，但“这种情况持续了几天，”美婼忆述，“几乎每隔一天都去。我们不习惯频繁外出，都对此厌烦了。我们得穿上纱丽，乘车出去，很晚才回来。我最后说：‘噢巴巴，又一部电影？我觉得我们不想去了。’”

巴巴说：“这部很不错。去看吧。”

“不管有没有好电影，我们都得去，”玛妮补充说，“但幸好大部分电影都还不错。”

阿娜瓦丝评论：“巴巴似乎总会安排好，让她们逗留普纳期间会有好电影上映。”

她们看过的影片包括：《特拉普一家》（一部关于冯·特拉普家族的欧洲电影），以及两部喜剧片，《飞行器里的好小伙》（关于一场从伦敦到巴黎的飞行竞赛）和《疯狂世界》（由斯宾塞·屈塞、米基·鲁尼、米尔顿·伯利主演。）

她们看过一部名为《相聚》的印地语电影。其中一幕，一个羞涩的姑娘和情人坐在划艇里，背景音乐由拉塔·曼吉茜卡演唱。歌曲开始，但声音太响，与场景很不协调。美婼向巴巴描述了这点。

蔻诗德喜欢去看电影，不管多频繁。“只要和美婼一起出去，她都喜欢，”美茹说，“而且她有各种各样的办法确保自己能参与外出活动，巴巴当然会看穿这点，并就此揶揄她，其他女子也会这么做。”

例如，蔻诗德在居住古鲁帕萨德的三个月期间，其职责之一是分担宝的部分守夜工作，好让宝有时间处理信件。否则，宝必须于午夜离开巴巴，开始回复信件，直到凌晨5点。因此巴巴指示蔻诗德从晚上6点至8点接班。

这给她带来了问题，因为那正是美婼等女子去看电影的时间。在美婼要去看电影的日子，蔻诗德就让宝继续守夜，称因为“美婼想要”她陪同去看电影。蔻诗德告诉宝，她看完电影回来就会接替他，但她始终没去。美婼以为蔻诗德和宝换了班，却不知道蔻诗德根本就没有值夜班。

在印度，电影票是提前售卖的，而且（女子们常坐的）楼厅座位要预留。每次女子们要去看电影，都于前一天（或当天上午）派阿娄巴去购票。若有其他女子陪同她们，阿娄巴会遵令购买（或预留）美婼前方以及后面的许多座位，或直接包下一整排，以防外人走到她们这一排，或从美婼面前走过找座位。如果有男士坐在她们后面，那么在看电影时，坐在美婼旁边的女子就得把手臂放在美婼的椅背上（不管其手臂累不累），以防有人从后面蹭到美婼。

一次，阿娄巴前往电影院，收银员在他的票上画了叉，不仅为她们预留了座位，还预留了周边座位，在她们周围形成一片空位区。回到古鲁帕萨德，阿娄巴向巴巴保证，电影票安排得百分之百令人满意——他自豪地宣布，比以往都好。可当女子们来到电影院时，却发现座位乱得很——这儿两个，那儿三个。高荷和阿娜瓦丝找经理交涉，要求安排连座。

她们回来后，巴巴问电影怎么样。“挺好，巴巴。”那座位怎么样？“不好。”

阿娄巴被召来训斥了一顿。原来，给票上画叉的收银员生病了，替班的人并不知晓额外的座位已被预留。

每当女子们去看电影，她们的新司机会站在旁边远处，之后美婼才出来。如果希拉在场，她会检查司机是否已经调高后视镜，这样他就不会无意间瞥到美婼。（开车时，他只能使用车外后视镜。）希拉会护送美婼上下车。美婼迅速钻进车，上车时举着头巾遮住脸。随后，司机倒退着走向车子，小心避免朝美婼的方向看。

当美婼和其他女子去看电影时，高荷和希拉则留在古鲁帕萨德，照顾巴巴的需要。美婼离开前，会给予精确指令：“记住，高荷，在巴巴吃饭时给他系上围兜[她特别注重不让豆糊弄脏他的长衫]。你给巴巴擦嘴时，动作要轻柔，不要着急。还有，你给他擦手指时，动作也要非常轻柔。要是你弄疼了巴巴，你可就麻烦了！”尽管高荷已经伴随巴巴生活了20年，完全清楚该怎么做，但美婼在离开前总会再次提醒。希拉也专心地听着，因为她知道在高荷忙于工作时，她得照顾巴巴。

对14岁的希拉来说，在古鲁帕萨德与巴巴独处的那些夜晚乃是梦想成真。她曾渴望能像美婼那样，始终伴随巴巴身边，为他料理个人事务。每天早晨，她都仔细观察美婼是怎样为巴巴洗手和梳理头发的。美婼对她解释，自己多么小心翼翼，以免梳子和刷子划伤巴巴的头皮。“我的动作可轻柔了。”她说。美婼还表示，她把自己的指甲剪得很短，这样给巴巴洗手时就不会抓伤他。（希拉已按巴巴的吩咐将指甲剪短。）因此当美婼去看电影时，希拉就有机会在巴巴吃完晚饭后帮他洗手。

“巴巴吃饭动作随意，”希拉讲述，“米饭和豆糊弄得到处都是。”希拉轻柔地把他的每根手指都擦干净，小心翼翼以免弄疼他。她把巴巴的盘子和调匙拿去洗掉，因为这也是美婼做的事情。美婼告诉过他，不要把巴巴的盘子放在地上洗，也不要让盘子碰到地面。（其他脏盘子被放在地上，佣人们蹲着在屋外水龙头下清洗。）

巴巴有频繁召见满德里的习惯，即使已经给他们布置了工作任务后也是如此，吃晚饭时，他就这样召来高荷。很多时候，被打断的当事人会感到烦躁；大约被打断四五次后，其说话声就会流露出怒气。但巴巴会提醒他们：“你在跟神说话。”

这种情况在每个满德里身上都发生过，只有美婼除外，她总是有礼貌地和巴巴说话。每当美婼被召见，无论她手头在忙什么，都会温柔地回应：“在呢，巴巴？”巴巴也从不训斥美婼，总是充满爱意地与她说话。

比如，一天晚上在古鲁帕萨德的餐桌前，美婼端起一碗咖喱汁给巴巴时，不慎在他面前掉落了碗。咖喱汁泼在桌上，还溅到巴巴身上。美婼非常尴尬紧张。巴巴抬头看着她，温和地说：“没关系，美婼。”她跑去拿块布给巴巴揩脸。

“美婼简直就像风一样，”希拉忆述，“她迅速跑去给巴巴拿东西。其他人会说：‘小心点，美婼。你可能会撞到东西。’但她从不会撞到。‘巴巴需要餐巾。’她会飞快地跑去。”

{注：其他人指出，美婼有时走路就像巴巴，大步流星。玛格丽特说，美婼的一举一动都透着优雅。即便上了年纪，美婼依然保持着那份优雅，动作宛如年轻女子。}

美婼回来后，开始揩桌子，但巴巴让她坐下，并叫美茹来做。当然，美婼因为碗从手中滑落而感到很难过，但巴巴再次告诉她莫为之烦恼。

美茹解释：“美婼比其他任何人都更为此事感到心烦，因为事情发生在巴巴身上。美婼像孩子一般，为自己的急性子而心烦。她非常渴望能帮上忙，并在各方面都做到完美，以配得上巴巴。我还记得，她曾多么温柔地告诉巴巴：她多么希望自己能有一副美妙的嗓音为他歌唱。巴巴会用饱含深情的目光看着她，并告诉她：他就是爱她本来的样子。而这对美婼来说意义重大。”

一天，美婼问巴巴某件事，巴巴表示同意。尽管玛妮知道，美婼问的事情并非那样。当玛妮和巴巴独处时，她心里有点不痛快，说：“巴巴，明天要是美婼说：‘世界是方的，对吗？’我猜您为了让她开心，也会同意说：‘没错，美婼，你说得对。’”

巴巴很严肃地看着她，回复说：“是的，我会的。”

蔻诗德也说过，后来几年，无论美婼说什么，她说得对不对，巴巴都会同意。

但后来，玛妮意识到，巴巴的回复所体现的意义，远比仅仅让美婼开心要重要得多。她逐渐明白，巴巴对待美婼的方式，正是他们全体应该对待巴巴的方式——即始终顺从他的心意。

玛妮详细解释：“可以说巴巴扮演了爱者的角色，以便我们能明白自己该怎样取悦他。巴巴会同意美婼说的话，以此向我们表明：我们该如何与他相处。这在当时可能会惹恼听者，但我后来意识到：巴巴通过把美婼称为他的至爱，通过他对美婼的爱，让我们得以窥见那种境界，使我们明白自己该怎样去爱他——我们的至爱。”

“唯有他能完美地去爱。当我们目睹巴巴对美婼的爱所呈现的这些瞬间，便看到了这点：他拥有的耐心，巴巴为取悦美婼的种种细微举动——可谓不遗余力！尤其在后期那几年。我个人学到了很多。

“巴巴对美婼的爱，我几乎可以说，是一位慈爱家长对孩子的那种爱；为让孩子开心，他会顺着她的心意。然而美婼是巴巴的至爱。那种爱并非世人所理解的寻常之爱。并非如此，但它是那么美好。

“因此，只有完人才能为我们示现完美的方式。他向我们示现了这点。当他把美婼称作至爱时，是给我们上了一堂课，向我们示范了：我们应当怎样对待、怎样取悦我们称之为至爱的人。”

1967年10月22日，美拉扎德，满德里大厅
与美赫纳施、拉玛、宝和希拉·喀邱瑞一起
玛妮拍摄——美赫纳施·喀邱瑞提供
