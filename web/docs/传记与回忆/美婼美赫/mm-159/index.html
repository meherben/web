1941年秋，美赫巴巴表示，为了他的工作，他必须横渡大洋。在他与乌帕斯尼·马哈拉吉会面后，以下电文寄给了在美国的伊丽莎白，由一直与她的通信玛格丽特执笔：“重大的灵性决定需要我在1942年2月15日至1943年2月15日的任何一天开言，并最晚在1941年12月中旬横渡大洋。资金不足；美国行程必须取消。因此，檀香山、菲律宾或太平洋某地无疑会更好，花费较少。”

因为巴巴表示战争结束后他会“开言”，所以现在战争预计要持续到1943年2月；1941年12月7日，日本袭击了太平洋上的珍珠港，玛格丽特意识到了这封电报的潜在意义。

10月28日，一行人离开盘奇伽尼前往印度西海岸的卡沃，在达瓦尔驿站旅店过夜，第二天抵达卡沃。男女满德里总是严格分开，尼鲁给大阿迪的一封信提到这一点：“28日中午，乘坐我们的元老巴士离开盘奇伽尼。这一次，巴巴和隐形人们都在巴士上，开车的是图克（图克拉姆，一名司机）。”

1940年4月，他们在卡沃时，曾住在堂皇饭店。西方人在海里游泳，巴巴在海滩上堆沙堡。这一次，他们在一座面朝大海的小房子里住了一周。“它在一条安静的主路上，没有公共汽车、轿车，也没有人，宁静而可爱。”美婼回忆说，“从我们的房子可以看到大海。那里有个大海湾。我们看到渔船满载而归。”

韦希奴的堂妹苏希拉和茵度，上次在卡沃和女子们住在一起，帮忙做饭，这次巴巴又叫来她们。她们住在一所独立的房子里，连同茵度的丈夫、三个孩子以及尼鲁。

因为当地市场上有大量新鲜的海鲜，巴巴允许苏希拉和茵度烹饪。他告诉她们，这是他在印度第一次允许女满德里吃鱼。

“我们的房子离得一弗隆远（约200米）。”苏希拉说，“在4点整，我们就要给女子们送饭。一个仆人接手，但我们还是进去看看是否一切妥当。（我们不送午餐，她们自己准备。）之后，巴巴与美婼坐在阳台上，叫我们唱些什么。”

下午的时候，巴巴会在他的房间里闭关几个小时，做他的内在工作，没有特别的玛司特为伴。傍晚，他和女子们出去散步。

在卡沃时，美婼甚至学会了游泳。事情发生在她们到达后不久。巴巴带她们到附近海边散步，那里有很多浅水湾和小型私人海滩。“要到海边，我们得走半英里主路，然后穿过一片茂密的松树林。松树很高，上面有松果。最妙的是路上没有人。当你走出松林，就有一片美丽的海滩。氛围很好。

“我们大约在上午9点或10点到达海滩。海滩在一个大海湾内，海浪轻柔而不汹涌。巴巴告诉我们他要去散步，我们也应该散步或寻找贝壳。这里非常隐蔽，附近几乎没有人。只有几个老人坐在沙滩上。卡曼玛西和芭奴玛西（科拉瓦拉）坐下来。巴巴轻快地走一圈。然后他响亮地打响指，大家集合，开始和他一起往回走。”

在走出松林之前，玛妮和恺娣走在最后，开始窃窃私语，咯咯笑着说些什么。巴巴转过身来，问她们为什么笑。“巴巴，大海和海滩是那么平静可爱，”她们说，“我们想学游泳。可以吗,巴巴？”

“游泳？”巴巴问。

“是的，我们不会游泳。既然我们住得离海这么近，而且西方人也跟我们在一起，她们可以教我们。”

巴巴考虑片刻，然后转向美婼说：“如果美婼同意学游泳，你们就都可以学。只有她说行，你们才能学游泳。”

“我从来没有想过要学游泳，”美婼说，“但是玛妮和恺娣对我说：‘说行，美婼。说行。’”

不过美婼犹豫了，回答说：“我不在乎是否学游泳。”

巴巴没有命令她学。他只是说：“如果你学游泳，她们也能学。”

美婼不喜欢被浸湿和受凉，更别提还有穿什么衣服的问题。她也有点害怕下水。

“我被夹在中间，”她继续说，“我一点也不想学游泳，但其他人想学，她们力劝我，哄我同意。”

她不情愿地答应了，说：“好吧，巴巴。”但心里嘀咕，“让我们看看巴巴如何应对吧。”她想着她们该穿什么，怎么学，等等。

其他人欢呼雀跃。回到家时，她们非常兴奋，立即把计划告诉玛格丽特。玛格丽特说：“你们要做的第一件事就是决定穿什么。”

“每个人都开始即兴制作游泳衣。你可以想象每人都穿着什么出来。太搞笑了。像一个精神病院！

“艾琳是个好女孩。她把我叫进她的房间，对我说：‘美婼，我知道你想有件衣服穿，也知道你不喜欢穿短的。’”

因为美婼不希望露腿，艾琳拿出一条在瑞士买的蓝色针织宽松裤，说：“这条会很适合你。”但是，由于艾琳相当高大，裤子需要修改。巴巴给了美婼一件泳衣，虽然穿在她身上也有点大，美婼还是穿上了，把它塞进宽松裤里。

｛注：玛妮记得美婼“穿的‘泳衣’长至脚踝。”｝

第二天，她们去了海滩。幸运的是，周围没有别人。越过美丽的大海湾直到很远很远，她们都几乎看不到渔民。她们在海滩上更衣，由四个女子举起一张大床单，像是屏风，一人在中间换衣服。第一天，只许美婼、玛妮和恺娣下水，由玛格丽特和艾琳指导。

“我就像一只待宰的羔羊，”美婼可怜地回忆道，“看起来一点也不高兴。”

她小心翼翼地走到齐腰深的水里，然后说：“够深了！现在告诉我该怎么做。”

玛格丽特和艾琳把她平放在水中，让她吸气，呼气。由于害怕下沉，她紧紧抓住她们，但还是全部照做了。“要是螃蟹咬了我的脚趾怎么办？”她大声问。

“啥都不会咬你。”玛格丽特向她保证，“只想怎样漂浮，并听我说的话。你要把心思放在这上面。”

由于这是第一天，巴巴说半小时后就要出水。回到家后，玛格丽特说她们必须在陆地上练习划水。女子们拿出枕头，放在肚子下趴伏。“我们决心学游泳，”美婼说，“几乎每个人都在练习——在每个房间，每个角落。场面非常滑稽。”

美婼和玛妮去自己的房间开始练习。“整个房子都疯了，”美婼说，“简直就像疯人院！”

从那以后，巴巴每天上午都允许她们去游泳。玛妮在日记中写道：“上午下海游泳，傍晚散步。一段美好的时光。”

第四天去海滩之前，巴巴告诉她们：“明天是游泳的第五天，也是最后一天。所以你们每人都要划十下。然后不再去海滩，也不再游泳。”

那天在海滩上，玛格丽特和艾琳告诉美婼：“要乐观。只要努力，你就能做到。明天是最后一天。”

玛格丽特是个好老师，给了美婼信心，但是美婼还有另一个问题：艾琳的针织长裤被水浸透后，会把美婼的腿向下拉。她只划了两下，就感到腿在下沉。

第二天早上，巴巴陪她们去了海滩。海水很凉，但海浪不猛，轻拍海岸。美婼很紧张。巴巴叫玛格丽特把她带到深处，几乎没过她的头。美婼仍然对自己没有信心，紧拉着玛格丽特和艾琳。艾琳试图给她鼓气：“勇敢点美婼，别紧张。你会游泳。用力吸气，再呼气。”

巴巴表明他会站在海滩上观看，拍手十下。一位女子站在他旁边报数。在水里，美婼持着巴巴的名。她深吸了一口气，开始了。“一……二……三，”巴巴拍着手，美婼在划动。

“划到第十下时，我已经沉到海底了，”她笑着说，“玛格丽特和艾琳把我拉了上来。我看起来像只湿老鼠。”

巴巴说：“很好。现在出来吧！”

“你至少划了五下，”玛格丽特告诉她，“然后就沉下去了。”

但是巴巴给了她几个“恩典分”，所以她通过了测试。“巴巴说：‘很好。’因为他不想让我们第二天再来！”美婼猜测。

现在轮到恺娣了。她耳朵里塞了棉花，被带到水里，她的表现和美婼一样。在第十下时，她就沉底了。但巴巴又说：“很好。出来。”于是恺娣也通过了。

最后，玛妮被带到深水区。她吸了一口气，她们让她开始。刚在第一下，玛妮就下沉了。她连一下都划不了。“怎么回事？”巴巴问，“其他人至少划了五下。”

“她没能让自己平衡。”玛格丽特解释说，“她还没学会。玛妮的腿比其他人长，”玛格丽特说，这对她来说更重（尽管玛妮的腿很瘦）。

“好吧。”巴巴说，“玛妮可以再来几天，好好学习。”

在那之后，玛格丽特只教玛妮，尽管吉蒂随同观看。不过，玛妮还是难以学会。于是巴巴说：“没关系。”这件事就此告终。她们不再去海边，而是继续沿公路散步。

后来，玛格丽特回忆起上课的事：“要是巴巴赶时间，他就希望你给她们上一节课——之后她们就能游到澳大利亚去！所以我教她们在椅子上划，趴在枕头上划，等等。美婼隐居得最深，一想到要露出四肢，她就感到害怕。她得到一条宽松长裤，穿着会下沉。她问巴巴能不能改得短点，巴巴允许。美婼爱好运动。她骑过马，体格健壮。玛妮则没有。”

美婼总结道：“我喜欢大海，但是一个人如果在海边待得太久，就会感到厌倦，因为它变得单调乏味。我更喜欢山山水水——河流、小溪和湖泊。”

11月8日，一行人乘轿车和蓝车离开卡沃前往贝尔高姆。在那里，再次入住萨凡特瓦迪王公的宅邸。之后于11月12日前往达瓦尔。虽然他们住的房子很宽敞，但没有电灯和自来水，房子附近的井几乎干枯。满德里不得不从远处一口更深的井里取水，而且运送足够40名女子用的水是一件非常累人的工作。

茵度·哈丹卡、她的家人以及苏希拉随同团队来到达瓦尔，她们又住在单独的房子里并做饭。（遗憾的是，新鲜的鱼没有了。）女子们喜欢与茵度最小的女儿曼妲玩耍，她九个月大，从来不哭。

11月14日，巴巴和一些男子离开，去拜访恰提巴巴，但为了到达他那里，他们不得不在暴雨中趟过齐膝的积水。巴巴返回达瓦尔，一路上联系了其他玛司特。

11月27日，一行人经萨塔拉前往阿美纳伽，在一家驿站旅舍过夜。这是巴巴最后一次乘坐蓝车，他评论道：“这辆巴士就像奎师那的战车，在我显现之后，人们将崇拜它！”

｛注：一个月后，蓝车被抽奖送人，之后作为礼物还给巴巴。巴士交给了萨若希，他让人进行了彻底检修，然后用它在阿美纳伽载客。还有几次，巴士也运载过美拉巴德的人，不过巴巴再也没坐过。｝

当一行人在11月28日回到美拉巴德时，巴巴继续在陵墓里闭关；但与以往不同的是，他在必要时会见满德里成员。在此期间，希芮茵麦来到美拉巴德，与顾麦发生了争执。听闻此事，巴巴说：“我父亲希瑞亚吉是个极好的灵魂。他心地善良，生性安静。但我母亲希芮茵麦，却恰恰相反！我必须平衡有利与不利的性情。由于她的天性，我忍受了很多，也承受了很多。然而我爱他们两人，并且两人都将得到解脱与拯救。”

巴巴指示男满德里在12号点燃他的度内火，他表明：“这次点火不是为了降雨，而是为了我工作的某种特定目的。”与此类似，据说赛巴巴用点燃油灯来控制第一次世界大战。

巴巴曾经预测，德国和日本将发展壮大，把地球四分之三踩在脚下。1941年12月上旬，情况似乎如此。希特勒尚未在俄国被击败，日本人占领了台湾、泰国、中南半岛以及中国大部分地区。

｛注：《美赫主》，第2738-2739页。｝

12月11日，也就是德国对美国宣战的同一天，巴巴开始靠水禁食一周。12月12日，他从闭关处出来——但全身裹着一张白床单，坐在度内旁边，由古斯塔吉点火。没有举行阿提、达善或其他仪式，但巴巴对满德里说：“你们都将见神。”

｛注：从那时起，下美拉巴德的度内火在每月的12日点燃。｝

第二天，巴巴心情很好，当天傍晚，他带女子们去阿美纳伽看电影。在孟买的医学院读书的高荷，与她的同学蔻诗德·纳姆达尔一起到来，她们获准在圣诞假期中在美拉巴德住一周。

｛注：蔻诗德·纳姆达尔（帕斯里查）是美赫吉·卡卡里亚的嫂子。｝

美婼的生日也在那时庆祝，其他几个亲近跟随者前来参加。12月底，巴巴离开美拉巴德三天，进行玛司特之旅，当他在12月23日返回时，伊丽莎白的狗吉皮的骨灰从美国寄到。骨灰埋葬在战士的墓旁，并在墓上立了碑。

第二天，有消息传来，乌帕斯尼·马哈拉吉在萨考利舍弃肉身，巴巴说：“我沉默的打破，也会像乌帕斯尼·马哈拉吉的去世一样突然和出乎意料。但区别在于感受的普遍性，在我开言时，这种感受将会非常强烈。众生都会感觉到。

“它将像地震那样震撼世界。在世界不同区域，人们会感受到不同程度的冲击。因此，他们会以不同的方式体验。”

12月底，巴巴又离开美拉巴德，去安拉阿巴德进行为期10天的玛司特工作，大壶节正在那里举行。

｛注：大壶节是萨度、苦行僧和宗教朝圣者的盛大聚会，每三年在印度不同的印度教圣地举行一次。｝

巴巴回到美拉巴德后，1月12日点燃度内火纪念乌帕斯尼·马哈拉吉。巴巴评论说：“今天是意义重大的日子。如今局势在扭转。正如柴已准备好，只需点火，现在好比是七点差一刻——马上就到七点钟。时间一到，我就给我的工作点火。”

他接着说：“一位伟大灵魂和我的一名亲近男满德里将很快去世。”

｛注：《美赫主》，第2757页。｝

第二天，穆罕默德玛司特从孟买被带到美拉巴德，永久留在巴巴身边。巴巴还提到，在去大壶节之后，他在开言之前还有一项任务要做——访问尼泊尔和西藏。

但首先，巴巴去了南印度，和恰提巴巴联系，再次见到巴巴时，恰提巴巴欣喜若狂，像孩子一样紧紧拥抱他。巴巴回到美拉巴德，却宣布又要转移所有人——这次是向北，回到德拉敦。

1941年12月，印度时报
作者收藏

美赫巴巴

一则公告

为促进世界的灵性提升，美赫巴巴指示他在印度及国外的弟子与跟随者，从1942年1月1日至1942年2月15日，每24小时以一餐两茶禁食。（可自由饮水）。

美赫巴巴希望所有其他有能力的志愿者，都能通过遵守以上禁食来分担这项工作。

美赫巴巴世界灵性中心，

于阿美纳伽，美拉巴德。
