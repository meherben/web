以前，上午和下午，巴巴能够在满德里大厅与主屋之间行走。但1963年他在普纳进行了多次辛苦的家访，每次出行都要上下古鲁帕萨德的陡峭大理石台阶，因此髋部受到影响。从普纳返回后，如今要去大厅，巴巴更经常地使用抬椅，由四名园艺少年抬过去。

美茹用餐桌旁的炉子为巴巴做早餐茶；不过，茶一上桌，就由美婼端去。她加入牛奶和糖，将茶倒入一只深碟（其实更像碗）。巴巴一向不喜欢从杯里喝茶，因为他希望茶快速变凉。

出于对至爱的深爱，无论巴巴喜欢什么，美婼也让自己喜爱之。例如，巴巴喜欢喝甜茶；美婼也往自己的茶里放三匙糖，这样饮用。一天早晨，玛妮坐在桌前，看着美婼为巴巴备茶。她以为美婼失误了，往茶里放了太多糖。玛妮试图阻止她，但巴巴说：“不，我爱喝甜茶。不要过分甜，但要偏甜。”还说：“美婼喜欢她的茶也像这样。”

{注：早餐美婼不喜欢在吐司上抹果酱，而是将吐司蘸一蘸甜茶，使之变得甜又软。}

不过，据埃瑞奇的妹妹玛奴所述，巴巴和美婼在一些事情上恰好相反。“美婼喜欢偏凉的天气，而巴巴喜欢偏暖的天气；美婼喜欢吃滚烫的热食，而巴巴喜欢凉食。他正是让她改掉爱吃热食习惯的完美人选。她刚吃一口热食，巴巴会说：‘我觉得口渴，想喝点水。’于是美婼起身去取水。她重新坐下吃饭时，巴巴又会要些东西——都是为了使她改掉这个习惯，直到她不在乎食物的冷热温凉。同样的事也发生在拉诺身上。她刚呷一口热茶，巴巴会说：‘去看看报纸到了没？’或提出任何事由，以阻止她享受美味的热茶。”

{注：美茹说：“巴巴会叫美婼不要吃太烫的食物，而适度的热则可以。”}

在美拉扎德，只有极少数情况下，美婼会给巴巴提供咖啡，但不在早餐而在上午时分。大多数时候巴巴都喝茶，他更喜欢。他不喜欢加马萨拉（香料）或薄荷的茶，只喝普通浓茶。美婼喜欢喝咖啡，但早上不喝。（在印度，咖啡用牛奶冲泡，所以她觉得早上喝咖啡过于浓郁厚重。）后来巴巴叫她不要喝咖啡。“一次，有人泡了咖啡，”美婼说，“巴巴问我在喝什么。‘咖啡，巴巴。’我答道。他说：‘现在可以喝，但以后不要喝了。’巴巴是否表示我不该每天喝咖啡（倘若他是说‘做这、做那’），但他一向说‘别做这、别做那’。”

那些日子里，巴巴吃得很少。“1963年之前，巴巴从不吃早餐，”美婼继续说，“总是喝一杯茶，有时一杯半。他会吹一吹，呷一两口热茶。凉一点后，他就从大碟上喝茶。后来在高荷的坚持下，他吃一点早餐。”

“1963年，我们注意到巴巴患了高血糖，”高荷细述，于是一天早上，她对巴巴说：“早餐很重要，巴巴。经过一整夜，肚子空了。早晨您一定要吃点东西。这必不可少。”

“我该吃什么？”巴巴问。

“鸡蛋。”高荷建议。

“不吃鸡蛋。”巴巴说。

{注：巴巴的母亲希芮茵麦，也患糖尿病。}

于是她们开始给他一根香蕉作为早餐；然后逐渐地，将香蕉切碎拌入粗麦粉粥；后来吃麦丝卷；再后是玉米片，每天都有变化。有时，他吃拉瓦或舍维（甜炸细米粉）。“我会让迈阿密的巴巴爱者买些谷类食品，比如麦丝卷或玉米片，”高荷继续说，“有时，巴巴会吃拌入一点牛奶的膨化小麦。他不喜欢每天吃同样的食物。”

“由于他无法咀嚼，”美婼解释，“巴巴喜欢吃软质食物。他不爱吃面包、黄油或吐司。他从不吃鸡蛋；偶尔吃些奶油和软面包。也不吃黄油。后来的年间，早餐巴巴会吃麦丝卷或玉米片，是西方爱者寄来的。但过些时日，他吃腻了，我们就用粗麦粉之类的做其他食物。”

根据高荷的笔记，这是1963年7月15日巴巴的饮食：

早晨7点，早餐：约6盎司淡茶，1.5盎司脱脂牛奶，用糖精代替糖。1盎司生活牌麦片，但巴巴只食用5克麦片，拌入一匙牛奶。

{注：选择“生活牌麦片”是因为它当时不含糖（或含糖量少），也是从迈阿密寄来的，有时还有小麦胚芽。几年后，还给巴巴寄来“益能健”小麦片（英国产品），以及桂格牌低糖型糖霜小麦泡芙（他最爱吃这款糖霜小麦泡芙）。}

上午8点半，维生素：1盎司生肝汁

上午9点：约2盎司甜李子

上午10点半或11点，午餐：约6盎司坚果咖喱，原料为4盎司椰奶、5颗磨碎的杏仁、1茶匙芝麻、2汤匙芫荽籽和其他香料、1/4茶匙红花籽油。这种咖喱与4、5、有时6盎司的麸皮面包一起食用。

中午12点：2盎司某种甜水果，芒果、木瓜或李子

下午2点：2盎司淡茶

下午5点：3/4盎司或1盎司麸皮饼干，放入牛奶浸泡软化；或2-3盎司咖喱和2-3盎司麸皮面包

白天，16盎司新鲜椰子水（如果有）；约4盎司鱼肉（如果有）放入咖喱；不吃蛋，不吃其他肉；煮熟的小扁豆糊，拌入10盎司的煮熟蔬菜（有时也用这道菜代替咖喱）。绝对不吃米饭，不吃土豆，不吃糖（水果中的碳水化合物含量除外）。

{注：普纳的K·格兰特医生已嘱咐巴巴要减重。}

然而，巴巴从未长期坚持某种饮食。几天后，他的饮食方案随即改变。

美国总统约翰·F·肯尼迪于11月22日遇刺身亡。当时美婼有一次不寻常的体验。肯尼迪在达拉斯被枪杀时，印度正值午夜，大家都在熟睡中。“我是睡得很沉的人，”美婼说，“一旦睡着，就睡得又沉又香。可是当晚午夜时分，我却睡得很浅，忽然清楚地听到某种响声，仿佛有人在我左耳边打了三下响指。我醒来，琢磨着那是谁。谁在试图唤醒我？没有人在。我翻了个身，没再多想，又睡着了。

“第二天，我们听到肯尼迪中了三枪的消息。我的体验是个迹象。我当时忘了告诉巴巴，但几天后记起并告诉了他。”

美婼说，巴巴喜欢约翰·肯尼迪，曾评论他是个优秀的人。不过，三年前举行选举期间，有一天在美拉扎德，当巴巴过来喝早茶时，女子们在听收音机播报的选举结果。“听到肯尼迪当选了，我们非常高兴，因为我们不喜欢[理查德]尼克松的长相。”

{注：尽管肯尼迪在总统任期内从未访问印度，但他的妻子杰奎琳，于1962年3月在印度待了9天。（在肯尼迪之后当任总统的林登·约翰逊，于1961年5月访问了印度；其继任者理查德·尼克松后来于1969年7月访问了印度。}

“很不错吧，巴巴，”她们说，“肯尼迪赢了！”

那一刻巴巴神情严肃，之后带着悲哀的表情说：“他本不该当选的。”

美婼感到惊讶。“可是他看上去比尼克松好多了，巴巴。您希望尼克松赢吗？没人喜欢尼克松。肯尼迪看起来强健又能干。他性格很好，也有威望。”

巴巴点点头，但未进一步评论。显然，他对这个结果并不满意。三年后，现在肯尼迪被刺身亡，她们想起巴巴的话。

巴巴用于代表肯尼迪的手势是字母K；而对于枪杀肯尼迪的人，李·哈维·奥斯瓦尔德，巴巴的手势是“啐”（意为糟糕无用）。在奥斯瓦尔德本人被杰克·鲁比枪杀后，报纸上开始登载关于可能存在的阴谋和鲁比参与该计划的报道。美婼询问巴巴，奥斯瓦尔德是不是枪杀肯尼迪的唯一凶手。巴巴告诉她正是如此。

12月23日星期一，美拉扎德举办女子活动，庆祝美婼生日。来自阿美纳伽、普纳、孟买和瑙萨里的300多名女子参加了活动。她们先在主屋门廊会见了巴巴和美婼，之后去大厅入座，倾听演唱。

{注：满德里大厅内摆有床垫，供活动开始前两天才受邀的少数人使用。}

“那天巴巴的座椅没有摆在大厅的角落，”美婼说，“而是放在离门不远处，这样女子们达善巴巴后，可以绕过它前行。”大厅坐满了人，（女子那边的）屋外搭了小帐篷，供人们坐在荫凉处。

{注：大厅里用了麦克风，以便男满德里（坐在他们那边屋外）可以听到音乐。}

到了巴巴回房间的时候，女访客说：“巴巴，别叫男子为您抬椅。今天是女子日，所以我们来抬您。”伴随“捷巴巴”的高呼声，客人们蜂拥而上，将他抬起。“巴巴不得不抓牢椅子，因为热情踊跃的女士们个个又笑又喊，致使抬椅来回摇晃。”人人都想帮一把。

巴巴去他房间待了15分钟，之后来到花园坐下，那里提供自助午餐。玛妮取来摄像机，拍了一段短电影。布加和其他美食，摆在树下的长桌上。每人膝上放着餐盘。三把椅子摆成一排：一把给巴巴，一把给美婼，第三把给巴罗达的王妃。“我没有一直坐在椅上，”美婼说，“我要吃饭时，坐在巴巴身边。他吃得不多。他会跟来访者开玩笑，尤其会逗[卡拉奇的]琵拉麦。”

琵拉麦坐在前面，边吃东西边笑。

“你干嘛笑？”巴巴问，“何事这么好笑？”

“没什么，巴巴，”她答道，“我能来这儿，真是太开心了。”

“好，别笑了，不然你会忘了吃饭的！”

美婼切了生日蛋糕，先给巴巴一块。他只吃了一点点，将余下的作为帕萨德给她。

一种近乎可触的喜悦弥漫在美拉扎德花园中——因为至爱坐在女信徒中间，朝着他心爱的人们微笑。

午餐后，大家重新聚集在大厅。阿露为美婼准备了一首生日歌，配曲是一首古吉拉特语婚礼进行曲。她把歌教给另十人，现在她们一起献唱，但阿露自己嗓音不好。巴巴选了另一名女子唱，她也说自己不擅唱歌。不过她也用沙哑的嗓音唱了。唱到一半，她说：“我告诉过您，我唱歌跑调。”

“不，唱得很好，”巴巴说，“继续！”

恺娣扮成一个戴着帕西帽、蓄须打伞的男子走进大厅，骗过了所有人，给现场增添了娱乐气氛。当这名“男子”跌撞地往前走，闯入女子专场聚会时，可以听到人们的倒抽凉气声和愤怒的抗议呼喊。当“男子”冲上前拥抱美婼时，众人变得愈加惊恐！

{注：恺娣后来扮成日本舞者，返场再演。}

杜恩·萨达，是生日庆典的参加者之一。她和美拉扎德“居民”宠狗彼得的生日都在1月10日。杜恩是每年都收到巴巴寄来生日贺卡或电报的幸运爱者之一。“致我们亲爱的杜恩，”有一年玛妮写道，“你的生活本身就是他的爱之讯息，欣然顺服于他的旨意。亲爱的美婼会把你的拥抱转达给至爱巴巴。”

另一年，埃瑞奇写道：“愿你永远保持乐观坚强，这样藉着你所辐射的至爱巴巴的大爱之光，我们或许能学会像可爱的你一样勇敢且面带微笑……愿你一如既往地勇敢、乐观且优雅，在生活中彰显至爱巴巴的大爱。”

1964年，杜恩收到此讯：“愿至爱巴巴的爱之阳光，永远使你精神焕发、安好愉悦；愿你洒向众人的喜乐，继续年年温暖我们的心灵。至爱巴巴将他的爱送给你——他珍爱的杜恩。”

杜恩的姐姐阿露最近去世了，关于她身患肌肉萎缩症的病苦，巴巴曾告诉她：“我可以触碰你，瞬间让你完全康复。但现在把痛苦承受完更好，别留到下次。”

2月25日，世界各地庆祝了巴巴的70岁生日。玛妮写信给杜恩：“昨晚10点，我们通过收音机（德里电台）收听了巴巴的名字和祷文，该电台用10分钟时间报道了‘德里的美赫巴巴70岁生日活动’。祷文是由巴巴爱者（国会议员）萨达·赛伽尔用印地语诵读的；提鲁玛尔·劳[发表]的部分演讲；（人民院议长）胡卡姆·辛，宣布活动开幕的的演讲；还有主持人桑吉瓦亚[雷迪]的最后致辞。节目似乎为这个良辰吉日画上圆满的句号，之后美拉扎德居民们去睡觉（至爱巴巴早已回房休息）。”

为庆祝巴巴生日，美婼穿上贵重的纱丽，涂了装饰性的吉祥痣（前额红点）。在她的生日和其他特别场合，美婼也会涂上吉祥痣，但巴巴本人从不给她的前额涂上提卡（红标记）。“巴巴从不在意这些事情，”美婼解释，“但我们过生日时，他会把糖果放进我们嘴里。”

美茹曾多次在巴巴生日那天为他作诗。但据她说，她仅有的构思诗句时间，就是在为巴巴洗衣服的时候。

巴巴在世时，美婼从未写过诗，但偶尔用英文写过几行。一次，纯粹为逗巴巴开心，她把自己读过的这首短童谣，背给巴巴听：

阿吉遇上大熊。

大熊遇上阿吉。

熊肚圆鼓起来。

鼓包正是阿吉。

大阿迪写了这首关于阿美纳伽的打油诗：

阿美纳伽，该死之地。

蚊蝇之窝，周一领饷。

阿迪的感慨让美婼特别有共鸣，她认为阿美纳伽是个糟糕的地方。她也对着巴巴背了此诗，但由于巴巴嘱咐过她切莫使用“该死的（damn）”这个词，美婼让美茹代她说出该词。

{注：巴巴还嘱咐过美婼，切莫对着巴巴的照片发誓。比如，倘若她想强调某件事是真的，切莫说“我对着巴巴的相片发誓。”}

并非只有美婼一人觉得阿美纳伽不够理想。“我们会把阿美纳伽称作‘DDD’——单调、干燥、多尘（drab,dry,dusty）。”玛妮坦言。

一天，美婼对巴巴诉说：“您为何选阿美纳伽作为您的总部？您为何想要来住这儿？这么糟糕的地方。当地单调灰暗，尘土飞扬，且索然无味。在印度的所有地方中，您为什么不选个更好的地方？干嘛选阿美纳伽？这是个丑陋肮脏的城镇。选了怎样的地方！”

巴巴挠挠下巴，沉思片刻。他显得有点内疚，然后承认道：“是，我确实犯了错。我似乎养成了这种习惯。在耶稣时代，我犯了错；我作为穆罕默德亦如此；现在我又这么做了。但下一次，”他承诺说，“我会记住！”

美婼自然更喜欢郁郁葱葱、风景优美、雨量充沛的地方，听到这么说非常高兴。她睁大眼睛，问道：“真的吗，巴巴？”

“我保证！”巴巴说，然后去了满德里大厅。美婼看着玛妮，问：“等一等，我们怎么知道下次他会因为现在的承诺而选个好地方？”

“就是。”玛妮说。

美婼不禁轻声笑了。“巴巴真贴心，总能给出恰当的回应。”她变得安于处境，说：“不知何故，阿瓦塔似乎总是和贫瘠之地有着密切关联。”

美婼至少很欣慰巴巴选了美拉扎德。“我不喜欢住在城里，”她继续说，“只有房子，[更多]房子，汽车和人群。总有太多喧闹。我也不喜欢任何机械的东西；我喜欢马车，但不是小双轮马车（tonga）——要么漂亮的维多利亚马车，要么轻便双轮马车（dogcart）。我喜欢大自然，有树木，植物，鸟儿鸣唱。这就是为什么巴巴带我们住在美拉扎德，在这里安家，因为这儿静谧祥和。巴巴一直喜爱这里的氛围。古鲁帕萨德达善活动后，他可以放松。过后，他在这里休憩。”

“美拉巴德对我来说和美拉扎德一样珍贵。因为是在美拉巴德，我第一次达善了巴巴；在那里，我为巴巴梳头，服侍他，为他洗脸、洗衣服和餐具，给他端饭。巴巴曾在那里说话唱歌。所以美拉巴德对我们来说很珍贵。

“不过巴巴在美拉扎德居住很多年。他在这里安家，在这里闭关。他最后的重大工作是在美拉扎德完成的。”

1963年1月19日，美拉扎德
高荷、玛妮、阿黛尔、美婼、美茹、娜佳
