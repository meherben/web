50               U. V. 11-22                        6-2-1924

（1）世界大家庭。
（2）还债的方法。

（1）

有句谚语说 “世界一家（Vasudhaiva Kutumbakam）”；Vasudha的意思是地球——世界；因此这意味着世界就是一个大家庭。世界是真人的家庭。父母子女和所有其他亲属构成世俗意义上的家庭。有的家庭有上百个成员。一家之主得照顾所有成员。神或真人同样也得照顾整个世界。神不可见；通过真人的形体才被世人看见。因此真人的家庭不受局限；这个世界的一切有生命和无生命物都是他的家庭成员。但在整个造物界，他尤其关心人类。总是希望人人在世时快乐，去世时达到更高境界。所有的吉瓦阿特玛（个体灵魂）都必须一次次出生，来承受其行为造成的苦乐。因此，即使一个人去世了，真人也绝不认为他离开了家庭；而是照样照顾死者；不过，当吉瓦阿特玛死亡时，真人才不再照顾他。这种照顾方式与世俗方式不同。在世间有人死了，家庭其他成员就不再想他——把他忘了；认为他已经自由；但真人只有在他超越生死循环时才停止照顾他。

真人总是希望人的吉瓦阿特玛要在当生死亡；这样的人生被真人视作富有成果的人生。吉瓦在活人身体中死亡，是人必须实现的真正、终极死亡。这种死亡引向神圣诞生和永恒幸福。所以说真人总是希望看到人实现其终极死亡；何以如此？因为人人都是他的家庭成员。在日常生活中，每家都总是希望家中诞生新生命，真人则总是希望每个家庭成员终极上死亡。

在真人的道场，成百上千人来到他身边；每人根据自身发展程度，被给予自动、不可见的帮助，从而得到世俗和灵性幸福；这都归功于那个地方的内在特质。陌生感、分别感一点一点地消失。一家人如果都在同样的层次，有相同的欲望，就会团结一致；但如果各自都有不同的欲望，自然会出现分裂。但如果与真人相处并接受其建议，人的欲望就会开始在质量和数量上减少，人也慢慢地达到无欲状态。起初，人没有欲望，人类一体；随着欲望的产生，人们也彼此分离。当你们都完全摆脱欲望时，就会再次团结起来；只有那时，与真人或神的分离感才会消失。除非那种个体性、分别感消失，否则是无法获得真正幸福的。

给花园水箱管道上安装一个花洒；水从花洒喷出，会形成许多水柱。每个水柱都自以为独立，相互竞争，看谁喷得更高。下方的水知道所有这些水柱都是它自身的一部分，并嘲笑它们的竞争精神。这些水柱缺乏稳定性，既无法享受，也对其他水柱没有用处。花洒的开口越大，水柱就越粗；喷得越高，水柱就越细。下方的水告诉它们，喷得越高摔得就会越惨。此外，下方的水源在那里是为了把水柱吸引回来。水柱落下时，开始感到没必要为喷得更高而骄傲：“现在我们有多广阔，多幸福！” 真人同样吸引那些有着类似不必要、不足道骄傲的人类，并把一切幸福给予他们。在灵性道路上每个人都始终渴望摆脱自己的渺小——自己的个体性，并与上帝状态合一。随着欲望的减少，他们开始体验自己是世界大家庭的成员；真人的品质开始在他们身上生根发芽，他们开始享受真正的幸福。

（2）

在真人身边，有时会看到在思想和行为上反对他的人，当然，这些人的敌对态度归因于那位真人的意志。这些反对者帮助那些追随者；对立双方相互帮助，消除彼此的缺点，最终都获得抵达真理（ Sat）状态的资格。俱卢族和般度族非常敌对，但最终两族的人都融入了师利奎师那。

在真人身边无论发生什么都绝非坏事，绝非错误；从世俗观点看似乎那样，但实则不然。甘蔗榨汁机的轮子总是朝相反方向转；但这种相反运动为我们带来甘甜的蔗汁。必须把水桶放入井中，再提上来，这两个相反行为让你得到水。因此对立双方都必不可少。然而人们既不守本分，也不彻底独立行事；从这种随意行为中，是得不到任何幸福的。只有通过了小学才能上中学。那些在前世全心全意地对神像赞颂膜拜等，因而做了各种善行的人，正是他们因为与神建立关系而升到更高位置，遇见以真人形式存在的神；只有他们才能从同真人交往中感到快乐；只有他们才能通过侍奉和伴随真人，才有资格获得达到那种无限极乐的知识，才有权知道真人为此采取的隐秘行动。这就是发生在那些已经与神建立联系者身上的事情。

与神建立了某种联系（Rinanubandha）的人，应不断努力培养和增进这种关系。“债务（Rina）” 这个词不仅仅意味着金钱债务。每个人从生到死都背负着各种各样的债务；索取是负债，给予是还债。在一切事务中的给予和索取，构成相互的债务。就是这些债务决定了一个人来世的 “关系”；这些关系对人的影响远远大于单纯的金钱债务，因为金钱只是处理世间事务的手段。给人食物、虐待人、阻止人遵守信仰、干涉善行、帮人作恶、迫于压力给予或接受某物、看见并渴望拥有某物等等——所有这些都涵盖在“债务”一词中。所有这些都是通过我们的身、心、智力和吉瓦达成的，这些债务对人的影响远远大于金钱。为偿还这些债务，人必须再次出生，又在还债过程中自动欠下新债；为偿还新债，还得再次投生，如此循环往复。就是由于这些债务，人才永远摆脱不了生死轮回。

智者和真人指出了许多摆脱这些债务的方法。其中最简单的方法，就是以某种方式与神建立关系；在这方面最好是纯质关系。戡刹（Kansa）、罗波那（Ravana）等人建立的是激质和暗质关系，也就是说，他们憎恨神；这种关系最终也让他们融入了神。不过这种关系不能产生快乐幸福。俱卢族通过暗质关系融入奎师那，但却始终没有幸福可言；另一方面，般度族因与神建立纯质关系，而获得一切世俗和灵性快乐，并且意识到自己的幸福。毫无疑问，暗质关系带来同样结果——获得神性，但是没有幸福，就像在无意识的深眠状态。纯质关系达到同样的神性状态；但在这种关系中，人作为神，或通过真人媒介，或通过自己的精体或浊体，完全有意识地享受那种极乐，享受那种能够成就一切、造福全世界的超自然力量。

要想摆脱所有这些关系（债务）并且获得神性（无限极乐），就应与神建立尽可能深厚的联系。必须在去世之前就开始建立这种关系。要么让神做你的债权人，要么让祂做你的债务人；这两个角色中，你应接受其中一个，把另一个赋予神。常言道“应当与神建立联系”。神无疑是看不见的；但你一旦开始为神的事业做点什么，就与神建立了联系。即使神什么都不要，我们也必须强行把自己的财产，包括金钱、心、智力和吉瓦交给祂——可能的话全部，或者部分奉献。换言之，我们应将“一切” 献在祂足前，然后按照自身信仰进行赞颂、膜拜苦行、念名、仪式等。无论做什么善行，我们都应说 “愿将此献给绝对存在大梵（Tatsat Brahmarpanamastu）”；我们这样做，神就与我们绑在一起；当然，联系的强度取决于我们奉献了什么，奉献了多少。神当然不需要这些；但我们必须强加给祂。在世俗生活中，债权人找到一个好客户，就会强行以低利率贷款给他；从而缓慢稳步地扩大业务。我们同样也应强行把我们的 “一切” 献给祂；如果我们这样做，可怜的神就不得不接受。我们献得越多，神跟我们就绑得越紧。祂迟早要偿还我们的债务。如果这笔债务很大，祂就会化身为人，到我们家里来服侍。这都是智者制定的精妙方法。在世俗生活中，债主会去找欠债的人，或把欠债的人叫到自己家还钱。神为了偿还我们的债务，同样也会要么叫我们到祂家，要么亲自到我们家；无论如何，当神偿还我们的债务时，我们必须与祂面对面。一旦与神相遇，我们又怎会继续活在生死循环中呢？无论以何种方式见到祂——不过是出于爱还是恨，个人生死轮回都会一劳永逸地终结。由于世俗债务难以摆脱，古代智者才提出了以某种方式与神建立联系的简单方法。

般度族在神那里存了大量功德；这就是为什么师利奎师那必须服务般度族。神说自己没什么东西还债，别无选择，只能服务。奎师那在般度家中喂马、洗衣等等。为黑公主（Draupadi）做了很多事。当毗湿摩（Bhishma）发誓要灭绝般度族时，奎师那扮演侍从角色，陪同黑公主来到毗湿摩的帐篷，从毗湿摩口中为黑公主得到祝福 “愿你永远婚姻幸福（Saubhagyavati Bhava）”；凶手（毗湿摩）把祝福赐予黑公主，从此般度族人再也无法消灭。毗湿摩赐福后，抬头看祝福对象是谁，看见黑公主；他一时愣住了，然后说：“这不是你所为；一定是那个黑脸（奎师那）的主意；祂在哪里？给我看看。” 毗湿摩看到祂，问祂为何化身侍从？奎师那的回答很简单：“为了保护我的信徒。”奎师那在般度族家辛勤劳作，就是为了还债。

圣人乔克哈梅拉（Chokhamela）属于马哈拉（Mahara）种姓；但是主（上帝）欠他的债；所以必须在他家中伺候，杀鸡宰羊、出卖兽皮等等。

圣人萨贾纳卡萨伊（Sajjana Kasai）是个屠夫；以卖羊肉为生。主不得不以仆人身份在他的店里卖羊肉。

圣人达马吉（Damaji）在全能者那里有很多储备；神只得以马哈拉种姓的身份去见当地的统治者，替达马吉结账。达马吉是位税务官；他所管辖的地区发生了严重饥荒，他就开放政府所有的粮仓，免费给饥民提供粮食。因而为了公众利益而非自身利益做了大善举。政府失去所有的钱财和粮食储备。由此积累的功德太大了；统治者也自动从中分得一份，结果，全能者不得不把“见神”达善赐予这位穆斯林统治者。何以如此？政府的粮食都用来救济饥民了，神因而欠了统治者的债。通过达马吉这个媒介，那位统治者获得神性状态。因此，与神建立纯质关系，总能打破世俗债务的束缚；神受 “债务” 束缚，无论如何都会出来偿还。

设想有个大债主——银行家。他在一个地方，并在各地开设了分行。每个分行都由一位经理负责，银行家只查看各个分行的账目。如果有欠债人不能按时还款，经理就要他卖掉房子；并说自己只是仆人，必须替主人收回钱。欠债人说他只有一所破房子，没有别的来养活妻子儿女；还说他愿意通过服务来还债。经理说他不是老板，为他服务没用。在多次催促和请求之后，经理要他去见老板，如果老板高兴，他就可以通过服务还债。欠债人来到老板家，二话没说就开始为老板服务。他服务得如此周到，不久老板就被他吸引。问他是谁，做什么的。他回答说他是老板的人，在老板身边服务。不管做什么，他都毫无尊严感、极其真诚。老板对他产生了感情。日子一天天过去，老板非常满意，看到他无偿服务，于是有一天要他接受自己的谢礼。他保持沉默，什么也不说，只是继续服务。当老板再次提到谢礼时，他说他不想要任何谢礼；只希望免除债务。然后讲述了整个事情的来龙去脉。老板很满意，命令经理取消他的全部债务。就这样，他不仅摆脱了债务，还额外从老板那里得到一份丰厚谢礼；之后老板也不让他离开，而是把他留在家里，就像家人一样。

同样，如果一个人为神的事业尽心尽力，以至于让神感到欣慰和满意，那么债务问题就迎刃而解；因为神高兴时，就会取消他的所有债务，然后把他留在自己身边，成为家中一员，也就是处于祂的位置。就这样，欠债人成为神。那时候给予和获取的问题又何在呢？

这种状态被称作解脱（Moksha）。这并非易事。要获得这种状态，就必须挣脱世俗束缚；为此，则必须与神建立联系。我们必须以这种纯质方式工作，心中不怀其他动机，这样我们与神的关系才能牢固建立。
