阿瓦塔即神在地球上的示现，美赫巴巴的显现将向人类示现其神性。阿瓦塔对每一个层面的意识进化和内化给予推进。通过宇宙工作，让人类有可能体验他作为神的显现。

一个又一个时代，阿瓦塔做同样的宇宙工作——唤醒人类走向真理和自由道路。出于永恒之爱，阿瓦塔为了宇宙而采用肉身，完成宇宙工作后放弃肉身，作为对世界的最后祭献。

然而，阿瓦塔离开肉身后，其工作却不停止。工作结果在100或200年期间逐渐显现，直到取得总体效果。该宇宙工作的总结果显现后，每一个意识层面，从石头到人类，都受到进一步推动，被提升到一个新层面。接下来的100年，人类的意识将被提升到直觉层面。那时人类就有可能沿着通向神的直道向内旅行，不受理性造成的智力阻碍所影响。

作为阿瓦塔宇宙工作的结果，人类总是被置于通向神的直道上；也总是在显现时期，人类觉醒到神。每一个阿瓦塔时代，人类中的自私、贪婪、嫉妒、淫欲、嗔怒、仇恨和傲慢倾向，皆被逐渐减少到适当程度；一个结果是人类能够在神爱里体验一体性。

然而，几百年之后，摩耶又开始表演，让人类忘记神的美，并创造一个新宗教，再度囚禁人类。经过几个世纪，这个新宗教逐渐地堕落为正统信仰。宗教表现变得机械化，失去神爱情感。这种情况发生在每一个时代。正统之监狱以宗教的名义囚禁人类。从琐罗亚斯德、罗摩、克里须那、佛陀、耶稣和穆罕默德时期，直到目前的时间周期，都能发现以往时代造成的不同正统类型。在现今的阿瓦塔时期，从前所建立的宗教监狱都开始倒坍，囚禁于正统牢狱内的人被解放。

通过几次化身，阿瓦塔的宇宙工作增强，在时间周期末尾，他在打破被扭曲宗教之牢狱的同时，对每一个意识层面给予总的推进。因此，在每个周期末，阿瓦塔的显现总是最伟大的。我们正是处于一个大时间周期之末。美赫巴巴是这个阿瓦塔周期的最后一次化身。因此阿瓦塔美赫巴巴的显现将是最伟大的，因为他的工作是这个大周期所有以往阿瓦塔工作的总巅。美赫巴巴作为神的显现期间，受影响的将不仅是世界的一部分——如穆罕默德与阿拉伯人，耶稣与犹太人和罗马人，佛陀、克里须那和罗摩与印度各种族。全世界的人类都将被唤醒。

宗教的建立是正统化的结果。正统的产生是因为那些让人们遵从规定标准的宗教领袖。这在世界每一个现存宗教里都能发现，虽然其形式各异。

单一型正统派——以宗教名义建立，不允许任何方面或范围的灵性道路进步。否定高级层面的精和心意识。只要仪式教规，保持严密的社会组织。其领袖把人们严密封锁在宗教监狱里，对自身宗教外的事情甚至不能试图体验。该正统类型否定秘教及内化过程中所展现的高级灵性意识状态。

这个建立在宗教之上的正统监狱，将被阿瓦塔美赫巴巴的宇宙工作之力量所打破。监狱中的人们将呼吸到灵性觉醒的自由空气。

这些正统监狱中，有的还包含着更小的监狱。每个小监狱则含有具体的宗教种姓，派别，或教派，各自又有具体的正统观念。每个种姓、派别或教派又有多种仪式教规。虽同属一个宗教，这些教派之间却存在着多元与分裂。有的教派承认内化高级意识状态，却是从自身的具体仪式教规方面来体验的。神秘状态可通过某些仪式教规来引发，却根本不能明确指示如何达到目标。

攻击型正统派——属于那些当周围灵性觉醒涌现时，试图以宗教名义保持平静的人。这个态度盛行于攻击性的正统派。除了跟随者，他们向所有的人关闭门户。其攻击性是在监狱的安全中和平静的外衣下进行的。

社会工作型正统派——是宗教的另一个方面。一个派别深陷仪式教规，另一个从事社会工作。其它派别投入传教和医疗工作，在全世界传播其宗教。其社会工作给人们提供经济援助，战胜疾病贫困，却是为了让人们皈依其正统信仰。

暴力情感型正统派——即狂热主义。极端情感使人成为暴徒，以宗教名义施暴。这些狂热分子教派不同，方法却大致相同。都是以宗教信仰的名义杀人，被奉为烈士，以期传播狂热，吸引新的跟随者。

在今后100年期间，通过阿瓦塔美赫巴巴的宇宙工作，所有宗教的信仰者都将在神爱中觉醒，所有的宗教都将像珍珠一样串在一条主线上。阿瓦塔是那同一个至古者。他一个又一个时代来临，总是为了唤醒人类走向真理道路。对波斯人，他作为先知琐罗亚斯德；对印度各种族，作为罗摩王，克利须那主，乔达摩佛；对希伯来人和罗马人，作为耶稣；对阿拉伯人，作为穆罕默德来临。在本周期他是美赫巴巴，人类的慈父。由于这是最后的周期，他的使命也是最伟大的，因为是面向世界所有的种族。

至古者来到时，唤醒人类的一部分转向神爱。但之后那个种族却以他的名义建立一个宗教牢狱。实践嫉妒仇恨而非博爱。因此会发现在每一个时间周期末尾，世界上存在着几个宗教。作为本周期最后一个阿瓦塔，美赫巴巴不得不将所有的宗教和派别串联一起。通过打破每一个宗教正统来完成此工作。

美赫巴巴是本时间周期最伟大的阿瓦塔，因为他是为人类一切种族而来的。其宇宙工作是以往所有阿瓦塔的全部工作的顶点。美赫巴巴在本时代保持沉默，但他给世人留下的文字、讯息、语录和真理著作，却超过了以往任何一个阿瓦塔。美赫巴巴在闭关中度过大部分时间，但他所做的旅行要多于以往任何一个阿瓦塔。美赫巴巴亲身接触了全世界成千上万的人，超过了以往任何一个阿瓦塔。过去没有哪一个阿瓦塔接触了如此多的人种。美赫巴巴联系了众多的玛司特，透露的有关精界心界层面及神醉的秘密，都要多于以往任何一个阿瓦塔。因此，与以往阿瓦塔相比，他的工作将更大地利益世界。

美赫巴巴的宇宙工作将是其以往阿瓦塔化身的总结，并将在这个阿瓦塔期间达至顶峰。世界各个宗教的人都将认出他是曾以琐罗亚斯德、罗摩、克利须纳、佛陀、耶稣和穆罕默德的形体出现的同一个至古者。

美赫巴巴将把本周期以往阿瓦塔时期所完成的宇宙工作带向顶点。在本周期他做了更多的工作，因此其显现将是这个大周期中最伟大的。美赫巴巴是本时间周期的最后一个阿瓦塔，他曾为每一个工作，以便使他们进入更深的内在意识层面，能够直觉地体验与神为一。其宇宙工作的顶点将是人类感受与神一体的时候。这将标志着他在地球上的最伟大显现。整个人类都将在神爱中感受一体性。由于他在显现期间所释放的爱力，嫉妒、仇恨、自私、傲慢、淫欲及嗔怒将大幅度消除。只有体验到这种爱的时候，人类才会摆脱自身的宗教监狱，在神爱里享受一体性。
