七道门

1967年，美赫巴巴指示我写有关他的传记、工作与显现。在此之前，他给了我几个要点：

那是在一次守夜时，巴巴叫我拿来纸笔。之后说：“有关我的显现，我将给你几个要点。记下每一点。

我的寓所是无限的……无形的……但它有七道门……每个门都向那些束绑于幻相中的人关闭着……内化的目的是打开这七道门，以便体验我的无限性。

第一道门极难打开……进化诸界皆站在这个门前……人类背朝这个门……全都面向幻相……人类世界离这个门最近。

我就是来打开这七道门的……为在第一道门上切开一个洞口而工作……这个门引向第一个层面……切开此洞是我此生的工作。”

必须切开的洞口

阿瓦塔的无限寓所有七道门，每个门都对束绑于幻相的人关闭着。人类意识经历内化的目的，乃是为了打开这七道门，一个接一个，以最终体验无限。

打开第一道门极其困难。意识进化中的诸界皆在第一道门外。进化诸界和人类全都背向这个门，目视幻相。人类离第一道门最近。有福的是那些已经转向第一个门的罕见者。更有福的是那些已经设法打开第一个门并且进入无限能量之精领域的人。

打开第一道门最为困难，因为幻相的牵拉极其强大，使大多数人类背离这个门。人类甚至已经忘了有一道通向无限能量领域的门，因为摩耶的强大牵拉让人类意识陷入幻相。人类不知道去哪儿找到这个门。尽管离它很近，却在黑暗中摸索，不知门在哪里。

神作为阿瓦塔降入人身时，从其无形寓所通过这七道门而来。他在地球上的工作，是为了在第一道门上切开一个洞口。这个门从浊界引向第一个精层面。在第一道门上切开洞口，是为了让个体经此进入精领域。这就是他肉身在世期间所作的工作。这是他为整个人类所做的宇宙工作。

这项工作最困难。在第一个门上切洞口时，阿瓦塔经历巨大的痛苦。倘若阿瓦塔不切这个洞，个体就不可能找到内化的入口。虽然洞口已经切开，但直到阿瓦塔离开肉身之后，洞口才会打开。

为打开洞口的准备工作完成后，阿瓦塔规定好洞口打开的时间，随后离开肉身。当洞口打开时，光从纯能量领域流入浊界。洞口一打开，光一经此流出，人类就因看见光而不胜欣喜。不可阻拦地朝向光，背离幻相。

光从精界倾入浊界时，将带来阿瓦塔对地球上整个人类的普遍显现。对这个光的体验将建立一个新的世界秩序，新人类将从中产生。正是在阿瓦塔之光的宇宙性显现期间，人类将接受美赫巴巴为神圣，基督，先知或弥赛亚。正是通过对这个强光的体验，人类将普遍地接受美赫巴巴是神。

洞口打开时离洞口最近的人，会看见更多的光，接受美赫巴巴为神，渴望与他合一。以至经第一道门上的洞口，进入无限能量领域。一些个体接受美赫巴巴是神，并努力藉着自己体验到的光找到洞口。其余的人类在某种程度上接受他是神，并藉着所体验的光移向洞口。这种群众倾向归因于真理的自然牵拉，虽然人类整体不进入内化。人类大众皆转向发自洞口的光；但不是所有的人都能找到洞口。虽然对阿瓦塔显现的觉知会在全世界变得明显，但这个觉知却因人而异。当人类整体接受美赫巴巴的神性时，向着真理的牵拉将愈来愈强大，幻相的牵拉将愈来愈减弱。在阿瓦塔的显现期间，真理纪元开始，并随着幻相被他所示现的真理战胜，而达至顶峰。

阿瓦塔的显现将消灭世界上四分之三的不自然业相，从而将进化过程带回自然状态。真理的太阳将从洞口照射到全人类，驱除四分之三的人类愚昧之黑暗。是阿瓦塔在其宇宙显现期间，通过此光给人类意识带来总体变化。这个人类意识中光自然地给世界带来总体变化。全世界的人们将认出这个光是神圣的，发自阿瓦塔的神圣寓所。

工作的三个阶段

生活的目的是证悟神。整个造物界就是为实现该目的而产生的，虽然造物界实际上并不存在。有一条直路通向成道。它直接穿过七个进化阶段和七个内化层面。每一个灵魂都必须经过进化和内化，才能达到上帝意识层面。

通向证悟的道路是笔直的，但几乎人人都错过它。因为不自然业相的积累使几乎每个人都偏离那条道路。自然业相促使意识的进化，对七个阶段的意识进化是必要的。不自然业相是在人类形体中积累的，并阻止人类走向内化。除非这些不自然业相从人心消除，否则向内化的进步就会拖延。人陷入浊意识，一生又一生在世间流转。

阿瓦塔出现在地球上，是因为整个进化业相模式已变得不自然。人类错过通往成道的直路，是因为不自然的状况。就连诸进化阶段也变得不自然，主要是因为人类对不同进化物种的科学实验和利用。

阿瓦塔宇宙工作的第一个阶段，在于清除人类和低等进化生物的不自然业相，从而把整个进化界置于通向成道的直路上。完成这个阶段时，阿瓦塔离开肉身。第一个阶段工作的结果，逐渐地在100至200年的期间展现。这个阶段是业相消灭与焚烧阶段。

离开肉身后，阿瓦塔工作的第二个阶段开始。这个阶段是分发美酒——他的神爱。阿瓦塔的酒店向全人类开放。他首先把酒慷慨地分给那些已在证悟直道上，并敞开心扉接受其美酒的人。这是陶醉阶段。

一个心为不自然业相所累的人，是不会渴望本阿瓦塔时代的神圣美酒的。渴望始于不自然业相被割除与烧掉之后；只有那时才会发现直道。由于阿瓦塔把所有的进化阶段重新置于直道上，其第一个阶段工作的结果是宇宙性的。这个发生时，宇宙的进化再次变得自然。这是一个净化阶段。

在第二个（陶醉）阶段，阿瓦塔继续工作，以便自由地分发美酒。有一些竭力多饮的个体将被推入更高一级的层面。有一些变得神圣陶醉的个体会渴望更多的酒，进入内化之门。有些个体仅仅品尝一下酒，却在暂时陶醉中，不向前进超越浊意识，虽然接近内在道路的入口。随着他的爱涌入世界，在一定程度上净化全体人类意识，阿瓦塔的酒也倾注人类心灵。

阿瓦塔的太阳之光——其辉灿——经七道门倾入三界。他的光经第七道门的洞口注入浊界。当各个进化阶段都在证悟直路上行进时，当人类体验神爱之酒时，每个层面的意识都会转向他的太阳之光。当地球上的人类处处看见这个光时，阿瓦塔工作的第三个阶段开始。这是他在地球上的显现。

在这第三个阶段，人类有意识地体验阿瓦塔显现的全部冲力，同时其它阶段的进化生命也普遍受到影响，进步被加速。离第七道门最近的人最直接而强烈地体验他的显现。其余的人类对显现的体验，取决于各自离第七道门的相对距离。作为阿瓦塔的显现，被人类看见的这个光将燃亮人类意识，以便实际体验神圣陶醉。

在离开肉身之日，阿瓦塔美赫巴巴开始了其宇宙工作的第二个阶段。自1969年1月31日起，他一直在慷慨地分发美酒。他肉身在世做第一个阶段工作期间，那些没有亲身接触他或亲眼见过他的人，什么都没有错过！在他们对他或他的来临无觉知的情况下，美赫巴巴已经为他们做好了第一个阶段的内在工作。他第一个阶段的工作帮助他们准备好接收他的酒，并参与他第二个阶段的工作。不过，他们若不向他敞开心灵，接受他的酒，实际上会错过其显现的真正光荣——神圣陶醉。

我还记得发生在1968年9月的一件事。显然与美赫巴巴第二个阶段的工作有关。巴巴同满德里讨论即将来临的1969年达善活动。

帕椎对巴巴说，“我们都老了。巴巴，关店吧！”

巴巴立刻不高兴地打手势说，“你说什么？关店！店门即将打开！”

那时我们谁都不明白巴巴的意思。但是，他离开肉身不久，更多的人开始来，虽然他们没有见过他。来此人类溪流表示他已经向世界打开酒店——慷慨地把酒分给所有那些在他第一个阶段工作中的不知不觉参与者。这些人走在通向他的道路上。

另一件事发生在1968年10月，巴巴工作的闭关阶段。由于巴巴不给爱者回信，我深感不安。那是严禁东西方爱者跟他通信的时期。

巴巴看出我的不安，对我解释说，“我的爱者很伟大，不求任何的物质或灵性东西。我是来膜拜他们的…...你为何如此不安？你跟随我这么多年，还不明白我在为他们做什么。

假如他们来，会看见什么？只是这具肉身！我在给予他们的真正东西是这个。”随即捶击了一下大腿——表示闭关工作的手势。

巴巴接着说，“我的工作是真正的东西——我正在给予他们。你将亲眼目睹，对那些没有见过我的人将会发生什么。”

因为他的工作是他已经给予世界的真正东西，所以现在人们开始来他这里。美赫巴巴为他们完成了其工作的第一个阶段，虽然他肉身在世时这些人没见过他。在他们不知不觉中，他已给他们赐予大福，以独特的方式让他们准备好参与他工作的第二个阶段——爱之酒。

在最后的日子里，巴巴的健康处于危急状态。1969年1月，巴巴还在讨论四月份将要举行的达善活动。他的痛苦异常强烈。身体被极大的宇宙重负压碎。这是他在地球上第一个工作阶段的最后一击。痉挛接连不断地袭击他的身体。似乎骨头在断裂。那个记忆永远不会离开我。

讨论达善时，巴巴说，“我一旦开始给我的爱者达善，就不会停下！它将是持续不断的，那时我将很强壮。”

我们这些满德里还是不明白巴巴的意思。但自从他离开肉身之后，我亲眼目睹越来越多的人来寻求巴巴的达善。我现在明白他是怎样持续地施达善的，是怎样分发美酒的。

现在他非常强壮。酒店打开，门一直敞开。摩耶关闭不了它。酒是第二个阶段，世界在接收之，因为酒是他的工作。他现在持续不断地给渴望其酒的人施达善。酒是最重要的阶段，因为这是准备时期——以参与其工作的第三个阶段——他向整个世界的神圣显现。

现在是全心全意地参与美赫巴巴工作的第二个阶段并畅饮爱之酒的时候。要利用这个灵性机会，尽量多饮他的美酒。我们的陶醉就是他的准备工作。这个准备将让我们更充分地体验他的显现。我们应该准备好俯身在他足前，向他顶礼——在工作中为我们受了无限痛苦的阿瓦塔。
