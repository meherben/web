阿瓦塔来临地球，标志着灵性动荡时期。该动荡有必要，因为阿瓦塔来到，发现人类意识被不自然业相污染，在世界上造成不良状况。

业相使心不停运作；制造心并使之思想、欲求和行动。一般人用浊眼看不见、甚至不能想象业相。有浊意识者无法想象物质存在之外的东西。无线电波由天线接收；视频波由卫星接收。二者都极其精微，能够穿墙越壁，远程传播，却不为播音或电视操作者所见。有浊意识的人怎能看见比光更精微的业相？

阿瓦塔来临时，通过对人类业相意识的工作，来净化清洁世界的业相环境。为在宇宙规模上完成工作，他使用宇宙心及其神圣、自由业相——瑜伽瑜伽业相。这些业相净化清洁整个宇宙的业相环境。只有离开肉身的时候，阿瓦塔才能将这些瑜伽瑜伽业相释放于全宇宙。随着他离开肉身，即刻发生世界规模的反应，因为这些瑜伽瑜伽业相开始其净化清洁工作。

目前，人类的意识最不自然。在人类意识的每一个方面，都存在着前所未有的贪婪，前所未有的淫欲，前所未有的嗔怒，等等。人们比过去任何时候都更贪食。所吃食物远远超过身体需要。吃的过多，胃便反抗，随后是消化不良。给他泻药，服后必须排泄，才会感到干净通畅。

同理，世上每个人目前也因其不自然业相的障碍，患有严重的内在消化不良。人人都变得要么太贪婪，要么太淫欲、太仇恨、太傲慢、太嫉妒、太恼怒、太自私。清除人心中这些障碍业相的，正是阿瓦塔通过宇宙心所释放的瑜伽瑜伽业相。在这个意义上，他的瑜伽瑜伽业相发挥着泻药的作用。过量的不自然业相造成个体的内在消化不良、焦虑或不满，阻止他向真理道路迈进。除非且直到从意识中清除掉这些业相，否则他就不能走向成道目标。这要求一定程度的心灭。

当阿瓦塔给予瑜伽瑜伽业相之泻药，来清除内在消化不良时，人感到不自在。阿瓦塔的工作之瑜伽瑜伽业相，清除掉不自然业相之垃圾污秽。服了泻药，就要去厕所排泄。对阿瓦塔的工作之瑜伽瑜伽业相，有些人也不自觉地做出反应。感到有必要去找所谓的圣人、古鲁和自封的高道。在阿瓦塔的工作中，假圣人假古鲁起着厕所的作用，成为处理不自然业相的媒介。

千万不要相信这些假圣人和假古鲁。其灵性高级仅仅是假装。其不自然业相使其倾向于要人追随顶礼。这种特别的不自然业相，使他们乐于被称作圣人、古鲁、大师，尽管名不副实。阿瓦塔利用这些特别业相，使他们成为他在世界上工作的媒介。他们是厕所，人们不自觉地找到这些伪师，来排除自身的障碍性业相。将一切尽情倒入厕所后，感到缓解舒适。通向神的道路清理之后，逐渐地从假圣人转向阿瓦塔——真缓解之源。而让他们寻找假圣人古鲁的，就是起着泻药作用的阿瓦塔瑜伽瑜伽业相。

世界上众多假古鲁蘑菇云般地出现，完全是阿瓦塔美赫巴巴对人类意识所做工作的结果。很多人追随冒牌古鲁，乃是对美赫巴巴解放业相之净化力量的反应。他们在寻找缓解途径，因自身不自然的意识状态，找到相应的缓解渠道。

那些直接找到美赫巴巴者，具有同他的直接联系。这是一种内在联系，这些人的不自然业相已经被净化到一定的程度，因此不会因接触阿瓦塔的神圣自由业相而感到不自在。因为不自然业相已被清理到一定的程度，他们的消化不良已得到缓解，道路障碍排除，所以能够直接来到真理之源——阿瓦塔美赫巴巴。

最终清除每个人心里的一切污垢者，是阿瓦塔。唯有他存在，因而假圣人假古鲁也全部在他之内，都是他在世界上工作的一部分，是阿瓦塔用来清洁世界环境的工具。

要清洁整个世界，就需要雇用很多很多人，从各个国家收集垃圾，集中到一处。在世界每个角落放上垃圾桶，能将阿瓦塔的工作量减到最低度，加快清理过程。那些有冒充圣人古鲁的虚伪和不自然倾向者，发挥着阿瓦塔的垃圾库作用。跟随者将垃圾扔进这些伪师。这些假圣人古鲁成为跟随者的垃圾桶。只要跟随者对伪师有信心，其垃圾便进入并留在垃圾桶。然而，跟随者一旦对伪师产生怀疑，那么他所扔的垃圾就会返回来，连同别人扔进去的垃圾，一起被抛回他自己身上！正是在此刻，阿瓦塔必须干预，将他从更不自然的遭遇中救出。当所有垃圾全被集中于一处时，则更容易让阿瓦塔处置。阿瓦塔只需要清空垃圾桶——但却是在垃圾桶假圣人承受所收集全部垃圾负担的痛苦之后。

这些假圣人古鲁尽管充当着阿瓦塔的垃圾桶和厕所，收集跟随者的垃圾污秽，但最终还是要被揭穿，不得不为虚伪受苦。现在人们看见他们享受生活、名利，但这不过是今生收集不自然业相，来世一生受耻辱痛苦。美赫巴巴警告说，在他离开肉身之后，可能会有多达77个假弥赛亚出现。

阿瓦塔美赫巴巴是这个幻相游戏中的实相，然而，在他离开肉身之后的今天，却有假救世主大批涌现。这些伪弥赛亚拥有成千上万的跟随者，并且向公众宣称自己神圣伟大。这就是阿瓦塔美赫巴巴在世人面前的蒙辱。如果一个人真正、全能、全知，而另一个人虚假、软弱、无知、但却宣称自己伟大，那么真正伟大者就会蒙辱。美赫巴巴的最大蒙辱是，他作为真正者，却鲜为人知，而那些虚假者却闻名遐迩。

不过，这种蒙辱仅仅是美赫巴巴工作的一个方面。正是这种蒙辱，将使他被荣耀，因为他的蒙辱是人类的准备阶段——帮助世人准备好在内心感受他的大爱显现。阿瓦塔美赫巴巴的显现，将是真相显现，其冲击力也将属于永恒真理，他的神圣之爱将把人类意识转向实在。
