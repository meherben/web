在其超越超越之原始状态，神处于一种无限寂静的状态。原始的道（Word），即原始问题“我是谁？”有一个无限声音，但这个声音是寂静之音，因此是无音之音。

在其原始状态，神即大有。但在其原始状态，神——大有——却不知道他是大有。大有通过原始问题“我是谁？”通过其无限声音被知道。这个无限声音超越了浊、精、心声音。浊、精、心界的声音是原始无限声音的七个影子。这七个影子的全部声音创造出一个最有限的声音，在这七个影子的声音之内，有着无限个的声音。原始的道是一个无限声音，正因为它是无限的，所以这个道是万音之音。这个道音属于无限的寂静——无限的无音之音。

为了对无音之音有个概念，只需观察一下你自己的思维心。心的性质与功能是思想；心就是那个思想状态。心进行思想，而在思想状态是没有声音的。一旦思想被转化为欲望，欲望被转化为言语，一个人就在浊层面听见其念头的声音。不过，言语后面的推动力却是思想，念头本身——它没有声音。原始问题“我是谁？”是原始的念头，但它被转移到浊、精、心世界的状态时，便成为原始的道。这个原始之道，因获得了答案，而永恒地作为无限念头存在着；这个无限念头是无音的。然而，因为其本质——无限念头本身，这个原始的“道念”引起一个无限声音。这一个无限声音又造成无限个声音。但这个无限声音永远地属于无音之音，因为它一直是无限的念头。

思想在有限心被消灭的涅槃状态止息时，原始的道被听见——作为对原始无限念头的答案。原始念头的状态——它创造了无限思想的过程——没有声音，并且不会被听见——即使在无限思想的过程本身变得充分活跃的第五层面。念头和思想是第五层面的心意识状态；该念头和思想虽然纯净，却仍处于声音状态。那个心声音，虽然被称做“神音”，却不是超越状态中神的原始之道的无音之音。原始问题是浊、精、心世界里一切万物背后的驱动力，正是因为那个问题——无限念头——的无音之音，一切万物都有了声音——每一个影子都进行思想，并在无限思想的过程中找到自己。

神的沉默

在超越超越中神的原始状态是沉默的。在神的原始无形中沉默是无音的；但在神的超越状态，沉默却有一个无音之音——这是因为原始念头，或者问题“我是谁？”神之沉默的这个无音之音，是回答该问题的动力，该动力是无限的。这个无限的动力产生了一切的心、精、浊世界。

声音来自于超越超越中神的沉默。沉默是该声音的永恒动力。产生于本初的无限问题，是一个无限的念头。因此，在涅槃状态声音成为无音；在涅未卡帕状态获得沉默。神的这个无限念头，即在涅未卡帕状态神的念头——“我是神。”因此获得沉默，因为无限心思想到无限的念头。

声音是无限的，并且有三个类型，每一个类型都有着性质上的无限差异。思想和感情的声音是造物界中最高级的声音，因为它属于纯心——末那。普拉那的声音是造物界中最强大的声音，因为它属于无限能量。宇宙的声音是最有限的声音，但它包含着无数个声音，因为它包含着宇宙中每一个生命的声音。因此在三界之间存在着声音上的无限差异。

在神的超越状态，存在着无限的大有和无限的大无。大有的声音是无音之音，因为它是原始念头的声音，或者说沉默的声音。大无的声音是有声之音，因为它是原始问题之音的回响，或者说原始声音的反响影子。声音来自于大无，不是来自于大有。但大无的这个声音没有大有的动力，因为声音不可能被大无所制造。那么人类听见的声音是什么呢？它是大无的声音！该声音什么都不是，因为这个大无声音没有一个能够带领人去认识整个造物界的动力。

当阿瓦塔降入造物界时，大有对于他就是一切，大无对于他什么都不是。大无造物界听任他的指挥，大无的回响声音亦如此。他通过其无限心，有意识地利用大无造物界来做他的工作，他虽然讲话，却永远地沉默，因为他的无限心包含了无限念头。

美赫巴巴通过其宇宙工作道出了他的道（Word），当他完成宇宙工作并离开肉身后，他的沉默开始打破。那个道是他的工作的声音，其工作的结果在他的显现期间被知晓或听见。他完成了自己的工作，但却在显现期间把其工作的道给予世界，因为这是其工作结果在地球上显现的时期。他的工作主要是去除人心中的业相障碍，以便听见原始的道，这个道通过七个层次的人类意识和七个层次的进化意识下移。在人类意识的第七层次——浊界，道成为他的名。

人类意识的终极目的是听见道，但在浊、精、心世界消失之前，是不会听见那个道的。业相的歼灭带来声音的歼灭，只有在涅槃状态——当声音全部消灭时，才能真正听见道——在沉默里。只有在无限沉默的状态，才能听见那个无限的道言，即无限的念头。涅槃是那个一切声音都消失的真空；涅未卡帕是无限心在无限沉默中思想着无限念头“我是神”的神圣状态。

阿瓦塔的宇宙工作是重新改变进化声音的方向，以便听见那个无音之音的道。他的消除业相的工作，从每一个进化层面排除不良的声音，特别是那些由不自然业相造成的牵累人类意识的不良声音。在人类意识里，不良的声音已经变得庞大，这个由世界上所积累的大量不自然业相造成的声音，已经成为巨大的障碍，阻止着人类整体向内化的自然进程。构成浊界中不良声音的，是一切的不自然念头、不自然欲望、不自然行为和对神的不自然态度。它们是人类意识走向内化的障碍。

阿瓦塔进行工作，以排除这些业相障碍。他通过把浊界的声音吸入自己的身体来完成该工作。该声音一被吸入，就会变成无音，用身体吸入浊界声音，即是他消灭浊业相的工作。一旦人类意识在声音与静默之间达到平衡状态，它就准备好听见那个来自于他的沉默的道。这个道影响着听见它的每一个思想心的声音，因为该道能够消灭业相的声音。这个道属于无音之音。他的道之音的无音，能够吸收一切的声音。这样，通过阿瓦塔的无音之道，人类业相被逐步地消灭。他的工作帮助每一个人做好准备，以倾听那个原始之道的终极之音。当人心在涅槃状态彻底摆脱一切的业相时，那时它将在涅未卡帕状态听见神的无限念头的无限沉默。
