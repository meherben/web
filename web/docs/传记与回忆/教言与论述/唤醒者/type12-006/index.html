我们很高兴能把这本小型杂志《唤醒者》，献给我们这个时代的在世灵性完美大师——美赫巴巴。因为我们相信，他注定是人类的伟大灵性唤醒者，伟大的灵性火炬，不时地降临人间启迪人类的心灵，不仅给予他们希望，而且使他们实际预尝其终极归宿——与神合一。

  因为他带给我们的，不是单纯的枯燥文字和说教，而是对上帝的实际经验，我们称他为“唤醒者”。他本人声明，“我不是来教导，而是来唤醒。”他尤其是来唤醒我们心中干涸的爱的。他表示，人类已达到智力发展的顶峰，其提升进化的下一步是灵性直觉的觉醒，该直觉主要通过心灵来运作。只有这种心灵上的改变，才能把人类从当前堕入的毁灭深渊中拯救出来。缺乏爱的理性，缺乏直觉的智力，被他比喻为混凝土水库，其中整个机器运转有条不紊，却是干燥和空虚的。仅有智力不可能拯救人类。仅有智力不可能使我们找到上帝，而人类没有上帝，就永远不能实现其真我或命运。

 大师27年多的沉默（译注：此文发表于1953年），在这个充斥着高谈阔论、智力辩论、形而上学竞争、人身诽谤和滥用真理的时代，有着非常深刻的意义。作为灵性完人，他所承担的沉默并不是为了自身的一种训练，而显然是为了全人类。它象征着神圣恩典，来自于超越心之处，以救赎心，用后者极为匮乏的光与力量重新将它充满。这种光与力量就是爱。来自源头的爱。完全纯洁无私的神爱。等同于生命本身的爱。

 长期以来，因为所有的技术进步，我们生活在一个真正的卡利年代或者说黑暗时代。不过每个时代皆是一个周期，并且步入一个觉悟的、灵性复兴的时代。这种人类的复兴，始终由这些伟大的觉者之一所引导，他们发挥着人类和上帝之间的活纽带的作用。他们把上帝的力量和恩典带入我们干涸空虚的心灵，让我们感受到哲学家和神学家仅仅能宣讲的东西。他们改变了人心，或许在其有生之年只改变了少数人；但正如巴巴的一位门徒所述，“这份爱心心相传”，在潜移默化中，最终改变人类的整个灵性节拍。它过去一直如此；并将永远如此。琐罗亚斯德、奎师那、佛陀、耶稣、穆罕默德，都不仅为了所处的时代，而是为了千秋万代而工作，因为神爱完全超越了时间。它位于时间的心脏，当我们时代的运行变慢（冷淡、残忍、虚弱或困惑），上帝通过一位伟大阿瓦塔心中的大爱脉动辐射，从而来恢复平衡。他们在意识上，在爱、极乐与知识上，皆为一；不过针对不同的时代，通过不同的人身，在不同的时间，聚焦于不同的层面。

 从心灵、从内在直觉和体验来讲，我们感到：美赫巴巴不仅是我们时代的真正阿瓦塔，而且将证明是有史以来最非凡的一位；感到上帝从未降临过如此丰沛的神爱恩典，因为人类正处于整个进化及内化史上的最紧要关头。我们必须要么爱，要么毁灭。上帝通过这个人，帮助我们选择。愿我们选择跟随他去爱——并被唤醒！

文章标题：《即将到来的灵性复兴：一篇社论》
作者：菲丽丝·弗莱德里克（Filis Frederick ）

翻译：碧砂 校对：石灰
