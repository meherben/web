阿瓦塔作为无限和永恒者一直永远显现。其作为无限与永恒者的神圣显现，在实在之第七层面被体验为未尼安卜弥卡——真理领域。

幻相领域通过两个心界和四个精界，延伸入浊界。阿瓦塔的神性虽然通过这三个存在领域一直显现，但对其神圣显现的体验，在每一个意识层面都不同。在心界，阿瓦塔的神性显现总是以心的形式——通过心——被体验为宇宙心和无限知识。在精界，阿瓦塔的神性显现总是以精形式——通过普拉那能量——被体验为宇宙能量和无限能力。在浊界，对其神性显现的体验因人而异——被体验为有神圣使命并给世界带来神圣讯息的神人。在意识面纱的第七层变薄，或因阿瓦塔的工作而被实际撕开之前，浊意识个体不能体验阿瓦塔的显现。面纱撕开之体验导致第七层面纱的揭开。

浊界每个人的无意识无限意识都被七层面纱所覆盖，该面纱由七层折叠的业相布料所编织。由浊业相构成的第七层面纱极厚。在这层面纱因浊欲望消灭而变薄之前，浊意识个体则不能感受阿瓦塔神性的显现。

浊意识个体感受阿瓦塔神性在世间显现，因阿瓦塔的业相歼灭工作而成为可能。面纱的浊层因业相的歼灭而逐渐变薄、更薄、最薄，直到完全撕破，从人心中拿去。阿瓦塔对整个宇宙工作，使每一个人心的第七层意识面纱变薄，以便尽可能体验他在浊界的神性显现。神性在浊界的显现，即世界一体性的体验、同全人类的兄弟之情，接受上帝父亲。无知面纱使人感到与神分离、与同类分离。这种分离感一直持续到面纱变薄——通过植根于淫欲、贪婪、嗔怒、仇恨、自私、傲慢和妒嫉之欲望业相的歼灭。

在阿瓦塔显现的100年期间，浊意识人类的四分之三浊业相将被逐渐消灭。这意味着，人类浊欲望——淫欲、贪婪、嗔怒、仇恨、自私、傲慢和妒嫉——的四分之三，连同使人类陷入这些欲望的全部念头的四分之三，都将被逐渐地消灭。为此，潜在于人类意识的一切东西都必须浮现于世。这就是为什么人类意识越来越陷入淫欲，越来越多地体验贪婪、嗔怒、仇恨、自私、傲慢和妒嫉。

浊欲望和思想的逐渐消灭，标志着浊面纱的变薄。随着这些浊欲望和念头被抹除，浊意识个体的面纱也越来越薄。随着一些个体的第七层面纱变薄，这种业相歼灭正在发生；有少数人的浊面纱已变得最薄，他们即将进入精界领域；有极少数人的面纱已被撕开，他们在进入阿瓦塔的显现领域。由于阿瓦塔的宇宙工作，世界上所有浊意识人的第七层面纱都在变薄，但程度不同。那些比别人更淫者，将体验一定程度的淫欲业相消灭；那些比别人更贪者，将体验一定程度的贪婪消灭，等等，每一种欲望皆然。由于人们的欲望重点不同，业相消灭也将因人而异。不过，人人都将根据其第七层面纱变薄的程度，体验美赫巴巴的显现。这种业相歼灭——使浊意识人类面纱变薄——即是他对世界显现并引领人类体验其神性。

一个人一旦进入精界，就不会有意识的退化；其浊意识已被全部消灭，随着前进，其意识越来越精微，而又强大。神的显现领域从精界第一层面开始，并延伸到心界第六层面，直到在第七实在层面(未尼安卜弥卡)被充分体验。第七层面处于真理领域，在该层面人本身成为神的活显现。对这样一个人，极乐体验难以言喻，因为随着成道者呼吸，其呼吸则成为一切生命的呼吸。

由于浊业相的错综复杂，在浊界存在着很多危险；这些复杂性即摩耶的诱惑。这些诱惑即构成人类浊意识的七个欲望。由于人心中涌现的这些欲望，有浊意识者极难感受神。这些诱惑簇拥着有浊意识的人，存在于浊界的每一个转折点。几乎浊意识人类所到之处，都有淫欲、贪婪、嗔怒、仇恨、自私、傲慢和嫉妒表现。因此，阿瓦塔必须工作，来削弱全人类的浊印象，使世界上每个人的第七层面纱随这些欲望消灭而变薄，以便能够感受神。

在显现期间，阿瓦塔使人类有可能接近神圣体验领域。如果整个人类都继续面向这个领域，那么每个人的面纱就会继续变薄。那时人类作为整体就会走近神圣领域入口。人类的这种接近神的感受，以及对自身内在认知的依靠，将呈现为“直觉”。有浊意识的人将不仅仅使用理智，还将在一种内在直觉层面上运作。然而，即便在人类意识的总体前进中，摩耶也总是扮演自己的角色。在阿瓦塔显现时期过后，人类又开始转向摩耶的诱惑，再次陷入幻相，随之又忘记神。

摩耶的诱惑总是存在于浊世界。进入神圣领域的途径，是跟随阿瓦塔——通过服从他留下的指示。进入内在神圣领域有一个入口；通过跟随阿瓦塔，通过服从他，一个人就创造一个门，并由此门进入内在领域。服从就是进入并住在神性显现之内在领域的大门。到阿瓦塔这里的每一个人，都必须通过服从阿瓦塔，来给自己造门，进入内在领域。

当一个人对阿瓦塔美赫巴巴产生兴趣时，就会想他，感受他，爱他，因而念记他。应认识到，是阿瓦塔将他带近其显现领域的。在终极上体验阿瓦塔的神性显现，意味着已经对他服从到造好了门并由此进入其内在领域的深度。

1969年1月31日上午，已于前夜完成其宇宙工作的美赫巴巴，把一些满德里叫到他房间。他生命垂危，但我们都不知道这是他的最后几个小时。巴巴令人从满德里大厅拿来写着哈菲兹三对诗句的木板。又令一位满德里在我们所有人面前宣读：

一个幸运的奴隶

理应执行大师的每项命令，

而不问“为何？”与“如何?”

对于大师向你说的话

切莫说错，因为，亲爱的，

错的是你自己无力理解他。

我是大师的奴隶，

他已将我从无知中解放。

无论我的大师做什么，

皆是为着全体相关者的最高利益。

这成为阿瓦塔美赫巴巴对跟随者的最后讯息。我们的灵性责任不仅是记住这些话，还要使之成为我们的生活。

美赫巴巴已将我们带近其神圣显现领域，他也会把全世界带到这一点——人们将转向作为神的他。然而，在将服从阿瓦塔成为大门之前，谁都不能进入其神圣显现领域。这就是为什么美赫巴巴在离开肉身之际，重申这些诗句，看我们能否对其讯息遵守到底。服从美赫巴巴，是他留给世界的最后讯息。

田心译自《本时代的阿瓦塔美赫巴巴在显现》Avatar of the Age Meher Baba Manifesting by Bhau Kalchuri,1985
