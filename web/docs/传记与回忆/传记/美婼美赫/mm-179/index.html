诺芮娜在闭关山顶拍摄的巴巴和美婼的照片，1947年
诺芮娜拍摄——美茹提供

巴巴在美拉扎德的时候，除了带女子们去看电影，还经常带她们长距离散步。这个活动也是在黎明时分进行的。巴巴和女子们经常早上5点半起床，7点出发去散步。巴巴快步走在前面，美婼等人在后，努力跟上他的步伐。

｛注：美婼总是特别注意让大家抬脚走路，以免在巴巴附近扬起尘土。｝

他们的路线通常是沿美拉扎德私人引道而行，再越过又宽又高的堤坡。卡卡沿引道种了树，每天用牛车拉着水桶从湖里运来水，浇灌树苗。美婼说：“过去巴巴沿着这条路走到湖边（我们女子在后面追赶！），由于卡卡的精心照料与辛勤劳动，巴巴得以遮荫。

“巴巴喜欢走路。”美婼继续说，她记得他走路时总是穿一双棕色网球鞋。“他以前步伐矫健优美。当我们走到水库时，经常看到日出。巴巴走到湖边，然后沿厚厚的护墙上下行走，步履如飞。玛妮、美茹、高荷和我与他一起走，散落在后，欣赏着风景和波光粼粼的日出倒影。巴巴也会带我们登上附近的山丘，他爬得十分敏捷。他会转过身来，看到我们挣扎着往上爬。

“‘来吧，没事的。’他会打个手势。巴巴爬过美拉扎德周围所有的山丘。”

有一次，巴巴前去美拉巴德一天，女子们独自出门散步。“那是凉爽的雨季，”美婼回忆说，“我们决定进行一次愉快的远足。大家带上面包和黄油三明治，去了水库和更远的没有去过的山丘。花的时间比我们想象的要长，过了三个小时才回来。

“诺芮娜在美拉扎德等候。她非常担心：‘姑娘们上哪儿去了？发生了什么事？’我们不知道需要这么久。我们回来时，她对高荷很是不快。”

高荷安慰她说：“我是医生，诺芮娜。如果发生什么事，有我和她们在一起。所以没必要担心。”

另一天，她们跟巴巴一起返回时，巴巴带她们来到湖的另一边，登上了那座远处山丘的山顶。女子们跟不上，只好让巴巴走在前面。美婼偶尔停下来采一朵花，她回忆道：“巴巴戴着一条蓝色棉质围巾。如果刮风，他就把头发绑到后面。要穿过干涸的河床，爬上满是乱石和荆棘的山丘，着实不易。巴巴穿着网球鞋，爬得那么灵活，那么优美。我们奋力跟随他，高荷像往常一样最后一个到达。在山顶，巴巴站在那里欣赏着风景。”

“瞧有多好。”他说，“从这里看风景很美。看看这湖。”

“他在那儿站了五分钟，然后沿着山顶行走。阳光炙烈，所以我们停留的时间不超过数分钟。”

巴巴让伊丽莎白开车到另一侧山脚迎候，送他们回美拉扎德——大家都又热又累。

美茹说：“有时候，巴巴会说：‘汽车需要开动来保养。’于是每天早上，伊丽莎白都开车带我们去不同的地方。然后我们会爬不同的山。”

“在那些日子里，”高荷补充说，“我们每天都会爬一座不同的山。过去的日子真好。当巴巴去进行玛司特之旅时，他叫我们去远足——我们照办。”

引道附近有一座山丘被称为“高荷山”。美婼解释了名字由来：“巴巴爬这座山的时候，动作是那么漂亮且轻松，而山坡上有松散的碎石。我们跟着他爬，可回头一瞧，看见高荷正往下滑去。我们去帮她，有人推，有人拉。大家都笑了。

“巴巴转身问：‘你们在干什么？’高荷慢之又慢地爬了上来。于是现在它被称为高荷山。”

在这段时期，美拉巴德山上发生了一件怪事。晚上，吉蒂听到像是有人在地上拖垫子的声音。所有人都听到了——除了曼萨丽。她们通知了巴巴，他捎话说，傍晚她们要在他的陵墓前进行阿提。

巴巴再来的时候，他问有谁听到了那些声音。所有人都举了手，除了曼萨丽。她说：“我从未看到或听到过什么。”

巴巴问：“如果你看到或听到了什么，会害怕吗？”

曼萨丽回答：“这让我怎么说呢，要是我还没看到它的话？”

“不，我知道你不会害怕。”巴巴说，“我知道的。所以我要告诉你们大家——无论谁听到什么，或者感觉到那里有什么，就告诉他：‘去曼萨丽那里吧！’他就会离开你们去找她。”

“让他来吧。”曼萨丽说，“可他到我这儿来有什么用呢？我会说：‘去美赫巴巴那里吧！’他会去您那里。您就只好对付他！”

一天晚上，曼萨丽睡觉时，被一阵奇怪而响亮的声音吵醒。她想起巴巴说过的话，就重复道：“去美赫巴巴那里吧！去美赫巴巴那里吧！”

巴巴下次来美拉巴德时，她提起这件事，并问：“您对他做了什么？”

巴巴只是轻笑。

10月16日，巴巴与男子们再次进行玛司特之旅。他离开三周，先去了阿杰梅尔（在那里，巴巴联系了几位玛司特，包括恰恰），然后去了巴罗达和艾哈迈达巴德。

在美拉扎德，一座山上建起了两间小屋，巴巴打算在那里闭关：一间在山顶的小屋给他住，下方不远处的另一间给阿里·夏。两间小屋只有10×12英尺见方，但有着芒格洛尔瓦屋顶，石棉板墙壁，并用钢架支撑以抵御强风。

｛注：下方小屋对面搭了一顶帐篷，供满德里值班人员用。｝

有一天，巴巴对包括诺芮娜在内的女子们说，他想带她们到闭关山上看看他的小屋。“在他进入闭关之前，这是吉祥的时刻。”美婼回忆道，“我们带着一个花环准备给巴巴戴。巴巴的步伐是那么飘逸快速，总是走在前面。

“巴巴敏捷地攀登，然后等着我们。他回望一下，看看我们在哪里，然后打响指：‘过来，快点！’我们跟上他，他又向上爬。

在第一处高地，巴巴指着美拉扎德住所的屋顶说：“瞧，从这里看多漂亮。”然后说：“我们现在继续向上。我的小屋在第二处高地上。”

巴巴开始登上那条短而陡的小路，其他人也跟上去。当美婼看到窄路两侧山坡陡峭而下时，她四肢着地跪下。“我感到很害怕。我无法站在高处，也没办法爬过去。”

看到她跪在地上，巴巴很惊讶，问她怎么了。“我恐高，”她说，“我觉得头晕。”

巴巴迅速过来援助她。他伸出手说：“抓着我的手。”

美婼抓住，巴巴的有力抓握将她拉过了陡坡。“当时我感觉很安全、很好。”

诺芮娜在闭关山的一边给巴巴和美婼拍了张照片，但美婼对照片效果不满意，并把它收起来。

“现在你感觉还好吧？”巴巴问，“别害怕。环顾四周，你可以从这里看到整个美拉扎德。那里有湖泊和村庄（坪坡岗）。真正的鸟瞰，不是吗？现在进小屋吧。”

巴巴走进小屋，女子们两个一组轮流进入。窗边放了一把椅子，面朝湖泊。巴巴坐着椅子，谈起他即将开始的闭关工作。当他走出小屋时，美婼给他戴了花环。

诺芮娜用玛妮的小相机又拍了一张照片。为了巴巴的安全，山顶上安了栏杆，旁边放了另一把椅子给巴巴坐。玛妮拍了一张巴巴靠着栏杆的照片。

｛注：这张照片裁剪扩印后，现在挂在美拉扎德主屋高荷的床头。｝

后来，美婼说：“我真希望闭关山的山顶有两倍宽，上面太狭窄了。”

还有一次，清晨她们和巴巴一起去闭关山，当他们爬上去的时候，山的上方出现了一道彩虹。

1947年12月5日星期五，太阳落山之际，巴巴独自爬上山，进入闭关。他在山上待了12天，每天早上6点到9点，与阿里·夏在较低的小屋里工作3个小时，然后待在山顶的小屋里。

有一次，巴巴在山上闭关时，美婼在室外做园艺。她偶然抬头望了望他的小屋，看见一个白色身影坐在栏杆旁。“巴巴不喜欢我一直盯着他看，所以我走开了。”她说。尽管美婼并不是故意看的，但那天下午巴巴传话说，女子们不能去后花园看向山丘。他希望他的闭关是彻底的。

但是允许女子们进行其他活动，甚至去电影院，正如大阿迪在一封信中提到的：“巴巴希望女士们在10号和14号去看电影，不管他是否在山上闭关；但由于汽油短缺，巴巴打消了这个念头。”

12月16日，巴巴指示在美拉巴德和部分在阿美纳伽的所有男满德里，下午4点在闭关山山顶与他会面。第二天，巴巴从山上下来，结束了闭关。不过，他与阿里·夏在美拉扎德又工作了两天，每天三小时。他带女子们去美拉巴德过了圣诞节。

12月28日，看完一场电影后，巴巴和美拉扎德的女子们再次来到美拉巴德，在那里待了四天。巴巴睡在凯克巴德的小屋，与前来庆祝美婼生日的跟随者们见面。

｛注：1947年12月5日早上，在开始闭关之前，巴巴带女子们去萨若希影院看了一场电影，18日，也就是结束闭关的第二天，他带她们去看了另一场电影。｝

而首先，巴巴同女满德里开了会。27日，他捎信说将在28日下午到达。一到，他就把所有人都召到东屋（美婼的房间），说道：“谁想待在美拉巴德，就必须接受这些条件：我永远不会来这里住，但想要见你们的时候我会来。我们会在电影院见面，或每当我召唤你们时见面。

“这些就是条件。谁想接受，就留下。如果不想，就在今天下午2点半之前，让我知道你想去哪里。我会给你买车票，给你戴花环，然后用火车送你走。”

大家散会，而曼萨丽最后一个离开。“我过去总是故意在最后离开，”她说，“这样我就可以有更长时间凝视巴巴，直到最后。即使是接受他的拥抱或帕萨德，我也会尽量在最后一个，以便能看他更久。那天巴巴在我之后走出来，但我不知道。普纳有几人被召来，我开始和她们交谈。”

“曼萨丽在哪？”巴巴问捷拜。

“我在这里。”曼萨丽回答。

“你在这里做什么？”

“跟来访者交谈。”

“拉诺那里有报纸（《印度时报》）。我还没看，去把它拿来。”

但曼萨丽去取时，巴巴跟着她。到了美婼房门口，他拦住她问：“你要去哪儿？”

“去取报纸。”

“告诉我，你的决定是什么？”

曼萨丽完全忘了巴巴向她们提出的问题。“您想要什么样的决定，巴巴？”

巴巴看着她：“我召唤大家时，你在那里吗？”

“是的，巴巴。”

“你可能在那儿，但你一定是打了个盹儿！”

“我就在那里。”

“你不记得了吗？好好想想。我捎了信……然后召唤你们。我说不管谁想留在这儿……”

“是的，是的。”曼萨丽打断了他，“有什么好决定的？这在多年前就决定了。”

“真的吗？你确定吗？”

“是的。”

“可你准备好了吗？”巴巴引用了一首流行歌曲中的歌词：“倘若我必须活着，我会住在你的巷口；倘若我必须死去，也会死在那里。”

他让曼萨丽复述这段歌词，她复述后，他又问：“你已经准备好了吗？”

“是的，巴巴。”

巴巴把她拉近，拥抱她，说：“你今天让我非常高兴。”

美婼站在附近，巴巴转向她，用双关语说：“德赛在德斯（十）分钟内就决定了！”

｛注：曼萨丽的姓是德赛。｝

巴巴有时召唤美拉巴德的人去美拉扎德住，但曼萨丽很少被邀请。玛妮解释了原因：“‘她会踩在我胸口上。’巴巴说。巴巴会让恺娣和曼萨丽一起待在美拉巴德，这样曼萨丽就不会是唯一一个他不召唤的人。曼萨丽不喜欢恺娣，她会把不被召唤的愤怒发泄在恺娣身上。恺娣全部忍受了，但最后说：‘我也没被召唤，曼萨丽！’”

｛注：巴巴曾向曼萨丽解释道：“什么是爱？你见过海里的岩石吗？海浪那么猛烈、那么频繁地撞击它，强度如此之大，致使它的侧面被磨损，但岩石坚定不移。你必须有这样的爱——坚如磐石。爱得永不动摇、永不衰退。”｝

事实上，曼萨丽更喜欢美拉巴德：“我从一开始就不喜欢美拉扎德。我希望巴巴在美拉巴德这里，我不想去那里。1947年或1948年，我们在那里待了一个星期。每个人都被叫去住一段时间。巴巴旅行归来时，问我们是否喜欢待在那儿。

“我说：‘如果您不在这里就不喜欢。’

“巴巴常常逗我说：‘美拉巴德是你的了。’

“我会说：‘您是主人；我在这里是仆人。’

“我从一开始就爱着美拉巴德。每次巴巴从美拉扎德来到美拉巴德，我都问他：‘巴巴，您什么时候像以前一样回来住在这里？’

“‘等等吧，’他会说。

“我全然不知巴巴会继续住在美拉扎德。希望永不破灭。过去（在蓝车旅行期间），他离开时总是说：‘现在我们要放火烧掉美拉巴德。我们不会再回来了。’

“他这样说过好几次，却总会回来。1946年，有一次他到美拉巴德来，我问了他同样的问题。

“巴巴说：‘如果你说：“巴巴，您喜欢去哪儿就去哪儿。我将留在美拉巴德。”我会更高兴。’

“我说：‘我不是为这般而来。’巴巴耸耸肩说：‘谁知道呢？’”

多年来，巴巴来美拉巴德过圣诞节的时候，经常会上演戏剧，在楼上的大宿舍里或在铁皮棚下。1947年也是如此，每个人都要在25日做点什么来娱乐他。

一个短剧演的是三位智者。参演的三个女子把纱丽披在身上做长袍，并且每人头戴通常的“王冠”——一个茶壶保温套！

｛注：如果有一个新的茶套被送到埃舍，它会被存放起来，首先用于一出戏，然后才成为日常的茶套。｝

但玛妮和高荷的幽默短剧在那天抢尽了风头。最初是巴巴本人提出这个建议的。美茹讲述了事情由来：“在美拉扎德，巴巴和我们在听美赫吉·卡卡瑞亚（一个忠实跟随者）从孟买寄来的波斯唱片。一些歌曲含有哈菲兹和其他著名神秘诗人的诗句。不少曲子有着现代感的快节奏，像是进行曲。

“其中一首唱的是伊朗历史上的一对夫妇，纳夫罗扎和菲罗扎。播放的时候，巴巴指着玛妮和高荷，说她们应该以这对有名的夫妻为题材，用这首曲子编排并表演一段舞蹈。”

玛妮费尽口舌，才让高荷相信自己甚至可以表演这个短剧。有几天，玛妮一直哄劝她，但高荷坚持说：“我不会跳舞！”

有一次，美婼听见她们在争论。“来吧，高荷，”玛妮说，“这是给巴巴表演的。你是唯一能做这件事的人。难道你不想逗巴巴笑吗？”

美婼过去看看发生了什么事，只听高荷抗议道：“可我感到很害羞。我怎么能在众人面前跳舞？”

“不，不，你能做到。”玛妮鼓励说。

最终，高荷同意了，两人在洋葱储藏室碰面练习。但当玛妮向她展示舞步时，高荷吓坏了。“我必须同时移动我的脚和胳膊吗？”

排练期间，每当巴巴召唤高荷的铃声响起，她就如释重负般地从折磨人的练习中逃脱。“是铃声让我得救。”她一边逃往满德里大厅，一边欢快地说。

在美拉巴德，高荷和玛妮走上了舞台，她们扮成那对伊朗尼老夫妇：高荷扮演丈夫纳夫罗扎，白须飘飘，头戴黑色伊朗尼帽，身穿黑色长外套；玛妮扮演妻子菲罗扎，身穿网织长袍、传统白丝绸阔腿裤，头戴包头巾。为了增加效果，玛妮还安上用柠檬做的假牙。那首歌曲用留声机播放，她和高荷开始跳舞。

美茹继续说：“玛妮在美婼的帮助下，用极大耐心和大量哄劝，说服高荷鼓起勇气练习。高荷以前从未演过戏，所以非常害羞和紧张。但在美拉巴德演出当天，她扮成年老的纳夫罗扎，表演得非常精彩。演出十分滑稽，高荷和玛妮在欢蹦乱跳时，巴巴、美婼和女满德里全部观众都笑得歇斯底里。高荷也跟着笑起来，却节拍未乱，笑得胡子直抖。而这恰似一个快乐的老人在和妻子跳舞，给她的角色增色不少。（高荷笑得太厉害，事实上，她笑尿了裤子！）

“美婼说，她们应该再来一场，因为大家都笑得太厉害了，无法真正欣赏这场舞蹈。”

在过去几年中，美婼的生日一直公开庆祝。有时，庆祝规模甚至比美赫巴巴的还要大。在那一年的12月31日，通过一场卡瓦里节目来庆祝美婼的40岁生日。第二天，巴巴和女子们回到美拉扎德。
