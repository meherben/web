147 喜爱的食物

1960年代，普纳

后来这几年，美婼等女子越来越关注巴巴的饮食。她们尽力为至爱准备开胃可口的饭菜。“巴巴喜欢辣味的食物，”美婼讲述，“不要太辣，中辣就行。早年，巴巴吃饭总要搭配辣椒。但在最后几年，巴巴吃饭不再配辣椒。对他来说原味豆糊太淡了，所以他会在酸辣酱里加少量的青辣椒。”

“巴巴爱吃酸辣酱——用新鲜青芒果[绝不是罐子里预制的]，大蒜，香菜，少许干姜，辣椒，再加几滴青柠汁做的。巴巴喜欢一种用14种食材制作的酸辣酱，是蔻诗德教我们做的。他还非常爱吃大蒜，不管是豆糊中的炸蒜，还是蒜香酸辣酱中的生蒜。通常在美拉扎德吃晚饭时，巴巴会把蒜香酸辣酱和炸蒜拌入原味豆糊，再淋上酥油。”

{注：巴巴曾告诉女子们，一次吃生蒜不要超过六瓣。}

夏天的时候，巴巴的主食旁有时会配上一个小盘，装着切成四瓣的柠檬或青柠。果籽已被细心去除，上面撒了少许盐和姜黄粉。巴巴先吃一口米饭配咖喱，然后吮吸青柠。洋葱被切成小丁，轻腌过。他喜欢卡春伯蔬菜沙拉，一种搭配胡芦巴叶、有时还拌点酸奶的生洋葱沙拉。还有些时候，他会吃拌有酸奶的萝卜丝。

{注：美婼非常喜欢生吃新鲜的青葱。她说：“我不喜欢炸洋葱。”}

在美拉巴德埃舍，巴巴总是吃木豆；后来，换成马粟豆和绿豆。他还喜欢将豆糊拌些阿姆苏（一种酸果干）。就像玛妮，巴巴喜欢豆糊和咖喱干稠些；而美婼更喜欢它稀些。他不太喜欢喝汤。但因为女子们说这对他有益，他会喝，“但不太喜欢。”巴巴爱吃基奇里（豆和米一起煮的烩饭），但大多数时候只吃简单的豆糊和米饭，或咖喱和米饭，搭配泡菜或酸辣酱，加半勺酥油。

{注：木豆、马粟豆和绿豆属于不同种类的扁豆。}

为了丰富口味，娜佳偶尔会做不同种类的咖喱：椰子、酪乳、蔬菜、菠菜、鸡蛋或土豆咖喱。巴巴爱吃马萨拉香料咖喱，还有丹萨克。此外，他喜欢用豆粉做的油炸零食，比如色芙。他爱吃布加——用洋葱或菠菜叶做的——还会在酪乳咖喱中加几块布加。

巴巴向来不爱吃蔬菜。他不喜欢胡萝卜、青豆、卷心菜、南瓜或秋葵，不过偶尔会要水煮秋葵。他也不是特别爱吃西红柿。他喜欢（各种）菠菜、胡芦巴叶、鹰嘴豆、花椰菜、茄子、象脚芋（他相当喜欢的根茎类蔬菜）、油炸帕特拉、酿青椒（内馅为土豆、洋葱和香料，随后油炸而成）。他还喜欢以各种方式烹饪的苦瓜，要么搭配酸辣酱或盐，要么切块后与红糖、炸洋葱和大蒜一起烹制。

巴巴最喜欢的蔬菜之一是花椰菜，但前提是要按如下方式烹饪：将一只洋葱切碎，放入酥油煎炒，在洋葱被煎黄之前，加入两三瓣大蒜、少许姜泥（不用捣得太碎）、一根青辣椒、一瓣丁香和一片桂皮。放入花椰菜，加少量水。用武火煮几分钟，然后转小火慢炖。加盐。继续小火煮，加入少许奶油。

{注：食谱由美婼和娜佳提供。}

巴巴喜爱的水果是芒果（他最爱吃的）、木瓜（去皮并切块，以便巴巴用调匙或用手拿着吃）、新鲜无花果、乌墨果（一种紫色蒲桃，无论成熟与否、甜还是酸）以及香蕉。普纳爱者寄来葡萄，巴巴吃了几颗甜而无籽的。埃尔查·米斯特里会从西姆拉寄来几包苹果，巴巴也会尝尝。一次在美拉扎德，他让美婼给他削几颗大又甜的印度枣（从一棵野生枣树上摘的）。在美拉扎德，会为巴巴现榨橙汁。难得甘蔗当季时，他会喝半杯甘蔗汁。

芒果的品种有上百种。阿方索芒果是最好的，但巴巴也喜欢“吸汁型”品种。“他会让我们把芒果挤一挤，然后他会吸吮果汁。每次巴巴从古鲁帕萨德回到美拉扎德，都会吃玛司特芒果树上长的芒果。这些芒果非常甜，连青芒果也是甜的。”

{注：美拉扎德的这些芒果树，是由马德拉斯的一名玛司特送给巴巴的种子培育而成的。}

当马斯喀特石榴上市的季节，阿娜瓦丝从孟买寄来了一大篮子。每天晚饭后，玛妮给巴巴读书时，巴巴会在卧室里吃一只石榴。她们在他床边放了两个盘子，一个用于放石榴，另一个用于盛他吮后吐出的石榴籽。

{注：之后，女子们围坐在餐桌前，嚼着这些被吐出的石榴籽，尽管汁液所剩无几，但因为巴巴吸吮过，它成了帕萨德。}

（可能是1963年的）一天，美婼看着巴巴在吮嚼并吐出石榴籽，有了主意。她端起一满盘的籽，巴巴问她要做什么。她说：“我想把您吃过的这些籽种下去。”美婼种下并悉心照料这些种籽。如今在美拉扎德主屋背后的水井对面，有三棵由这些种籽长成的石榴树。这些树不到五年便结出果实，巴巴也吃过这些树上的石榴。

当巴巴吃完饭，餐具被拿出去时，他的盘子上若有食物剩余，女子们个个都想把它当帕萨德吃掉。她们没法（按自己原本希望的那样）当着巴巴的面把它吃完，而是在他离开后，其中一位女子把食物分给大家，或者当她们在做指定的家务，在各个房间之间走动经过餐厅时，每个人会拿一点。此外，美婼透露：“我们有时会把巴巴杯子里剩下的饮品当作帕萨德喝掉。”

美婼还坦言，她喜欢看着巴巴将米饭和豆糊拌在一起。他的手非常好看。她觉得，当巴巴用手拌食物时，实际上给它增添了风味！

美茹证实了这点：“我们吃同样的食物，但味道却不如[他盘子里剩的饭菜]。只有巴巴拌过之后，才变得那么美味。我们都想分到一份。”

巴巴不会每天吃甜点；通常，他只吃一片木瓜。在圣诞节、别人的生日或他自己的生日，早晨巴巴会吃拉瓦（他很喜欢）或米粉。他不爱吃水果蛋糕，因为里面有太多水果和坚果，他觉得很难嚼。如果他要吃蛋糕，则喜欢软蛋糕，但即便那时，他通常也只吃一小块。巴巴喜欢冰激凌，偶尔也吃巧克力，但不会主动要。若有一块巧克力放在他面前，他会吃。他爱吃奶油，偶尔会吃一点奶酪。

有一次在美拉扎德，当奶酪端上来时，每人都给自己盘子里盛了几块。由于巴巴正避免摄入胆固醇并尽量减重，她们就没有给他盛。巴巴微笑着，伸出手，从美婼的盘子取了一块。“多拿些，巴巴，”她说，“还有一块呢。”但巴巴说够了。美婼后悔一开始自己没有主动给他一些。

奶酪在当时的印度不容易买到，他们吃的奶酪大多是西方爱者寄给巴巴的。“有时，在巴巴给我们分发巧克力和奶酪的难得场合，”玛妮讲述，“从未吃过奶酪或见过巧克力的佣人们也总是有份。她们对这些东西毫不在意。我们会赶紧过去，从巴巴手中接过巧克力帕萨德，希望能拿到最大的一块。佣人们过来时，会满怀着敬意和爱接过礼物。对奶酪同样如此。我们馋得流口水，欣喜地接受。但佣人们却迟迟不吃。由于不喜欢那种气味和味道，她们把奶酪放在储物架上多日，但因为是巴巴给她们的，她们最终还是会吃掉。”

拉诺提到，每当有不速之客来访，巴巴需要分发帕萨德时，她们就得把巴巴分给她们的份内美食重新收集起来，这样巴巴就有好东西可以分发了。巴巴离开肉身后，美婼会积攒一些美食，比如巧克力蛋糕，说：“把它留给西方人吧，她们会爱吃的。”

拉诺叹道：“她们在西方有这些东西吃。那我们呢？我们从来都没机会享用。”

因为巴巴被告知要控制体重，所以巴巴吃的木豆得仔细清理过，不能留壳。“所以它会非常甜，”美婼解释，“我们往里面放一点大蒜和酥油。巴巴不吃太多酥油，因为他不想增加体重。”

{注：格兰特医生建议巴巴的理想体重应是124磅，但高荷不记得巴巴是否真的减掉足够的磅数达到该重量。}

巴巴在自己房间称重，他踏上秤时，美婼和玛妮分别在两侧扶着他。高荷跪在地上读数值。“巴巴非常可爱，安静地站在秤上配合，还牵着我的手。130磅对巴巴来说体重太轻了，但我们不便多言。毕竟高荷是医生。”

有时候，美婼会稍加劝说：“巴巴，您为啥不吃些奶油或黄油呢？”

巴巴对她说：“你吃吧。你吃了，就相当于我吃了！”

有很多年，巴巴是严格的素食者。作为素食者，他和女子们都从不吃鸡蛋。不过自1947年起，巴巴允许她们偶尔吃鸡蛋。晚年，当娜佳做了鸡蛋咖喱，他会吃，但晨间早餐他从不吃鸡蛋。巴巴不喜欢炒蛋或煮蛋，对他来说太淡了。他午餐喜欢吃煎蛋卷，里面加点辣椒。但在晚年，这被证明太难消化。

{注：关于素食主义，美婼评论：“最重要的是爱神。吃不吃肉并不会增减你对神的爱。有些吃肉者可能比一些素食者更爱神。”}

美婼指出，在某些口味上，她和巴巴恰好相反：“巴巴不喜欢卷心菜；而我喜欢卷心菜。我不喜欢花椰菜和乌墨果；而他喜欢。巴巴更爱吃鱼肉而不是羊肉；我正好相反，更喜欢羊肉。巴巴爱吃的另一道菜是苦瓜。我不太爱吃，但如果它摆在桌上，我会吃。巴巴过去常吃苦瓜，所以我也得吃。”她笑着补充。

就像巴巴，美婼更爱吃米饭而非面饼。“巴巴不吃任何硬的东西。晚年，他希望食物软些。他食欲不佳，对饭菜提不起兴趣，尤其是在香料和盐的摄入受限后。巴巴吃饭一向有点快，而对米饭，也不必嚼太多。巴巴总是用手抓饭吃。他希望快点吃完，不喜欢食物太烫。有时，他和男子们外出时，他一只手拿着锅盖给食物扇风，另一只手抓饭。他吃饭时像个孩子，匆忙进食时，有时会把米饭撒到身上和盘子四周。他会系着大围兜，这样长衫就不会被弄脏。”

由于巴巴被建议食用高蛋白餐食，娜佳开始做咖喱或豆糊配羊肉作为午餐。给巴巴上菜后，他会在吃之前挑出小块的羊肉，放在盘子边沿。美婼以为他最后会吃这些肉，但巴巴只就着两三块羊肉吃米饭和咖喱。剩下的都留在盘子上。巴巴告诉美婼他吃完了，要肥皂和水洗手。“巴巴，您还没吃肉呢，”她指出，“医生建议您要摄入高蛋白食物。”

{注：晚餐，巴巴照例吃米饭和豆糊。}

“不，我吃够了。这是给马斯坦的。”

“马斯坦的食物备在外面呢。够它吃的，我们在厨房给它留了点羊肉。您应该多吃蛋白质。”

“我吃得够多了。这是给马斯坦的。我乐意给它，它也乐意吃。所以我们俩都很乐意。这有什么问题呢？”

“每天巴巴都这么做，”美婼忆述，“他首先想到马斯坦，把羊肉留在盘子边。我绝不会那么做。有时候，还没开始吃饭，巴巴就把最好的肉给马斯坦吃。当你饿着肚子，面前又有美味佳肴时，你自然会想赶快吃。这恰恰体现了巴巴对动物的深沉之爱。”

尽管如此，女子们并不放弃。次日，娜佳让人去市场买了更多肉。当巴巴发现盘中咖喱里的肉更多了，便对着女子们会心地笑（“那时他的神情非常可爱”），仿佛表示他知道她们有何图谋，就是想哄他多吃点肉。而巴巴确实会多吃两三块。

如前所述，马斯坦一直被拴在屋后，因此当巴巴准备喂它时，美婼去将它解开。“任何别的狗被拴过之后都会跑走，”美婼指出，“可当我解开绳子时，马斯坦抬头看着我，直到我说：‘去巴巴那里。’它随即欢快地奔进屋，在餐厅里坐好，抬头望着巴巴。它从不习惯大幅度地摇尾，只是轻轻摆动，我们就知道它很开心。巴巴会拿一点羊肉給它，实际上是放入它嘴里。”

一次美婼说：“巴巴，您不必递给它吃。狗特爱吃羊肉，自己会凑过来吃的。它们可喜欢吃肉了。”

巴巴说：“不，有好多肉。它得吃快点。”

“巴巴希望马斯坦吃得飞快。‘来呀，看有这么多。吃吧。’他好像在说。”

偶尔巴巴说：“马斯坦爱吃鸡蛋。拿个蛋来。”美婼取来。巴巴把生鸡蛋磕在手中，给马斯坦吃，让狗舔他的手。

巴巴其实不太喜欢吃羊肉，也不喜欢吃咖喱肉末（牛肉末或羊肉末）或炸肉饼。为摄入蛋白质，正如美婼所述，他更爱吃鱼。在库希如宿舍大阿迪的冰箱里保存着海鲜，每天会被送到美拉扎德。总是鲳鱼，这是一种海鱼（味道类似鲳参鱼），去骨切片后，裹上面包屑油炸。

但即便有鱼肉，还是很难让巴巴多吃。美婼说：“如果午餐有好吃的东西，比如鱼肉，我会说：‘巴巴，真的很好吃。尝尝，吃一点吧。’但他只喜欢咖喱和米饭。他会说：‘你吃吧。你吃了，就跟我吃了一样。’我们也就不再勉强他了。”

美婼等女子只是偶尔才吃鱼肉或羊肉，不像巴巴每天吃。他会亲自提议：“你们为何不让人送些来？”于是她们会要一些。

美婼爱吃羊骨的骨髓，喜欢啃骨头。一次，巴巴对她说：“小心点，别咬得太用力，不然会伤到你的牙齿。”

美婼被巴巴的关心所感动。“就连我自己的母亲都不会如此细心。”她感激地说。

1965年5月1日-6日，古鲁帕萨德达善
米兰拍摄
