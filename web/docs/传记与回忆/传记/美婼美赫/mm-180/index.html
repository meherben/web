美拉扎德，1948年1月10日
巴巴与美茹、艾微·杜思、美婼、玛妮、高荷
查米安·杜思·诺尔斯拍摄——苏非再定向提供

1948年1月7日，一位叫艾微·杜思的美国女子和她18岁的女儿查米安来到美拉扎德，第一次会见美赫巴巴。艾微由她本人的穆希德（灵性领袖）拉比·马丁，指定为西方世界苏非定向教团的穆希德。拉比·马丁是诺芮娜和伊丽莎白的朋友，她接受美赫巴巴为阿瓦塔，在1947年8月底去世之前，任命艾微为她的继承人。

艾微到来时，出于尊重，她戴了一顶白色帽子，就像要去教堂。她给巴巴和女子们带来五彩缤纷的漂亮丝巾作为礼物。在艾微和查米安五天的逗留期间，有一次为了好玩，巴巴又让艾微戴上帽子，并让女子们戴上丝巾，查米安给大家拍了照。

17日，巴巴开始与玛司特、苦行僧和穷人工作，为期40天。在此期间，他进行不完全禁食，每天只吃一餐。

伊丽莎白花了很多时间，在便携式打字机上打字（用食指）。她只停下一会儿，带她的狗儿捡得出门，因为狗生病了。几个月前，伊丽莎白为捡得的健康状况不佳而哭泣。当被问及原因时，她告诉巴巴：“捡得快要死了。”

巴巴评论：“这只狗会活得比圣雄甘地还久。”

1月30日，巴巴在早上说道：“今天将发生一件非常重要的事情。”傍晚5点17分，获悉甘地被暗杀。他死的时候，口念罗摩之名。

捡得又活了6个月，直到7月份死去，然后被葬在美拉巴德山。巴巴还给了伊丽莎白一只大丹犬幼犬，名叫丹尼，而萨若希送给巴巴一只腊肠狗，名叫巴尼亚。玛妮的苏格兰猎犬爆竹也在美拉扎德住了一段时间。

“爆竹会在丹尼的肚子下玩耍，因为丹尼很高。”美婼回忆说，“爆竹喜爱丹尼；但爆竹受不了伊丽莎白的狗，捡得。”

他们回到美拉扎德后不久，爆竹就被送到美拉巴德，巴巴说他在那里更安全。这只狗和吉蒂、拉诺一起在宿舍住了一年多。有时，他看起来很苦闷，要求外出。拉诺带他出去，但他不肯大小便，拉诺只好又领他上楼。“他只是觉得无聊。”她下结论。

通常，吉蒂照顾爆竹。然而有一次，当吉蒂训练谷露和佳露为巴巴表演时，恺娣在看管狗。这一天（1949年5月14日或15日），爆竹从后门逃跑，在美拉巴德山后被野狗咬死。吉蒂心烦意乱，“我觉得自己从没像爱爆竹那样爱过狗。”她表示。

｛注：后来，吉蒂在美拉扎德照管了丹尼一段时间。丹尼长大后，对女子来说，他太高太壮了，所以1948年7月14日，巴巴把他送给住库希如大院的大阿迪。在新生活时，丹尼被送给孟买的某个人。有一次，吉蒂和拉诺看见丹尼在那里溜达。她们走到他跟前，狗太亲热了，差点把她们撞倒。｝

1948年2月，世界各地的巴巴爱者们受令遵从某些指示。女满德里进行一个月的不完全禁食，一天一餐，喝茶两次。

2月7日，巴巴出发进行玛司特工作。在前往阿拉哈巴德一年一度的大法会之前，他先去孟买联系了玛司特。在阿拉哈巴德，他在3小时内联系了4000名苦行僧，向每人顶礼——这样做给他的颈部带来巨大的压力。巴巴于9日离开阿拉哈巴德，两天后回到美拉扎德。

｛注：不寻常的是，圣雄甘地在德里被火化后，骨灰被放入铜罐中，用火车从德里运到阿拉哈巴德。2月10日（巴巴离开后的第二天），骨灰被浸入恒河与亚穆纳河的神圣交汇处，河岸上三百万人观看。｝

根据琐罗亚斯德教的历法，于2月13日庆祝巴巴的54岁生日，这天美拉巴德的女子被邀请到美拉扎德。许可拜访的还有：顾麦和女儿珀茹嘉；高荷的母亲蔻诗德；埃瑞奇的妻子蔻诗德；埃瑞奇的妹妹美茹·达玛尼亚；希琳·达玛尼亚；以及纬露·伊朗尼。

｛注：埃瑞奇的妻子蔻诗德·杰萨瓦拉后来与一个假古鲁有牵连。巴巴叫她和他断绝联系，她拒绝。巴巴命令埃瑞奇不要再和蔻诗德有任何瓜葛，他服从了。巴巴舍弃肉身后，蔻诗德遇到玛妮，对她说：“你把我忘记了。”玛妮回答说：“我忘记了那些忘记美赫巴巴的人。”｝

12月，巴巴和美拉扎德的女子们来到美拉巴德。美婼身穿一件深红色天鹅绒夹克，戴着诺芮娜的面纱（诺芮娜第二次结婚时用的）。伊丽莎白获准拍下了全体合影。美婼对这张照片不满意。

“同类的人似乎排在了前面，”她说。美婼更喜欢年轻的女孩站在巴巴身边，或者诺芮娜，她们看起来总是那么优雅。

“害羞者和西方人总是在后面。卡库会来到前面，咧着嘴笑，她掉了几颗牙。在这张照片中，她站在巴巴近旁。一些照片就这样被糟蹋了。卡库和苏娜玛西会站得挨近巴巴。”

（当美婼向小蔻诗德提起这件事时，蔻诗德声称是诺芮娜让母亲苏娜玛西站在前面的，因为她太矮了。美婼不认同，认为苏娜玛西是自己站到前排的。）

｛注：有时候，如果美婼对一张照片的效果不满意，就会对它进行修改，比如插入另一张巴巴照片。｝

美拉扎德要建一座新屋，巴巴建议由美婼等女子来设计。美婼和美茹坐在一起讨论方案。她们决定巴巴的卧室在楼上——这样更私密，巴巴待在自己的楼层也更隐蔽（他总是更喜欢隐蔽）。巴巴自己说，刚来时瓦露建的那个旧厨房，应该用水泥建成永久性的。此外，还打算再添一间厨房。美婼说：“我们提出了带两个房间的双间厨房方案。”

新屋在建时，美拉扎德的男女满德里于2月15日搬去阿美纳伽暂住。美婼、玛妮、美茹、高荷、诺芮娜、伊丽莎白和瓦露住在高荷父母家，吉蒂和拉诺也轮流住那里。三年前，美拉扎德进行修缮时，她们在“帕帕家”待了三个星期；这一次，她们将在那里住7个月。

｛注：帕帕家后来被拆掉了。｝

男子们住在附近一所叫做冰厂屋的房子里。高荷的父亲鲁西·帕帕也去那里住，但在她们居住期间，他为她们采购。高荷的母亲蔻诗德和高荷的妹妹罗珊搬到了别处。

巴巴白天待在阿美纳伽和美拉巴德（那里的新满德里大厅也在建设中），晚上住在美拉扎德附近的戈亚拉小屋。

美婼描述了她们的新住所，高荷家的衣柜锁上了，但其余家具“都很好”，留给女子们使用。“住处方便适宜。在房子东北侧的房间里，给巴巴放了一张床（他下午在那里休息）；旁边是诺芮娜和伊丽莎白的卧室，位于房子的中间部位。隔壁房间用作客厅和餐厅，有地毯、漂亮的家具、屏风和一个书柜。有一间颇大的卧室给我们住（美婼、玛妮和美茹）。”

女满德里在帕帕家继续禁食：“我们早上可能只喝一杯茶。卡卡会在冰厂屋为诺芮娜和伊丽莎白单独做饭，她们一起去那里吃午饭。我们其余人在三四点钟用下午茶——蔬菜、薄饼、面包、黄油和茶。我们在上午做事的时候就开始饿了，到三点钟时，大家都饿坏了。

“我们也很调皮，通过提醒玛妮（她比别人更讨厌禁食）来戏弄她：‘现在来点又香又脆的薯片该有多好啊。’

“其他人则开始谈论肉饼。大家口水直流，试图让对方更饿。下午，我们大吃一顿来弥补上午的。这顿过后必须坚持到第二天下午。”

后来，女子们已经习惯了这种安排，以至于在禁食期结束后，她们仍然在早上吃早餐，在三、四点钟用下午茶，不吃晚饭。

3月14日星期六，在帕帕家待了一个月后，巴巴带女子们去了孟买，乘坐伊丽莎白的绿色德索托。在那里，他们第一次住在阿娜瓦丝和纳瑞曼·达达禅吉的新公寓阿厦那。纳瑞曼和巴巴，还有一些男子搬到美赫吉家。阿娜瓦丝则和女子们住在一起，带她们观光，并看了几场电影。

美婼给巴巴带了一个装着枕头和床单的行李袋。她知道巴巴在孟买也想去看电影，所以她在行李袋里装了一双他最喜欢的鞋子——很舒适的鞋，用柔软的英国皮革制成，敞口式设计，这让他的脚不会热。

“鞋子看起来很时尚。”美婼说，“巴巴穿着很好看，他喜欢这双鞋，因为他穿着很舒服。巴巴在孟买穿过两三次。”

虽然巴巴对孟买的访问严格保密，没有公开达善，也没有召唤其他巴巴爱者，但阿露·卡姆巴塔的表妹特米娜·乌姆里加最近结婚了，阿露希望表妹的婚礼纱丽和其他新衣得到祝福。她来到阿厦那，想把它们在巴巴的凉鞋上放一下，这双鞋一直在那里展示。令她大吃一惊的是，她发现巴巴本人就坐在公寓里。巴巴拿起那包衣服，给了美婼和玛妮各一件上衣。“我倍感欣喜与蒙福，”阿露回忆说。

3月20日，巴巴和女子们返回阿美纳伽，由大阿迪驾驶德索托。一路上，他们经常路过流浪的吉普赛人。巴巴总是把大家的注意力引到他们身上，评论说他羡慕他们的生活。“那难道不是一种美好的生活吗？”他问阿迪。

“为啥巴巴总是这样提到吉普赛人？”阿迪纳闷。后来，他意识到巴巴是在暗示即将到来的新生活。

阿迪把他们的行李绑在行李架上，但在经过罗纳乌拉后不久，车顶有什么东西被吹下来。美婼看见它落向左侧，就告诉巴巴。阿迪停车下去，发现有一个包裹掉到路上。不幸的是，他们没有意识到那个装着巴巴漂亮鞋子的行李袋，大约在一英里前就掉了下来。

当他们到达阿美纳伽时，发现行李袋不见了，美婼感到很难过：“我叫巴巴责备阿迪为什么不仔细绑好袋子。我们把所有东西都放在了车顶，以便后座有更多空间伸腿，但现在我很后悔这么做。”

｛注：在阿美纳伽，巴巴开始在鲁西·帕帕家过夜，而不是在戈亚拉小屋。｝

从孟买回来几天后，巴巴开始了一次漫长而艰苦的玛司特之旅（当时正值盛夏），先是到加尔各答，然后到印度北部的瑞希克什。他离开了将近一个月。

｛注：当巴巴在这次和随后旅行在外时，大阿迪受令早晚去鲁西·帕帕家，并在与高荷交谈后，每天给巴巴发送两次关于女子们状况的电报。阿迪的电报总是写着：“一切平安。”｝

巴巴不在的时候，女子们忙着帮邓完成他的书《行道者》。玛妮在一个单间里与邓单独见面，她念出邓列出的乌尔都语名字，以便他正确拼写。邓还画了一幅印度彩色地图来配这本书，但印刷出来之后，满是错误。玛妮、美婼和美茹负责修正。

“有几百张图，”美婼回忆道，“邓非常讲究，要我们修改得十分完美，甚至不让人看出修改过。给了我们刀片、橡皮和黑墨水。在一处，必须用B替换P；另一处用o替换e。我们每天上午都做这事，坐在光线更充足的门边，一天做一定的量。这是一项需要专注细心的工作，不过我喜欢做。”

在巴巴回来前，一些山羊溜进了花园，啃食植物。如此过了几天，女子们把几只羊拴了起来，决定不还给羊的主人，除非他答应看管它们。然而第二天，主人并没有来接他的羊，女子们不得不饲喂它们。到了第三天，她们已经厌倦了照顾动物，当主人终于来时，她们把山羊推回给他。

巴巴回来后，偶尔会坐在帕帕家客厅的沙发上，但是客厅装有带护栏的大窗，在夏天十分炎热。“那时会很不舒服，”美婼回忆说，“玻璃变得很热。我们一直关着窗户，但那个房间太热了。”

｛注：正是在帕帕家，巴巴注意到美婼因为之前打排球受伤，走路一瘸一拐的，于是温柔而慈爱地在她的膝盖上涂了碘酒。｝

巴巴在帕帕家的时候，让人把一个当地穆斯林男孩带到他的房间，好让那个男孩认识并敬爱他。

巴巴从瑞希克什带回一个惊喜：一只雌性幼獒犬，最初起名叫“果儿-果儿”（不倒翁）。巴巴亲自买来喂养她，并在回阿美纳伽的路上照看她。她在美拉扎德当看门狗养，卡卡在那里照看她（不过美婼认为卡卡没有很好地训练这只狗）。卡卡把她的名字缩短为“谷儿”或者“谷鲁”（花朵）；但后来，由于她的脚爪有像靴子一样的白色斑纹，女子们给她改名为“靴子”。

｛注：靴子后来成了巴巴最喜欢的狗儿马斯坦的母亲。｝

“靴子是一只漂亮的幼犬。”美婼说，“她有一身乌黑的漂亮皮毛。巴巴喜欢黑狗胜过白狗。靴子的皮毛太浓密了，拨开后甚至看不到皮肤。她的毛粗厚，像哈士奇，不柔滑。”

巴尼亚和她们一起去了帕帕家，但美婼不太喜欢这只狗：“巴尼亚不会和我们做朋友。总之，我不喜欢腊肠狗。诺芮娜喜欢它，那条狗也喜欢她，所以她照顾它。她会陪巴尼亚散步，然后把它拴在床脚。”

在这段时期，发布了一个通告，声明“巴巴从1948年5月21日至7月20日的两个月，将进行特殊灵性工作”，在此灵性关键时期，他不希望被通信或会面打扰，除非是他特别要求的。

巴巴定期和阿里·夏一起工作，并乘车往返于阿美纳伽、美拉巴德和美拉扎德。6月7日，巴巴再次乘火车去联系古吉拉特邦的玛司特；6月底去孟买进行另一次玛司特之旅。

那一年，巴巴还在穆斯林斋月的最后三天禁食，7月21日结束，巴巴之前说过，这也是他为期两个月特殊灵性工作的结束。
