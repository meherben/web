新生活

86 决定时期

东屋，上美拉巴德，1938年2月19日
美茹·达玛尼亚（梅塔，最左边）、希芮茵麦、巴巴、苏娜玛西、美婼、拉诺、蔻诗德、吉蒂、顾麦
玛妮收藏

与女满德里在盘奇伽尼度假后，美赫巴巴一行人回到美拉扎德。几天后，巴巴安排在美拉巴德召开会议，以“讨论和决定满德里的未来”。会议于1949年8月15日至20日进行。

前三天，巴巴上午在下美拉巴德会见男满德里几小时，然后在上美拉巴德与女子们度过剩下的时间。巴巴从美拉扎德乘车前往，（前三天）陪同的有美婼、玛妮、美茹、高荷、娜佳和瓦露。他在下美拉巴德下车，女子们被载到山上等他到来。

第一次会见男子们时，巴巴强调了三点：

第一，由于我的某种个人灾难，我会真真切切地绝对无助。这在10月1日之后发生，我希望在此之前，尽可能利用我们的有限资源，为满德里做好安排，因为此后，我将不得不停止——并会停止——照管任何人的物质事务。

其次，这几天中我将制定条件，只允许那些在各方面准备完全自愿执行条件的人留在我身边，对其他人将无法顾及。

第三，将解散美拉巴德和坪坡岗埃舍，从而把它们从我的地图上抹去！感谢神，我期待已久的时刻终于到来。全世界都将知道我是怎样地与何等地变得无助，我也将知道满德里会跟我走多远。

｛注：《美赫主》，第3382–3383页。｝

所有事情都必须公开坦诚地讨论，即使是私人问题，正如巴巴所说：“没有什么会被保密。”

那天下午在上美拉巴德，所有人都被召到美婼的房间。除了美拉扎德的女子，在场的还有吉蒂、拉诺、恺娣、蔻诗德、苏娜玛西、曼萨丽、卡库和玛奴·杰萨瓦拉（她来待几天）。凯克巴德的妻子捷拜和三个女儿美茹、佳露和谷露也在场，还有拜度的妻子苏彤与女儿朵拉和莎瓦。美茹（伊朗尼）回忆说，当时气氛很紧张，“这是一段非常严肃而紧张的日子。你能从巴巴的表情中感觉到它的重要性，这是一件至关重要的事情。

｛注：顾麦、珀茹嘉和美茹·达玛尼亚从库希如大院前来。｝

“我们进屋时巴巴对我们微笑，但我们感觉到他表情中的严肃。他让大家就坐。每人都带着小凳子，各自找个可以看见巴巴的地方坐下（他坐在美婼的床上）。美婼坐在他身边的凳子上。”

大家都进屋后，巴巴让人把门锁上。通常情况下不会这样做，这提醒女子们这个场合极其重要。

“巴巴用字母板告诉我们，由玛妮解读，说我们是多么难得的珍宝，这些年来是多么忠实地服从他，我们待在他的埃舍离他这么近，是多么幸运。巴巴说现在他也期望我们的服从，当他讲完时，每个人都要依次走到他面前，表明是否会服从他，去他决定我们该去的地方。”

｛注：摘自邓·斯蒂文思等编写的《美赫巴巴新生活的故事》（加州伯克利：贝吉尼图书馆，1976），第133页。｝

巴巴规定：“谁都不要向我提任何建议，谁都不要问我任何问题。我的决定是最终决定，任何人都不允许再待在这里（美拉巴德）。

“要心中牢记，除了神我谁都不是，而神总是做对他的孩子们最好的事。他想让他们开心，从不想让他们受苦。但是，出于他自己的原因，有些事情必须要做。

“现在你们必须在我的工作中帮助我。我要离开，再也不回来。你们这辈子都不会再见到我。我离开的时候，别让我看到你们哭泣的脸。”

巴巴说，无论他说什么，都要百分之百地服从，即使他把一些人送去孟买，或者让一些人结婚。“无论我对你们说什么，我对此都有准备。如果我要求你们嫁给扫厕所的人，你们都会服从吗？”

她们说她们会的。

“如果我让你们嫁给一个老头呢？”她们点头说会的。

巴巴询问其中一人，是否愿意嫁给某个人。玛奴默默祈祷：“别问我这个，巴巴；除了这个都行。”

他不断地发问，就连美婼也没能幸免。“如果我要求你走出这么多年的隐居生活呢？如果我让你给满德里洗衣服，你会做吗？”

“会的，巴巴。”她回答。

巴巴接着告诉她们，他很快就要带着几个满德里离开美拉巴德，去印度北部徒步旅行，但第一天他没说要带谁去。他也许把所有的女子都丢下，也许带走几人；他会决定。

｛注：有人说，巴巴在新生活旅行中的最初计划不包括任何女满德里；其他人则认为巴巴一直打算带上四位女子。据玛奴·杰萨瓦拉说，第一次会议后，回到美拉扎德时，美婼请求巴巴带她一起走，巴巴心软了。｝

在讨论不伴随巴巴者的生活费用和巴巴的财产处理时，他对男子们说：“任何财产都不能保留在我名下，除了美拉巴德山上为我建好的墓地——你们都应记住，我舍弃肉身后，必须葬在那里……

“我想完全摆脱一切人与事。现在不会向任何事情妥协。

“我要变得冷酷无情，一清二白，身无分文。

“记住这句老话：‘连神都怕穷光蛋。’”

萨若希、纳瑞曼和美赫吉——三位在现实与世俗事务上都富有经验的商人——提出要接管和维护埃舍的财产，便于巴巴未来的任何工作，他同意了。除了这三人，另有两人（拉姆玖和嘉尔·科罗瓦拉）被任命为“安置瓦拉”，监督对于迄今为止完全依赖巴巴者的安置。因此，美赫吉成为下美拉巴德的所有者，萨若希成为美拉巴德山的，纳瑞曼成为美拉扎德的。出售这些财产的收入将用于帮助那些没有留在巴巴身边的人，但对其他人不提供任何供应。“我和跟我走的人都要受苦。”巴巴告诉萨若希。

“我们将在没有任何保护的情况下出发，我们将不得不乞讨。”

在上美拉巴德与女子们第二次开会时，巴巴表示有四个女子要跟他一起去——但还是没说出她们的名字。

他给了女子们四种选择：

  1. 如果你们中的任何人有家庭成员为你提供经济上的支持，就可以留在美拉巴德山的住所；但山下的任何男满德里将不会以任何方式提供帮助。

  2. 你可以为生计而工作，把能节省下来的东西都留给那些一直依赖我的家庭。

  3. 你可以随心所欲，但跟我再无关系。

  4. 你可以把一切都交给我，完全按照我说的去做，完全信任我为你做的任何决定。

“如果你们服从我，我会很高兴。”巴巴总结道，并表示希望她们选择第四项。“谁会服从我的命令？举起手来。”

知道巴巴将要离开她们，唯独蔻诗德没有举手。巴巴惊讶地看着她，问道：“为什么？你不打算服从我？”

“不打算，巴巴。”蔻诗德回答，“我要做自己想做的。”

巴巴对她的回答不满意，但蔻诗德依然坚持。

因为她母亲苏娜玛西举手表示服从，巴巴说：“看看你母亲。瞧她多好，愿意服从我。你却不愿意吗？”

“不，我不愿意。”她重复道。

后来，蔻诗德解释说：“我知道有些事情已预先安排，我感到不对劲。美婼迅速举起手，因为她知道自己会跟巴巴一起走。我们之间没有讨论过，但我能想到这些。那我为什么要同意呢？娜佳当时抱病，无法徒步，所以我知道她不会一起去。”因此，蔻诗德希望她也能被选中。

巴巴让那些愿意服从他的人一个接一个上前，亲吻他的手，以确认服从的承诺。除了蔻诗德，每个人都走上前去，但巴巴也向她伸出手。蔻诗德不确定自己是否会被抛下，但她感到某种恐惧。她知道巴巴是以吻手来劝诱她们，因为在这段时期，禁止她们碰触或拥抱巴巴——但蔻诗德依然愿意放弃。她待在原地不动。

“还有谁不想听我的？”巴巴问，然后直视着蔻诗德，“你不想听吗？”

“不想，巴巴。”她重复道，“我要做我想做的。”

“你不爱我了？你不想服从我？”

“我很爱您，但如果您叫我走，我不会喜欢。我不想离开您。”

“真正爱至爱者，愿意服从他，并以至爱的快乐为快乐。”巴巴和蔼可亲地花时间阐述这个主题，试图说服她。说完，作为最后的诱因，他补充道：“分离只会持续几天，也许以后我会再次召唤你，我们会重聚。但首先，你必须同意服从我。”

这起了作用。蔻诗德为给巴巴添了这么多麻烦而感到羞愧。当他再次问：“你难道不爱我吗？”她回答：“是的，巴巴，我爱您——我也会服从您。”

“现在我很高兴。”巴巴表明，叫她到身边。蔻诗德站起来，走到巴巴身边，巴巴拥抱了她——在场的人中他只拥抱了她。蔻诗德轻泣着，但巴巴告诉她：“不，别哭。”

“要笑。”他命令道，她照办，“即使你觉得自己正被切成碎片，也要面带微笑。在爱之中，这就是勇敢的含义。”

这也将是新生活的重要主题之一，如美茹回忆的：“巴巴说，那些和他分享（新生活）的人将总是快乐的，无论在什么情况下都不会生气或闷闷不乐。我们必须毫不犹豫地暗自服从巴巴。我们应该非常小心，永远不要扰乱巴巴的心情。那些没有准备这样做的人，就不要和巴巴一起进入新生活。”

第二天上午，8月17日星期三，巴巴为男满德里提供了三种选择：

  1. 那些发现自己有能力满足我制定的条件并接受的人，将跟我走。

  2. 那些不能伴随我的人，必须自谋生计，如有节余，应该分给那些依赖我的家庭，并继续执行我给的命令，或我今后可能给的命令。

  3. 既不能跟我走，又不能支持他人，且不能执行我的命令者，只好自行其事。

｛注：《新生活的故事》，第138-139页。｝

巴巴没有给男子他给女子的第四种选择——让他本人决定。但他说明，无论如何，“每个人——无论男女，都必须在神前、在我面前，对他或她各自的决定全权负责，无论是直接做的还是通过我做的。”

他还告诉男子们，当他建议拜度和凯克巴德家的女子可以先跟他们商量时，女子们都说她们不属于男子，而属于巴巴，会按巴巴说的做。

巴巴补充道：“在仔细考虑了这四点之后，在场的每个女子都承诺遵守第四点——照我说的做。我让她们吻我的手，以表示她们的诚意和承诺。之后我告诉她们，当心不要让这个吻成为犹大之吻，而要让它成为服从之印。”

那天下午在美拉巴德山上，巴巴终于向女子们宣布了他的四个同伴：美婼（42岁）、玛妮（31岁）、美茹（22岁）和高荷（34岁）。蔻诗德仍然希望能跟巴巴一起走。“当我听到我不会去的时候，”她回忆说，“我很震惊。”

美婼相信自己一定会去，毕竟巴巴已经和她们单独住在美拉扎德了，她这样推想。玛妮也觉得自己会被带上，但美茹和高荷没有这种信心。

美茹回忆她是怎么知道自己要去的：“每个人都上前回答会服从巴巴。我看着他的眼睛，答应了。无论巴巴说什么，我都同意，根本没想过会发生什么。巴巴没有私下告诉我我要去。我第一次听到这个消息是巴巴在会议上宣布的，当时我们都在一起。我很高兴，但自然我们当时都反应严肃。我感到有责任按照巴巴的要求过好新生活。”

“几乎可以肯定，美婼一定事先就知道巴巴会带哪些女子去。”高荷后来猜测，“但当巴巴说他要带四个女子一起过新生活时，我做梦也没想到自己会去，因为相对来说我是新人。”

高荷对那些做决定的日子，讲述了她的记忆：

在美拉扎德，人们对新生活只字不提。这一消息是在美拉巴德宣布的，我们只是被带到了那里。我们知道要开会，巴巴会有新决定，他事先只透露了这么多。巴巴带我们乘车去美拉巴德，之后大家聚集在美婼的房间里。巴巴非常严肃，每个人都吓住了。

巴巴说要带上四个女子。我确信自己不会被带上，我知道美婼和玛妮一定会跟他走。通常，不管巴巴做什么，都会告诉美婼，我们一般过后才听到他的计划。例如如果他要闭关，他会告诉她，从而让她有所准备，不会突然宣布而让她大吃一惊，不会把她吓到。巴巴会让美婼准备好。

在会议上，没有提到哪四个女子要跟巴巴一起去。我回到美拉扎德时，觉得自己原本是来永久居住的，现在却要被抛在后面。巴巴当然只会带走那些和他一起生活了一辈子的人——比如蔻诗德和娜佳——或者美茹。我在那里只待了两年。他不可能带我去。

我那时感到灰心丧气——非常害怕。每天傍晚，我们从美拉巴德回来时，我都感到很难过。我确信巴巴不会把我包括在内。

对于如何安置大家，巴巴提出了意见，比如恺娣、苏彤、朵拉、卡库拜、曼萨丽——所有这些讨论都在进行。傍晚，为了放松，巴巴让我们在楼上（美拉巴德）的宿舍里玩猜字谜游戏，巴巴也参加了。然后我们回到美拉扎德，第二天一早再次出发。

｛注：在一次猜字谜游戏中，巴巴选择美婼和恺娣作为他的搭档，来表演《随风而逝》（即《飘》）。恺娣过后心想，选的电影名字真有讽刺意味，因为很快一切都将名副其实地“随风而逝”！｝

一天傍晚，从美拉巴德回来后，我站在墙后面，慢慢地给花坛浇水。我感到沮丧消沉，想着巴巴离开后我该怎么办。我想到结束自己的生命，说真的我想过自杀。

“活着有什么用？”我想，“我不想再回到世上。”

我原本背对着主屋门廊，就在这时，我听到一声击掌。我转过身，只见巴巴站在门廊上，美婼就在他身边。

巴巴叫我过去。“你在想什么？告诉我。”

我说：“巴巴，我知道自己不会和你一起踏上新生活。我感到非常沮丧。”

“还有呢，还有什么？”

“您走后我就不想活了。我不能没有您，也不想回到世间。活着有什么用？”

巴巴笑着对美婼说：“告诉她她疯了！告诉她，她要和我一起过新生活。她将是新生活中的第四位女子。”

当时我高兴极了，简直不知如何是好。“巴巴，我太感激您了。”

巴巴说：“别担心。你将和我在一起。”我把这理解为永远，而不仅仅是那时。

我心想：“巴巴是多么伟大、多么仁慈啊。”

巴巴说我会去的时候，我简直难以置信，这是我一生中最快乐的时刻。我从没想过会被带入新生活，也没想过能永久和巴巴在一起，因为他说过：“别抱希望，别想再见到我。”

第二天，当我们去美拉巴德时，巴巴宣布了哪四个人要去。

曼萨丽知道她不会跟巴巴一起去，因为这些年来他一直把她留在美拉巴德。但实际上，他永远不会回到美拉巴德的声明对她来说是一个伤害性打击：“我感到前途一片漆黑。巴巴是那么认真、那么严肃。新生活对我来说是一个巨大的冲击，就像巴巴说的，他再也不会回来了。此前，他定期访问美拉巴德。现在，没有人能留在美拉巴德，就连帕椎也不得不在纳伽租了一个房间。

｛注：在新生活期间，帕椎带着简餐来美拉巴德度过白天，但他不在这里过夜。阿里·夏和穆罕默德玛司特被交给希度照顾，满德里中只有他留在下美拉巴德。鹦鹉米图被送给娜格丝·考特沃，她住在阿冉岗附近的家属宿舍。后来，这只鸟要么走丢了，要么被猫杀死了。｝

“所有人都哭了，除了将伴随他的四个人。在他的要求下，我们都听从了他的命令。他说他会安排我们的去处。”

在决定哪些女子同去之后，巴巴把这周剩余的时间花在下美拉巴德的男子们身上。他警告他们，要想跟随巴巴，就不得不放弃具有灵性倾向和信仰的所有观念，不期望丝毫回报，不管是灵性的还是其他。而且，巴巴会像兄弟一样生活在他们中间，但他们必须继续把他当作大师，暗自服从。他们也不能邀请或鼓励任何人向自己或巴巴表示敬意或礼敬。对任何此类行为都必须立刻同样回礼。

巴巴总结说：“想跟我走的人应该当作自己已死。正如一具尸体无关于任何物质，不问任何问题，也不求任何东西——那些伴随我的人也必须像尸体一样和我在一起。

“我要看看谁想和我一起去，谁无缘无故地想死！”

｛注：埃瑞奇讲道：“当我们第一次得知女子们要和我们一起进入新生活时，我纳闷这怎么可能，因为有限制。我们不能见她们，也不能和她们交谈。我们甚至不能大声说话，因为女子们不能听到我们的声音。这样我们怎么可能和她们走在路上？该如何玩这种捉迷藏游戏？巴巴说：‘别担心。从10月16日起，一切都将结束，我们将开始新的生活。不会再有那样的事情，她们会像你们一样成为同伴。女子们将帮助男子们，男子们将帮助女子们。’”｝
