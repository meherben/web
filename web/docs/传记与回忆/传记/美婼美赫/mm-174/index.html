海得拉巴欢庆山房屋六个月的租约到期了，所以美赫巴巴决定搬回马哈拉施特拉邦，这次是搬到帕萨尼的纳瓦伯（王子）的房屋，距离瓦伊两英里，在去盘奇伽尼的路上。1945年9月6日，巴巴一行人出发，第二天到达普纳，巴巴和女子们住在宾德拉屋。9月8日，他们前往瓦伊。当汽车驶过一条长长的隧道时，女子们把头伸出车窗外，呼喊巴巴的名，来听回音。

起初，住在帕萨尼的女子有：美婼、玛妮、美茹、娜佳、吉蒂、拉诺、玛格丽特和瓦露，还有两个女仆拉克玛和拉克希。几周后，来自美拉巴德的其他女子也加入了她们。一些满德里也在帕萨尼，住在院外的房间，院落被10英尺高的堡垒般的墙包围着。

房子本身相当大，但即使属于一个纳瓦伯，它也不算太华丽。因为围墙很高，女子们看不见外面。巨大而荫凉的芒果树环绕着房子。她们在树上系了一个秋千，尽管巴巴太忙，没时间荡秋千，但美婼和玛妮荡过。

她们刚到的时候，美婼选择了一间窗户风景如画的房间。在大橱柜上方，挂着一幅装裱华丽的王公画像，雄霸着整个房间。这幅画让她觉得不舒服，她不想一早起来就看到一个男人的脸。所以她问巴巴能否把它搬走，所有女子（包括两个仆人）帮忙把它搬到了图书室，那里离她们的房间有一段距离。（她们开玩笑说王公“真重”。）满德里把这幅画挂在图书室里，它像是原本就在那里。

在接下来的三个月里，巴巴往返于瓦伊和美拉巴德之间，还去了赖布尔、加尔各答、卡图克、那格浦尔和博帕尔，他联系玛司特、召开会议、救济穷人，并在一个山顶进行高强度闭关工作。

美婼回忆说，纳瓦伯的房子很安静，有“一种可爱的氛围。我们共用大房间。所有的美拉巴德女子都在那里，因此有很多饭要做，很多菜要洗。巴巴说我们可以使用房子的图书室。我们的房间前面有一个漂亮的阳台，下午我们在那里编织、缝纫或读书。大部分时间，巴巴都在外做玛司特工作。”

有几次，美婼和玛格丽特在图书室或花园里读诗。对于一些美婼认为特别美的诗句，玛格丽特鼓励她记住。美婼试着背了几篇，但从没背诵给巴巴听。“虽然我给巴巴唱过一两首歌，”她说，“但我不记得给他背过诗。”

瓦伊附近的森林地带凉爽宜人。“允许我们每天出去散步，但不是单独外出——可以三人一组，但通常是四人。巴巴指示，我们一起不能少于三人。（一组经常和另一组相遇。）一个原因可能是该地区有老虎，这里就像一个山谷。巴巴不在的时候，我们也会在早晚散步。”

对于美茹、谷露和佳露·达斯托来说，美婼等人散步时走得太快太远了。达斯托家的胖姐妹们跟不上，所以通常她们会留下来。在散步中，有人偶尔收集牛粪来给花园施肥。有一次，吉蒂弯腰去捡拾，但其他人叫道：“停下，吉蒂！那不是水牛的，是人的！”

琵拉麦是女子院门的守门人，她与玛西轮流值班，有时与卡库。吃完早餐、洗完澡后，琵拉麦要在早上7点开始值班。热水会为她洗澡准备好，但有一次，芭奴拜（她是智障）溜进来，先洗了个澡。琵拉麦被激怒了。

巴巴走过来的时候，琵拉麦正在对芭奴拜怒斥，但他什么也没说就走了过去。紧接着，琵拉麦拥抱了芭奴拜。巴巴走回来说：“我不敢相信自己的眼睛。我前一秒路过的时候，你简直要揍她了！”

接着他又说：“我爱你的宽恕品质。”他召来所有人，说道：“生气可以——但要像琵拉那样。一时生气，下一刻却完全忘记。”

“琵拉玛西非常直率。”曼萨丽解释道，“她有一种品质——这一刻暴怒，下一刻就懊悔、拥抱、请求原谅。巴巴非常爱她。玛格丽特也有类似的品质，她说话总是直接了当。在埃舍，我最喜欢琵拉和玛格丽特。”

美婼说：“琵拉麦很健谈，但人很好。她的丈夫十分安静平和，无论琵拉说什么，他都会同意。她没有钱，但她有一颗强大的心，而且总是很慷慨。”

9月18日，巴巴前往美拉巴德，除了其他事情，他还审查了坪坡岗正在进行的建设工作。卡里玛玛（满德里成员）正在扩建宅地上的小农舍，并为女子们建造了几个储物间，她们需要更多的空间。

巴巴返回帕萨尼，但很快又离开，在赖布尔附近的安吉拉斯睿希山山顶进行高强度闭关。

12月15日星期六，巴巴和男女满德里回到美拉巴德。十天后，隆重庆祝了美婼的38岁生日，有许多外地客人来参加为期三天的庆祝活动。

｛注：碰巧，美婼喜欢的一部“完美”电影正在萨若希影院上映：《玉女神驹》，讲述的是一个小女孩和她的马的故事。12月28日早上6点，巴巴带所有女子乘坐两辆巴士去观看。｝

当女子们留在山上时（美拉扎德的建设工作还未完成），巴巴在1946年1月进入闭关，住在后来凯库希如在下美拉巴德的小屋。他有一个月没见女子们。他原打算在那间小屋多待些日子，但被敦德路上来往频繁的车辆打扰，他决定搬到安静得多的坪坡岗。

2月2日，巴巴单独召见吉蒂和拉诺，告诉她们：“我很快就要派艾琳和玛格丽特去欧洲为我工作，会把你俩留在这里。”

第二天，巴巴带美婼、玛妮、美茹、娜佳、玛格丽特和瓦露前往美拉扎德，巴巴在后来彭度住的房间进入半闭关。巴巴与玛司特们工作，与女子们去闭关山散步，或者沿道路走到水库，偶尔还和她们一起去萨若希影院看电影。

｛注：那些在美拉巴德的女子也乘巴士去影院。｝

玛格丽特不知道她很快就要去西方了，但她记得有一次外出，巴巴对她有点粗暴：“有一次巴巴特意伤害我。我们要去阿美纳伽。我被降到最低级别，没有和姑娘们一起坐巴巴的车，而是与梅特拉尼（厕所清洁工）一起前往。

“‘玛格丽特和梅特拉尼在哪儿？’巴巴问。

“我穿上了自己最好的衣服。我不想回应，在生闷气。

“‘咦，你跟我出去的时候，难道不穿件漂亮的衣服吗？’就在我们上车前，巴巴问。

“我不想回答。他知道我没啥衣服可穿。

“他看着我。我真的很吃惊。

“然后玛妮悄悄告诉他，我没有什么衣服。

“‘好吧，玛妮会给你做一件。’

“我没有说谢谢，我太生气了。但她确实给我做了一件。”

钢琴从美拉巴德送来，放在美拉扎德的小农舍里，安置在客厅一角的地毯上（巴巴最初使用的房间隔壁）。巴巴说吉蒂可以每周（有时一周两次）来给美婼上钢琴课。派专车去美拉巴德接吉蒂。美婼学过的一首歌曲是《只用您的眼睛，赐我以美酒》。但几个月后，当她们离开美拉扎德时，课程也随即结束。

｛注：在1947年，当时诺芮娜和伊丽莎白住在美拉扎德，需要更多房间，这架钢琴被送回了美拉巴德。美婼同意，因为她对学钢琴不感兴趣。“吉蒂教我的太复杂了，”她说，“我还有其他工作要做。”在开始新生活前，巴巴把钢琴给了萨若希的妻子纬露。｝

从2月9日起，巴巴每天晚上都离开美拉扎德，去半英里外的一间小农舍睡觉，那间农舍简单称为戈亚拉农舍，因为它属于戈亚拉先生的房产。

｛注：戈亚拉农舍后来被改造成了一间库房。｝

按照琐罗亚斯德教的日历，2月15日是巴巴的生日，他带女子们去了幸福谷。这是巴巴第一次也是唯一一次从美拉扎德全程走到幸福谷。他们一早出发，此时天气凉爽，大家一路和巴巴聊着天。美婼回忆说，巴巴穿着长袍和宽松裤。午餐时，他们享用了一顿特别的非素食餐——羊肉炒饭，由大阿迪从阿美纳伽带来。之后他们乘车返回，因为现在走路回去太热了，尤其是在饱餐一顿之后。

3月底，巴巴宣布玛格丽特在5月回英国，他希望她从那里去美国。玛格丽特很惊讶，因为当时所有军队都还在复员遣散，要从英国赶到美国很难。

巴巴笑了，说：“你必须去，我已经让你成为我在美国的纽带。”

玛格丽特确实去了美国，在美国芭蕾舞剧院找到了一份巡回演出工作，这使她走遍全美。

艾琳几乎立刻就被送回了瑞士。艾琳从未说过她想念瑞士，也没说过她想回去，而玛格丽特却有一次提到想念“英国的气候，季节的变化，秋天的色彩，以及冬天。”

临走前，艾琳问巴巴对她有没有什么命令。“你需要命令做什么？”他回答说，“你和我在一起待了八年。如果你到现在还不知道该做些什么来取悦我，那一切都是徒劳。你可以结婚，可以吃肉，可以喝酒。但是记住，你已经和我在一起八年。”

艾琳说：“这反而比他给出一些规则要困难得多。”

3月26日左右，艾琳和邓一起被派往孟买，安排她回家的船票。通常在印度乘火车旅行时，艾琳生病了，就和某人一起乘坐头等车厢，而埃舍其他人乘坐二等或三等。邓是军队的少校，所以他总是坐头等军用车厢。在这次旅行中，他填表时写成“邓肯少校和他的妻子”，这样艾琳就可以和他一起旅行。但是邓警告艾琳当他们回来后，不要在埃舍提及这件事。她的船票买好后，他们去看了一场电影。

回到美拉巴德，巴巴问他们在孟买都干了些什么。他不停地探问更多的细节，直到艾琳最终承认他们去看了一场电影。

巴巴训斥她：“你一旦放松，就钻空子！你不该未经我允许就去看电影，你知道这里其他人不能去。你不该让自己得到别人没有的自由。”

后来，艾琳写道：“在埃舍中如此严格之后，有一点自由会让人高兴，可以四处走走，做自己喜欢的事。这是自然的。但过后，我们感觉很糟糕。”

三个星期后，艾琳出发时，巴巴告诉她不要联系他在孟买的任何弟子，而是独自住旅馆，直到她的船出发。

4月14日，娜丁·托尔斯泰在纽约去世，享年62岁，死于卢格里格氏症。巴巴发电报给诺芮娜：“告诉伊丽莎白，娜迪亚活在我内里，同我在一起，为我而活，胜过以往任何时候。”

两天后，巴巴离开美拉扎德，与美婼、玛妮、美茹去了一处“秘密地点”，在那里他可以闭关。后来得知，那是位于尼兰简普尔的一个房子，在德拉敦郊外，是帕帕·杰萨瓦拉为他租下的。

当吉蒂、拉诺和玛格丽特受令与邓一起提早出发时，她们甚至不知道自己要去哪里。他们要在德里等候巴巴，然后和他一起去“闭关地”。在火车上，邓把女子们说成是他的亲戚，这样她们就可以像艾琳那样和他乘坐军用车厢。女子们都戴着遮阳帽，但在旅途中进入一个军用招待所前，邓对她们说：“看在上帝的份上，在我们进去之前，把这些遮阳帽摘掉。你们看起来像一群传教士！”

在德里，他们在一家英国俱乐部短暂休息后，在火车站与巴巴碰面，然后和他一起去了德拉敦。娜佳、恺娣、蔻诗德、苏娜玛西几人与巴巴一行在曼玛德会合，一起坐火车旅行。曼萨丽、凯库巴德的家人和拜度的家人被留在美拉巴德山，还有患有严重疟疾的瓦露。
