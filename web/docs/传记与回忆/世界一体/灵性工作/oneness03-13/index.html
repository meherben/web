头脑之所以会告诉你这些都不适用的两个原因

虽然我们不会忽视美赫巴巴关于服务的话语，然而一旦涉及从内在一体的高度去服务的理念时，我们也许会说，“是的！内在一体是真理。可既然我尚未体验之，怎可能自身坚持该真理或与他人分享呢？若试图这么做，我就成了伪君子。”而这样说时，我们不知不觉中已忽略美赫巴巴的一则主要讯息——关于怎样服务，以及为此该怎样生活。

所以可以归结于这点。你认为阿瓦塔美赫巴巴的典型追随者，有可能在日常生活中坚持内在一体真理吗？还是认为一体性是一种不切实际、乌托邦式的理想，将之付诸行动纯属徒劳？这样想并不奇怪，我们中许多人，包括过去的我，都会觉得从内在一体的立场去服务是不可能的。整个尝试听上去自以为是。即使我们有一丝可能性做到这点，在当今世界也徒劳无用，因而不切实际。

但值得注意的是，美赫巴巴对我们揭示：推进众生一体的真理不仅是可能的，而且是务实的。他在语录“新的世界秩序来临前的阵痛”一文中向我们保证，坚持这一真理是完全现实可行的。他说：

洞悉到一体性的灵性价值，乃是推进真正的统一与合作。同胞之情将成为真正洞悉力的自然结果。建立在灵性认识基础上的新生活是对真理的肯定。它不是属于乌托邦的空想，而是切实可行的。

因此，通过灵性认识，我们实现新生活，其中内在一体性被洞悉，在生活中自然得到促进。如果我们仍不确定洞悉力和灵性认识的重要性，美赫巴巴的陈述应该会消除所有的怀疑。而且，它肯定会引起我们的注意，即巴巴怎样在进入新生活阶段前几年，就使用“新生活”一词以揭示其永恒意义。

不过让我们继续来探讨也许是另一个挥之不去的念头，那就是，“即使灵性服务于我而言是可能的，但我为家庭和事业上的责任奔波忙碌，无暇再做任何服务。”

因为美赫巴巴强调了服务，我们很可能以为，那意味着我们必须参与日常生活之外的某种服务活动。但美赫巴巴工作的很大一部分是为人类带来灵性生活，那自然包括了平常人类经验的所有方面，由此个人生活的通常概念扩展为一体生活。这就是为什么，坚持和传递内在一体真理，不一定要求我们参与某项服务活动。我们的目标可以是，尽量在自身的一切活动中坚持该真理。

因此，无论我们在做什么，只要我们内心肯定一体性，该活动便升华为灵性工作。一度被自我视为平常无奇的东西，现在则成为对灵性真理的表达，并摆脱了自我的批判分别性质。无论我们置身何处，在做什么，心灵开始能够传递一体感。

我的最后说明

这是多么精彩的游戏！我必须履行义务和责任，同时又要维护一体性。很多次我不得不放弃工作上的成功（这在信托办公室是必要的），以维护一体性——对我的灵而言很重要。一次又一次，我得不断地提醒自己：我找到了心灵，并将通过坚持真理，而非通过完成我认为该完成的工作，被引向独一大灵之真理！

为了至关重要的东西而放弃看似必要之物并不容易。这基本意味着，为了对我的一切与永恒真理为一的“信心”，而违背我所“知道”的一切。尽管这可能是痛苦的，但我若一心想要真理，就会得到慰藉。因为我为坚持真理而采取的行动本身就是一种慰藉。

让我们的头脑莫存怀疑，因为美赫巴巴已权威地声明：最重要的工作、最重要的自由、最重要的礼物与最重要的服务，都是同一个：让自己和他人深刻认识众生一体的真理。

他的结语

美赫巴巴在他的语录“灵性工作者的任务”一文中的最后结语，是这句强有力的话：

通过灵性工作者的不倦努力，人类将被引入持久和平与能动和谐、不移信心与不衰喜悦、无尽甜蜜与不朽纯洁、常新之爱与无限认识的新生活。

译自《世界一体（第三册）服务：为人类的灵性自由而工作》

翻译：蘭宇姝寧

校对：石灰
