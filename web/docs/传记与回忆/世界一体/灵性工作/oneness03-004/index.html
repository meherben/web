如前言中所述，生活即是服务，因为所有的行动都服务于某个目的。所以根本而言，我们的行动最终要么服务于分别自我，要么服务于灵魂真我。自古以来，最重要的灵性律则始终是爱上帝，并且爱邻如己。问题是，当我们试图以爱心服务他人时，有时会发现自己无法突破彼此强加的壁垒。我们会因为无法像对亲近或亲爱的人那样为他人着想而受挫沮丧，尤其是当我们为之服务者似乎并不领情或心怀敌对，甚而不值得我们服务时。若非出于对他们的爱之情感，我们的服务可能以责任感开始，以绝望或痛苦而告终。

美赫巴巴以他的权威性陈述向我们保证，他乃是每一颗心灵的内居者，该痛苦困境有其出路。因此，我们可以服务在他人之内的他而非他人。即便如此，我们还是经常犹豫不决。虽然我们相信阿瓦塔美赫巴巴在每个人之内，但仍然习惯性地只看到眼前的那个人。这是因为我们的信仰尚未成为一种活的信心，该信心使我们能够像已然体验到真理，即通过为他人服务，我们实际上在服务他一样行动。

因此，坚持美赫巴巴住在每个人心中的信念是至关重要的。否则我们的灵性生活将会受挫，因为我们没有满足爱邻如己的基本灵性需要，其本身维护着我们本是一体的真相。我们爱他人之内的他，不仅将我们的服务带入人心，助益传递灵性认识，而且引导我们体验巴巴话语中的真理，即他乃是一切存在中的存在。

多年以来，人们络绎不绝前来信托办公室问候埃瑞奇。出于对他的体贴，尤其随着他逐渐年长，很多人会说：“不要只是为了拥抱我而站起来。”而埃瑞奇，他一边从椅子上站起来，一边回应说：“我不是在拥抱你，我是在拥抱你里面的他。”

听埃瑞奇这么说，有时我会暗自发笑。我看轻了他的话，想着他只是那个可爱的老样子。直到后来我才明白，通过这样一个简单的行动，他在抱持真理——那就是，美赫巴巴是每个人内里的居住者。

为了将美赫巴巴视作每颗心灵的内居者来为他服务，我觉得我们必须做两件事：（1）忠诚地接受这一点，即使我们还没体验到它。（2）只要我们对如何继续服务变得不确定，就不断提醒自己这一真相。如果不接受这一真相作为我们的服务所凭靠的基本原则，就定会感到矛盾重重。我们将总是与己与人冲突不和——恼怒于我们可能在服务他人的分别妄我，沮丧于看不见我们本应为之服务的那一位。

美赫巴巴向我们保证，我们能够服务别人之内的他，他说：“服务大师，即是服务每个人内里的你自己。”他的话语有助于我们回答这个问题：“我们服务谁——美赫巴巴、他人或自身？”而正如我们所能理解的，他把他们都包括在内，因为真理之内没有区别；一切都是一，因为永恒的灵魂之中没有差别。

我们若能确定想要与之合一者是谁，将帮助我们理解能从何处开始传递灵性认识。首先，当我们专注于灵性一体性，这本身就是一种灵性认识，它极大地助力我们将无私服务的六个特征付诸行动。因此，一旦我们忽视造成彼此分别的回报、结果、名望欲求，就消除了分别幻相，使我们的服务真正地无私。由于确信我们其实是在服务他人之内的美赫巴巴，我们对他人的回应自然会更有爱心。这样我们就可以开始通过行动去呈现一体感，即便对众生一体性不置一辞，而这些行动本身就传达了对真理的灵性认识。

此外，一旦服务专注于灵性一体性，我们便能在满足他人的物质、智力、情感和文化需求之服务中作出选择。但它将通过灵性认识的途径来实现。此外，尤为关键的是，我们将关注到人们灵魂的灵性需求。我们将有机会帮助他人达成他们自己对灵性一体性的认识，削减其分别幻相。这种最高服务，正如美赫巴巴所说，“为所有人类问题提供正确的视角，并促成解决方案”。

如果我们服务的重点不是灵性认识，则沦为对人们世俗需求的服务，这些需求不仅是短暂无常的，而且最终没有意义。我们或许在无私地服务，试图减少分别自我的意图，但若非以“为所有人类问题提供正确的视角，并促成解决方案”的方式来服务，即美赫巴巴所说的最高服务，那么我们的服务就是有所缺失的。

既然我们有了一个行动的起点，那如何将对众生一体的灵性认识付诸行动，又该如何传递呢？
