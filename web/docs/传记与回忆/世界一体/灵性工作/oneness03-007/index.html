怎样通过直觉服务
听从内在美赫巴巴的指引

在（语录）“撒达那的深层方面”一文中，美赫巴巴指出，“羯磨瑜伽撒达那的实现[或无私服务的践行]，要求行动发自对真理的感知。”但如若我们并未觉得自己感知到了真理，会如何？巴巴通过阐明“羯磨瑜伽，亦即行动之道，是毫无恐惧或犹豫地、按照心灵最佳直觉行动”，来帮助我们走出困境。长久以来，我完全不知巴巴所言“心灵最佳直觉”为何意。而经过努力服务于他多年之后，对他可能的意味，或至少是它对我的意义，我终于有了一些感知。

我认识到谁都能获得直觉，而不仅仅是具有灵性倾向者。这只是心智活动的一部分。直觉有各种样貌。赌徒时而说他们有直觉。有所谓“女性直觉”的说法，表明对女性确有此天赋的一种普遍认同。直觉可以很简单，就像在响铃时凭直觉知道是谁打来电话一样。

但是当美赫巴巴使用“心灵最佳直觉”这一表述时，我感到他是指那些将我们引向真理的直觉。我这样说，并不仅仅指那些与坚持内在一体性的真理有关的直觉。当他甚至在日常环境中指引我们之时，这也意味着很平常的直觉。如果我们警觉到内在的静默之音，毫不犹豫地跟随它而无所畏惧，那么我们便是在巴巴的引导之下。并且对我来说，那些帮助我们跟随他的直觉是最好的。

关于平常直觉，我拿我生活中一个明显的例子加以说明。1978年，我初到信托办公室，和埃瑞奇一起工作。我清楚地记得，当走进信托办公室的一间档案室时，一种感觉来了——现在我能认出它是直觉。它指示我做一个明显的小的动作，而我没有做。我不记得是什么了。当天晚些时候，我把这件事告诉了埃瑞奇，说那种念头涌现时，我没有听从，只是忽略掉了。他一反常态地训斥我道：“那是巴巴！”你可以想象我的惊讶甚或惶恐，我竟然忽略了巴巴。移居印度那年我才28岁，还带有某种宏大的灵性观念，但听闻这也是巴巴的时候，着实令我震惊。而我从未留意过这些想法。尽管如此，遗憾的是，直至今日，我仍然迟钝于捕捉直觉的微妙活动，以及毫不犹豫地做出反应。但我正在为之努力。

在语录“随时准备服务”一篇中，美赫巴巴开篇即作出一系列的陈述，以便我们可以考虑以此为准则来服务他。我感觉到，如果依这些准则而行，不仅会使我们的服务更加无私，也会使我们准备好，能够接收直觉之音。

这些准则是：

  1. “时刻准备好，为人类事业服务。”

  2. “根据[你]个人的禀赋能力，选择[你]力所能及的工作。”

  3. “对[你]能够提供的服务，必须坚持不懈，即使外部条件极为艰难。”

  4. “随时服务的决心不可动摇。”

  5. “服务应在需要时自发产生。必须以合作的精神提供服务，不应坚持有限‘我’。”

打出这张列表时，我惊讶地发现，它们描述了我在信托办公室工作的头15年里的尝试。不知不觉中，我一直努力践行着这些有关服务的坦率态度。这最终引导我深化自身理解，并为更大的接受度做好准备。

阅读美赫巴巴在同一篇语录“随时准备服务”中给出的另一组陈述，更是帮助了我加深这种接受度。这些话出自题为“由爱激发的服务保证和谐”的段落，给了我们可以采取的具体行动——这将使我们的心灵对他的驱策之直觉，愈加活跃灵敏。

这段话以这样的观点开始：“即使在提供无私服务时，求道者也要保持思想警惕。”于我而言，在试图爱与服务美赫巴巴的过程中，我们似乎不理解，甚至没有考虑到警惕思想的必要性：我们或许觉得，巴巴只是要我们爱他，念记他；或者满德里没有强调这样的见解；或者警惕思想，听起来像是“静心的”或“机械化的”。不管什么原因，巴巴坚持其必要性，即使我们的服务是无私的。我还感觉到，要想听到心灵的最佳直觉，对思想警惕势在必行。因为我们若被头脑征服，又怎么能听到直觉，从而受他指引？

然而什么是对思想警惕，我们又该怎么做呢？无一例外地，它也是一门可以习得的艺术。在我们能够警惕思想之前可以采取的第一步，是美赫巴巴在《语录》里对不同种类静心系列加以论述的第六章中所提到的，他称之为“见证”。他说，这需要持之以恒的练习。你们中的有些人或许还记得，1970年代，埃瑞奇经常在满德里大厅演说，作为心的见证者的重要性。我从未明白过他的意思。只有在进入自我觉察的过程之后，我才发现我的心开始自然地见证自身活动。

我发现，当我观察自己的心念时，各种各样的想法纷至沓来。于是我只是开始观察它们，而不评判自己。如果我评判内里的孰好孰坏，很可能会无意识地压抑自己不愿承认的一面。我发现，诚实地接受自己内心的一切是至关重要的。而只要我没有把这些想法付诸行动，就不会受到伤害。此外，通过不断的自我控制，负面念头的力量终究会减弱，而至最终消失。

通常，我们如此认同思想及其无休止的活动，以至于我们“认为”我们就是思想。但是美赫巴巴指出，我们并非我们的头脑。我们或许会有许多的想法，好的和坏的。然而事实是，我们并非那些坏的或好的念头。他说，我们应将自己认同于他，而非我们的思想。

对心的见证，使得我们开始不与之认同。可以这么说，我们从其复杂纠葛中退后一步而观看它的“表演”。一旦习惯于被动地见证心的方式，我们就可以进入下一步，即积极地保持思想警惕。

语录“自我的性质与终结”一篇中，美赫巴巴说，“自我的所有问题，只有通过明智和有意识的行动才能解决，因此自我的彻底消灭，只有在自我的所有成分都经过明智意识之火焰时才有可能。”于我而言，这种“明智和有意识的行动”即是保持思想警惕。在我看来，通过越来越清晰地感知，心理活动可以怎样任意操纵我们付诸行动，一直见证心理活动的那部分心智似乎变成了“明智意识”。

因此，设想我们有愤怒、贪婪或不耐烦的念头。见证的心智观察到这一点，而后有智慧认识到，一旦这些想法被付诸行动，就会给我们造成伤害。因此，它通过照亮这些粗糙的自我表达来警惕思想。经由明智意识，我们可以照看心，警惕它，并解决自我带来的问题。如此一来，它便不会损害我们的无私服务，后者的重点是传递灵性认识。通过这样做，我们愈发准备好聆听直觉之音和跟随美赫巴巴。我感觉到，我们若将巴巴的话铭记于心，并真诚地付诸行动，就会受到指引，像宝说的那样，“清除心中不必要的噪声，让我们听到他的提示之音。”

这段宝贵话语接下来的一句话，美赫巴巴告诉我们：“求道者必须谦卑、诚实和真挚。”我们对听闻这样的话太习以为常了，以至于不去分析它们真正的涵义。起初，我以为这些话和做一个“好”人有关。后来随着对思想的观察，我发现巴巴所说的那种诚实、谦卑和真挚与“好”毫无关系。这对我来说是一种震惊，而当观察到自我是如何不断企图维持与他人的分别时，这种震惊仍在继续。

而现在，在多年观察思想、目睹自我无休止的坚持之后，我用这种方式来衡量谦卑、诚实和真挚：承认我们其实并非作为孤立的自我而存在，就是谦卑；说我们所做的一切都是谎言，就是诚实；敢于锲而不舍地尝试付诸行动并依然如常生活，就是真挚。这听起来或许不可能，且与只是做一个真挚诚实之人相去甚远。但正如我所说，在多年见证自我及其无休止的坚持之后，我认为，只有这种不同寻常的理解才能帮助我们根除自我。

这让我想起了美赫巴巴所做的一个鲜为人知的祈祷文。我之所以知道它，是因为埃瑞奇给一个满德里写了此文，经我的手传递。这个祷文是：“我不是身体。我不是心。我不是这。我不是那。我只是那我所是之实相的活谎言，而除非该谎言死去，否则实相就不会揭晓。”

所以心是一个活谎言，不可真正信任。这就是为什么我说，我们需要灌输一种承认我们确实不是孤立自我存在的谦卑，一种表明我们所做的一切皆假的诚实，一种锲而不舍敢于尝试付诸行动的真挚。

我们怎样才能做到？如前所述，我认为可以先试着通过见证，不认同自己的思想，而后保持思想警惕。所有的麻烦基本上都来自于对思想的认同。生活中的许多分歧与不和谐都源于坚持自己“正确”的理念。通过认识到我们根本就不存在，而我们所谓的“真正意义上”的一切都是谎言，来放弃这一点，这样可以帮助我们放下不时陷入的与他人之间的心理斗争。

最起码，这让我们不会加强与他人的分别感，也给我们机会保持与他们的一体感。虽然我们谁也不可能始终这样行动，但我感到，如果不时地这样去做，将帮助我们听到直觉之音，从而允许我们以一种削弱分别幻相的方式服务。

见证和警惕思想是一种内在活动，但我们也必须警觉自己的行为。继续看这一段，美赫巴巴接着说道，“他[求道者]的服务不应纯粹为了炫耀，应是真爱的结果。”正如“什么是无私服务”一章中所提及的，无私服务的要素之一就是不求名誉声望。我们得承认，我们的行为中通常都有炫耀的成分。世界是一个大舞台，而我们想要扮演主角。我们也许关心他人意见，或是想要改善我们对自身的看法。这两者都会微妙地影响我们的行为。因此，我们必须在行动中摆脱上述需求，以便该行动能够专注于服务本身，允许爱、耐心等内在品质得以表达。自然而然地，当观察自己的行为时，我们有更多的机会听到直觉之音，而能在服务中得到引导。

美赫巴巴在上述语句中还指出，我们的服务“应是真爱的结果”。我的理解是动机不应模糊不明。我提供服务应纯粹出于服务本身，而非其他别物。我的爱也许不纯洁，但我的服务意愿应该是真诚的。

当我们在生活中有这样的重点时，它就把我们带到了美赫巴巴接下来在此段落，所论及的一点，“若由爱激发，他的爱会使他和别的求道者和谐相处，不生嫉妒。如果同道之间缺乏充分和谐，服务就不符合灵性理想。”

美赫巴巴在此告诉我们，如果我们的行动确实由爱所激发，那么这种爱将使我们与他人和谐相处。他因而清楚表明，努力做出调整、保持和谐取决于我们。这意味着不应让误解在我们与同道之间制造距离，而是通过我们对美赫巴巴的爱，在心里向他们靠近。这条准则是一个内置的直觉检验器。它使我们在紧张的行动中能立刻做出判断，我们是被主导的分别妄我占了上风，还是愿意承受误解的压力，用爱及其对一体性真理的直觉来使之冷静。正如“通过灵性认识明智地服务”一章中所指出的，美赫巴巴强调，在我们的行动中和谐的元素是必要的，以使我们的服务能以灵性认识来完成。如若我们的行为没有产生和谐，那么很有可能我们并未得到心灵的指引，而是被一些自私的欲求引发行动。

在我与埃瑞奇共事的这些年里，他向这里所有的服务者始终强调的一件事就是要和谐行事。起初，我以为这只是他对我们的爱之表达，但随着时间的流逝，甚至在他去世后的今天，这一表达的重要性变得相当清楚。我得出的结论是，虽然我们的爱不纯洁，但或许足够真实，以至于当心灵表达和谐时，内在一体性的真理就能得到维护。这就提供了影响我们周围活动的可能性。心灵使我们团结，而头脑使我们分裂，因此和谐的表达是灵魂的胜利，因为它们反映了一体性的真理。

总之，为了更经常听到那可使我们以灵性认识来服务美赫巴巴的直觉之音，我感到以下几点会有帮助：让念头经过明智意识之火焰，见证思想，进而保持警觉；培养对诚实、谦卑和真挚的真正认识；观察我们的行动，以使我们的服务纯粹出于服务本身；最后，以和谐的精神来进行服务从而产生一体感。

所有这些都是有助于直觉的、个人和内在的活动。以和谐的精神服务，自有其内在的一面，但创造出一种有助于传递一体感的氛围，其外部意义也显而易见。因此，我们必须意识到如何促成这种氛围的形成。对人性的认识、尤其是对自由之渴望的日益增长，可以帮助我们获得这种觉知，因为和谐不能被强加于人——它只能作为一种自由自觉的行为而被给予。

美赫巴巴在语录中解释了自由的根本性质，我们将在下一章节看到。籍由他的话语，我们也会开始了解，基于灵性认识之行为的终极意义，在于它给我们带来灵性自由。我们现在正站在门口，以准备迈出接下来的一大步。

译自《世界一体（第三册）服务：为人类的灵性自由而工作》
