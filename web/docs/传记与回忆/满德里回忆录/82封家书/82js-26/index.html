1959年2月23日

亲爱的家人们：

这是美拉扎德的一个晴朗宁静早晨。树上尽是鸟鸣，这些冬日的访客们正以狂喜迸发的告别交响曲倾泻着它们的喜悦。这几天清晨我们听到，与这些音符以及我们虽不那么悦耳却熟悉的日常家务噪音交织一起的，还有更为陌生的各种交通噪声，那是从接近美拉扎德大门那段未铺砌的私家路上传来的。时而是牛车或马车，时而是出租车或轿车，自行车或巴士——将不同宗教与信仰的男女老少载来，有的来自几英里外的阿美纳伽，有的则来自几百英里外的印度各地，皆怀着同一个目的：将他们的崇敬与爱献给巴巴，并接受他的拥抱。看着一批批人群在附近芒果树的树荫下歇息；听到众人的说话声、偶尔的笑声或婴儿的啼哭，这已经成为我们非常熟悉的景象。有些人徒步前来朝圣，比如一个四女一男组成的家庭从家乡步行60英里前来，途中不时停歇露营。这一切皆是对至爱的近期东方通告的回应——其中表示，无论巴巴身在何处，都允许任何人于上午9点至12点来见他；同时严格规定，（用他自己的话说）见面“不得超过几分钟，期间足以怀着爱见我、问候我，并接受我无所不包的爱之拥抱。”

遵照巴巴的意愿，今年美拉扎德不庆祝他的生日——哪怕是最简朴的形式也不举行，因此就连我们祝他一声生日快乐，都算得上“庆祝”了。另一方面，其他各地都在庆祝巴巴生日；印度许多地区都大规模地庆祝，各个巴巴中心为此筹备了数周之久。在南方广阔的安得拉邦，巴巴的著作和有关巴巴的书籍（经政府官方许可）被陈列在公共图书馆、中小学和大学。至少有个巴巴中心将庆祝他的生日长达十一天——活动包括上演一部关于巴巴生平的戏剧，并在25日向穷人施食。在北方哈默坡地区，人们举行一年一度的朝圣，纪念巴巴踏足那片土地的日子。届时各个村镇的人们会聚集在那些因巴巴到访而圣化的地点，还会像印度在纪念一位至爱者（神祇）的重大吉祥场合那样举办常规庙会，以增添节庆气氛。现场成千上万的巴巴追随者会彻夜“持诵”巴巴的圣名——直至25日凌晨5点，即他诞生的时辰。其他地区——中部、北部、东部、西部亦都如此；在曾经只有寥寥几位巴巴爱者的地方，如今他的大爱讯息（如巴巴自己所言）“如火焰般”迅速传播。他还补充道：“时间已到，必定如此。它将不断增长，传遍四方，不可阻挡。”

我想你们大多数人都知道，亲爱的艾微与杜思先生在游历中东期间，获得至爱允许，已短暂访问印度，只为见他一面。此次到访恰逢17日古鲁帕萨德的达善日，她在寄给（或正要寄给）所有团体的美好简述中，描写了见面情景。再次见到她真是太好了，不知怎的，仿佛你们每个人的一小部分也都来了。还有一场类似短访亦获得许可，这次是一位来自法国的巴巴爱者——菲利普·杜珀斯。他在美拉巴德见到了巴巴。那天上午正值“阿冉岗日”，全村人都倾涌而出，接受巴巴的拥抱。有人把阿冉岗视作“巴巴村”——因为他率领少数弟子首次定居此村附近，建立了美拉巴德。许多村民——如今已是成年男女，彼时尚是孩童——都是在巴巴的爱与关照下长大的。他们的孩子也同样忠爱巴巴，在我们去美拉巴德时，总能欣喜地看到这些小家伙脸上洋溢着笑容（尽管常常没洗脸），追着巴巴的车一边奔跑一边大喊“巴巴，巴巴”，并试图触碰他贴着车窗的手……

还有弗朗西斯·布拉巴赞——一位来自澳大利亚的巴巴爱者，不过他的此行很难称作短期访问——巴巴为特殊工作将他召来，期限未定。他与满德里同住，就像他们中的一员；而他对诸多不便的淡然态度，始终让我们惊叹不已。目前他正致力于完成《与神同在》一书——这部作品以无韵诗体写就，美妙绝伦，按巴巴的意愿将于今年在澳大利亚出版。巴巴让人向他朗读了此书，并表示，在世阿瓦塔的这部史诗于他在世期间写成，并由他本人亲耳聆听，这一独特事实对后世将具有重大影响与意义。他对此书的一句赞美之词是：“我的爱将触动所有阅读此书者的心灵，从未有书做到这点。”弗朗西斯目前在孟买，参加那里的巴巴生日庆祝活动，今天会出席一场新闻发布会。我们确信发布会将像普纳的那场一样成功：当时他从科伦坡抵达普纳时，受到美赫中心的盛大欢迎……

近来，至爱尽管有疼痛，却一直比往常走得更多。他不再用手杖支撑，而是推着小婴儿车前行，这样可以更平稳地不间断迈步。有时我们看见他驻足，向满德里指着某株仙人掌或开花灌木，表示欣赏。傍晚，巴巴喜爱从窗户眺望风景——在宁静暮色中，成列的羊群沿着平缓山坡漫步归家，有时头顶还会浮现一轮满月的淡淡轮廓……数日的午后已然提醒我们，夏季正迅速临近，不久我们将要收拾行李，于7号随巴巴出发——先到孟买的阿娜瓦丝与纳瑞曼家度过我们一周的假日，然后前往普纳三个月，再次在古鲁帕萨德度夏——亲爱的王妃已将房子提供巴巴随时使用，想住多久都行……下一封家书很可能又会延迟，因此我很高兴这一封的篇幅颇长，消息丰富。

我必须再补充一则消息，此事让美拉扎德的两个上午格外精彩。一名年轻的卡瓦里歌手——他常参与阿美纳伽美赫中心的活动——两次来到美拉扎德为巴巴献唱。巴巴非常喜爱那些歌曲与他的音质，也喜欢伴奏者的击鼓，故召他们再次前来。一首歌中，有几行令人难忘的歌词是：

我难以言表

当我找到您时，找到了什么。

我已找到目标，找到真我——

果真我找到了人身中的神！

向你们各位他亲爱的家人致以巴巴的爱，伴随即将到来的巴巴年，以及永恒中的一切时光，

深爱你们的

玛妮

巴巴的以下话语，已于今日火速发往印度和巴基斯坦的各个中心，用于生日庆祝活动。由于无法及时寄达西方的全体相关者，巴巴希望我将之写入这封家书：

“永恒中的每时每刻，我们每一个人皆是同一个不可分的神，祂始终独一无二，即便在25日也不例外。”

——美赫巴巴

所有寄给至爱的生日祝词，皆已怀着深爱收到。
