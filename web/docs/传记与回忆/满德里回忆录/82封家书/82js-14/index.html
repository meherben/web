印度坪坡岗

1957年12月1日

亲爱的巴巴家人们：

11月27日，巴巴与美拉巴德和美拉扎德的满德里举行了会议，就他必须在1958年7月前举办的东西方撒晤斯作出最终决定。他希望于28日一早就（向美国、英国、欧洲及澳大利亚）发出如下电报：

作为上帝通过神圣知识，作为病人凭借肯莫尔医生的知识，我已决定：在印度举办东西方联合撒晤斯绝对不妥。我一定会于1958年5月给西方爱者撒晤斯，默土海滨15天，澳大利亚5天*。速告全体。玛妮稍后会详告细节。向你们各位致以我永恒的爱。

巴巴

{注：请按“5”，而非“6”——此处是我个人的误解。玛妮}

巴巴要我汇报会议上讨论的要点（哈里·肯莫尔医生也出席了会议）。巴巴表示：

“我对哈里非常满意——无论他对我的爱，还是他的医术。他百分之百精通业务，通过尽其所能帮助我的身体，帮助了我的工作。他已尽最大努力，效果令人满意。但髋关节状况非常糟，他知道，（正如我一直所说）我再也无法像从前那样自如行走了。他说，这点我也清楚，倘若他早几个月来，我现在就可以正常行走了。但那并非神意。我的事故绝非‘意外’，归根到底只有一点：过去我想要的已经发生，现在我想要的将会发生。持续的疼痛对我的工作是一种干扰，因此哈里·肯莫尔来了，帮助很大。他将我的身体结构调整至平衡状态，自事故以来，如今我第一次能以良好姿势挺直站立**。**为保持这种结构平衡，他建议于大约一年内要格外小心，在施达善及撒晤斯期间采取严格预防措施。不能对我的身体造成压力，我必须避免疲劳，避免吃力的活动，比如在达善期间给大批信众递发帕萨德，或接受他们的花环和拥抱。我已答应，在12月及之后的普纳和孟买施达善期间遵循他的建议。

“我告诉哈里，只要他在这里照顾我，我就会按他说的做；他不在时，我也会尽量照他的嘱咐做。但我不能承诺完全遵守，因为我有工作要做。他满意地处理了他的业务，我也必须处理我的业务。我为了人类而采用这个身体，在这一年里，我必须用我的身体工作——出于对人类的爱而必须做的工作。因此，我绝不能过分照顾身体，以至让它妨碍我的工作。另一方面，我必须给身体足够的照料，它才能承受得住我面临的工作压力。

“我已决定不联合举办东西方撒晤斯，原因有二。首先，因我身体伤残，那会对我造成巨大压力和劳累。其次，倘若我不顾这些因素举办撒晤斯，我就不能够把我希望通过撒晤斯所给予的东西，充分给予我的爱者，他们也不能够接受我希望他们得到的一切。所以我决定分别举办撒晤斯——在印度给东方人，在默土海滨和澳大利亚给西方人。我将于2月举办东方撒晤斯，并将要求他们遵照哈里的建议嘱咐，克制表达爱意的肢体动作（如献花环、拥抱等）。东方撒晤斯参加者的人数限于1400人（分两组，各700人）。

“我肯定会在1958年5月给我的西方爱者撒晤斯，默土海滨15天，澳大利亚5天。我不想要任何宣传，不要‘公开日’活动，不要那种意义上的‘访客’。这次撒晤斯，将是为了那些渴望来印度参加我的撒晤斯者（包括打算参加者和不能成行者），也是为了其他爱我、愿意服从我、希望参加撒晤斯者。

“7月15日后，将不再有撒晤斯、集会、公众达善等等。不管我的身体状况及外部形势如何，我都必须在7月15日前完成这一切。”

巴巴希望我附上这则他给西方爱者的讯息：

“我对你们的爱满意，并知道你们不加疑问且欣然接受我的意愿。我知道什么最好，我的决定是为了最好目的。我以唯有神能爱的方式爱你们，定会在1958年5月*给你们我的撒晤斯。这次撒晤斯将100%令我满意地给予你们我希望你们得到的东西。届时你们将完全明白我的意思。抓住我的衣边，越来越爱我，你们将充分接受我将给予的东西。向你们各位致以我的爱。”

{注：澳大利亚撒晤斯可能在6月初举办。}

肯莫尔医生于4日离开美拉扎德后，巴巴将于12月8日在普纳、（本月迟些在孟买）施达善。因此后续巴巴会告知我关于他来访的更多细节（以及默土海滨与澳大利亚相关安排的大致要点），以便传达给你们。

致以巴巴的圣诞问候

以及美拉扎德全体家人的至深爱意

玛妮
