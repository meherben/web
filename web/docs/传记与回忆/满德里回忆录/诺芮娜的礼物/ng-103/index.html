《灵性日记片段》

非人格大我之直觉

选自1942年6月《美赫期刊》

1942年3月5日，诺芮娜·马切贝利王妃

在纽约发表的小组谈话

外界并没有领会“瑜伽”的真谛，人们可以通过这门科学认识自身的灵性构造。

新时代完全忽视了人内在的灵性次第。这是由于人高度进化的理性头脑所致。如果人们少一点理性主义，会更容易获得高级意识的灵性成就。要获得对真正价值的更高认识，作为有自觉理解力的普通人，就要从内在去了解具有上帝意识的人的事实情况，这是毫无异议的。

普通人对这个事实一无所知，他不可能对该事实有实际的概念或经验，因为他没有真正渴望去了解高于常人称作智慧层次思维的东西。

当今没有人拥有正确的方法通向这种内在纯粹功能，也就是直觉。它被普遍误解，尤其被精神分析学家所曲解。他们都有着迷信的态度，认为在通向人的内在或精神方面，直觉是一种虚假的心理方法。我在这里讲的是常规语言，因为我在这个西半球不能用神秘语言说话，理性主义方法在这里已形成固定观念，与这个新进化周期的直觉觉醒相违背。本次思想传递是诺芮娜·马切贝利通过美赫巴巴的恩典，在美国对亲近小组谈话期间接收的。

这个新进化周期在人的精神构成上有着明确的目标要实现。人的新精神构成，将通过直觉领悟到靠智力或理性方法绝不可能认识的东西，并通过认识将它们转化成对生命的更深刻觉知。

因此，本时代的崭新意识将是：所有人都会拥有一种远更深刻的洞见，比如直觉认识。

直觉是人可以藉以认识整个心智内部有机结构的精神状态。当我们谈到人的整个心智时，必须了解东方的观点：即整个心智是一切曾经是、现在是和将来会有的普遍外显世界；我们不可能用别的方式弄明白这点，因为这正是人们必须在这个新进化时代通过洞见（直觉的等义词）来领悟的东西。

所有这些术语，也必须在未来通过个体的实际直接体验加以矫正，届时他将能够通过直觉从内在感受正确的术语。一旦体验与任何类型的术语划上等号，用批评和偏颇的观点来看，术语和名称都显得多余。能够读懂神秘语言者，不管作者采用什么术语词汇，都能感受其内在涵义。

总之，随着人类能真切感受术语词汇的内在意思或含义，神秘语言在将来会受到高度赞赏。

新时代显然正致力于创造性思维和纯然感受的统一。一旦在对深层含义或意思的体验中头脑和心灵相融合（这是理智型的人们无从涉及的神秘事实），认识与知识这两种不同的方式永远不再是有争议的问题。

没有比灵性认识中的新觉醒更能定义新时代的了！没有比通过人自身的学习或普通的三体瑜伽科学，更能有意识地发展这种内在新觉醒的了。这里就是切入点——新降临的阿瓦塔之律动大能乃是人的新灵性方面的唤醒者。

不管我们怎么称呼瑜伽科学，当第四体，亦称以太灵体（Ethereal body），在自觉个体的心领域中被激活并被意识到时，瑜伽科学就抵达终点。

这就是我称作的真理瑜伽（Yoga of Truth）。

真理瑜伽的意思是实际觉知到作为人的灵魂实质的灵体。这就是所谓的第四体——基督身体。它是阿瓦塔本人在这场证悟真理的新分配中，在世间，在地球上使用的唯一形体。这不是普通意义上讲的，表示阿瓦塔显现之神圣化身的词汇；它将是向普世人类发出觉醒呼吁的大能律动。对大能律动的体验必须强烈到足以使人降伏智性反应，并通过创造性宇宙心的直觉意识使人们内在证悟它拥有神光。由此，人会在真正意义上认识到他所谈论思索的东西——神光。我在之前的演讲中说过，人只有于自身内在认识灵魂觉性的固有事实后，才能证悟神光。

当今的人类，因对自身内在的上帝意识有太多的理性认识和知识而被蒙蔽。人们对证悟内在上帝意识状态一无所知。人们谈论这个问题时，会为自身最好的一面——即做到真正接纳和谦卑的可能性——而争论不休。

要做到接纳和谦卑，意味着要放弃通过心理研究、智力探索、博闻强识来寻找内在真正实相，该实相是具足潜藏的，但却远远超出智力及其所有想象中的可能性——即通过自身的苦思冥想寻找那决不可能用智力找到的东西。

将精力浪费在通过心智来研究那想象中的内在上帝意识，可谓令人惋惜。但我们还能做什么？到印度寻找真理的理性求道者，其意图固然是诚实的，但妄称真理唾手可得则相当幼稚。没有人能够唾手可得。寻找真理是我们面临的最漫长乏味、艰辛困难的任务。

当今人人对之好奇的这个真理究竟是什么？真理的相对性是不可避免的，明白这一点胜过彻底的不可知论和否认真理实相（可意识到自己的内在神性）。事实就是这样。现在我回到“真理瑜伽”这个词，在此向西方世界的公众声明：它是要靠新降临的阿瓦塔的恩典于内在唤醒的。

新降临的阿瓦塔是位男子。当他作为被需要的全能上帝以人身显现时，一定会得到公认。被人需要意味着，他自己尚未证悟其具足的上帝状态，必须被促成达到完满神圣喜乐才能够成为神人。

对所有人类而言，要获得这种高级意识状态是极为艰巨的任务，不过一旦他们用自己的眼睛去看，用自己的心去感受，用自己的理性辨别力去了解——**人的圆满形式是什么样的，**他们就会毫不犹豫地继续前进，并且找到道路——通过行道才可能获得这个称为神的终极意识状态。人实际上是超人类。人的内部结构并无不同……只是外部结构有别，使人们呈现为各有分别的人类，有着各别的诠释方式、各别的习惯、各别的欲望和需求。人类本身在灵性结构上，是与其神圣本体、未被发现的上帝意识状态协调一致的。因此，真理瑜伽不可能靠进一步的追求、研究、发现、购买或租借……它只能来自阿瓦塔本人的恩典。所有人里面的第四体是相同本质，通过对该本质的有意识觉知，人们会更深入地理解彼此的需求。只有通过对以太灵体的这种觉知，人们才能更深刻地理解“新世界秩序”的含义。所有人对这个词都略知一二，可他们的认识多么幼稚！

世间无新事。没有人会发明新机器来发现内在的神。无论做什么都无法使人幸福。无论再做什么都无法创造更多的宗教观。在过去的时代或者说年代，从最近的阿瓦塔——即耶稣对基督徒、穆罕默德对东方世界——显现以来，一切都已经做完。

这两位伟大的阿瓦塔已经给世界各地带来深刻的意识转变。人们尚不懂得感激。

经历过这场席卷全球的正义深远的世界大战之后，他们会懂得感激。这场战争结出的硕果——深刻的意识转变——将在新分配期间取得进展。

必须将新分配理解为，由阿瓦塔所唤醒、人有意识体验以太灵体的事实造就和秩序建立。当它在人的内里创造上述事实时，这位具有基督意识的人物——现今叫美赫巴巴——将不会受到误解。

这个新分配无异于所有时代阿瓦塔化身为纯洁无私人类期间的旧分配。这完全是具有上帝意识之神人的圆满形式，他有能力在人的内里造就人自身无法造就的东西。关于这个新分配的事实已经毋庸赘言。
