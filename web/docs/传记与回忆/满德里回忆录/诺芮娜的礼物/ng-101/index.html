《灵性日记片段》

序言

向大师献上这些灵性日记片段的诺芮娜·马切贝利王妃，一直具有神赐的深刻祈祷能力。正因为她无私地献身于大师的神圣事业，大师才挑选她，通过她发送灵性之光。一个孩童般单纯、毫无偏见者，能够成为神圣之光（与神圣之爱一样）的真正接受者。她焕发热忱的真诚祈祷，被大师所接受，成为从事他神圣工作的灵性信使。

经历早年对耶稣基督的忠爱，以及后期很多的内在灵性体验，她做好准备拜见大师本人，并且被他所接受，从事他的特别类型灵性工作。她在下面的话中提到，在拜见大师之前她自己的一些亲密灵性体验：

“从孩提时，我就知道上帝。祂赐恩向我显现。祂以创造性的爱触动我的心，驱使我遵循灵性的生活方式。祂早在我十二岁、情感初萌的时期，便拯救了我。祂现身耶稣基督来跟我说话，用无上智慧的语言向我解释，这个已开始在我内里升起的爱，对实现最高形式的灵性之爱是绝对必要的渴望。

“祂以令人难忘的语言对我说话，这番话至今仍在我内心起作用，使我产生对生命神圣主题的更深认识。祂说：

‘我是你最初和最后的爱。’

“1931年我见到美赫巴巴时，就完全领悟了这番话的含义，认出他是基督化身。我尚未提此事，大师就告诉我，他即是以基督形体向我显现、给我灵性指引者。他在我内心建立了对他的无条件信任。

“自从见到大师后，我爱他胜过爱自己。讲到这里，我忆起1947年，当时我经历了一场久病，生活中所有的希望和欢乐都已消逝，我的全部精力不论好坏都消耗殆尽，随后我接到大师的电报，命我去印度回到他身边。在这仁慈的消息带来的热情时刻，我意识到，即使表面上陷入健康糟糕和精神绝望的状态，我的生命仍完成了反转，竟然上升迈向它的真正实现。我的意志迫切地指引我去印度，不是为我自己，而是为了服务大师，他可能会通过我表达他自己。

“他有意识地将他的思想传递到我内里，以便可以看到他自己通过我思考。我作为他的弟子，充分意识到这一点。我来印度是要实现我生命的梦想，即通过他、在他内里、为了他而存在，并成为他表达自身的活工具。”

*“通过不断流经他的神爱，美赫巴巴转化了那些前来寻求解脱者的意识，以便他们可以通过体验懂得有史以来的贤哲们给予的理论教诲。”*1927年她经历的诸多重大决定性体验，就证明了这点。

如她所述，在1927年她经历的那些灵性体验当中，曾有目击自己死亡的神秘体验，她在其中不仅体验到肉体生命的停止，还体验到低级意识的终结，暂时被实在之光所吞没。她试图直观地捕捉各种形式、高低不等的生命经验。她甚至成功地进入石头状态，体验到即使在意识的最初级形态中，亦即神圣显化的最早阶段，那种要进化、扩展并达到自知的巨大冲动虽然难以表达，却强有力地存在着。她在纽约实际见到大师之前，灵魂就激荡着神圣躁动的期待，准备迎接人生新的开始，并且知道，与大师见面之日将是她生命中最大转折点的到来。会面实际发生时，她的心喜极而泣，因为历经所有的痛苦之后，她终于面对面见到了神。

诺芮娜·马切贝利解释说，1941年末，她感到一种发自内心的明确召唤，要向美国大众宣讲大师以及他的使命，尽管大师当时在印度，距美国有万里之遥，但她接收到思想传递，命她从美国的东海岸前往西海岸。于是，她把美赫巴巴的圣名带到一些灵性活动中心，效力于大师的灵性使命。她带着大师的祝福前往那里，由于跟大师协调一致，她对求道者团体发表的演讲，给了他们巨大的帮助。许多听众获得最高级的灵性体验，他们确信大师通过她的演讲在做他的灵性工作。我在此转摘了有幸听过她演讲的两个重要人士的来信内容。

S.C.先生写道：“王妃进入房间后开始演讲，不一会儿，我就被巴巴通过她传达的话深深感动，但让我印象尤为深刻的是我实际看到的情况。我目睹的是一个简单、非常实际的客观事件。只见能量线从王妃身上传出，射向四面八方，渗入屋里在场的每个人，就像你可以想象的，电能持续不断地从电池流出来那样。这些能量线是实心的，而且清晰可辨（并非朦胧幻影或无形之物）。后来我回到家中，认真思考究竟发生了什么事，才意识到这是一位强有力的大师竟然从万里之遥完成的伟大工作。

“我问自己：‘那些能量射线的意义何在？’像巴巴这样的大师，做事不会只是为了展示能力。在我知晓巴巴的十多年时间里，他最突出的特点之一就是工作。巴巴总是在工作。而我们，全世界的人，都是他的工作对象。上帝总是处于劳役状态。我忽然明白了这些电能射线的用途（当然它们比电更强大更精微）。它们旨在净化我们心中积累的层层印象，即巴巴称作的‘业相’。”

D.S.先生描述了他对王妃另一场演讲的体验。他写道：“当时我强烈地意识到，仿佛我的心直接升至头部，似乎与那里的中心融合或结合。体验这些的同时，我忽然明白，自己松脱了不止这一世的业力束缚和纽带……也因此逃离了整个痛苦蒙昧生活的低级循环，体验到新生活浪潮的开端，即使在该范围内，也远比旧生活循环中可能想象出的任何事物都更为美好圆满。”

如王妃所述，大师通过她，向她所到之处的全体听众传播讯息，发出直接而激动人心的呼吁。他的话充满无可挑战的权威。巴巴通过她说：

“我是新基督。

你们等待我已久。

我是真正的导师。

你们将通过直接体验知道我的实相。

你们将认识我，你们将看见我，你们将感受我。

这个神圣揭示将是我的恩典。

你们生来就是要爱活着的上帝的。”

正如在所有的先驱性工作、尤其在灵性领域中常发生的那样，她不得不面临大量的偏见和反对。有些人沾沾自喜地说，他们对世俗教育和哲学、或者有组织宗教的老牌教会所呈现的现代文明相当满意；他们跟不上鲜活教导的新节拍，思想保守固步自封，总想按照自己的狭隘观念妄加判断。对所有这样的人，美赫巴巴通过弟子给予了直接回答。王妃爽快地给了我，大师通过她的思想传递发布的多份直白公告和声明的重要摘录。我转载的只是其中的几条。他说：

“你们无需权衡我话语中的利弊。

必要的是你们应当领会之。

你们必须一劳永逸地领会之。

你们将见证我蜕变人类意识的工作。

为了给人类生活带来根本改变的神圣事业，

我现在马上就做，还是多花点时间，都不要紧。

重要的是我将在未来几年内做这件事。

这将是有目共睹的，凡被改变者，

都会发现我是该结果背后的原因。

我乃是世界的主与仆。

你们将需要我。

记住，你们不能错过我，因为你们需要我。”

在她举办美赫巴巴灵性思想传递的各种聚会上，人们提出各种各样的问题。这些问题代表并体现了严重的理智取向，也就是我们这个时代的特征。下面转载了一些意义重大的问题，以及大师通过她所作的回答：

问：“普通人说的话与您说的话有什么不同？”

答：“我的言语就是大能。

我的思想就是行动。

我就是真理。”

这些演说期间，现场鸦雀无声。听众确信就是大师在通过弟子说话，于是他们纷纷向通过她说话的大师提问。

问：“我们如何认出您？”

答：“敞开心扉迎接我，我会对你揭示我自己。通过体验，我对众生揭示我自己。”

问：“证悟真理的直道是什么？”

答：“放弃自我。

与我合一。

把你的生命交给我。”

问：“我们何以知晓自己接受了您给予的东西？”

答：“我会改变你自身。

你自身会体验到那超乎理解的爱。

我是人格神。

忠实地服务我。”

这些激动人心的演说期间，大师通过她工作，引发了人们积极或消极的反应。一些人经受良心的拷问，一些人则体验到和平降临。他们在善与恶的对立面之间经历快速的摇摆，促使他们下决心断然做出选择。这带来人性中纯洁与不纯因素的筛选。那些通过感受来理解者，知道正是大师的爱和慈悲在工作。

那些准备好心灵被唤醒者，则呼求更多的爱。大师通过弟子诺芮娜，对他们说：

“记住，无论你们是好是坏，无论你们对自己理想中的上帝有没有无私奉爱，无论你们喜爱我的帮助还是因为偏见而反抗我，我都爱你们。”

“我作为非人格神爱你们。

那是光，创造‘事实’，赋予众生以生命。

我还作为真理化身爱你们，让你们永远铭记。

我作为人格神，乃是真理的真实显现。

该真理，我可以凭意愿使你们证得。

这将是我给你们的馈赠。”

“非人格神作为绝对实在，存在于万人万物、有限世界、超越的领域和看不见的世界中。我是成为人的同一个神，以便接近你们，使你们感受到神爱的温暖和真实。”

“我用深不可测的方式带领你们走向解脱。

要获得解脱，就要摆脱欲求。

我可以用我的意志促成之。

我的意志就是爱，

你们将在这个时代

在我所决定的时刻证悟的大爱。”

大师通过弟子，对那些迷途和绝望者说：

“我将带领你穿越灵魂的暗夜。

把你的全部缺点交给我。

我将使你超越之。

我是爱之洋。

你会获得救赎。

你会找到我的平安。”

“接受我的律动。

无保留地跟上节拍。

这将让你超越自己。

你的内在自我在呼救，我真理的节奏将把你救赎，

将开启你的心灵，

将赋予你新的爱，

将把你纳入灵性思维的知识秩序。”

“我是在人人内里制造秩序的光。

我是一切众生里的神圣意志。

我降临世界来服务你们。

我能让人成为他靠自己无法达到的。

你需要我。”

1947年大师通过灵性思想传递，提示一小批爱者，他们应该前往纽约的拥挤贫民窟寻找最为不幸绝望的民众，以便他把灵性祝福赐予他们。

巴巴给穷人的祝福语：

“让我来帮助你们。我能帮助你们。放心，我将帮助你们。

你们会知道这点，那时我会亲自前来，使你们享有我为你们每一位持有的、你们可以同我和其他人共享的珍宝——那就是爱。

不要担心。”

由弟子诺芮娜向听众发表的这些独特声明，事后被她记录下来。这些声明被赋予真理的力量，对他们的信心是一种挑战。这成为明确的考验。有些人毫不犹豫，怀着心中焕发的全新热忱来见她，准备跟随大师。在她发出呼吁的各种演说中，大师通过王妃讲述的语言极为透彻、简单明了。这是人与人之间的语言。真理的朴素事实，对每个人而言变得明白易懂，不再是一团迷津。大师下降到每个人的层面，成为众生的父母和唯一挚友。生命的对立面通过爱得以融合。

有整整五年，诺芮娜·马切贝利都在从事这项思想传递的使命，直到她接到大师命令，不再通过灵性光的运动来工作，因为目的已经实现。1947年她被召回印度。

不带任何偏见、满怀热望服务大师事业的她，舍弃了在西方过奢华生活的一切诱惑，并完全顺服地接受了牺牲和服务的生活。自从被大师安排从事更高类型的工作，一种全新的宁静降临到她身上。

由她接收的美赫巴巴讯息一直被忠实地记录下来，现收录于《灵性日记片段》中。

这是真正的灵性智慧，可帮助不同类型的求道者去认识和理解各种思想形态中蕴含的真理，为所有的自由思考者带来启发。

这是完美意识到内外反应的纯然无私服务。纯粹思想对人类振动体验的帮助，是不为智力所理解的，然而它是可见、可感知的。

当一个思想被传递到某人时，接收这种传递的功效和价值，取决于该传递源头的灵性地位。但即使在最佳情况下，它也只能激励并引导接收者。然而，如果由于弟子有着更棒的灵性准备，大师的赐恩会直接把弟子的心用于传达真理，弟子通过思想传递，不仅自身被提升到更高意识、与大师更密切一致，而且成为创造性的力量，激励和指引着无数仅通过智力寻找真理的人们。

当大师通过弟子的“我心”思考时，他通过弟子的思想传递，振动着不可抗拒的真理脉动之力量。在这类思考中，弟子知道不是他、而是大师正通过他思考，他意识到无论视野方面还是有效工作上，都绝非自身所能企及。大师使用弟子的心时，通过这个过程授予的讯息和教导，在精确性、清晰度或力量上都完好无损。

美赫巴巴自从1925年7月10日起一直保持沉默。他通过字母板直接授述很多深刻的灵性语录，并发布诸多鼓舞人心的讯息。这些都已发表在《美赫巴巴期刊》上，也已经独立出版。

但本书中弟子诺芮娜所传递的大师讯息，乃是大师内在的创造性和振动性思想传递的直接表达。通过这本书，大师给所有求道者提供了真理的层面。让饥渴疲惫的世人谦卑地深思讯息中的每一个字，以便将其落实在日常生活中，按照鲜活真理的形象重塑自身吧！那些成为他的生命宗教新福音使徒的人是有福的。

阿迪·K·伊朗尼

1948年，印度，阿美纳伽国王路
