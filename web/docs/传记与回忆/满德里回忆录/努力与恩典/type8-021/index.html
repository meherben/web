*我带来人类可能接受的最大珍宝；这个囊括了一切其他珍宝的珍宝经久不衰，因与人分享而增加。准备好接受之。                        *

——美赫巴巴

作为弥赛亚或称阿瓦塔，美赫巴巴是通向目标、通向神的神圣催化剂。当人们想知道神显现为弥赛亚、基督、美赫巴巴的特点时，我不得不说，那远不止是巴巴的精彩阐释。与他接触的真正价值是“荣福直观”——你若有幸得到的话。这关系到你在多大程度上了解他的真实身份。1954年的一天，我突然强烈地感悟到巴巴即基督。他随即投来我迄今接收的最犀利一瞥！他仿佛很惊讶，有人竟如此深刻地看穿了他的“乔装”。

美赫巴巴能够而且有时候确实非常慈爱地揭开他的一些面纱，让我们瞥见他的无量爱光，在精神上与他融合。他比任何教导都更有效地向我们展示了神爱能够溶解分别、促成结合；展示了神爱确实是我们与神圣至爱结合之路。

美赫巴巴给我们的最伟大教导，其实根本就不是教导。他给我们的最伟大教导是在那些特殊场合，通过他对我们的大爱，让我们洞见他的存在本质，实际上吸引我们进入他的神圣甜美。

努力与恩典

阿瓦塔美赫巴巴不只是来稍微动一动我们；他是来完全撼动我们解脱！所以，我们需要他的介入和恩典，需要他在内层面对我们工作和操纵，把埋藏在我们潜意识中的东西提到表面，以便有意识心予以处理和明智地消除或溶解。

巴巴希望我们自由，不再做二元对立领域的受害者。他已经来到监狱，打开门，要我们出去。在他的恩典作用下，面纱揭开，光明显露。他所带来的东西不依赖于任何条件，因此重要的是我们信任他，以及他能为我们做的一切。我们真诚努力，他就会在一切方面帮助我们。

这是美赫巴巴对我们个体所做的伟大工作之一。这不仅仅是我们表面上多积德的问题，而是把制造淫、贪、嗔和自私的无知连根挖出！我们的目标是摆脱自我意识生活。我们必须为此努力。

重要的是要明白，我们的努力旨在服从巴巴永流不息的大爱恩典并由之维系，而不是依旧服从自身的业相制约并由之维系。

勤奋的学生

滤除幻相并接受美赫巴巴的爱和内在帮助，总是需要努力。不过，根据我的经验，巴巴总是慈爱地激励我们做这些内在工作努力。我们倾向于拖延，认为什么都不用做就会达到目标，但是我们必须努力。必须奋起反抗一切让我们自满的东西。我们必须成长，达到更成熟的意识状态，上升到真实层面。我们都有能力做出英勇努力。

通过这样的努力，我们会吸引美赫巴巴的更多恩典；正如勤奋好学的学生，比淡漠自满的学生更吸引教师的注意和帮助。通过配合巴巴试图对我们做的工作，我们能够唤醒并吸引他的更多关注和帮助。如果我们目的诚实，愿把需要处理的一切都提到表面，他就会持续不断地对我们工作。

美赫巴巴不断地给予恩典，但我们必须接受。通过邀请他的介入，我们敞开心灵，接收内在改变，摆脱业相障碍。通过接受他的恩典，我们也把一切交给他；放下对业相的执著，让它们离开。我们决定舍弃浊层面。这需要深刻的心灵革命。

我们开始认识自身的业相以及对它们的痴迷。认识到自己怎样不断地给意识制造面纱。通过我们的主观内在努力和巴巴的恩典，业相面纱变得透明，这时业相就不再霸凌我们。

内在道路

通过一步步摸索，我们获得更多光，更多灵感，更多洞见。面纱脱落，内在视野越来越清晰。信心变为确信，内见成为觉照。我们体验美妙的意识扩展。觉知到自己实乃灵魂。这就是内在道路。

可以看出，这种内在工作部分是自己的，部分是大师的。大师的部分是揭开我们的幻相面纱，让我们越来越觉知真理；我们的部分则是配合他的帮助，停止制造更多面纱——这些面纱将我们束缚于幻相，阻碍我们看见自身存在真性。

然而归根结底，我们内在障碍的消除是大师的恩典所为。就连我们自己的努力都是他促成的。事实上，这一切都是他自己做的。我们以为我们是做者，但他才是真正的做者。正是他自己在唤醒我们内心中的他自己。

神圣珍宝

诗人兼至师鲁米说：“灵性道路上，需要努力。但恩典比努力大千倍。当太阳升起时，自我努力的蜡烛即可吹灭。”强烈地爱美赫巴巴是我们的努力，但本质上是他的礼物。这涉及完全接受他对我们的神圣而个人之爱，其中包括他的神圣恩典。

美赫巴巴对我们的神圣之爱是亲密而持续的。这神圣宝贵，永不止息。他的爱囊括并揭示了神圣恩典宝藏，这也是他给我们的礼物。巴巴的神爱恩典无限无穷，无法测量。他的神爱恩典不只是短暂施予的，而是永恒的。他的神爱恩典轻易取代了通常决定我们意识状态的严格因果律。通过他持续不断、永不减少的神爱恩典，我们从摩耶的束缚中解放出来，并觉知到自己的完整性。

即便在此刻，若能够通过至爱巴巴的神爱恩典来认识到我们自己的完整性，即是从对任何匮乏、需要或欲望感的痴迷中立刻解脱出来。在完整性中，没有什么可添加的。完整是我们灵魂的本性。实现完整的特征是一种幸福释放感和持久满足感——在美赫巴巴慷慨而不断赐予的神爱恩典之甜美现实中。

爱的至高无上

美赫巴巴对我们说过：“你们属于我。”我们都属于他。不管怎样，他都是我们的朋友，他把天国放银盘上送给我们！与他想同我们分享的东西相比，金银不过是沙粒而已。

因此，要在心中寻找至爱巴巴，专注于他，而不是专注于欲望等次要事物。神爱能够取代欲望的流动，将我们的注意力转向心中爱的流动。这使我们进入一种不同的境界，一种超意识的境界。自我开始削弱，心目打开，心越来越纯洁。就像黎明来临；这就是我们的灵性觉醒。

（全书完）
