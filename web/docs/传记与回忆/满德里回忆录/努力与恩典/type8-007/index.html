第8章 改变焦点

正常意识类似催眠。一旦瞥见幕后的实在，你便醒来，再不甘心于普通生活之死亡。—达文·肖

为帮助我们达到精神层面，美赫巴巴在努力在受苦。我们也必须与嗜好搏斗，把注意力集中于他。这能赋予我们必要的专注，摆脱欲望。我们也许拿不准所做的对还是错，但若意图良好，目的真诚，巴巴则来救援，在内里对我们工作。支持我们，和我们同行。我们跌倒，他会拉起，继续前进。我发现，不可思议的是，巴巴在最微小的事情上对我们工作。实际上，他比我们自己还更关心我们的进步。

毫无疑问，巴巴在对每一个想让他工作的人工作。这是我们和他之间关系的主要部分；他持续不停地对我们工作。不是说时而对我们工作一点儿。我感到，他愿意不断地对我们工作，只要我们愿意真正投入灵性道路。

他的工作就是：帮助我们看清我们能做什么。他说，我们必须工作——努力精进，他的角色是确认和巩固我们的最高直觉和认知，把我们的意识推向下一个意识层面。但工作我们必须得做。付出努力。除了百分之百的努力，我们还须接受百分之百的恩典。这似乎矛盾，但巴巴在《宇宙讯息》中说，他就是来释放这种神圣恩典的。他为我们的工作，就是我们的救赎。

先找大师

有人问美赫巴巴，“要不要先消灭欲望，再来找大师？”换言之，是否应该净化心灵后，再努力爱大师？巴巴说，“不必。要先找我。”把精力投入努力爱大师，这本身就会帮助我们战胜弱点，净化心灵。制造一种离心力，驱逐虚妄，阻挠虚假。我们的能量振动大幅升级，内在视野拓宽，勇往直前。

我感到，不幸的是，很多人让自身弱点成为障碍。此乃一大陷阱。他们说，“我不配巴巴的爱。”让自卑感成为自己与大师之间的屏障。事实上，你不可能等到心灵纯洁，完美无瑕。对此巴巴在《真正的师徒关系》中，告诫弟子“要不顾自身缺点去爱，不要等到能够净化自心。”也就是说，不要让自己的失败和缺点阻挠爱。巴巴知道我们的全部弱点缺失，他对我们的爱是无条件的，不加评判地接受我们，不受正统或局限束缚。

我们在美赫巴巴那里找到安全和庇护。因此要努力觉知他对你个人的爱。他的关怀从不间断，他的性情不染嗔怒，不懂报复。随着他对我们的业相开刀，我们也经历必要的表面推拉周期。要争取每一次都努力向他靠近。

通向无限之门

你可以用任何可能的方式去爱巴巴。他是通向无限的大门。巴巴说，“你在自己的层面爱我，我会把你提到我的层面。”此乃整个秘密所在。通过爱他个人，我们逐渐地在不受限的意义上爱他。

我感到，每一个走近巴巴者，也会在最个人的意义上体验他。他的形体成为通向无限的门户。他毕竟是个人化的神圣至爱，是我们能够真正爱戴者，真正景仰者；所以我们在路上也偶尔体验他的有形美。

只管爱他。感受他是你意识的一部分。让他成为你的灵性道路，你的修行或途径；而非某个机械练习或体系。美赫巴巴说，“我了解道路及其迷津，因为我就是道路。我就是目标。”若怀着爱收听他，就能享受神圣至爱的在，在一定程度上参与目标。

在巴巴身边时，我们时而确实会体验到这一点。在个体和群众中间，他的意识占绝对主导，有时会把你扫荡入他的意识状态，让你品尝一口神的无限自由和甜美。

培养伴侣感

在内心，我们必须相信最高的可能性。负面念头意味着受摩耶蒙骗。归根结底，都是同内里的巴巴工作，培养伴侣感，越来越靠近他。这能够改变一个人的脑心倾向。

通过唤醒对巴巴的内在感情，在心灵的层面接近他——我们的一切努力全在于此。很多事情都能帮助培养这种伴侣关系：他怎样几乎不停地为人类受苦，怎样为我们的灵性救赎付出代价；随着对他的生平了解加深，我们也许会发展对他的感情和爱他的方法。也可以遵从他的内在指导，连接他的在，努力控制自己的思想观点。

甚至给他写（他在肉身中收不到的）信，也有助益。记得有一次，巴巴对我的信回复说，“你的信把你拉近我。”通过写信，向他倾诉心扉。思念他，努力在内心达到他，努力在内里联系他，努力测量他的意义。

这需要利用我们的念头。虽说这似乎不可能，但我的体验是，我们越想他，就越觉知到他。是能够学会感受他的。我记得上班的时候，只好努力让心灵活着：尽管头脑专注于别的，但保持感情——心灵中心——的觉醒和活跃，感受巴巴的在。

当然，通过心灵中心念记巴巴，我也不总是成功。但你不能因做不到而谴责自己。只是朝这方面努力。进行体育或技术训练，不可能一开始就出类拔萃——必须朝那方面努力。开始体验巴巴的在时，你会发现，那不是痛苦不快的工作；而是一种愉快喜悦的体验。事实上，通过这样做，是能够在一切时间体验幸福的。

美赫巴巴爱我们，希望支持我们，和我们分享他的体验。他想和我们分享神的国——它一直敞开。他想成为我们的不离伴侣。我们允许，他会的。我感到，现在他不在肉身了，甚至更容易接近。越在内里伴随他，就越向神圣纯意识敞开，更能摆脱诱惑，也就是我们的弱点。

为抵制我们对摩耶的上瘾，大师通过内在揭示自己，授予真理，融化虚妄。他的真理超越我们所执著的任何价值。随着我们的内在努力，他也以自己的方式帮助我们。

对大师干预的逐渐接受，引向同他的更大亲密度。我们受内在驱使，想清洁清理心灵。通过这种亲密，我们在某种程度上成为他意识的一部分。换言之，当我们认同于无限，也就是我们的灵魂层面、大师代表的生命层面时，他则会把我们带到他的层面。这不是可以想象的。大师的爱——自由内在地给予的爱——消融一切业相，取缔我们对摩耶的上瘾。

因此我们必须学习不认同低我。必须保持已获成果和视野。必须立身于已获自由的正面态度。

爱之无上

我们本应用心灵眼睛看，用意识眼睛知。用心灵眼睛看，乃神秘之见，以此认识内在道路，内在神爱。在心灵层面用爱光看。必须通过爱大师，爱巴巴，来坚持这种爱光的无上性。

爱不是伤感情绪，不是某种感情。而是远为精纯的东西。是一体感，觉悟，无限自由和知识——智慧洞见。是实在真理光束。爱是实在。实在也许是最好的词，因为爱促成虚妄不实面纱的脱落。

美赫巴巴说，随着我们对他的一心专注，他会打开心灵之门，释放爱的辉光，在思想层面转化我们的意识。当我们在心灵里肯定爱时，光明被揭示。心灵不再接受低自尊之类的错误观念。我们不去试图爱别人，而是争取心灵的爱光，从而使爱流溢，自然给予。

美赫巴巴的语录，都可以说是对爱的阐释。我们本应把意识扩展到这种爱。这带来对自我实现的新认识。真正的实现是灵性的表现，而不是获取物质或个人成就——这一教训来之不易，因为我们喜欢得到东西，狭隘自身意识。

因此，我们是在给予——让爱流动——而非获取中，体验实现的。爱的时候不需回报，因为你已在体验充实。爱是自身实现，给予即充实。最终成为巴巴所说的神圣爱，其中毫无自我考虑，只有对内在神恩的依赖。

要在心灵里寻找巴巴，全神贯注于他，而非欲望之类的东西。神爱能够取代欲望流动，把我们的注意力转向心灵爱流。把我们置于不同的领域、超越的意识。自我开始减弱，心灵之眼打开，心灵越来越纯。好比黎明降临；这就是灵性觉醒。
