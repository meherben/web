美赫巴巴乃神爱之不灭甜美。我们被其神爱存在的无量甜美包围，此乃一切空间之真性，完完全全地渗透我们，其实就是我们自身的真性和存在。——达文·肖

随着在精神上逐渐地成长，我们发现再也无法容忍自身的某些行为、思想和情感。也更多地觉知到那些与我们内在生命相容的行为、思想和情感。我们越来越想有内心的平静，这意味着更多的和谐、提升、更多的内在光明和越来越深刻的价值观。我们看到，这与其说是接受一门教义，不如说是淘汰那些在我们不知不觉中影响我们的东西。

我们正在努力走向神性——神圣的存在、爱与真理；这超越一切法则，不为任何事物支配或取代。这就是巴巴所拥有和给予也是支撑他的东西。我们来到他这里，他的神性也支撑我们。他将我们从那些统辖较低意识层面的次要法则中提升出来，并将我们置于“无法则法则”的神爱法则之下；这意味着我们将获得完全的自由。当然，我们因为目的诚实，而不会钻空子做错误的事情；相反，这会让我们摆脱想做任何非至纯之事的意愿。

对大师的爱、信任和亲密感，逐步提升我们的意识并创建一条开放的通道。这虽然进展缓慢，却是真正的工作，持续地提升我们意识。所以说我们要用一生的时间努力摆脱潜意识的制约，以便停止用错误观念来限制大师或者说上帝。大师帮助我们看穿这些有关大师和我们自身的错误观念。认识深化为洞察力。我们看到自身怎样被印象捕获，意识怎样被业相模式拖累。

一旦调到大师的频道，就是在接受他的帮助——不管我们是否意识到。在他的帮助下，印象溶解，心灵中心打开，爱流动。皇冠宝石即神爱流动。每个人都应平等地感到同他的亲近感；谁都不必感到自己被排除在外。所有人都可以平等地同他建立关系。他不会厚此薄彼；人人都注定要与神亲近。

给灵魂穿上巴巴

1954年，在印度，美赫巴巴接连几天暗示说，他将给我们一项特别的修行，将让我们随时体验到他和我们同在——无论我们在做什么，工作还是闲暇。他把这种修行称作“自然禅”。我听见他这么说，就自忖：“哇，这一定是某种玄奥的东方修行、密法。”

到了那天，有人问：“您要告诉我们的是什么方法？”巴巴解释说，自然禅的意思就是自然静心；你早晨起床，第一件事就是“给灵魂穿上巴巴”；到中午，做同样的事情——给灵魂穿上巴巴；下午5点左右，再做一遍；最后，在晚上睡觉前，再次给灵魂穿上巴巴。巴巴说，这就像整理领带，只需几秒钟。每天几次，给他几秒钟的时间，意识就有可能得到显著提升。

通常，一般人，尤其是上班族，一睡醒就不得不盘算当天的日程安排。不过，你仍然可以按巴巴所说，用几秒钟给灵魂穿上巴巴。这为一天定下基调，让你准备好应对摩耶。临近中午，你开始看表。“还没到12点。”于是在11点半、11点45分、直到正午，都想起巴巴。快到下午5点时，同样如此。就这样，过一段日子，你就会养成大部分时间都在想巴巴的习惯。

同时这也促使你想弄明白“给灵魂穿上巴巴”的意思。灵魂在哪儿，巴巴是谁？这涉及到你的感受和认同，涉及到方方面面，实际上让你调到巴巴的频道。

我感到巴巴希望我们思考“给灵魂穿上巴巴”的含义。他已经获得神圣自由，因此我们不应重新陷入身体习惯和人格范式，而是要给灵魂穿上巴巴的意识、而非我们的低级意识。这会抵制其他急于进入的思绪，使之停在某条岔道上。

对我而言，“给灵魂穿上巴巴”意味着肯定灵魂的真实身份——你的真性。给灵魂穿上巴巴，等于接受仁慈之主及其一切：永恒救度、安全、持续的恩典、神圣的爱、纯、真、美。这能或多或少捕捉巴巴的综合临在、神的临在，并让这种临在充溢我们的心灵和内在生命，而非沉迷于各种业相兴趣——只是为了让头脑忙碌不停。

换言之，我们在主导局面，自主抉择，而不是被业相的呈现所侵害，随波逐流。随着精神成长而做越来越好的选择——这都取决于我们。我们选择控制自身的反应；一心专注内在之神（大师）；当即给灵魂穿上巴巴；完全地信任他，接受他所提供的一切。

保持流动

我们给灵魂穿上巴巴的同时，也放下诸如人格等局限，升至更高意识水平。我们到达并享受高级意识状态时，会无意识地倾向于试图抓住体验并使之结晶。但它会溜走，由不得我们。我们则想方设法重获那种体验。

灵性生活的秘密之一，就是持续地保持流动。我们学会抵制那种想要抓住灵性体验的倾向；不再试图贮存那些体验的残余。我们通过变得流动，建立一种新节奏；让一切流动。

我们信任大师时，就全心全意地信任他，无须抓住某个事物，即便是灵性体验。我们让暂时的体验来来去去，知道随后还会有更多。但是真正的东西，真正和持久的幸福，将成为正常流动的一部分。爱的新节奏产生——我们该怎样对待自身思想、情感、欲望和残留体验（业相）的新节奏。

我们本应保持流动。我们有一股流动的能量，这在灵性文献中有时用数字8表示。我们通常让能量流入，以便改善自我，给予我们更多的财物、更重要的身份、各种自私的事物。我们误以为必须这样做才能体验幸福。但美赫巴巴指出这是一种误解。实际情况恰恰相反。正如巴巴所言，“真正的幸福在于让他人幸福。”

作为对无意识征服的一部分，巴巴来把能量重新导向灵性。当我们把意识连上他的意识时，我们的能量就流向他，被清洗干净，再流回我们——这在形式世界可被称作“给予”的能量。因此我们必须同他合作，努力改变能量的方向，使之保持流动，尤其当我们的反应导致流动减慢或停滞时。这还包括怎样学着把一切交给巴巴，放下一切，并且坚持这样做。

渴望拥有渴望

作为重新导向我们的能量和把低级欲望转变为更高目标的途径，美赫巴巴强调了渴望真理、渴望神的重要性。我们通过把想象转向更具建设性的目标，来减慢欲望机器，关掉发动机。这就是升华。

无法将束缚于欲望的能量一扔了之。我们将欲望的能量转向更高的事物，而不是试图阻止或压抑欲望。否则我们只是在火上浇油。从灵性的角度来看，我们将之升华为对神、爱或解脱的渴望。这并不容易；而是一个成长的问题。我们每个人都必须找到适合自己的方法。

我相信，升华就是新的密教。在升华中，我们怀着爱和渴望，抛开一切条件，走向作为第一因的神圣至爱——无限上帝。

我们倾向于无意识地认同自己并不真想要、但欲望本性却让我们紧抓的事物。这就是为什么这些东西还在，因为我们不放手。但是总有一天我们必须走向第一因，溶解整个幻相。此乃完美升华。

渴望之礼物

渴望在灵性道路上必不可少。渴望会耗尽低级的欲望。1934年我在纽约首次见到美赫巴巴，他在那三天给我注满了爱和对灵性生活的强烈渴望。越充满巴巴的爱，就越感到渴望。当时我并未意识到这是一份大礼物——巴巴将这份渴望赐予我，这是我们所有人都需要的。

对神的渴望如同汽油之于汽车。渴望给灵魂提供燃料，提供抵达实相的能量。渴望的能量就像钻孔机，穿透很多内在障碍，烧毁束缚我们的业相。尤其是抵消我们的欲望本性，重新将能量导向发现内在真理。

我逐渐认识到，努力培养和鼓励这种渴望是极其重要的。例如，我们可以阅读圣人的作品和巴巴的著作，特别是激励爱的内容。我感到，我们一旦瞥见了内在生命，就会意识到这才是我们真正想要的，就不会想走岔路，虽然我们确实会一次又一次偏离方向。发生这种情况时，我们只需要努力回到正轨，朝真正目标前进。当我们成熟时，自然会转向神，渴望回归神。

翻译：石灰  田心
