谁认为我是什么，我就是什么。——美赫巴巴

神圣恩典取代一切律法。此乃美赫巴巴的真相：神圣恩典。我们却习惯于在意识中制造局限和有限。通过无意识的编程——给潜意识装满有限信念——用局限教育头脑，使之变得暴虐。

就这样，我们制约着巴巴改变我们内里的能力，也局限着我们自身的能力。这些我们认为真实的局限，完全是自我编程的。最好是牢记巴巴的话，“一切的有限和受限，皆是主观自造的。”

我们每时每刻都在进行这种编程，大多数时间却意识不到。必须开始认识到自己在头脑里，在意识里编程什么，找到能在哪里有效地运用信心和自信；而不是成为一切发生的受害者。耶稣说，“当你祈祷，相信你已收到，你应接受。”（马太福音）；美赫巴巴也在不同场合说过实质同样的话，比如，一个人深思什么，就成为什么。他还表示，你想自由，就会自由——你真想要神，就会成神。

所以说，觉知自己是怎样编程的，是怎样将有限范式强加给自身意识的，很重要。美赫巴巴说，“只有当一个人有力地将生命掌握在手中，打破旧模式，坚持按自身内见创新时，才会在神圣图画上绘出新的线条。”

作为求道者，我们需要创造的新范式，包括纯洁、自灭、爱等至高品质。要抵消旧范式，就得坚持将那些品质作为我们的原型，以便新范式得以产生。

编程痛苦

在某种程度上，我们是自身最大的敌人。倾向于无意识地编程负面暗示，不自觉地消耗能量。结果是受苦。美赫巴巴说，“人类百分之九十九的痛苦是不必要的。”还说，“人因顽固无知，将痛苦施加给自身及同类；却奇怪地问，‘我们为什么要受苦？’”我相信那百分之一的“必要”痛苦是为获得自由、丢开局限所必要的手术剧痛。

自找的痛苦坚持不去，是因为我们不信任神，不把一切交给他。“巴巴的希望”中说，“当你受苦时，就想：‘巴巴想让我受苦。’”我感到这是他在告诉我们，停止自我编程，向神对我们的计划——他的编程——敞开。巴巴不想要我们受苦，而想要我们专注于他，作为停止无意识编程循环的途径。

于无形处编程

我们不停地对“因”进行工作，在原型层面编程。我们根据某个信念，在无形中创造一个原型。之后它被显现出来，我们所体验的“果”，则强化并维持原来的信念。

从心理学的角度，我们的潜意识接受并回应“暗示”。在原型编程中，回应的是宇宙心，它通过我们的潜意识工作，径直将暗示显现出来，仿佛是一项命令，不管是否准确、明智、甚至可行。

宇宙心和我们的潜意识不受先例或浊障碍制约。当然这可以对我们有利。真相是我们乃无限精神，与神一体。如果我们立足于真理，这就会显现，成为我们的体验。

宇宙心是创造性的，不是毁灭性的。它没有识别力，而是自动回应暗示。它没有人格，没有观点，没有私心。但它作为神的一个方面，却有某种个人性，完全无害。这就是为什么我们能够感受神或无限的人格临在，为什么我们能够同他为伴，感受他的引领。

“我是......”

美赫巴巴说，神人阿瓦塔比无限上帝更强大。他有意识地与宇宙心合一，能够并确实以宇宙心的万无一失、不可战胜、绝对可靠之属性，又以对我们个人和造物界的充分意识，来回应人们。

他对我们、为我们的目的，是要我们快乐，又要把我们从世界幻相和错觉中解放出来。但我们却限制他。1954年，在一次达善活动中，巴巴一边给来自各阶层的数千人施达善，一边转向我们西方人，说，“我爱他们全体，无论大小、高低、贫富——所有的人。任何人把我当作什么，我就是什么。”他说这话时，我感到他指的是其形体背后的无限生命状态——宇宙心或者说无限上帝。

其它很多场合他也说过类似的话，比如，“对每个人，我似乎是他所认为的。”“我在你里面，宇宙心能够在任何时间，把任何东西，给任何人。只是遵从如下指示：爱我；不欺骗；不做恶。我将和你同在。”这些话意义重大。哪怕初步的理解，就让我们认识到同大师的关系是多么重要。

将巴巴看作无限上帝（或宇宙心），即接入能力、能量、真理和实在的人格和非人格线路。这就是阿瓦塔和至师的意义。他们意识到我们和我们的业相困境，是能在个人层面转化我们的“变压器”。

作为有意识的宇宙心，巴巴回应我们的每一个心血来潮。还回应我们对他的看法和感受。这是因为他是我们对他的形象的反射。把有限观点投射于他，是在局限他对我们的工作。

例如，如果我们把他当作法官，那么我们的主观、自造体验就会是受他审判。也就是说，我们把他当作法官，他就成为法官。把他看作大师和朋友，他就是我们的大师和朋友。我们同他的关系取决于我们怎样看他，怎样待他。

通过无限之神还是通过美赫巴巴进行编程，结果都一样。但我感到，通过巴巴，具有明确的优势。我认为，这帮助我们更多地体验神的人格方面，尤其因为这是巴巴采用人身的原因。

第一因

大师能够并将会对我们做什么，全在于我们。因此，我们最好承担起自身的编程，将注意力从外部条件层面转向大师本人，一切万物之源。

我们过于溺爱自造的环境，花大量时间予以反应，认识不到世界，乃至思想感情世界，只是‘一个果”，不是“第一因”。

陷入连锁反应

美赫巴巴说，我们是一切现象的制作者；从自身投射出万物。他要告诉我们的是，我们在创造自己的世界——物质世界、感情世界和思想世界，因而也能够随心所欲设计、制作之。1954年在印度，巴巴引用门徒拜度的话，“我们制造一切，却傻瓜一般成为自己主宰之物的奴隶。”

我们若把幻相世界——而非神或大师——视为第一因，并把反应建立于这个错误的前提，即是制造二度错误。陷入连锁反应，其中一个事件（一个“因”）导致一个反应（一个“果”），这个果又成为下一个反应的因，等等。随着因果链继续，我们在错误中越陷越深。发现自己整个时间都在应付偶然事件；不停地预设，除非一定的条件满足，一些条件才能产生。

神的编程

然而对于神，却没有偶然或局限。所以，不要继续同条件斗争，而是需要后退，径直走向作为第一因的神圣至爱：我们的朋友、至爱，比我们更希望我们获自由的全能之因。这意味着专注作为第一因的大师或神：对我们发生的一切事件之因。之后回应其作为第一因的编程结果，也就是其无所不能、无所不知、无所不在等所有属性导致的结果。这样做，就能改变我们的念头、意识、潜意识——以及环境。

必须认识到，美赫巴巴作为第一因，完全不受限和“不确定”，也就是没人能够制约他。因不受偶然事件所束缚，一切貌似牢固的障碍对他都不算什么。我们需要把全部注意力放在巴巴身上，不去管境况等一切次要物。由于在因果层面、条件层面生活，我们受制于担忧和各种各样的幻相，体验疑虑和恐惧。不要管那个层面。要走向作为第一因的巴巴或神。

安住于第一因

对一直坑害我们的幻相，必须看穿。通过从条件层面升到第一因，并认识到这些条件只是心的机械作用而已，则容易做到这一点。留在第一因层面，会认识到这些幻相仅仅是想象的产物。守在第一因层面，则可能会体验意识的清晰，心的平静，乃至极乐。

因此我们必须学会安住于作为第一因的大师或神，安住于那个观点。安住于第一因，是我们所能做的最实际的事情。呼吁巴巴本人，不要依赖小小的偶然。他是一切问题的解决。真正地如此看他。

安住于第一因，要求充分信心，信心取代理智。因为生活中的一切情景皆想象，受变化的快速影响。我们发现，没有一物一成不变，万物都会瞬间发生变化，无论处于什么环境。因此，似乎固定不变的情况，也会即刻变化。芥子大的信心，能够制造奇迹。这千真万确。

知识的价值

要让无意识的编程成为有意识的，涉及到利用宇宙的替代秩序，它们不是奇迹，只是一套不同、更高的律法。从这些更高律法上运作，不是一般意义上的施展奇迹，而是利用我们的智能，遵守宇宙的推动力量，该力量完全仁慈，祝福万人万物。

也许这一切知识的最大启示是，我们能够怎样准确无误地依赖神、巴巴、宇宙心。信心可以转化成确信。明白这个道理，你就能真正放心地在每一个情形中依赖神。从而能够从那个角度工作——努力越来越信任神，相信真理将取代摩耶。就会知道无须同这个那个烦恼、这个那个问题搏斗。

我们应把全部的信心和信任置于大师或神。必须认识到他能够做任何事情。我们信任大师的指引时，他就能够并且实际引导我们。这就是把自我意志臣服于神意的含义。也就是我们愿意抛开自己的选择，接受神的意志。这不是要我们忽略生活条件。而是尽最大努力不担忧，信任神。我们完全信任他时，就把责任给了他。他能够照管一切的问题。安住于第一因，实际上就是把一切交给巴巴，体验自由。

田心译自《努力与恩典》第14章
