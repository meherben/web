  7 分钟阅读  

心地纯洁的人有福了，因为他们必得见神。—马太5 : 8

通过精练过程，人人被塑造成人间圣殿。这个过程始于我们与无时限精神认同，并认识到这可显现于我们生活中时。

内在道路由通向真理的踏脚石构成，我们在精神的层面运行。通过摈弃虚妄，走向神，走向美赫巴巴，走向内里实在， 因为要体验真理就须摈弃虚妄。随着在精神里运行和更多光明进入，我们体验到提升、无时限和喜悦。这不是同负面事物搏斗，而是加强正面的，越来越爱神，渴望纯爱，纯真理。

道路还涉及到努力找到内在的神，努力在内里感受神的在，感受圣爱、圣恩、圣美。道路对人人敞开，巴巴说最终每个人都会走上此道。

神圣博弈

认识到自己是多么接近灵性道路，开始内在工作有多么容易，需要时间。我感到这不是遵循某个教条或者纯粹接受某个信仰的问题，而是解决具体的业相面罩的问题，这些面罩由我们的思想、感情和欲望构成。换言之，这不是对“外物“工作的问题，而是在内里工作，解放意识。涉及到将关注置于何处，对渴望何在的觉知。

可幸的是，我们无须像早期基督徒那样，同狮子一道被扔进竞技场。不过，我们面临的东西更糟糕——欲望本性！尽量减少充满欲望的自我，需要注意无数的细节，发觉可持续做的小努力。

我喜欢从神圣搏弈的角度看。不是教条或体系，而是设法抵制自我的妄求。该神圣搏弈是“自身游戏”，目标是“将死”妄我。涉及到努力改变乃至最终消灭业相。

如在棋盘上移动棋子，抵制狡猾的敌手，我们也要采取行动，抵制阻挠我们前进的业相势力。为适应每一种内在新情况，须提前几步制定战略计划。毕竟在战役当中，不是着手制定战略的好时候！

每个人都能学会预测引发自己强烈反应的东西，并发展出最佳策略，抵制封锁在自身业相里的能量。在各种情形下都须小心翼翼，知道该怎么做。例如，“欲望”含有巨大能量，可通过把它转化为灵性渴望，也许只是读一些励志书籍，来引导或升华冻结于欲望业相里的能量。此例可以说是一着棋。另一着棋是不忘世界只是幻相这一事实。还有一着是把自我歼灭看作正面的事情。这种貌似微小的内在棋步积少成多，到一定时候就能戏剧性地转化内在力量。整个过程相当于清理或净化心灵中心。

心灵位置

一切的善和一切的恶，皆产生于心灵。耶稣讲到心灵的罪恶，心灵的纯洁。1954年在印度，有位西方人要巴巴解释耶稣的话“心灵纯洁的人有福了，因为他们必将见神。”于是一天下午巴巴给我们讲了心灵是什么，它的位置，它与思想功能的关系。下面是我当时对这段精彩语录的笔记：

心有双重功能。潜伏的印象必须处理解决，于是呈现为念头。心的这个思想功能被吠檀多教徒称作末那。心的第二个功能属于情感、感受；被称作“安塔-卡拉那”；意思是心灵。因此，所谓的心灵实乃心的第二功能。

印象（亦即业相）通过思想感情加以消耗。念头仅属于心的第一个功能。各种各样的念头。情感和欲望属于心的第二个功能——心灵。所有的苦、乐、失望、幸福、震惊等情感，皆属于这个安塔卡拉那。事实上，在酣眠中——你睡觉时——印象处于潜伏状态。……

那么是什么将你从酣眠中唤醒？印象。印象唤醒你。行为的印象。这些印象首先通过念头，之后通过欲望，再之后通过行动消耗。所以奎师那在《梵歌》中说，“只让印象通过思想消耗。”这样就不会形成新的印象。你若做不到这一点，那就让印象通过欲望、渴望、情感消耗掉——但不要通过行动。这样，新的印象也会形成，但不会那么深。

若将印象付诸行动，新印象定会形成。这说明心的第一个功能不重要。它是自然的。重要的是心的第二个功能，因为它是欲望所在地，除非心灵（心的第二个功能）摆脱了一切欲望——所有的情感，也就是说，除非心灵纯净赤裸，否则神——你的最内在大我——就无法显现自身。

所以说心灵是心的情感层面；意识的思想和情感层面皆是心的部分；甚至在我们无肉身时，心也存在。 作为未表现倾向潜伏于潜意识的业相，首先呈现为念头，接着（若未受阻）表现为情感，最终（若未受阻）表现为行动。巴巴解释说我们受各种各样的业相驱策，他还强调思考与行动的区别，及其结果的不同。

巴巴说，不要担心情感和行动念头。它们也造成业相，但同身体层面的表现相比微不足道。因此，被欲望或强烈情感围困时，我们应在内在情感层面削弱之，不付诸行动，否则便做了最糟糕的事情：播下更多的同类业相种子。

打开心灵中心

美赫巴巴说，他给我们读的书，是掌握着生命奥秘钥匙的心灵之书。这说明心灵是多么重要。因此，我们的很多工作需要集中于把心灵从业相冲动中解放出来。这项工作要通过心灵中心，也就是与主观、潜意识层面相联系的情感中心，而非智力推理功能。通过情感中心功能，觉知生命的精神层面。

巴巴尤其强调敞开心灵的重要性。此乃灵性道路有意识地开始之处，因为我们是通过心灵，意识到情感和欲望层面的业相的。也是在该层面能够体验神圣之爱、美、自由、喜悦的充实——结合自我消灭，即放弃分别我的观念。

巴巴说，“自我是对自他分别的肯定，爱是对自他一体的肯定。因此只有通过真爱才能消解自我。”所以我们必须学会怎样在不受“自我”污染的意识里，保持爱的流动。这涉及到净化心灵，让爱通过心灵中心流动。爱经由净化的心灵流动，我们也随之散发真、爱、美、纯等神圣品质。这即是我们的目标。

让爱流动，不想自私的东西，有助于溶化基于错误观念和愚昧无知的自私，从而消除意识里的面纱。这并非刻意地强迫思想或情感，而是细致得觉知到自私念头是怎样形成于欲望，这些欲望来自何处，这一切引向何方。

随着内在工作，我们注意到自己的意识更安住于主观层面，对世界的反应即从该层面流出。价值更明确。看到什么业相驱策在经过，并能做出英明举措加以抵制。

因此，真正的工作不是智力训练，引向特别知识，而是学会怎样敞开心灵中心，这意味着超越业相冲动之层面，让爱自由流动。

心灵纯洁

1958年，美赫巴巴在美国的最后时刻，对我们说，“我在你们每个人里面。但只有你将别的一切从心中驱除时，我才能进入。”他又说，“我是神。我在你们每个人里。但我感到害羞；若发现你心里有一丝不洁，我就不进去。”他没有说我们得从“坏”变“好”，而是要我们从心中清除不洁物，也就是念头和欲望。

心灵的纯洁意味着神的纯洁。爱和内在自由一旦产生，心灵纯洁就作为副产品自动跟上。因此我们不是集中于纯洁本身；那易于引向自我主义。

骑士与少女

发现我们内里有个巨大爱库，学会怎样打开心灵中心，爱就能涌出，是件美妙的事情。在美赫巴巴身边，我们很多人都会觉知到心灵中心的打开，爱流溢出来。他的爱就像是虹吸管，抽出我们对他的爱。我们情不自禁地爱他。结果认知大大加强，发现自己置身于深得多的意识层面，并能在内层面更空前清晰地识别价值。

我们发现自己被新的力量支持，因为新的能量得到释放；同新能量和洞见一道，是对内在念头、欲望和情感的更大控制。世界不再强加于我们，而是越来越受我们控制。这都是心灵的一个功能，因此让心灵敞开和软化，极其重要。

在童话故事里，身着闪亮盔甲的骑士保护美女。这是个脑心譬喻。头脑对防御心灵中心的平衡很有帮助，心灵最靠近灵性领域，应该占主导。骑士帮助保持爱经心灵中心流动，同时对可能试图涌现的业相冲动给予关键控制。

我们寻求的是头脑的和平，实际上也是心灵的和平。这意味着和谐，提升，更多内光，越来越深的价值。我们须自问，最重视什么。若看重头脑的和平，心灵的和平，就会付出努力，防御心灵，藉此就能够见神。最后，体验脑心的高度统和。这时，如美赫巴巴所说，“妄我成为真我的爱者。”

业相坑洼

毫无强制地控制自身思想和情感，是件微妙的工作——努力，是的；但不是强制。这是个识破业相情结和采取闪避行动的问题。业相情结建立在错误知识、信仰和局限的基础上。这都关系到个人的特别业相。

就像是在熟路上散步。我们了解湿滑地带、坑洼和路引向何处。头几次也许犯错，掉进泥坑，但很快学乖，绕开陷阱。

从经验中得知业相将我们引向哪里后，就会认识到必须趁早将它们导向。经过一定时间，我们就能看到业相压力的开端，着手在其最早显现阶段加以抵制。好比铁路工人观察一辆火车缓缓行进。突然看见一节“脱缰”车从相反方向奔来。他迅速用道岔把后者转入侧道。微笑着看前一辆火车离险驶过。前一辆车代表真理，脱缰车代表业相造成的无知。我们是能够学会下意识躲闪的：麻烦苗头一出现，即刻岔开思想感情列车。

我们须学会怎样操纵心，以获得更大的控制——不是有意地压抑，而是重新导向能量，体验更大自由。最终，思想模式不再控制我们；反受我们控制。这不是盲目的控制，而由对真理的认识和服从所支持。逐渐地觉知到一切其实都是幻相。我们也成为爱的渠道，爱的江河，爱的海洋。
