**“他是神吗？” **

1939年，美赫巴巴在印度南部的班加罗尔做玛司特工作时，当地的三个少年来帮忙：阿穆杜（Amdu），文寇巴（Venkoba）和克里希纳·奈尔（Krishna Nair）。工作结束后，巴巴下令拆除玛司特中心，并把很多玛司特带回美拉巴德。离开前，巴巴把三个少年叫来，说他们有什么要求都可以提出来。阿穆杜想要一辆马车，文寇巴想当商人。巴巴打手势恩准，后来二人都如愿以偿。轮到克里希纳时，他说想跟随巴巴，也获准留了下来。

1946年，克里希纳在德拉敦（Dehra Dun）郊区为巴巴守夜。巴巴往往要求守夜人保持绝对地安静，不可弄出一点声音来。克里希纳被蚊子咬得厉害，就轻轻地拍击，赶蚊子。这干扰了巴巴的睡眠，巴巴把他叫进来，责备了他。克里希那不高兴地想：“巴巴说自己是博伽梵，却不体谅服侍他的人。他是神吗？”

通常，为巴巴守夜的门徒第二天可以睡个懒觉。但克里希纳早上4点刚值完班，巴巴却出乎意料地叫他去吃早饭，然后找辆马车，5点钟出发，跟巴巴一起去哈德瓦（Hardwar）联系玛司特。

这个玛司特叫“南伽巴巴（Nanga Baba）”，一半玛居卜，一半撒里克。也就是说，他有时候融入神，有时候意识到造物界。他已经在一棵树下单腿站立了好几年了，每六个月换一只腿站着，还一直保持静默。他有很多跟随者；巴巴到达时，他的跟随者却一个都不在。南伽巴巴一看见巴巴，立刻双脚并立，合掌，开口说话：“啊，博伽梵！我等您已经等了很多年了，您终于来了。主啊，让我解脱吧！”随即拜倒在巴巴足前，啜泣不止。

一周后，巴巴派克里希纳再次去看南伽巴巴，并让他带上鲜花和一杯水。克里希纳到时，却发现那个地方围着一堆人，原来南伽巴巴已于当天早上死去。他的一个跟随者说，玛司特的临终之言是：“我亲眼见到了博伽梵，并得到了他的祝福。我此生的任务已经完成。”他的面部极为安详喜悦，散发着巨大的平静。 克里希纳把鲜花放在他的尸体上，洒上水，就离开了。

这次经历让克里希纳恢复了对巴巴的信心，从此愉快地服从大师的命令。

克里希纳·奈尔的婚事

1942年，美赫巴巴在德拉敦居住期间，克里希纳守夜。克里希纳有个习惯，在守夜前，他每天晚上5点钟散会儿步。巴巴的住房对面有一所女子学校，有4个女孩子经常偷看克里希纳，其中一个女孩子邀请克里希纳陪她散步。克里希纳不愿跟女孩子打交道，就朝她吐了一口唾沫。女孩的感情受了伤害，便向巴巴告状。

巴巴把克里希纳叫来，问明缘由后，批评了他，并让女孩子用凉鞋打他，让他向女孩子顶礼道歉。女孩子离开后，巴巴问他为什么那么做。克里希纳答道：“巴巴，我不想碰任何女人；我不想跟女人有任何联系。”

巴巴在字母板上拼写道：“你说你不想碰女人，但你会结婚的！你还会有个儿子！他还会哭，他哭时，谁去照料他？”

“不，巴巴，我不会结婚的。”

“你向我挑战吗？”巴巴问道。

为了表示决心，克里希纳还写下了血书：“我不结婚。”

四年后，1946年7月，巴巴在回Niranjanpu前，给克里希纳一个月的假去看望母亲。刚到家没几天，母亲就开始张罗他的婚事。克里希纳写信向巴巴请示，巴巴的回电只有一句：“服从你母亲的意愿。”12天后，克里希纳结婚了。婚礼的第二天，巴巴来电报要克里希纳立刻返回。

克里希纳一到，巴巴把其他门徒支走，问道：“你结婚了吗？新娘漂亮吗？她爱你吗？”

“巴巴，我总共跟她呆了8个小时，怎么会知道她爱不爱我？”

巴巴说：“她比你好。你不晓得她有多爱你。”

后来克里希纳按照巴巴的指示，回家生活。

1949年10月，在新生活开始之前，巴巴召见克里希纳，派他去全印度的各个宗教的名刹古寺朝圣——印度教，伊斯兰教，琐罗亚斯德教，基督教等等。他每到一处，都要在这些圣地顶礼，并且念‘美赫巴巴’的名。巴巴还让韦希奴给他拨出2000卢比做为开销。克里希纳从贝拿勒斯（Benares）出发，用了七年半的时间，完成了这次大朝圣。就在上路前，克里希纳收到家人的来信，说他妻子生了个儿子。巴巴叫他对此事儿保密，等门徒们都到大厅后，巴巴当着众人的面，突然问道：“你的妻子和儿子还好吧？”

其他门徒都无比惊讶。伽尼医生说：“巴巴，您这是施的啥奇迹啊？克里希纳没有老婆，却有了儿子？”

巴巴叫韦希奴把克里希纳于1942年写的血书拿来。韦希奴用了近一个小时才找出来。巴巴举着纸条说：“这个坏蛋还向我挑战，说他不会结婚！现在他却娶了妻，生了儿子！”

尼鲁医生插话说：“巴巴，克里希纳背着我们结婚，还没有庆贺呢。得请客！”

巴巴揶揄道：“你们别看着我啊，结婚的那个人又不是我。请客的应该是克里希纳。”

不过，巴巴还是给大家买了糖果，来庆贺这件喜事儿。

田心译自《美赫主》和《神人剪影》
