普纳

1959年4月9日

亲爱的家人们：

3月7日清晨，我们依依不舍地向美拉扎德挥手作别。那天恰逢印度教历法的吉日——希瓦神节（崇拜主希瓦的盛大之夜），也是全国性假日。在普纳，我们在古鲁帕萨德停车用午餐（由深爱巴巴的埃瑞奇家人送来）——然而尚未进食或休息，巴巴便带满德里去了一位非常亲近的爱者伽德卡家，并拥抱了病重的他。伽德卡是早期弟子之一，其“生活本身便是向他人传递的巴巴爱讯”，病中他不断呼喊的便是“巴巴”。他深受大家敬爱，普纳的巴巴小组会为他唱诵令他心悦的巴巴-巴赞，以帮他熬过痛苦长夜。此次珍贵的会面我并未在场，所以本不应由我来记述此事，但至爱归来时脸上洋溢的爱与喜悦足以说明一切。几天后，我们接到伽德卡去世的消息，巴巴告诉我们，唯有他知道伽德卡是多么幸运——他同样在弥留之际呼喊巴巴的名，已经永远来他这里……

我们照例在孟买的达达禅吉家度过一周，期间在多重意义上都无比充实——因为他们怀着深爱照顾我们，让这段时光远不止是一场假日。不过恐怕“假日”二字并不适用于亲爱的巴巴，因为此次到访期间，他从不停歇、毫无保留地奉献自己，接见数以千计的人。在每天上午8点至12点的规定时段，他们前来达善巴巴，人人都得到他的拥抱。刚到9点，门厅与楼梯便已挤得水泄不通，长队一路延伸到屋外，沿着道路经过我们窗下。透过窗户，我们可以瞥见一列衣着得体的人们，他们来自各行各业，宗教背景各异——大多数人手捧鲜花，许多人还带着自己的孩子。其中有不少人此前从未见过巴巴，然而一旦见到他，便不舍得离去；总会一次次再来，并带来亲朋好友，希望与他们分享自己寻得的这份珍宝。通常12点，巴巴会离开达善房间，显得容光焕发，却也难掩疲惫，柔软长衫与粉色外套的后背已被汗水浸透（尽管开着空调）。即便在此之后，他也常常折返，拥抱某个恳求见他的迟到者——凡来寻求他的爱的人，都无一空手而归。

仿佛上午的活动还不够辛劳似的，巴巴又主持了多场下午的活动，全然不顾他的身体亟需休息。一天下午，在桑德拉拜礼堂举行了卡瓦里演唱。礼堂容纳了数百名爱者，使他们有机会享受他数小时的珍贵撒晤斯。13日下午的活动尤为特别——巴巴访问了瓦达拉的圣约瑟中学。此行既是应校长雷戈神父的亲自邀请，也缘起于一位巴巴爱者（负责该校慈善医务室的女医生）多年来的无私服务与爱之劳动。1400名学生逐一走到巴巴跟前，接受他的帕萨德与拥抱。应邀对学生们讲几句话时，埃瑞奇拿起麦克风，以质朴有力的话语“介绍”了巴巴——这些话不仅直抵学生们（目标听众）的心底，更让在场所有人深受触动。遗憾的是当时未记录这番话，故我仅能向你们略述大意。埃瑞奇向他们解释，“美赫巴巴”之名的字面意思即“慈父”——可他不仅是慈父，还和众生处于一切的层面。“所以你们可以把他视作你们的朋友、兄弟、父母乃至你们的神——亦或所有这些，因为他是你们将他视作的一切。”随后他回忆道，过去做学生时，听说某位贵宾要到访学校，总会非常激动，难免好奇他们会讲些什么。“现在这位来宾却不言说！他来给你们的不是言语，而是爱。他不是来给你们演讲，而是来祝福你们；不是来教导，而是来唤醒你们。他不是与你们握手，而是作为慈父拥抱你们。有一天你们将会意识到，你们今天真正领受的东西的重大意义……”

从那里，巴巴径直驱车前往盲人就业之家，此行是应一位深爱他的名誉秘书之邀。这些来自不同宗教、多才多艺的年轻人，向巴巴展示了他们如何织布、制作篮子和椅子等等。而最能表达自己的是他们的管弦乐演奏——巴巴则带着无限温柔的微笑注视着他们。接着，每个人向巴巴献上一朵小玫瑰，有位满德里后来（描述那种气氛）说，当巴巴拥抱这些盲人时，每一张脸都发生了惊人转变，仿佛其内心的一盏明灯被开启……有个小伙子问巴巴，他因何如此不幸目盲。巴巴说他并非不幸——他只是不知道自己的幸运。他说：“众生皆目盲，连那些你认为看得见的人也目盲，因为他们只看见非真实之物。你也看不见真实，但在一种意义上你是幸运的：你同样也没有感知到虚假——只是你的复明欲望在束缚你。因此，切莫要求肉眼视力，而要求赐真视力——它将使你看见唯一值得见者，唯一存在者。时刻持我的名，不断地想念我——我把我的爱与祝福给予你们全体……”

至爱的临在犹似赐予生命的活水，再次让古鲁帕萨德重焕生机；幸运者们乘此赐予东方的良机，纷纷前来畅饮。我们在普纳的逗留，始于每日寻求达善者的蜂拥而至——其中不仅包括普纳的巴巴爱者及许多“新人”，还有来自印度各地的诸多小组，有的多达70人，往往需要坐三四天的火车才能抵达。加尔各答组的带队者是一位高等法院的法官及其家人——他们此前未见过巴巴，正在当地筹建巴巴中心。他们临别时留言：“我们虽然即将离开普纳，却把自己最珍贵的部分留在您的足前”……每逢周日则更像撒晤斯，众人围聚在至爱身边，倾听虔诚的年轻巴赞组令人萦怀的唱诵。巴巴身着粉色外套，容光焕发如太阳般，无一丝倦意——尽管我们深知，他经历了上午连续不断的活动之后（有时甚至延续至下午），他必定甚感疲惫……不过事情就是如此，并将永远如此。他作为完美之化身，扮演着“人”的角色，而正是这一人性面，永恒地昭示着他就是那一位、他对人类的无尽之爱、以及他于奴役中的主宰……

根据新通告，自4月1日起（为期两个月）只有周日可以达善巴巴。不过，2日这天却有个独特而令人愉快的例外：巴巴接见了即将赴英国参加锦标赛的印度板球队。自学生时代起，板球一直是巴巴最钟爱的运动。在一个格外辛苦忙碌的上午，我们听见巴巴评论：“可怜的阿瓦塔有这么多事要做，而此刻他更愿看一场精彩的板球赛。”巴巴拥抱了每位队员，埃瑞奇宣读了巴巴授予他们的特别讯息。该讯息登载于多家报纸的体育专栏——有英文报、本地语报，有地方报、全国报（有些还配上巴巴与球队的合影，以及巴巴的单人照），标题有《一线曙光》、《球队获美赫巴巴祝福》等等。临别时，巴巴再次拥抱每个人，送给每人一份他的讯息，说道：“带上我的爱，你们将发挥出色。”那是个不同寻常的上午，看到板球队员们离开古鲁帕萨德时，脸上洋溢着希望自信与爱戴崇敬，真是让人振奋……

受时间与篇幅所限，无法将所有事件及细节都写入信中——但我必须再补述一件事，知道你们定会乐于听闻……住在宫邸庭院里的那位看管人，除了有个大家庭，还养着几只山羊、猫和一条皮毛柔滑、神态欢悦的可爱狗儿。我们时常看见，那条狗与某只山羊以极为独特的方式一同玩耍——既尊重彼此的玩耍方式与规则，又都决心智胜对方。一天清晨早餐过后，至爱满怀兴致地观看了这场四足生灵的竞技——也许两名公平竞赛者觉察到了观众是谁，于是表演得格外活跃精彩……
